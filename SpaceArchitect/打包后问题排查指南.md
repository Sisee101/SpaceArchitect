# MoneyManager 打包后问题排查指南

## 🎯 目标
找出为什么打包后完成订单时金钱不增加的根本原因。

---

## 📋 第一步：编辑器测试

### 1. 启用调试日志

在Unity编辑器中：
1. 选择场景中的 MoneyManager 对象
2. 确保 `Enable Debug Log` 已勾选
3. 选择场景中的 TaskManager 对象
4. 确保 TaskManager 的 `Enable Debug Log` 也已勾选

### 2. 运行游戏并查看Console

运行游戏后，应该看到以下日志：

```

✅ MoneyManager: 通过FindObjectOfType找到TaskManager（场景对象: TaskManager）
✅ ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✅ MoneyManager: 已成功订阅TaskManager的任务完成事件
✅   - TaskManager对象: TaskManager
✅   - TaskManager激活状态: True
✅   - TaskManager启用状态: True
✅   - 事件订阅者数量: 1 (或更多)
✅ ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 3. 测试订单完成

完成一个订单后，应该看到：

```

✅ MoneyManager: 收到任务完成事件！TaskId=1
```

### 4. 使用调试方法

在Console中输入（或创建一个测试按钮）：


## 📦 第二步：打包测试

### 1. 打包前检查清单

- [ ] MoneyManager 的 `Enable Debug Log` = true
- [ ] TaskManager 的 `Enable Debug Log` = true
- [ ] 在 Inspector 中**手动指定** TaskManager 引用（最重要！）
- [ ] 在 Inspector 中手动指定 OrderDataConfig 引用
- [ ] 确认 Development Build 已勾选（可以看到日志）

### 2. 打包设置

**Build Settings**：
1. 勾选 `Development Build`
2. 勾选 `Script Debugging`（可选，用于更详细的调试）
3. 勾选 `Wait For Managed Debugger`（可选，用于调试器附加）

**Player Settings**：
1. 检查 `Scripting Backend`：
   - Mono：通常更稳定
   - IL2CPP：性能更好，但可能有兼容性问题
2. 检查 `API Compatibility Level`：
   - .NET Standard 2.1（推荐）
   - .NET 4.x

### 3. 打包并运行

1. Build 游戏
2. 运行可执行文件
3. 完成一个订单
4. 关闭游戏

### 1. 找到日志文件

**Windows**：
```

```

或者：
```
[游戏目录]\[游戏名]_Data\output_log.txt
```

**快速查找方法**：
1. 按 `Win + R`
2. 输入：`%USERPROFILE%\AppData\LocalLow`
3. 找到你的公司名文件夹

### 2. 分析日志

用文本编辑器打开 `Player.log`，搜索以下关键字：

#### 检查点1：MoneyManager 是否启动？
搜索：`MoneyManager: Start()`

❌ **异常情况**：找不到这个日志
- **原因**：MoneyManager 没有启动或被销毁
- **解决**：检查场景中是否有 MoneyManager 对象

## 🔍 第四步：根据日志判断问题

### 情况A：找不到 TaskManager

**症状**：
```
❌ MoneyManager: 【严重错误】未找到TaskManager！
```

**解决方案**：
1. 在 Unity 编辑器中打开场景
2. 选择 MoneyManager 对象
3. 在 Inspector 中找到 "Task Manager" 字段
4. 从场景中拖拽 TaskManager 对象到这个字段
5. 保存场景
6. 重新打包测试

---

### 情况B：找到 TaskManager 但订阅失败

**症状**：
```
✅ MoneyManager: 通过FindObjectOfType找到TaskManager
❌ 没有 "已成功订阅TaskManager的任务完成事件" 日志
```

**可能原因**：
1. 事件订阅代码出现异常
2. TaskManager 的 OnTaskCompleted 事件为 null

**解决方案**：
1. 检查是否有异常日志
2. 确认 TaskManager 脚本正确编译
3. 尝试重新导入脚本

---

### 情况C：订阅成功但收不到事件

**症状**：
```
✅ MoneyManager: 已成功订阅TaskManager的任务完成事件
✅ TaskManager: 任务 1 已完成
❌ 没有 "MoneyManager: 收到任务完成事件" 日志
```

**这是最关键的问题！**

**可能原因**：
1. **IL2CPP 编译问题**：事件委托被优化掉
2. **多个 MoneyManager 实例**：订阅的不是当前实例
3. **事件订阅被意外移除**：在某个地方取消了订阅
4. **MoneyManager 被销毁**：在事件触发前被销毁

**解决方案**：

#### 方案1：确保只有一个 MoneyManager
```csharp
// 在 MoneyManager.Awake() 中添加
Debug.Log($"MoneyManager 实例创建: {GetInstanceID()}");
```

#### 方案2：检查 Scripting Backend
1. Edit → Project Settings → Player
2. Other Settings → Scripting Backend
3. 尝试切换为 **Mono** (而不是 IL2CPP)
4. 重新打包测试

#### 方案3：使用更简单的事件系统
不使用 C# 事件，改用 UnityEvent 或单例模式

---

### 情况D：收到事件但金钱不增加

**症状**：
```
✅ MoneyManager: 收到任务完成事件！TaskId=1
❌ 没有 "任务完成！金钱已增加" 日志
```

**可能原因**：
1. orderDataConfig 为 null
2. 找不到对应的订单信息
3. orderAmount 为 0

**解决方案**：
1. 检查日志中的错误信息
2. 确认 SphereOrderDataConfig 配置正确
3. 确认订单的 taskId 和 orderAmount 配置正确

## 🎯 推荐的修复顺序

### 第1优先级：手动指定引用（最重要！）

**在 Unity 编辑器中**：
1. 选择 MoneyManager 对象
2. 在 Inspector 中手动拖拽：
   - Task Manager → 场景中的 TaskManager
   - Order Data Config → SphereOrderDataConfig 资源
3. 保存场景
4. 重新打包测试

**为什么这样做**：
- 避免运行时查找的不确定性
- 100% 可靠
- 性能更好

---

### 第2优先级：切换 Scripting Backend

如果手动指定引用后问题依旧：

1. Edit → Project Settings → Player
2. Other Settings → Scripting Backend
3. 从 IL2CPP 切换为 **Mono**
4. 重新打包测试

**为什么这样做**：
- IL2CPP 可能对 C# 事件有兼容性问题
- Mono 更稳定，更容易调试

## 🔧 最终解决方案（如果以上都不行）

### 方案：使用静态事件代替实例事件

修改 TaskManager：

```csharp
// 添加静态事件
public static event Action<int> OnTaskCompletedStatic;

public void CompleteTask(int taskId)
{
    // ... 原有代码 ...
    
    // 触发实例事件
    OnTaskCompleted?.Invoke(taskId);
    
    // 同时触发静态事件
    OnTaskCompletedStatic?.Invoke(taskId);
}
```

修改 MoneyManager：

```csharp
void OnEnable()
{
    // 订阅静态事件
    TaskManager.OnTaskCompletedStatic += OnTaskCompleted;
}

void OnDisable()
{
    // 取消订阅
    TaskManager.OnTaskCompletedStatic -= OnTaskCompleted;
}
```

**优点**：
- 静态事件不依赖实例引用
- 更可靠
- 不受初始化顺序影响
