# MoneyManager 打包后问题深度排查

## 🔍 问题现状
- 编辑器中：完成订单可以正常增加金钱 ✅
- 打包后：完成订单金钱不增加 ❌
- 已修复：`Resources.FindObjectsOfTypeAll` → `FindObjectOfType`
- 但问题依旧存在

## 🎯 可能的原因分析

### 原因1：事件订阅时机问题（最可能）

#### 问题描述：
MoneyManager 和 TaskManager 的初始化顺序可能导致事件订阅失败。

```csharp
// MoneyManager.Start()
void Start()
{
    FindMissingReferences();  // 查找TaskManager
    SubscribeToTaskManager(); // 订阅事件
}

// TaskManager.Start()
void Start()
{
    // 初始化任务状态
    // 事件声明：public event Action<int> OnTaskCompleted;
}
```

**问题**：
1. 如果 MoneyManager.Start() 在 TaskManager.Start() **之前**执行
2. 此时 TaskManager 可能还没有完全初始化
3. 事件订阅可能失败或无效

**在打包后更容易出现**：
- 编辑器中：对象初始化顺序相对稳定
- 打包后：初始化顺序可能改变，导致订阅失败

#### 解决方案：
使用 Awake 和延迟订阅

---

### 原因2：FindObjectOfType 的参数问题

#### 问题代码：
```csharp
TaskManager[] allTaskManagers = FindObjectsOfType<TaskManager>(true);
```

**问题**：
`FindObjectsOfType<T>(true)` 的参数 `includeInactive` 在某些Unity版本中可能不支持或行为不同。

#### 解决方案：
- 使用不带参数的版本
- 或使用 `FindObjectOfType<TaskManager>()`

---

### 原因3：MoneyManager 没有正确找到 TaskManager

#### 可能情况：
1. TaskManager 在场景中被禁用
2. TaskManager 在子对象中
3. TaskManager 的脚本执行顺序有问题

#### 检查方法：
查看打包后的日志文件

---

### 原因4：事件订阅被重复移除

#### 问题代码：
```csharp
void SubscribeToTaskManager()
{
    if (taskManager != null)
    {
        // 先取消订阅（防止重复订阅）
        taskManager.OnTaskCompleted -= OnTaskCompleted;
        
        // 重新订阅
        taskManager.OnTaskCompleted += OnTaskCompleted;
    }
}
```

**问题**：
如果 `SubscribeToTaskManager()` 被多次调用，可能导致订阅混乱。

---

### 原因5：IL2CPP 编译问题（打包特有）

#### 问题描述：
使用 IL2CPP 编译时，C# 事件可能出现问题：
- 事件委托被优化掉
- 反射调用失败
- 泛型方法问题

#### 检查方法：
查看打包设置中的 Scripting Backend

---

- Windows: `%USERPROFILE%\AppData\LocalLow\公司名\游戏名\Player.log`
- 或：`游戏名_Data\output_log.txt`
