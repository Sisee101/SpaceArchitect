# 冲击波缩放大小控制说明

## 🎯 控制冲击波大小的参数

### 1. `maxDistance` - 最大扩散距离（控制冲击波大小）

**字段名称**：`maxDistance`

**位置**：在 Unity Inspector 中，选择 `ShockwaveRing` GameObject，查看 `ShockwaveController` 组件

**设置**：
- **类型**：`float`（浮点数）
- **默认值**：`1.5`
- **作用**：控制冲击波从中心扩散的最大距离

**代码位置**：
```csharp
public float maxDistance = 1.5f;
```

**效果**：
- **数值越大**：冲击波扩散得越远，覆盖范围越大
- **数值越小**：冲击波扩散得越近，覆盖范围越小

### 2. `width` - 冲击波宽度

**字段名称**：`width`

**位置**：在 Unity Inspector 中，选择 `ShockwaveRing` GameObject，查看 `ShockwaveController` 组件

**设置**：
- **类型**：`float`（浮点数）
- **范围**：`0` 到 `0.5`（使用 `[Range(0, 0.5f)]` 限制）
- **默认值**：`0.1`
- **作用**：控制冲击波边缘的宽度

**代码位置**：
```csharp
[Range(0, 0.5f)] public float width = 0.1f;
```

**效果**：
- **数值越大**：冲击波边缘越宽，过渡越平滑
- **数值越小**：冲击波边缘越窄，过渡越锐利

## 📊 参数对比

| 参数 | 控制内容 | 默认值 | 范围 | 效果 |
|------|---------|--------|------|------|
| `maxDistance` | 冲击波扩散的最大距离（大小） | 1.5 | 无限制 | 数值越大，冲击波越大 |
| `width` | 冲击波边缘的宽度 | 0.1 | 0 到 0.5 | 数值越大，边缘越宽 |
| `strength` | 冲击波的强度 | 0.05 | -1 到 1 | 数值越大，效果越明显 |

## 🔧 如何调整大小

### 调整冲击波大小（范围）

1. **选择 GameObject**：
   - 在 Hierarchy 中选择 `ShockwaveRing` GameObject

2. **查看 ShockwaveController 组件**：
   - 在 Inspector 中找到 `ShockwaveController` 组件
   - 找到 `Max Distance` 字段（在 `动画设置` 标题下）

3. **调整数值**：
   - 增大数值：冲击波扩散得更远，覆盖范围更大
   - 减小数值：冲击波扩散得更近，覆盖范围更小

### 调整冲击波宽度

1. **找到 `Width` 字段**：
   - 在 `ShockwaveController` 组件中
   - 在 `动画设置` 标题下

2. **调整数值**：
   - 使用滑块调整（范围：0 到 0.5）
   - 或直接输入数值

## 📈 推荐值

### 小范围冲击波
- `maxDistance`: `0.5` 到 `1.0`
- `width`: `0.05` 到 `0.1`

### 中等范围冲击波（默认）
- `maxDistance`: `1.5`
- `width`: `0.1`

### 大范围冲击波
- `maxDistance`: `2.0` 到 `3.0`
- `width`: `0.15` 到 `0.2`

## ⚠️ 注意事项

1. **maxDistance 没有上限**：
   - 可以设置很大的值（如 5.0、10.0）
   - 但过大的值可能导致效果不明显或性能问题

2. **width 的范围限制**：
   - 范围是 `0` 到 `0.5`
   - 超出范围的值会被限制

3. **两个参数的配合**：
   - `maxDistance` 控制冲击波扩散多远
   - `width` 控制冲击波边缘有多宽
   - 两者配合可以创建不同风格的冲击波效果

## 🎯 总结

**控制冲击波缩放/大小的参数是**：
- **`maxDistance`**：控制冲击波扩散的最大距离（大小）
- **`width`**：控制冲击波边缘的宽度

**调整方法**：
1. 选择 `ShockwaveRing` GameObject
2. 在 Inspector 中找到 `ShockwaveController` 组件
3. 调整 `Max Distance` 字段来控制大小
4. 调整 `Width` 字段来控制边缘宽度
