# 检查星星不可见问题

## 🔍 问题分析

用户反馈：
- Scene 视图中可以看到星星
- Game 相机视角看不到星星
- StarSpawner GameObject 是激活状态
- 之前修改冲击波后，星星就看不到了

## 📋 已检查的内容

1. ✅ **相机设置已恢复**：
   - `Requires Opaque Texture`: `Auto` (2)
   - `Orthographic Size`: `5` (已恢复)

2. ✅ **星星 Prefab 设置**：
   - Layer: 0 (Default)
   - 使用 ParticleSystem
   - Render Mode: 0 (Billboard)
   - Material: `star1.mat` (不透明材质)

3. ✅ **相机 Culling Mask**：
   - `m_Bits: 4294967295` (所有层都启用)

4. ⚠️ **场景中未找到 StarSpawner**：
   - 场景文件中没有找到 `GalaxyDistributorXY` 脚本的引用
   - 可能需要在场景中手动添加 StarSpawner GameObject

## 🎯 可能的原因

### 1. 场景中没有 StarSpawner GameObject

**检查方法**：
- 在 Unity 编辑器的 Hierarchy 窗口中查找 `StarSpawner` GameObject
- 如果没有，需要从 Prefab 拖入场景

**解决方法**：
1. 在 Project 窗口中找到 `Assets/Prefeb/levels prefeb/StarSpawner.prefab`
2. 拖入场景的 Hierarchy
3. 确认 GameObject 是激活状态
4. 运行游戏，星星应该会自动生成

### 2. StarSpawner 的 Scale 设置问题

**已修复**：之前所有星星的 `minScale` 和 `maxScale` 都是 0，已修复为：
- Core Planets: `minScale: 2, maxScale: 4`
- Dust Layers: `minScale: 0.2, maxScale: 0.6`

### 3. 粒子系统渲染问题

**可能原因**：
- 粒子系统的 `Max Particles` 设置为 0
- 粒子系统的 `Start Lifetime` 设置为 0
- 粒子系统的 `Start Size` 设置为 0

**检查方法**：
1. 在场景中找到生成的星星 GameObject（StarSpawner 的子对象）
2. 选中其中一个星星
3. 在 Inspector 中查看 `Particle System` 组件
4. 检查：
   - `Max Particles` 是否 > 0
   - `Start Lifetime` 是否 > 0
   - `Start Size` 是否 > 0

### 4. 相机视野范围问题

**已恢复**：`Orthographic Size` 已恢复为 `5`

**如果还是看不到**：
- 检查 StarSpawner 的位置是否在相机视野范围内
- 检查星星生成区域（`areaSize`）是否在相机视野范围内

### 5. 渲染顺序问题

**可能原因**：
- 其他物体遮挡了星星
- 星星的渲染队列设置不正确

**检查方法**：
1. 在 Game 视图中，使用 Scene 视图的 Gizmos 查看星星位置
2. 临时禁用其他可能遮挡的物体（如背景、其他特效）

## ✅ 建议的解决步骤

### 步骤 1：确认场景中有 StarSpawner

1. 在 Unity 编辑器中打开 `SampleScene`
2. 在 Hierarchy 窗口中查找 `StarSpawner` GameObject
3. 如果没有，从 `Assets/Prefeb/levels prefeb/StarSpawner.prefab` 拖入场景

### 步骤 2：检查 StarSpawner 设置

1. 选中 `StarSpawner` GameObject
2. 在 Inspector 中查看 `GalaxyDistributorXY` 组件
3. 确认：
   - Component 是启用状态
   - `areaSize` 设置合理（如 `100, 50`）
   - `corePlanets` 和 `dustLayers` 都有 prefab 引用
   - Scale 设置已修复（不是 0）

### 步骤 3：手动触发生成

1. 如果 StarSpawner 在场景中，但星星没有生成：
   - 在 Inspector 中找到 `GalaxyDistributorXY` 组件
   - 点击 `Generate Galaxy` 按钮（如果有）或重新运行游戏

### 步骤 4：检查生成的星星

1. 运行游戏
2. 在 Hierarchy 中展开 `StarSpawner` GameObject
3. 查看是否有子对象（生成的星星）
4. 选中一个子对象，检查：
   - GameObject 是激活状态
   - `Particle System` 组件是启用状态
   - 粒子系统正在播放

### 步骤 5：检查相机设置

1. 选中 `Main Camera`
2. 在 Inspector 中确认：
   - `Culling Mask` 包含 `Default` 层（应该包含所有层）
   - `Far Clipping Plane` 足够大（当前是 1000）
   - `Orthographic Size` 是 5（已恢复）
