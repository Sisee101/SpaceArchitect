# 关于 ShockwaveRing 遮挡星星问题的说明

## 🔍 问题根源

即使设置了 ZTest 为 Always，星星仍然被遮挡，主要原因是：

1. **Render Queue 过高**：
   - 之前是 3002（在所有透明物体之后）
   - 即使 ZTest 是 Always，Render Queue 仍然控制渲染顺序
   - 如果 Render Queue 太高，冲击波会在所有物体之后渲染，从而覆盖星星

2. **Scene Color Node 的特性**：
   - Scene Color Node 读取屏幕内容并叠加效果
   - 如果冲击波在星星之后渲染，它会覆盖星星

## ✅ 已修改

### 1. ZTest 设置为 Always (8)
- 不进行深度测试，不会因为深度而遮挡

### 2. Render Queue 降低
- 从 3002 降低到 2990
- 这样冲击波会在透明队列中渲染，而不是在所有透明物体之后

## 🎯 如果还是不行

可能需要：

1. **进一步降低 Render Queue**：
   - 尝试 2985、2980 等
   - 但要注意不要影响其他透明物体的渲染

2. **检查星星的 Render Queue**：
   - 确认星星粒子系统的 Render Queue
   - 可能需要调整星星的 Render Queue，确保它在冲击波之后渲染

3. **考虑其他方案**：
   - 如果 Scene Color Node 的限制导致无法解决，可能需要改用其他实现方式
   - 例如：使用 Command Buffer 或 Renderer Feature

## 📋 当前设置

- **ZTest**: Always (8)
- **ZWrite**: Off (0)
- **Render Queue**: 2990
- **Surface Type**: Transparent (1)

## ⚠️ 注意事项

- Render Queue 不能太低，否则可能影响其他透明物体的渲染
- 如果冲击波效果不正常，可能需要调整 Render Queue
- Scene Color Node 需要 Opaque Texture，确保相机设置正确
