# 修复冲击波彩色问题

## 🎨 问题描述

冲击波效果显示为**彩色**，而不是预期的**单色/灰度**效果。

## 🔍 问题原因

冲击波效果应该是**单色**的（通常是白色或灰色），但显示为彩色通常是因为：

1. **冲击波效果没有正确转换为单色**：
   - 冲击波强度（标量）需要转换为 Vector3（RGB）
   - 如果 R, G, B 三个分量不同，就会显示为彩色

2. **Combine 节点连接错误**：
   - 如果 R, G, B 输入连接了不同的值，就会产生颜色
   - 应该将**同一个值**复制到 R, G, B 三个分量

## 🔧 解决方法

### 方法 1：确保 Combine 节点正确连接（推荐）

**正确的连接**：

```
Multiply (标量输出，冲击波强度)
  ↓
Combine 节点
  - R 输入：连接 Multiply 的输出
  - G 输入：连接 Multiply 的输出（**复制同样的值**）
  - B 输入：连接 Multiply 的输出（**复制同样的值**）
  ↓
Combine 的 Out 输出（Vector3 RGB，三个分量相同 = 单色）
  ↓
Add 节点的 B 输入
```

**关键**：R, G, B 三个输入必须连接**同一个值**，这样才会是单色（白色/灰色）。

### 方法 2：检查 Add 节点的连接

**正确的连接**：

```
Sample Texture 2D (RGBA) → Add 节点的 A 输入
Combine (Vector3 RGB) → Add 节点的 B 输入
Add (Out) → Fragment 的 Base Color
```

**注意**：
- `Sample Texture 2D` 输出 RGBA（4个分量）
- `Combine` 输出 Vector3 RGB（3个分量）
- `Add` 节点会自动处理不同维度的相加

### 方法 3：如果还是彩色，检查是否有其他颜色输入

检查 Shader Graph 中是否有：
- 颜色属性节点连接到冲击波效果
- 其他颜色计算影响最终输出

## 📝 详细步骤

### 步骤 1：检查 Combine 节点

1. **打开 Shader Graph**：
   - 打开 `SG_Shockwave_RendererFeature.shadergraph`

2. **找到 Combine 节点**：
   - 用于将冲击波强度（标量）转换为 Vector3

3. **检查连接**：
   - R 输入：应该连接冲击波强度（标量）
   - G 输入：应该连接**同样的**冲击波强度（标量）
   - B 输入：应该连接**同样的**冲击波强度（标量）

4. **如果不同**：
   - 断开 G 和 B 的连接
   - 重新连接到**同一个**冲击波强度输出

### 步骤 2：检查 Add 节点

1. **找到 Add 节点**：
   - 用于混合屏幕内容和冲击波效果

2. **检查连接**：
   - A 输入：`Sample Texture 2D` 的 `RGBA` 输出
   - B 输入：`Combine` 的 `Out` 输出（Vector3 RGB）

3. **确保连接正确**：
   - 不要将颜色属性连接到冲击波效果
   - 不要将不同的值连接到 Combine 的 R, G, B

### 步骤 3：测试

1. **保存 Shader Graph**
2. **运行游戏**
3. **按 B 键触发冲击波**
4. **检查效果**：
   - 应该是单色（白色/灰色）
   - 不应该有彩色

## 🎯 正确的连接流程

```
冲击波强度计算：
  Smoothstep → Multiply (RippleStrength) → 标量输出
    ↓
  Combine 节点
    - R: 标量（复制）
    - G: 标量（复制）
    - B: 标量（复制）
    ↓
  Vector3 RGB（三个分量相同 = 单色）
    ↓
  Add 节点的 B 输入

屏幕内容：
  Sample Texture 2D (RGBA) → Add 节点的 A 输入

最终输出：
  Add (Out) → Fragment 的 Base Color
```

## ⚠️ 常见错误

### 错误 1：R, G, B 连接了不同的值

```
❌ 错误：
Combine
  - R: 连接了冲击波强度
  - G: 连接了其他值（如 CenterPoint.x）
  - B: 连接了其他值（如 CenterPoint.y）

✅ 正确：
Combine
  - R: 连接了冲击波强度
  - G: 连接了**同样的**冲击波强度
  - B: 连接了**同样的**冲击波强度
```

### 错误 2：直接使用 Vector2 或 Vector4

```
❌ 错误：
Screen Position 的 XY → 直接连接到 Add 节点

✅ 正确：
冲击波强度（标量）→ Combine (R, G, B) → Vector3 → Add 节点
```

## 🔍 调试方法

### 方法 1：检查 Combine 节点的输出

1. **在 Shader Graph 中**：
   - 选择 `Combine` 节点
   - 查看预览窗口
   - 应该显示**单色**（白色/灰色）

2. **如果显示彩色**：
   - 检查 R, G, B 输入是否连接了不同的值
   - 确保三个输入连接**同一个值**

### 方法 2：检查最终输出

1. **选择 `Add` 节点**：
   - 查看预览窗口
   - 应该显示混合后的效果

2. **如果显示彩色**：
   - 检查 `Combine` 节点的输出
   - 确保是单色

## 📝 总结

**冲击波显示为彩色的原因**：
- `Combine` 节点的 R, G, B 输入连接了不同的值
- 导致输出是彩色而不是单色

**解决方法**：
- 确保 `Combine` 节点的 R, G, B 输入都连接**同一个**冲击波强度值
- 这样输出就是单色（白色/灰色）

**检查步骤**：
1. 打开 Shader Graph
2. 找到 `Combine` 节点
3. 检查 R, G, B 输入是否连接了同一个值
4. 如果不是，重新连接
