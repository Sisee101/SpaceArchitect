# 恢复原始冲击波效果 - 完整指南

## ✅ 检查清单

按照以下步骤确保所有设置都恢复到原始状态：

### 1. 确认 Material 使用原始 Shader

**检查 `ShockwaveRing.mat`：**

1. 在 Unity 编辑器中打开 `Assets/timestop/ShockwaveRing.mat`
2. 在 Inspector 中检查 **Shader** 字段
3. **应该显示：** `Shader Graphs/SG_Shockwave`（不是 `SG_Shockwave_New`）
4. **如果不对，修改为：** `Shader Graphs/SG_Shockwave`

**Material 的 Shader GUID：**
- 原始：`2ebff1db8d793604ea6db68283728bec` (SG_Shockwave)
- 如果显示其他 GUID，需要切换回原始的

---

### 2. 确认 Material 属性值

**在 Material Inspector 中检查以下属性：**

- `_RippleDistanceFromCenter`: **1.5**（初始值，会由脚本动态修改）
- `_RippleStrength`: **0**（初始值，会由脚本动态修改）
- `_RippleWidth`: **0.025**
- `_CenterPoint`: **(0.5, 0.5, 0, 0)**

**Render Queue：** `2995`（透明队列）

---

### 3. 确认 Prefab 设置

**检查 `ShockwaveRing.prefab`：**

- **Mesh**: `Sphere`（不是 Quad）
- **Position**: `(1.9, 1.3, 3.5)`
- **Scale**: `(121.94, 121.94, 121.94)`
- **Is Active**: `true`
- **MeshCollider**: 存在（可选，不影响效果）

---

### 4. 确认 Shader Graph 文件

**确保使用原始的 `SG_Shockwave.shadergraph`：**

1. 打开 `Assets/timestop/SG_Shockwave.shadergraph`
2. **不要使用** `SG_Shockwave_New.shadergraph`
3. 如果 `SG_Shockwave.shadergraph` 被修改过，需要从版本控制恢复

---

### 5. 确认脚本设置

**检查 `ShockwaveController.cs` 脚本：**

- `shockwaveMaterial`: 应该引用 `ShockwaveRing.mat`
- `shockwaveDuration`: 1
- `maxDistance`: 1.5
- `width`: 0.1
- `strength`: 0.05

---

## 🔧 如果 Material 使用了错误的 Shader

### 方法 1：在 Unity 编辑器中修改

1. 选择 `ShockwaveRing.mat`
2. 在 Inspector 中找到 **Shader** 下拉菜单
3. 选择 `Shader Graphs/SG_Shockwave`
4. 保存

### 方法 2：直接修改 Material 文件

如果 Material 文件中的 shader GUID 不对，需要修改：

**当前（如果错误）：**
```yaml
m_Shader: {fileID: -6465566751694194690, guid: WRONG_GUID, type: 3}
```

**应该改为：**
```yaml
m_Shader: {fileID: -6465566751694194690, guid: 2ebff1db8d793604ea6db68283728bec, type: 3}
```

## 📋 原始 Shader Graph 的关键特性

原始 `SG_Shockwave.shadergraph` 的特点：

1. **使用 `Normalize` 节点**（但不在距离计算路径上）
2. **使用 `Screen Position (Raw)` 模式**（不是 Default）
3. **Render Queue: 2995**（透明队列）
4. **Surface Type: Transparent**
5. **Blending Mode: Alpha**

## ⚠️ 如果还是没有效果

检查以下内容：

1. **主相机的设置：**
   - `Requires Opaque Texture` 可以是 `Auto` 或 `On`（原始版本可能不需要强制 On）

2. **wrapgrid 的设置：**
   - 原始版本可能 wrapgrid 是透明的，不影响效果

3. **场景中的 ShockwaveRing：**
   - 确保 GameObject 是激活的
   - 确保 Material 正确应用

4. **脚本引用：**
   - 确保 `ShockwaveController` 脚本的 `shockwaveMaterial` 字段引用了正确的 Material

---
