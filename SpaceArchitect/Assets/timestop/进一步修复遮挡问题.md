# 进一步修复 ShockwaveRing 遮挡星星问题

## 🔍 问题分析

即使将 ZTest 设置为 Always，星星仍然被遮挡。可能的原因：

1. **Render Queue 过高**：
   - 当前：`m_CustomRenderQueue: 3002`（在透明队列之后）
   - 这会让冲击波在所有透明物体之后渲染，即使 ZTest 是 Always

2. **Scene Color Node 的限制**：
   - Scene Color Node 读取的是不透明纹理（Opaque Texture）
   - 粒子系统（星星）可能不在不透明纹理中
   - 即使冲击波不遮挡，Scene Color Node 也可能读取不到星星

## ✅ 已修改

### 1. 降低 Render Queue

已将 `ShockwaveRing.mat` 的 Render Queue 从 `3002` 降低到 `2995`：
- 这样冲击波会在透明队列中渲染，而不是在所有透明物体之后
- 但仍然在透明队列的较高位置，确保效果正常

### 2. ZTest 已设置为 Always

之前已将 ZTest 设置为 Always (8)，不进行深度测试。

## 🎯 如果还是不行

可能需要检查：

1. **星星的 Render Queue**：
   - 确认星星粒子系统的 Render Queue
   - 可能需要调整星星的 Render Queue，确保它在冲击波之后渲染

2. **Scene Color Node 的限制**：
   - 如果 Scene Color Node 读取不到星星（因为星星是粒子系统），可能需要其他方法
   - 考虑使用不同的屏幕空间效果实现方式

3. **尝试更低的 Render Queue**：
   - 如果 2995 还是太高，可以尝试 2990 或更低
   - 但要注意不要影响其他透明物体的渲染

## 📋 测试步骤

1. 运行游戏
2. 检查星星是否可见
3. 按 E 键触发冲击波
4. 确认冲击波效果正常，且不遮挡星星
