# 使用 Overlay 队列让冲击波不遮挡透明物体

## 🎯 问题

禁用渲染器的方法不行，因为会把所有透明的东西都过滤/遮蔽了，包括玻璃材质或透明底的东西都看不到了。

## ✅ 解决方案

使用 **Overlay 渲染队列（4000+）**，让冲击波渲染在最上层，但不影响深度测试，从而不遮挡透明物体。

### 已修改

1. **移除禁用渲染器的逻辑**：
   - 恢复 `ShockwaveController.cs` 到原始状态
   - 渲染器始终启用，不会过滤透明物体

2. **设置 Render Queue 为 Overlay（4000）**：
   - 将 `ShockwaveRing.mat` 的 Render Queue 设置为 `4000`
   - Overlay 队列会在所有透明物体之后渲染，作为屏幕空间效果叠加

3. **ZTest 已设置为 Always (8)**：
   - 不进行深度测试，不会因为深度而遮挡

## 📋 Overlay 队列的特点

- **Render Queue 4000+**：Overlay 队列，用于 UI 和屏幕空间效果
- **渲染顺序**：在所有透明物体之后渲染
- **不影响深度**：不会遮挡前面的物体
- **适合屏幕空间效果**：如冲击波、全屏特效等

## 🎯 效果

修改后：
- ✅ 冲击波效果正常显示
- ✅ 不会遮挡透明物体（星星、玻璃等）
- ✅ 作为屏幕空间效果叠加在场景上
- ✅ 所有透明物体都可见

## ⚠️ 注意事项

- Overlay 队列会在所有透明物体之后渲染
- 如果效果不正常，可能需要调整 Render Queue 值（如 3995、3990 等）
- Scene Color Node 读取的是不透明纹理，但透明物体仍然可见（因为冲击波不遮挡）

## 🔄 如果效果不正常

如果冲击波效果不正常，可以尝试：
1. 调整 Render Queue 值（如 3995、3990 等）
2. 检查 shader 的混合模式设置
3. 确认 ZTest 设置为 Always
