# 最终调试步骤 - 冲击波只显示右半边

## 🔍 如果所有节点连接都正常

如果所有节点预览都正常，Fragment 的 Alpha 也是 1，连接也没问题，但游戏中只显示右半边，请按以下步骤检查：

## 🎯 检查清单

### 1. 检查 Shader Graph 中的 MainTex 属性

**检查**：
1. **打开 Shader Graph**
2. **查看 Blackboard**（左侧属性面板）
3. **查找 `MainTex` 或 `_MainTex` 属性**：
   - 类型：`Texture2D`
   - 名称：`_MainTex`（带下划线）

4. **检查连接**：
   - `MainTex` 属性应该连接到 `Sample Texture 2D` 的 `Texture` 输入

### 2. 检查 Sample Texture 2D 的 UV 输入

**检查**：
1. **找到 `Sample Texture 2D` 节点**
2. **检查 `UV` 输入**：
   - 应该连接到 `Combine` 节点的输出（Vector2）
   - `Combine` 节点应该组合了 `Split` 的 R (X) 和 G (Y)

3. **检查 `Sample Texture 2D` 的预览**：
   - 应该显示完整的屏幕内容
   - 如果只显示一半，问题在 UV 坐标

### 3. 检查 Renderer Feature 的设置

**检查**：
1. **在 URP Renderer Asset 中**：
   - 确保 `ShockwaveRendererFeature` 已添加
   - 确保 `shockwaveMaterial` 已正确设置

2. **在 Material 的 Inspector 中**：
   - 检查所有属性是否正确设置
   - 特别是 `_CenterPoint` 应该是 `(0.5, 0.5, 0, 0)`

### 4. 检查最终输出

**检查**：
1. **在 Shader Graph 的 Main Preview 窗口**（右下角）
2. **查看最终效果**：
   - 应该显示完整的冲击波效果
   - 如果只显示一半，问题在最终输出

## 🔧 可能的解决方法

### 方法 1：检查 MainTex 属性

如果 `MainTex` 属性不存在或未连接：
1. 在 Blackboard 中创建 `Texture2D` 属性
2. 命名为 `_MainTex`
3. 连接到 `Sample Texture 2D` 的 `Texture` 输入

### 方法 2：检查 UV 坐标提取

确保用于 `Sample Texture 2D` 的 UV 坐标：
1. 使用 `Screen Position (Default)` 模式
2. 使用 `Split` 提取 R (X) 和 G (Y)
3. 使用 `Combine` 组合成 Vector2
4. 连接到 `Sample Texture 2D` 的 `UV` 输入

### 方法 3：检查 Renderer Feature 的 Blit

我已经修改了 Renderer Feature，显式设置 `_MainTex`。请测试一下是否解决了问题。
