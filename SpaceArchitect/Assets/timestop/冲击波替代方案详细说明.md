# 冲击波替代方案详细说明

## 🎯 当前实现的问题

**当前实现**：使用 Scene Color Node 的 Shader Graph，在 GameObject 上渲染
- ❌ Scene Color Node 只能读取不透明纹理（Opaque Texture）
- ❌ 无法读取透明物体（玻璃、星星等）
- ❌ 大 GameObject 可能遮挡透明物体

## 📋 三种替代方案对比

### 方案 1：Renderer Feature（推荐 ⭐⭐⭐⭐⭐）

**效果接近度**：⭐⭐⭐⭐⭐（最接近）

**工作原理**：
- 在 URP 渲染管线的特定阶段插入自定义渲染
- 可以读取完整的屏幕内容（包括透明物体）
- 使用全屏 Quad 渲染，不会遮挡任何物体
- **可以复用现有的 Shader Graph**

**优点**：
- ✅ 效果最接近当前实现
- ✅ 可以复用现有的 `SG_Shockwave.shadergraph`
- ✅ 读取完整的屏幕内容（包括透明物体）
- ✅ 不会遮挡任何物体（全屏后处理）
- ✅ 性能好（在渲染管线中执行）
- ✅ 可以精确控制渲染时机

**缺点**：
- ⚠️ 需要编写 C# 脚本（Renderer Feature）
- ⚠️ 需要修改 URP Renderer 设置

**实现复杂度**：中等（需要编写约 100-200 行代码）

**推荐指数**：⭐⭐⭐⭐⭐（最推荐）

**优点**：

**实现复杂度**：较高（需要创建多个文件，修改 shader）

**推荐指数**：⭐⭐⭐

## 🎯 推荐方案：Renderer Feature

### 为什么选择 Renderer Feature？

1. **效果最接近**：
   - 可以复用现有的 `SG_Shockwave.shadergraph`
   - 只需要修改 Scene Color Node 的读取方式
   - 视觉效果几乎完全一样

2. **完美解决所有问题**：
   - ✅ 读取完整的屏幕内容（包括透明物体）
   - ✅ 不会遮挡任何物体
   - ✅ 冲击波效果正常

3. **实现相对简单**：
   - 只需要创建一个 C# 脚本（Renderer Feature）
   - 修改 URP Renderer 设置（添加 Feature）
   - 可以保留现有的 `ShockwaveController.cs`

### Renderer Feature 实现方案

#### 1. 创建 Renderer Feature 脚本

```csharp
using UnityEngine;
using UnityEngine.Rendering;
using UnityEngine.Rendering.Universal;

public class ShockwaveRendererFeature : ScriptableRendererFeature
{
    class ShockwaveRenderPass : ScriptableRenderPass
    {
        private Material shockwaveMaterial;
        private RenderTextureDescriptor cameraTextureDescriptor;
        
        public ShockwaveRenderPass(Material material)
        {
            shockwaveMaterial = material;
            renderPassEvent = RenderPassEvent.AfterRenderingTransparents; // 在所有透明物体之后渲染
        }
        
        public override void Execute(ScriptableRenderContext context, ref RenderingData renderingData)
        {
            if (shockwaveMaterial == null) return;
            
            // 检查强度，如果为 0 则不渲染
            float strength = shockwaveMaterial.GetFloat("_RippleStrength");
            if (strength <= 0) return;
            
            CommandBuffer cmd = CommandBufferPool.Get("Shockwave Effect");
            
            // 使用全屏 Quad 渲染
            cmd.DrawProcedural(Matrix4x4.identity, shockwaveMaterial, 0, MeshTopology.Triangles, 3);
            
            context.ExecuteCommandBuffer(cmd);
            CommandBufferPool.Release(cmd);
        }
    }
    
    private ShockwaveRenderPass m_ScriptablePass;
    public Material shockwaveMaterial;
    
    public override void Create()
    {
        if (shockwaveMaterial != null)
        {
            m_ScriptablePass = new ShockwaveRenderPass(shockwaveMaterial);
        }
    }
    
    public override void AddRenderPasses(ScriptableRenderer renderer, ref RenderingData renderingData)
    {
        if (m_ScriptablePass != null)
        {
            renderer.EnqueuePass(m_ScriptablePass);
        }
    }
}
```

#### 2. 修改 Shader Graph

- 移除 Scene Color Node（因为 Renderer Feature 可以直接访问屏幕内容）
- 使用 `_BlitTexture` 或 `_AfterTransparentTexture` 读取屏幕内容
- 或者使用 `Blit` 命令直接传递屏幕内容

#### 3. 配置 URP Renderer

- 在 URP Renderer Asset 中添加 ShockwaveRendererFeature
- 设置 Material 引用

### 实现步骤

1. **创建 Renderer Feature 脚本**
2. **修改 Shader Graph**（使用 Blit 或直接读取屏幕内容）
3. **在 URP Renderer 中添加 Feature**
4. **测试效果**
