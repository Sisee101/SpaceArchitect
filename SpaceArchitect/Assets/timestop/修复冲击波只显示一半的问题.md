# 修复冲击波只显示一半的问题

## 🔍 问题分析

**现象**：
- Combine 节点是白色的（单色，正确）✓
- 断开屏幕内容后，冲击波只在**右边**显示
- 左边完全没有效果

**原因**：
这通常是因为**中心点设置**或**Screen Position 使用**有问题。

## 🔧 可能的原因

### 原因 1：Screen Position 模式不匹配

**问题**：
- 冲击波计算使用 `Screen Position (Raw)`
- 但中心点使用的是 `(0.5, 0.5)`（这是 Default 模式的坐标）
- Raw 模式的坐标范围是 0 到屏幕分辨率，不是 0-1

**解决方法**：
- 确保冲击波计算和中心点使用**相同的 Screen Position 模式**

### 原因 2：中心点坐标不正确

**问题**：
- `CenterPoint` 设置为 `(0.5, 0.5)`（屏幕中心）
- 但如果使用 Raw 模式，需要转换为屏幕分辨率坐标

**解决方法**：
- 如果使用 Raw 模式，中心点应该是 `(Screen.width/2, Screen.height/2)`
- 或者统一使用 Default 模式

### 原因 3：距离计算有问题

**问题**：
- 距离计算可能有问题，导致左边距离计算错误

## 🔧 解决方法

### 方法 1：统一使用 Default 模式（推荐）

**步骤**：

1. **检查 Screen Position 节点**：
   - 用于冲击波计算的 `Screen Position` 节点
   - 确保模式是 **Default**（不是 Raw）

2. **检查中心点**：
   - `CenterPoint` 应该是 `(0.5, 0.5)`（屏幕中心，0-1 范围）

3. **检查 Subtract 节点**：
   - 确保 `Subtract` 的 B 输入连接了 `CenterPoint`
   - 而不是 `Vector2 (0.5, 0.5)` 常量

### 方法 2：如果使用 Raw 模式

如果必须使用 Raw 模式：

1. **中心点需要转换**：
   - 不能直接使用 `(0.5, 0.5)`
   - 需要使用屏幕分辨率坐标

2. **或者使用 Screen Position (Default)**：
   - 更简单，坐标范围是 0-1
   - 中心点就是 `(0.5, 0.5)`

## 📝 详细修复步骤

### 步骤 1：检查 Screen Position 节点

1. **找到用于冲击波计算的 Screen Position 节点**：
   - 应该是 `Screen Position (Raw)` 或 `Screen Position (Default)`

2. **检查模式**：
   - 如果是 Raw，改为 **Default**
   - Default 模式的坐标范围是 0-1，更容易使用

### 步骤 2：检查中心点设置

1. **检查 CenterPoint 属性**：
   - 在 Shader Graph 的 Properties 中
   - 应该是 `Vector2` 或 `Vector4`
   - 默认值应该是 `(0.5, 0.5)`

2. **检查 Subtract 节点**：
   - `Subtract` 的 B 输入应该连接 `CenterPoint` 属性
   - 而不是 `Vector2 (0.5, 0.5)` 常量节点

### 步骤 3：检查距离计算

确保距离计算流程正确：

```
Screen Position (Default) → Subtract (CenterPoint) → Length
  → Subtract (RippleDistanceFromCenter) → Absolute
  → Smoothstep
```

**关键点**：
- 使用 `Screen Position (Default)`（坐标范围 0-1）
- `CenterPoint` 是 `(0.5, 0.5)`（屏幕中心）
- `Subtract` 后得到从中心到当前点的向量
- `Length` 计算距离

## 🎯 推荐的连接方式

### 使用 Default 模式（推荐）

```
Screen Position (Default)
  ↓
Subtract (B 输入连接 CenterPoint 属性，默认值 0.5, 0.5)
  ↓
Length
  ↓
Subtract (RippleDistanceFromCenter)
  ↓
Absolute
  ↓
Smoothstep (RippleWidth)
```

### 关键点

1. **Screen Position 使用 Default 模式**：
   - 坐标范围：0-1
   - (0, 0) = 左下角
   - (1, 1) = 右上角
   - (0.5, 0.5) = 中心

2. **CenterPoint 使用属性**：
   - 不要使用常量 `Vector2 (0.5, 0.5)`
   - 使用 `CenterPoint` 属性，可以在代码中动态设置

3. **确保 Subtract 正确**：
   - A 输入：Screen Position (Default)
   - B 输入：CenterPoint 属性

## 🔍 检查清单

- [ ] Screen Position 使用 **Default** 模式（不是 Raw）
- [ ] CenterPoint 属性默认值是 `(0.5, 0.5)`
- [ ] Subtract 的 B 输入连接了 `CenterPoint` 属性（不是常量）
- [ ] 距离计算流程正确：Screen Position → Subtract → Length → Subtract → Absolute → Smoothstep

## 📝 总结

**问题**：冲击波只在右边显示，左边没有

**原因**：可能是 Screen Position 模式不匹配或中心点设置不正确

**解决方法**：
1. 使用 `Screen Position (Default)` 模式
2. 确保 `CenterPoint` 是 `(0.5, 0.5)`
3. 确保 `Subtract` 的 B 输入连接了 `CenterPoint` 属性

修复后，冲击波应该从屏幕中心向四周扩散，左右两边都应该有效果。
