# 修复冲击波只显示右半边的最终检查

## 🔍 如果所有节点预览都正常

如果 Absolute、Smoothstep 等节点的预览都正常，但游戏中只显示右半边，问题可能在：

### 1. 最终输出的连接

**检查**：
1. **Add 节点的输出**：
   - 应该连接到 `Fragment` 的 `Base Color`
   - 检查连接是否正确

2. **Fragment 节点的 Alpha**：
   - 应该设置为 `1`（完全不透明）
   - 或者从 `Sample Texture 2D` 的 `A` 输出连接

### 2. Renderer Feature 的 Blit 方式

**可能的问题**：
- Blit 的方式可能有问题
- 或者源纹理和目标纹理的设置有问题

### 3. 屏幕内容采样的问题

**检查**：
1. **Sample Texture 2D 的 UV**：
   - 应该使用 `Screen Position (Default)` 的 XY
   - 确保 UV 坐标范围是 0-1

2. **MainTex 属性**：
   - 确保正确设置
   - Renderer Feature 会自动传入屏幕内容

## 🔧 可能的解决方法

### 方法 1：检查 Fragment 的 Alpha

1. **找到 Fragment 节点**
2. **检查 Alpha 输入**：
   - 应该设置为 `1`（完全不透明）
   - 或者从 `Sample Texture 2D` 的 `A` 输出连接

3. **如果 Alpha 为 0**：
   - 效果会完全透明，看不到

### 方法 2：检查 Add 节点的连接

1. **找到 Add 节点**
2. **检查输入**：
   - A 输入：`Sample Texture 2D` 的 `RGBA`
   - B 输入：`Combine` 的 `RGBA`（冲击波效果）

3. **检查输出**：
   - 应该连接到 `Fragment` 的 `Base Color`

### 方法 3：检查 Renderer Feature 的 Blit

可能需要在 Renderer Feature 中调整 Blit 的方式。

## 🎯 快速测试

### 测试 1：单独查看冲击波效果

1. **断开屏幕内容**：
   - 断开 `Sample Texture 2D` 到 `Add` 的连接
   - 将 `Combine` 的输出直接连接到 `Fragment` 的 `Base Color`

2. **运行游戏，触发冲击波**：
   - 如果显示完整的冲击波：说明冲击波效果本身是正确的
   - 如果还是只显示一半：说明问题在冲击波计算或输出

### 测试 2：检查 Fragment 的 Alpha

1. **找到 Fragment 节点**
2. **检查 Alpha 输入**：
   - 应该设置为 `1`
   - 如果为 `0`，效果会透明

### 测试 3：检查最终预览

1. **选择 Fragment 节点**
2. **查看 Main Preview**：
   - 应该显示最终效果
   - 如果只显示一半，问题在最终输出

## 📝 检查清单

- [ ] Absolute 节点预览正常（对称的径向渐变）
- [ ] Smoothstep 节点预览正常（完整的白色圆圈）
- [ ] Multiply 节点预览正常
- [ ] Combine 节点预览正常（单色）
- [ ] Add 节点预览正常
- [ ] Fragment 的 Base Color 连接正确
- [ ] Fragment 的 Alpha 设置为 `1`（或从 Sample Texture 2D 的 A 输出）
- [ ] Main Preview 显示正常
