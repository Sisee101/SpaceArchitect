# 解决星星不可见问题

## 🔍 问题确认

经过检查，**场景文件中没有找到 StarSpawner GameObject**。这就是为什么 Game 视图中看不到星星的原因。

## ✅ 解决方案

### 步骤 1：在场景中添加 StarSpawner

1. **在 Unity 编辑器中**：
   - 打开 `SampleScene` 场景
   - 在 Project 窗口中找到 `Assets/Prefeb/levels prefeb/StarSpawner.prefab`
   - **将 StarSpawner.prefab 拖入 Hierarchy 窗口**（或直接拖入 Scene 视图）

2. **确认 StarSpawner 设置**：
   - 选中 Hierarchy 中的 `StarSpawner` GameObject
   - 在 Inspector 中查看 `GalaxyDistributorXY` 组件
   - 确认：
     - Component 是启用状态（✓）
     - `areaSize` 设置合理（如 `100, 50`）
     - `corePlanets` 和 `dustLayers` 都有 prefab 引用
     - Scale 设置已修复（不是 0）

### 步骤 2：运行游戏测试

1. **运行游戏**（点击 Play 按钮）
2. **在 Hierarchy 中展开 `StarSpawner`**：
   - 应该能看到很多子对象（生成的星星）
3. **在 Game 视图中查看**：
   - 应该能看到星星特效

### 步骤 3：如果还是看不到

**检查相机位置和 StarSpawner 位置**：

1. **选中 `Main Camera`**，查看位置：
   - 当前位置：`x: 0, y: 1, z: -10`

2. **选中 `StarSpawner`**，查看位置：
   - 如果 StarSpawner 的位置离相机太远，星星可能不在视野内

3. **调整 StarSpawner 位置**（如果需要）：
   - 将 StarSpawner 的 x, y 坐标调整到接近相机位置
   - 或者调整 `areaSize`，使星星生成区域在相机视野内

## 📋 已修复的设置

1. ✅ **StarSpawner Prefab 的 Scale 设置**：
   - Core Planets: `minScale: 2, maxScale: 4`
   - Dust Layers: `minScale: 0.2, maxScale: 0.6`

2. ✅ **相机设置已恢复**：
   - `Requires Opaque Texture`: `Auto` (2)
   - `Orthographic Size`: `5`

## ⚠️ 注意事项

- **Scene 视图能看到星星**：这是因为 Scene 视图使用的是 Scene 相机，不受 Game 视图相机设置影响
- **Game 视图看不到星星**：这是因为场景中没有 StarSpawner GameObject，或者 StarSpawner 的位置不在相机视野内
