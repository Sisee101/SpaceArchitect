# 修复星星特效不可见问题

## 🔍 问题分析

发现 `StarSpawner.prefab` 中所有星星的 `minScale` 和 `maxScale` 都设置为 **0**，这会导致生成的星星大小为 0，完全不可见。

## 📋 问题位置

在 `Assets/Prefeb/levels prefeb/StarSpawner.prefab` 中：

```yaml
corePlanets:
  - minScale: 0  # ❌ 应该是非零值
    maxScale: 0  # ❌ 应该是非零值
  - minScale: 0
    maxScale: 0
  - minScale: 0
    maxScale: 0
dustLayers:
  - minScale: 0
    maxScale: 0
  - minScale: 0
    maxScale: 0
```

## ✅ 解决方案

### 方法 1：在 Unity 编辑器中修复（推荐）

1. **打开 Unity 编辑器**
2. **找到 `StarSpawner` GameObject**（在 Hierarchy 或场景中）
3. **选中它**，在 Inspector 中查看 `GalaxyDistributorXY` 组件
4. **为每个星星类型设置合适的 Scale 值**：
   - **Core Planets**（核心行星）：
     - `minScale`: `0.5` - `1.0`
     - `maxScale`: `1.5` - `2.5`
   - **Dust Layers**（尘埃层）：
     - `minScale`: `0.1` - `0.3`
     - `maxScale`: `0.3` - `0.6`

### 方法 2：修复 Prefab

1. **打开 `Assets/Prefeb/levels prefeb/StarSpawner.prefab`**
2. **在 Inspector 中修改 `GalaxyDistributorXY` 组件的 Scale 值**
3. **保存 Prefab**

## 🎯 推荐的 Scale 值

根据原始代码逻辑，建议使用以下值：

**Core Planets（核心行星）：**
- `minScale`: `2.0`
- `maxScale`: `4.0`

**Dust Layers（尘埃层）：**
- `minScale`: `0.2`
- `maxScale`: `0.6`

## ⚠️ 其他可能的问题

如果修复 Scale 后仍然看不到星星，检查：

1. **StarSpawner GameObject 是否激活**：
   - 在 Hierarchy 中确认 `StarSpawner` 的复选框是勾选的

2. **相机设置**：
   - 主相机的 `Requires Opaque Texture` 设置为 `On` 不会影响不透明的星星
   - 但如果星星使用透明材质，可能需要调整

3. **渲染距离**：
   - 检查相机的 `Far Clipping Plane` 是否足够大
   - 检查星星是否在相机的视野范围内

4. **Layer 设置**：
   - 确认星星的 Layer 没有被相机的 Culling Mask 排除

## 🔧 快速修复步骤

1. 在 Unity 编辑器中选中 `StarSpawner` GameObject
2. 在 Inspector 中找到 `GalaxyDistributorXY` 组件
3. 展开每个 `Core Planet Setting` 和 `Dust Layer Setting`
4. 将 `minScale` 和 `maxScale` 设置为非零值（参考上面的推荐值）
5. 如果修改的是 Prefab，点击 **Apply** 保存
6. 运行游戏测试

## 📝 注意事项

- 如果场景中有多个 `StarSpawner` 实例，需要分别修复
- 修改 Prefab 会影响所有使用该 Prefab 的场景
- 修改场景中的实例只会影响当前场景
