# 重新检查 Shader Graph 连接

## 🔍 重新分析

你说 Smoothstep 没有与 MainTex 相乘，让我重新检查连接。

## 📋 正确的连接应该是

### 冲击波计算部分

```
Screen Position (Raw) → Subtract (0.5, 0.5) → Length
  → Subtract (RippleDistanceFromCenter) → Absolute
  → Smoothstep (RippleWidth)
  → Multiply (RippleStrength)  ← 只与强度相乘，不与 MainTex 相乘
  → Combine (R, G, B 都连接同一个值)
  → Add (B 输入)
```

### 屏幕内容采样部分

```
Screen Position (Default) → Split → Combine (R, G) → Sample Texture 2D (MainTex)
  → Add (A 输入)
```

## 🎯 如果连接正确，颜色问题的可能原因

### 情况 1：屏幕内容本身是蓝色的

**现象**：
- 右边：灰色（冲击波效果明显，覆盖了屏幕内容）
- 左边：蓝色（屏幕内容本身是蓝色，冲击波强度较小）

**原因**：
- 屏幕内容在左边是蓝色的（比如背景）
- 冲击波强度在左边较小，被屏幕内容覆盖
- Add 节点将两者相加：蓝色 + 灰色 = 蓝色

**解决方法**：
- 增大冲击波强度（`strength` 值）
- 或者检查冲击波强度是否在不同位置不同

### 情况 2：冲击波强度不均匀

**现象**：
- 冲击波强度在不同位置不同
- 导致某些位置显示为屏幕内容颜色

**检查方法**：
1. 查看 `Smoothstep` 节点的预览
2. 应该显示一个白色圆圈（冲击波遮罩）
3. 如果圆圈不均匀，说明计算有问题

### 情况 3：Combine 节点的 R, G, B 输入不同

**检查方法**：
1. 选择底部 `Combine` 节点（用于冲击波效果）
2. 检查 R, G, B 输入
3. 应该都连接了**同一个值**（Multiply 的输出）
4. 如果不同，会导致颜色问题

## 🔧 调试步骤

### 步骤 1：检查 Combine 节点

1. **选择底部 Combine 节点**（冲击波效果）
2. **查看预览**：
   - 应该显示单色（白色/灰色）
   - 如果显示彩色，说明 R, G, B 输入不同

3. **检查输入**：
   - R, G, B 应该都连接了**同一个值**
   - 如果不同，重新连接

### 步骤 2：检查冲击波强度

1. **查看 Smoothstep 节点的预览**：
   - 应该显示一个白色圆圈
   - 圆圈应该是对称的

2. **检查 Multiply 节点**：
   - 确保 B 输入连接了 `RippleStrength`
   - 预览应该显示强度调整后的效果

### 步骤 3：单独查看冲击波效果

1. **临时断开屏幕内容**：
   - 断开 `Sample Texture 2D` 到 `Add` 的连接
   - 将 `Combine` 的输出直接连接到 `Fragment` 的 `Base Color`

2. **运行游戏，触发冲击波**：
   - 如果显示为单色：冲击波效果正确，问题在混合
   - 如果显示为彩色：冲击波效果有问题

## 📝 可能的问题和解决方法

### 问题 1：冲击波强度太小

**现象**：左边显示为蓝色（屏幕内容颜色）

**解决方法**：
- 在 Inspector 中增大 `Strength` 值
- 从 0.05 改为 0.1 或更大

### 问题 2：Combine 节点的 R, G, B 输入不同

**现象**：冲击波本身显示为彩色

**解决方法**：
- 检查 `Combine` 节点的 R, G, B 输入
- 确保都连接了**同一个值**

### 问题 3：屏幕内容影响

**现象**：与屏幕内容混合后显示为不同颜色

**解决方法**：
- 这是正常的，如果屏幕内容本身是蓝色的
- 可以增大冲击波强度，让它更明显

## 🎯 快速检查

1. **选择底部 Combine 节点**，查看预览
   - 应该显示单色（白色/灰色）
   - 如果显示彩色，检查 R, G, B 输入

2. **选择 Add 节点**，查看预览
   - 应该显示混合后的效果
   - 如果左边是蓝色，可能是屏幕内容本身是蓝色

3. **运行游戏，触发冲击波**
   - 观察效果是否正常
   - 如果效果正常，说明连接正确

## 📝 总结

如果 Smoothstep 确实没有与 MainTex 相乘，那么连接可能是正确的。

**颜色问题的可能原因**：
1. 屏幕内容本身是蓝色的，与灰色冲击波混合后显示为蓝色
2. 冲击波强度在左边较小，被屏幕内容覆盖
3. Combine 节点的 R, G, B 输入不同（虽然不太可能）

**解决方法**：
1. 检查 `Combine` 节点的预览，确认是否单色
2. 增大冲击波强度，让它更明显
3. 单独查看冲击波效果，确认是否单色
