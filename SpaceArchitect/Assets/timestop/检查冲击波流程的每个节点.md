# 检查冲击波流程的每个节点

## 🔍 重新分析

既然第二个 Subtract（Length 之后）显示为**中间向四周扩散**，说明：
- ✅ 距离计算部分是正确的
- ✅ Length 节点工作正常
- ✅ 第二个 Subtract 也工作正常

**那么问题可能在后续节点**。

## 📋 按顺序检查每个节点

### 1. Absolute 节点

**检查**：
1. **找到 Absolute 节点**（在第二个 Subtract 之后）
2. **查看预览**：
   - 应该显示**对称的径向渐变**
   - 中心是黑色（距离 0）
   - 边缘是白色（距离最大）
   - **应该是对称的，左右两边都有**

3. **如果只显示一半**：
   - 说明 Absolute 的计算有问题
   - 或者输入有问题

### 2. Smoothstep 节点

**检查**：
1. **找到 Smoothstep 节点**（在 Absolute 之后）
2. **查看预览**：
   - 应该显示一个**完整的白色圆圈**
   - 圆圈应该是对称的，从中心向外
   - **左右两边都应该有**

3. **检查输入**：
   - `In` 输入：Absolute 的输出
   - `Edge1` 输入：应该是 `0` 或较小的值
   - `Edge2` 输入：应该是 `RippleWidth`

4. **如果只显示一半**：
   - 检查 `Edge1` 和 `Edge2` 的值
   - 或者 `In` 输入有问题

### 3. Multiply 节点（与 RippleStrength）

**检查**：
1. **找到 Multiply 节点**（Smoothstep × RippleStrength）
2. **查看预览**：
   - 应该显示强度调整后的效果
   - 如果强度为 0，显示黑色
   - 如果强度大于 0，显示白色/灰色

3. **如果只显示一半**：
   - 检查 `RippleStrength` 的值
   - 或者输入有问题

### 4. Combine 节点

**检查**：
1. **找到 Combine 节点**（将标量转换为 Vector3）
2. **查看预览**：
   - 应该显示单色（白色/灰色）
   - **应该是对称的，左右两边都有**

3. **检查输入**：
   - R, G, B 应该都连接了**同一个值**
   - 如果不同，会导致颜色问题

## 🎯 重点检查节点

### 优先级 1：Absolute 节点

**为什么重要**：
- 如果 Absolute 只显示一半，后续所有节点都会受影响

**检查方法**：
1. 选择 Absolute 节点
2. 查看预览
3. 应该显示**对称的径向渐变**
4. 如果只显示一半，问题在这里

### 优先级 2：Smoothstep 节点

**为什么重要**：
- 如果 Smoothstep 只显示一半，冲击波效果就会只显示一半

**检查方法**：
1. 选择 Smoothstep 节点
2. 查看预览
3. 应该显示**完整的白色圆圈**
4. 如果只显示一半，问题在这里

## 🔧 如果 Absolute 只显示一半

**可能的原因**：
1. 第二个 Subtract 的输出有问题
2. 或者 Absolute 的计算有问题

**解决方法**：
1. 检查第二个 Subtract 的预览
2. 确保显示为中间向四周扩散
3. 如果正常，检查 Absolute 的输入连接

## 🔧 如果 Smoothstep 只显示一半

**可能的原因**：
1. Absolute 的输出有问题
2. `Edge1` 或 `Edge2` 的值不对

**解决方法**：
1. 检查 Absolute 的预览
2. 确保 `Edge1` 是 `0`
3. 确保 `Edge2` 是 `RippleWidth`
