# 修复冲击波颜色不一致问题

## 🎨 问题描述

冲击波效果显示为**不同颜色**：
- 右边：灰色
- 左边：蓝色

## 🔍 问题原因

冲击波应该是**单色**的（白色/灰色），但显示为不同颜色可能是因为：

1. **冲击波效果与屏幕内容混合**：
   - 冲击波效果本身可能是单色的（灰色）
   - 但与屏幕内容（左边可能是蓝色背景）混合后，显示为蓝色

2. **Add 节点的混合方式**：
   - `Add` 节点是**加法混合**
   - 如果屏幕内容是蓝色，加上灰色冲击波，可能显示为蓝色

3. **冲击波强度不均匀**：
   - 如果冲击波强度在不同位置不同，可能导致颜色不一致

## 🔧 解决方法

### 方法 1：检查冲击波效果的计算（推荐）

确保冲击波效果是**单色**的：

1. **检查 Combine 节点**：
   - R, G, B 输入都连接了**同一个值**
   - 输出应该是单色（白色/灰色）

2. **检查 Multiply 节点**：
   - 确保 `Multiply` 的输出是标量（单个数值）
   - 然后复制到 Combine 的 R, G, B

### 方法 2：调整混合方式

如果冲击波效果本身是单色的，但与屏幕内容混合后显示为彩色，可以尝试：

1. **使用 Multiply 混合而不是 Add**：
   - 将 `Add` 节点改为 `Multiply` 节点
   - 或者使用 `Lerp` 节点进行混合

2. **调整冲击波强度**：
   - 如果冲击波强度太小，可能被屏幕内容覆盖
   - 尝试增大 `strength` 值

### 方法 3：检查屏幕内容采样

确保屏幕内容采样正确：

1. **检查 UV 坐标**：
   - `Screen Position` → `Split` → `Combine` → `Sample Texture 2D` (UV)
   - 确保 UV 坐标范围是 0-1

2. **检查 MainTex**：
   - 确保 `MainTex` 属性正确设置
   - Renderer Feature 会自动传入屏幕内容

## 📝 详细步骤

### 步骤 1：检查 Combine 节点

1. **打开 Shader Graph**
2. **找到底部 Combine 节点**（用于冲击波效果）
3. **检查 R, G, B 输入**：
   - 应该都连接了**同一个值**（冲击波强度）
   - 如果不同，重新连接

4. **查看预览**：
   - 应该显示**单色**（白色/灰色）
   - 如果显示彩色，说明 R, G, B 输入不同

### 步骤 2：检查 Add 节点

1. **找到 Add 节点**
2. **检查输入**：
   - A 输入：`Sample Texture 2D` 的 `RGBA`（屏幕内容）
   - B 输入：`Combine` 的 `RGBA`（冲击波效果）

3. **查看预览**：
   - 应该显示混合后的效果
   - 如果左边是蓝色，可能是屏幕内容本身是蓝色

### 步骤 3：测试冲击波效果

1. **单独查看冲击波效果**：
   - 临时断开 `Sample Texture 2D` 到 `Add` 的连接
   - 将 `Combine` 的输出直接连接到 `Fragment` 的 `Base Color`
   - 查看是否显示为单色

2. **如果显示为单色**：
   - 说明冲击波效果本身是正确的
   - 问题在于与屏幕内容的混合

3. **如果还是彩色**：
   - 说明冲击波效果计算有问题
   - 检查 `Combine` 节点的 R, G, B 输入

## 🎯 可能的原因分析

### 情况 1：冲击波效果本身是单色的

**现象**：
- 右边：灰色（冲击波效果明显）
- 左边：蓝色（屏幕内容覆盖了冲击波）

**原因**：
- 冲击波强度在左边较小，被屏幕内容覆盖
- 或者屏幕内容在左边是蓝色

**解决方法**：
- 增大冲击波强度（`strength` 值）
- 或者调整混合方式

### 情况 2：冲击波效果计算有问题

**现象**：
- 冲击波本身显示为不同颜色

**原因**：
- `Combine` 节点的 R, G, B 输入不同
- 或者冲击波强度计算有问题

**解决方法**：
- 检查 `Combine` 节点的 R, G, B 输入
- 确保都连接了同一个值

## 🔍 调试方法

### 方法 1：单独查看冲击波效果

1. **临时断开屏幕内容**：
   - 断开 `Sample Texture 2D` 到 `Add` 的连接
   - 将 `Combine` 的输出直接连接到 `Fragment` 的 `Base Color`

2. **运行游戏，触发冲击波**：
   - 如果显示为单色：冲击波效果正确，问题在混合
   - 如果显示为彩色：冲击波效果有问题

### 方法 2：检查 Combine 节点的预览

1. **选择底部 Combine 节点**
2. **查看预览窗口**：
   - 应该显示单色（白色/灰色）
   - 如果显示彩色，说明 R, G, B 输入不同

## 📝 总结

**可能的原因**：
1. 冲击波效果本身是单色的，但与屏幕内容混合后显示为彩色
2. 冲击波效果计算有问题，导致不同位置显示不同颜色

**解决方法**：
1. 检查 `Combine` 节点的 R, G, B 输入是否都连接了同一个值
2. 单独查看冲击波效果，确认是否单色
3. 如果冲击波本身是单色的，调整混合方式或增大强度

**快速检查**：
- 选择底部 `Combine` 节点，查看预览
- 应该显示单色（白色/灰色）
- 如果显示彩色，检查 R, G, B 输入
