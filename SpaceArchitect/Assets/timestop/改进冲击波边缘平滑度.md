# 改进冲击波边缘平滑度 - 从原始 Shader Graph 学习

## 🔍 发现的关键差异

对比原始的 `SG_Shockwave.shadergraph` 和新的 `SG_Shockwave_New.shadergraph`，发现了以下**关键差异**，这些差异让原始版本的边缘更平滑：

### 1. **Normalize 节点** ⭐ 关键差异

**原始版本使用了 `Normalize` 节点**，而新版本没有使用。

**Normalize 的作用：**
- 将向量归一化（标准化），使其长度为 1
- 这样可以确保距离计算更加均匀，不受屏幕宽高比影响
- **让冲击波边缘在不同方向上更加平滑和一致**

**使用位置：**
- 在 `Screen Position - CenterPoint` 之后，`Length` 之前
- 流程：`Screen Position` → `Subtract (CenterPoint)` → **`Normalize`** → `Length`

---

### 2. **Smoothstep 的 Edge 参数计算方式**

**原始版本可能使用了不同的 Edge1 和 Edge2 计算方式：**

**新版本（当前）：**
- `Edge1` = `RippleWidth`
- `Edge2` = `RippleWidth + 0.01`

**原始版本（更平滑）：**
- 可能使用了基于 `RippleDistanceFromCenter` 的相对计算
- 或者使用了更宽的过渡区间（Edge2 - Edge1 的值更大）

---

## ✅ 改进方案

### 方案 1：添加 Normalize 节点（推荐）

**步骤：**

1. **在 `Subtract` 节点之后添加 `Normalize` 节点**
   - 位置：`Screen Position` → `Subtract (CenterPoint)` → **`Normalize`** → `Length`
   - 作用：归一化方向向量，让距离计算更均匀

2. **连接方式：**
   ```
   Screen Position (Default)
   └─> Subtract (A)
       └─> CenterPoint (B)
           └─> Subtract (Out) → Normalize (In) → Normalize (Out) → Length (In)
   ```

3. **为什么有效：**
   - 归一化后，距离计算不受屏幕宽高比影响
   - 冲击波在所有方向上都是完美的圆形
   - 边缘过渡更加平滑自然

---

### 方案 2：增加 Smoothstep 的过渡区间

**如果添加 Normalize 后边缘仍然较硬，可以增加过渡区间：**

**当前设置：**
- `Edge1` = `RippleWidth`
- `Edge2` = `RippleWidth + 0.01`（过渡区间 = 0.01，很小）

**改进设置：**
- `Edge1` = `RippleDistanceFromCenter - RippleWidth`
- `Edge2` = `RippleDistanceFromCenter + RippleWidth`
- 或者：`Edge1` = `RippleWidth * 0.8`，`Edge2` = `RippleWidth * 1.2`

**这样做的效果：**
- 更大的过渡区间 = 更平滑的边缘
- 但可能会让冲击波看起来更"模糊"

---

### 方案 3：使用更平滑的曲线函数

**除了 Smoothstep，还可以尝试：**

1. **使用 `Smoothstep` 两次（双重平滑）：**
   - `Smoothstep(Smoothstep(...))` - 更平滑的曲线

2. **使用 `Power` 节点调整曲线：**
   - `Power(Smoothstep(...), 0.5)` - 更柔和的过渡

---

## 🔧 具体实施步骤（推荐：方案 1）

### 步骤 1：添加 Normalize 节点

1. 在 Shader Graph 中，找到 `Subtract` 节点（计算 `Screen Position - CenterPoint`）
2. 在 `Subtract` 和 `Length` 之间添加 **Normalize** 节点
3. 连接：
   - `Subtract` 的 `Out` → `Normalize` 的 `In`
   - `Normalize` 的 `Out` → `Length` 的 `In`

### 步骤 2：调整 Smoothstep 的 Edge 参数（可选）

如果添加 Normalize 后边缘仍然较硬：

1. 修改 `Edge1` 和 `Edge2` 的计算：
   - `Edge1` = `RippleDistanceFromCenter - RippleWidth * 0.5`
   - `Edge2` = `RippleDistanceFromCenter + RippleWidth * 0.5`
   - 或者使用更大的偏移值（如 0.05 而不是 0.01）

### 步骤 3：测试效果

1. 保存 Shader Graph
2. 运行游戏，按 E 键测试
3. 观察冲击波边缘是否更平滑

## 📊 对比总结

| 特性 | 原始版本 | 新版本 | 改进后 |
|------|---------|--------|--------|
| **Normalize 节点** | ✅ 有 | ❌ 无 | ✅ 有 |
| **边缘平滑度** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ |
| **方向一致性** | ✅ 完美圆形 | ⚠️ 可能受宽高比影响 | ✅ 完美圆形 |
| **过渡区间** | 可能更大 | 0.01（很小） | 可调整 |

---

## 🎯 最终建议

**优先添加 `Normalize` 节点**，这是让边缘更平滑的关键。如果还不够，再调整 Smoothstep 的过渡区间。

**完整的改进流程：**
```
Screen Position (Default)
└─> Subtract (CenterPoint) → Normalize → Length → Subtract (RippleDistanceFromCenter) → Absolute
    └─> Smoothstep (Edge1: RippleWidth, Edge2: RippleWidth + 0.02) → Multiply (RippleStrength) → Combine → Add (Scene Color)
```

**关键改进点：**
1. ✅ 添加 `Normalize` 节点
2. ✅ 增加 Smoothstep 的过渡区间（0.01 → 0.02 或更大）
3. ✅ 确保所有连接正确
