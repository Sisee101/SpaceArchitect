# 修复冲击波只显示右半边的问题

## 🔍 问题分析

**现象**：
- Screen Position 使用 Default 模式 ✓
- Combine 节点是白色的（单色，正确）✓
- 但冲击波只在**右边**显示，左边完全没有

**可能的原因**：

### 原因 1：Screen Position 的 XY 提取有问题

**问题**：
- `Screen Position (Default)` 输出是 Vector4
- 需要正确提取 XY 分量用于距离计算
- 如果提取方式不对，可能导致坐标错误

**检查**：
- 确保使用 `Split` 节点提取 R (X) 和 G (Y)
- 或者直接使用 Screen Position 的 XY 输出（如果节点支持）

### 原因 2：CenterPoint 的 X 坐标不对

**问题**：
- `CenterPoint` 应该是 `(0.5, 0.5)`
- 但如果 X 坐标不对，中心点会偏移

**检查**：
- 在 Material 的 Inspector 中检查 `_CenterPoint` 的值
- 应该是 `(0.5, 0.5, 0, 0)`

### 原因 3：Subtract 节点的输入顺序不对

**问题**：
- `Subtract` 节点：A - B
- 如果顺序不对，可能导致距离计算错误

**检查**：
- A 输入：Screen Position (XY)
- B 输入：CenterPoint (XY)
- 结果：从中心点到当前点的向量

### 原因 4：Screen Position 的坐标系统问题

**问题**：
- Default 模式的坐标系统可能有问题
- 或者需要翻转 Y 坐标

## 🔧 解决方法

### 方法 1：检查 Screen Position 的 XY 提取

1. **找到用于距离计算的 Screen Position 节点**
2. **检查如何提取 XY**：
   - 如果使用 `Split` 节点：
     - `Split` 的 R 输出 = X 坐标
     - `Split` 的 G 输出 = Y 坐标
   - 如果节点直接有 XY 输出，使用 XY 输出

3. **确保 XY 都正确提取**：
   - 不要只提取 X 或只提取 Y
   - 需要同时提取 X 和 Y

### 方法 2：检查 Subtract 节点的连接

1. **找到 Subtract 节点**（用于计算从中心到当前点的向量）
2. **检查输入**：
   - A 输入：Screen Position 的 XY（当前点坐标）
   - B 输入：CenterPoint 的 XY（中心点坐标）
3. **检查顺序**：
   - 应该是：`Screen Position - CenterPoint`
   - 结果：从中心点到当前点的向量

### 方法 3：检查 CenterPoint 的值

1. **在 Material 的 Inspector 中**：
   - 找到 `_CenterPoint` 属性
   - 检查值是否为 `(0.5, 0.5, 0, 0)`

2. **在代码中**：
   - `ShockwaveController.cs` 中设置的是 `(0.5f, 0.5f, 0, 0)`
   - 这是正确的

### 方法 4：检查距离计算的完整流程

确保流程正确：

```
Screen Position (Default)
  ↓
Split (提取 R=X, G=Y)
  ↓
Combine (R, G) → Vector2 (XY 坐标)
  ↓
Subtract (A: XY 坐标, B: CenterPoint XY)
  ↓
Length (计算距离)
  ↓
Subtract (RippleDistanceFromCenter)
  ↓
Absolute
  ↓
Smoothstep (RippleWidth)
```
