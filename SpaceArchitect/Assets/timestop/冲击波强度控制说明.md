# 冲击波强度控制说明

## 🎯 控制冲击波强度的数值

### 在 ShockwaveController 组件中

**字段名称**：`strength`

**位置**：在 Unity Inspector 中，选择 `ShockwaveRing` GameObject，查看 `ShockwaveController` 组件

**设置**：
- **类型**：`float`（浮点数）
- **范围**：`-0.2` 到 `0.2`（使用 `[Range(-0.2f, 0.2f)]` 限制）
- **默认值**：`0.05`

**代码位置**：
```csharp
[Range(-0.2f, 0.2f)] public float strength = 0.05f;
```

## 📊 强度值的作用

### 1. 初始强度

- `strength` 是冲击波效果的**最大强度**
- 当冲击波触发时，强度从 `strength` 值开始
- 然后逐渐减少到 0

### 2. 动画过程

```csharp
float currentStrength = Mathf.Lerp(strength, 0f, progress);
```

- **开始**：强度 = `strength`（你设置的值）
- **结束**：强度 = `0`
- **过程**：线性插值（Lerp）从 `strength` 到 `0`

### 3. 传递给 Shader

```csharp
shockwaveMaterial.SetFloat("_RippleStrength", currentStrength);
```

- `strength` 值会传递给 shader 的 `_RippleStrength` 属性
- Shader 使用这个值来控制冲击波效果的强度

## 🔧 如何调整强度

### 方法 1：在 Inspector 中调整（推荐）

1. **选择 GameObject**：
   - 在 Hierarchy 中选择 `ShockwaveRing` GameObject

2. **查看 ShockwaveController 组件**：
   - 在 Inspector 中找到 `ShockwaveController` 组件
   - 找到 `Strength` 字段（在 `动画设置` 标题下）

3. **调整数值**：
   - 使用滑块调整（范围：-0.2 到 0.2）
   - 或直接输入数值

### 方法 2：在代码中调整

```csharp
ShockwaveController controller = GetComponent<ShockwaveController>();
controller.strength = 0.1f; // 设置为 0.1
```

## 📈 强度值的效果

### 正值（0 到 0.2）

- **效果**：冲击波向外推（膨胀效果）
- **数值越大**：效果越明显
- **推荐值**：`0.05` 到 `0.1`

### 负值（-0.2 到 0）

- **效果**：冲击波向内拉（收缩效果）
- **数值越小**：效果越明显
- **推荐值**：`-0.05` 到 `-0.1`

### 零值（0）

- **效果**：无效果（不显示冲击波）

## ⚠️ 注意事项

1. **范围限制**：
   - 范围是 `-0.2` 到 `0.2`
   - 超出范围的值会被限制

2. **实时调整**：
   - 可以在运行时调整 `strength` 值
   - 但只有在触发新的冲击波时才会生效

3. **Material 属性**：
   - `strength` 值会传递给 Material 的 `_RippleStrength` 属性
   - 确保 Material 使用正确的 shader（`SG_Shockwave_RendererFeature`）

## 🎯 快速参考

| 字段 | 类型 | 范围 | 默认值 | 说明 |
|------|------|------|--------|------|
| `strength` | float | -0.2 到 0.2 | 0.05 | 冲击波最大强度 |
| `_RippleStrength` | shader 属性 | 动态 | 0 | Shader 中的强度属性 |

## 📝 总结

**控制冲击波强度的数值是**：
- **字段名**：`strength`
- **位置**：`ShockwaveController` 组件的 Inspector
- **范围**：`-0.2` 到 `0.2`
- **默认值**：`0.05`

**调整方法**：
1. 选择 `ShockwaveRing` GameObject
2. 在 Inspector 中找到 `ShockwaveController` 组件
3. 调整 `Strength` 字段的值
