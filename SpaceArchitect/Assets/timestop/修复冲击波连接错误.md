# 修复冲击波 Shader Graph 连接错误

## 🔴 发现的错误连接

根据你的 Shader Graph，发现了以下**关键错误**：

### 错误 1：Smoothstep 的 Edge1 和 Edge2 连接错误 ❌

**当前错误连接：**
- `Edge1` 连接到了 `Add` 节点（Screen Position + 常量值）
- `Edge2` 连接到了 `CenterPoint` 属性节点

**正确连接应该是：**
- `Edge1` = `RippleWidth` 属性节点
- `Edge2` = `RippleWidth + 0.01`（使用 Add 节点）

**修复步骤：**
1. **断开** Smoothstep 的 `Edge1` 和 `Edge2` 的所有连接
2. 添加 **Property: RippleWidth** 节点（如果还没有）
3. 添加 **Add** 节点
   - `A`: **RippleWidth** 属性节点
   - `B`: 常量值 `0.01`（使用 **Vector1** 节点或直接输入）
4. 连接：
   - `RippleWidth` → `Smoothstep` 的 `Edge1`
   - `Add` 的输出 → `Smoothstep` 的 `Edge2`
5. **删除**顶部的那个错误的 `Add` 节点（连接 Screen Position 和常量值的那个）

---

### 错误 2：Multiply 的 B 输入连接错误 ❌

**当前错误连接：**
- `B` 输入连接到了 `CenterPoint` 属性节点

**正确连接应该是：**
- `B` 输入连接到 `RippleStrength` 属性节点

**修复步骤：**
1. **断开** Multiply 的 `B` 输入与 `CenterPoint` 的连接
2. 添加 **Property: RippleStrength** 节点（如果还没有）
3. 连接：`RippleStrength` → `Multiply` 的 `B` 输入

---

### 错误 3：Combine 节点连接不完整 ❌

**当前错误连接：**
- 只有 `A` 输入连接了
- `R`、`G`、`B` 输入都没有连接

**正确连接应该是：**
- `R`、`G`、`B` 三个输入都连接到 `Multiply` 的输出

**修复步骤：**
1. **断开** Combine 的 `A` 输入连接（如果连接了错误的东西）
2. 将 **Multiply** 的输出连接到 **Combine** 的 `R` 输入
3. 将 **Multiply** 的输出**再次连接**到 `G` 输入（Unity 允许同一个输出连接多个输入）
4. 将 **Multiply** 的输出**再次连接**到 `B` 输入
5. **或者**：只连接 `R` 输入，Unity 会自动将同一个值复制到 `G` 和 `B`（取决于你的 Unity 版本）

---

## ✅ 正确的完整连接流程

```
1. Screen Position (Default)
   └─> Scene Color (UV) → Scene Color (Out)
   └─> Subtract (A)
       └─> CenterPoint (B)
           └─> Subtract (Out) → Length (In) → Length (Out)
               └─> Subtract (A)
                   └─> RippleDistanceFromCenter (B)
                       └─> Subtract (Out) → Absolute (In) → Absolute (Out)
                           └─> Smoothstep (In)
                               ├─> Edge1: RippleWidth
                               └─> Edge2: RippleWidth + 0.01 (Add 节点)
                                   └─> Smoothstep (Out) → Multiply (A)
                                       └─> RippleStrength (B)
                                           └─> Multiply (Out) → Combine (R, G, B)
                                               └─> Combine (Out) → Add (B)
                                                   └─> Scene Color (Out) → Add (A)
                                                       └─> Add (Out) → Fragment (Base Color)
```

---

## 🔧 快速修复清单

按顺序检查并修复：

- [ ] **删除**顶部的错误 `Add` 节点（Screen Position + 常量值）
- [ ] **断开** Smoothstep 的 `Edge1` 和 `Edge2` 的错误连接
- [ ] **连接** `RippleWidth` → Smoothstep 的 `Edge1`
- [ ] **创建** `RippleWidth + 0.01` 的 Add 节点 → Smoothstep 的 `Edge2`
- [ ] **断开** Multiply 的 `B` 输入与 `CenterPoint` 的连接
- [ ] **连接** `RippleStrength` → Multiply 的 `B` 输入
- [ ] **断开** Combine 的 `A` 输入（如果连接了错误的东西）
- [ ] **连接** Multiply 的输出 → Combine 的 `R`、`G`、`B` 输入
- [ ] **确认** 最终的 Add 节点：`A` = Scene Color，`B` = Combine 输出

---

## 🧪 测试步骤

修复后：

1. **保存** Shader Graph
2. **检查** Material 的 Inspector：
   - `_RippleStrength` 应该为 0（初始状态）
   - `_RippleDistanceFromCenter` 应该为 0
   - `_RippleWidth` 应该为 0.1
   - `_CenterPoint` 应该为 (0.5, 0.5)
3. **运行游戏**，按 **E** 键
4. **观察**：应该能看到冲击波效果（背景变亮）

---

## ⚠️ 如果还是没有效果

检查以下内容：

1. **Material 是否正确应用**到 ShockwaveRing GameObject
2. **ShockwaveController 脚本**是否正确设置了 Material 引用
3. **主相机的 `Requires Opaque Texture`** 是否为 `On`
4. **wrapgrid 的 Render Queue** 是否为 `Geometry`（不透明）
5. **Shader Graph 的 Surface Type** 是否为 `Transparent`
6. **Fragment 的 Alpha** 是否设置为 1
