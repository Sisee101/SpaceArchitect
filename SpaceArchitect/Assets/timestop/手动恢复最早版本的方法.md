# 手动恢复最早的 Shader Graph 版本

## 🎯 快速方法

由于路径问题，建议你**手动执行以下步骤**：

### 方法 1：在项目根目录使用 Git Bash

1. **打开 Git Bash**（不是 PowerShell）
2. **导航到项目目录**：
   ```bash
   cd "/d/游戏/empty/SpaceArchitect/SpaceArchitect"
   ```
   或者使用短路径（如果有）

3. **查找最早的提交**：
   ```bash
   git log --oneline --all --reverse -- "Assets/timestop/SG_Shockwave.shadergraph"
   ```

4. **查看最早版本的内容**：
   ```bash
   git show <最早提交hash>:Assets/timestop/SG_Shockwave.shadergraph
   ```

5. **恢复到最早版本**（创建新文件，不覆盖）：
   ```bash
   git show <最早提交hash>:Assets/timestop/SG_Shockwave.shadergraph > Assets/timestop/SG_Shockwave_Original.shadergraph
   ```

---

### 方法 2：在 Unity 编辑器中

1. **打开 Unity 编辑器**
2. **在 Project 窗口中找到** `Assets/timestop/SG_Shockwave.shadergraph`
3. **右键点击** → 如果有版本控制选项，选择查看历史
4. **恢复到更早的版本**

---

### 方法 3：检查 Material 文件的历史

**Material 文件可能包含更早的 shader 引用：**

1. 在 Git Bash 中执行：
   ```bash
   git log --oneline --all --reverse -- "Assets/timestop/ShockwaveRing.mat"
   ```

2. 查看最早版本的 Material：
   ```bash
   git show <最早提交hash>:Assets/timestop/ShockwaveRing.mat
   ```

3. **查找 `m_Shader` 字段**，看看它引用的 shader GUID 是什么

4. **如果 GUID 不同**，说明有更早的 shader graph 版本
