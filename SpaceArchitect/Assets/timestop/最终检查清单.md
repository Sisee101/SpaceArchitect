# 最终检查清单 - 冲击波只显示右半边

## 🔍 如果所有节点预览都正常

如果 Absolute、Smoothstep 等节点的预览都正常，但游戏中只显示右半边，请检查：

### 1. Fragment 的 Alpha 设置（最重要！）

**检查**：
1. **找到 Fragment 节点**
2. **检查 Alpha 输入**：
   - 应该设置为 `1`（完全不透明）
   - 或者从 `Sample Texture 2D` 的 `A` 输出连接
   - **不要留空或设置为 0**

3. **如果 Alpha 为 0 或未设置**：
   - 效果会完全透明，看不到
   - 或者只显示一部分

### 2. 检查 Main Preview

**检查**：
1. **在 Shader Graph 的 Main Preview 窗口**（右下角）
2. **查看最终效果**：
   - 应该显示完整的冲击波效果
   - 如果只显示一半，问题在最终输出

### 3. 检查 Add 节点的连接

**检查**：
1. **Add 节点的输入**：
   - A 输入：`Sample Texture 2D` 的 `RGBA`
   - B 输入：`Combine` 的 `RGBA`（冲击波效果）

2. **Add 节点的输出**：
   - 应该连接到 `Fragment` 的 `Base Color`

3. **Add 节点的预览**：
   - 应该显示混合后的效果
   - 如果只显示一半，检查输入

### 4. 检查 Renderer Feature 的 Material

**检查**：
1. **在 Renderer Feature 中**：
   - 确保 Material 正确设置
   - 确保 Material 使用正确的 Shader Graph

2. **在 Material 的 Inspector 中**：
   - 检查所有属性是否正确设置
   - 特别是 `_CenterPoint` 应该是 `(0.5, 0.5, 0, 0)`

## 🎯 最可能的问题

### 问题 1：Fragment 的 Alpha 未设置

**现象**：效果只显示一部分

**解决方法**：
1. 找到 `Fragment` 节点
2. 将 `Alpha` 输入设置为 `1`
3. 或者从 `Sample Texture 2D` 的 `A` 输出连接

### 问题 2：Main Preview 只显示一半

**现象**：Shader Graph 的预览就只显示一半

**解决方法**：
- 检查最终输出的连接
- 检查 Fragment 的 Alpha 设置

## 🔧 快速测试

### 测试 1：检查 Fragment 的 Alpha

1. **找到 Fragment 节点**
2. **检查 Alpha 输入**：
   - 如果未连接，设置为 `1`
   - 或者从 `Sample Texture 2D` 的 `A` 输出连接

3. **保存并测试**：
   - 运行游戏
   - 按 B 键触发冲击波
   - 查看效果是否正常

### 测试 2：检查 Main Preview

1. **在 Shader Graph 的 Main Preview 窗口**（右下角）
2. **查看最终效果**：
   - 应该显示完整的冲击波效果
   - 如果只显示一半，问题在 Shader Graph

### 测试 3：单独查看冲击波效果

1. **临时断开屏幕内容**：
   - 断开 `Sample Texture 2D` 到 `Add` 的连接
   - 将 `Combine` 的输出直接连接到 `Fragment` 的 `Base Color`
   - 将 `Fragment` 的 `Alpha` 设置为 `1`

2. **运行游戏，触发冲击波**：
   - 如果显示完整的冲击波：说明冲击波效果本身是正确的
   - 如果还是只显示一半：说明问题在冲击波计算或输出

- [ ] Main Preview 显示正常（完整的冲击波效果）
