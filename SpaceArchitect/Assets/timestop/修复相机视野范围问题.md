# 修复相机视野范围问题

## 🔍 问题分析

用户反馈：在 Scene 视图中旋转和放大画面，有些角度可以看到星星，说明星星确实存在，但 Game 视图看不到。

**问题原因**：
- **相机位置**：`x: 0, y: 1, z: -10`
- **相机旋转**：无旋转，朝向 +Z 方向
- **正交大小**：`5`（视野范围只有 10 单位宽，从 -5 到 +5）
- **StarSpawner 位置**：`x: -35.9, y: 2.87, z: 16.3`
- **星星生成区域**：`200x100` 单位（以 StarSpawner 位置为中心）

**问题**：
- 相机的正交大小只有 5，意味着 X 和 Y 方向只能看到从 -5 到 +5 的范围
- StarSpawner 在 `x: -35.9`，远在 -5 到 +5 范围外
- 星星生成区域是 `200x100`，大部分星星都在相机视野范围外

## ✅ 解决方案

### 已修复：增大相机的 Orthographic Size

已将相机的 `Orthographic Size` 从 `5` 调整为 `50`，这样：
- 视野范围从 10 单位增加到 100 单位（从 -50 到 +50）
- 可以覆盖星星生成区域的大部分范围

### 如果还需要调整

**选项 1：进一步增大 Orthographic Size**
- 如果 50 还不够，可以增大到 100 或更大
- 但要注意：视野越大，物体看起来越小

**选项 2：调整相机位置**
- 将相机移动到更接近星星生成区域的位置
- 例如：`x: -35.9, y: 2.87, z: -10`（与 StarSpawner 的 x, y 对齐）

**选项 3：调整 StarSpawner 位置**
- 将 StarSpawner 移动到相机视野范围内
- 例如：`x: 0, y: 1, z: 16.3`（与相机的 x, y 对齐）

## 📋 相机设置说明

**正交相机（Orthographic Camera）**：
- `Orthographic Size`：控制视野大小
  - 值越大，视野越大，但物体看起来越小
  - 值越小，视野越小，但物体看起来越大
- 对于正交相机，没有"焦距"概念，只有视野大小

**当前设置**：
- `Orthographic Size: 50`（已调整）
- 视野范围：约 100 单位宽（从 -50 到 +50）

## 🎯 测试步骤

1. **运行游戏**
2. **在 Game 视图中查看**：
   - 应该能看到星星特效
3. **如果还是看不到**：
   - 检查 StarSpawner 是否在场景中
   - 检查星星是否已生成（在 Hierarchy 中展开 StarSpawner）
   - 可以尝试进一步增大 Orthographic Size
