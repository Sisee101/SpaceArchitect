# 主界面任务完成动画系统分析

本文档分析如何在01_MainHub场景中实现任务完成功能，包括气泡消失动画和胜利结算视频播放。

---

## 📋 功能需求

1. **任务完成检测**：键盘输入1（临时测试，后续可替换为真实任务完成逻辑）
2. **气泡消失动画**：对应任务的气泡播放消失动画
3. **胜利结算动画**：屏幕中间播放胜利结算视频

---

## 🎯 系统架构分析

### 核心组件

1. **TaskManager（任务管理器）**
   - 管理任务状态
   - 检测任务完成（键盘输入1）
   - 触发任务完成事件

2. **BubbleAnimationController（气泡动画控制器）**
   - 管理气泡消失动画
   - 与SphereIconManager集成
   - 处理动画播放和完成回调

3. **VictoryVideoPlayer（胜利视频播放器）**
   - 管理胜利结算视频播放
   - 控制视频播放时机和完成回调

4. **TaskBubbleMapping（任务-气泡映射）**
   - 建立任务ID与Sphere的映射关系
   - 配置数据结构（ScriptableObject）

#### 1.3 扩展SphereIconManager

**新增方法**：
- `HideIconWithAnimation(GameObject sphere, Action onComplete = null)`：播放消失动画后隐藏图标
- `HideIconForSphere(string sphereName, Action onComplete = null)`：根据Sphere名称隐藏图标

**动画实现**（使用协程）：
```csharp
private IEnumerator PlayHideAnimation(GameObject icon, Action onComplete)
{
    // 缩放动画：从1缩放到0
    float duration = 0.5f;
    float elapsed = 0f;
    Vector3 startScale = icon.transform.localScale;
    
    while (elapsed < duration)
    {
        elapsed += Time.deltaTime;
        float t = elapsed / duration;
        // 使用缓动函数（easeOut）
        float easeT = 1f - Mathf.Pow(1f - t, 3f);
        icon.transform.localScale = Vector3.Lerp(startScale, Vector3.zero, easeT);
        yield return null;
    }
    
    // 动画完成，销毁图标
    if (icon != null)
    {
        Destroy(icon);
    }
    
    // 调用完成回调
    onComplete?.Invoke();
}
```

```csharp
[CreateAssetMenu(fileName = "TaskBubbleMapping", menuName = "Game/TaskBubbleMapping")]
public class TaskBubbleMapping : ScriptableObject
{
    [System.Serializable]
    public class TaskBubblePair
    {
        public int taskId;
        public string sphereName;
    }
    
    public List<TaskBubblePair> mappings = new List<TaskBubblePair>();
    
    public string GetSphereNameByTaskId(int taskId)
    {
        var mapping = mappings.FirstOrDefault(m => m.taskId == taskId);
        return mapping != null ? mapping.sphereName : null;
    }
}
```

## 🔧 技术细节

### 气泡消失动画实现

**方案A：缩放 + 淡出（推荐）**
```csharp
// 同时缩放和淡出
icon.transform.localScale: 1 → 0
iconImage.color.a: 1 → 0
```

**方案B：仅缩放**
```csharp
// 只缩放
icon.transform.localScale: 1 → 0
```

**方案C：旋转 + 缩放**
```csharp
// 旋转并缩放（更有动感）
icon.transform.localScale: 1 → 0
icon.transform.rotation: 0 → 360度
```

**推荐**：方案A（缩放 + 淡出），视觉效果最好

---

### 视频播放实现

**RenderTexture方式（推荐）**：
1. 创建RenderTexture（分辨率：1920x1080或根据视频）
2. VideoPlayer的RenderMode设置为RenderTexture
3. 将RenderTexture赋值给RawImage的Texture字段
4. 优点：可以添加后处理效果，性能更好

**Direct方式**：
1. VideoPlayer的RenderMode设置为Direct
2. 直接渲染到RawImage
3. 优点：配置简单
4. 缺点：性能稍差，功能受限

---

### 事件系统集成

**选项A：Unity Event（Inspector配置）**
- 使用UnityEvent，可以在Inspector中配置
- 优点：可视化配置，无需代码
- 缺点：类型安全较差

**选项B：C# Event（代码配置）**
- 使用C#的event和Action
- 优点：类型安全，代码清晰
- 缺点：需要在代码中订阅

**推荐**：选项B（C# Event），更符合现有代码风格

## ⚠️ 注意事项

### 1. 任务完成检测

**后续**：需要替换为真实任务完成逻辑

**建议**：

### 2. 气泡与任务的关联

**方式A：通过Sphere名称关联**
- TaskData中存储Sphere名称（如"Sphere 1"）
- 通过名称查找对应的图标

**方式B：通过Sphere GameObject引用**
- TaskData中存储Sphere GameObject引用
- 直接通过引用查找图标

**推荐**：方式A（通过名称），更灵活，支持预制体

---

### 3. 视频播放时机

**选项A：气泡动画完成后立即播放**
- 流程：气泡消失 → 视频播放
- 优点：流程顺畅
- 缺点：可能太快

**选项B：气泡动画完成后延迟播放**
- 流程：气泡消失 → 延迟0.5秒 → 视频播放
- 优点：给玩家反应时间
- 缺点：需要配置延迟时间

**推荐**：选项B（延迟播放），体验更好

---

### 4. 多个任务的处理

**当前需求**：一次完成一个任务
**后续扩展**：可能需要支持多个任务同时完成

**建议**：
- 设计时考虑扩展性
- TaskCompletionHandler可以处理任务列表
- 支持批量播放动画

---

### 5. 视频播放完成后的处理

**选项A：自动隐藏视频面板**
- 视频播放完成后自动隐藏
- 优点：自动化
- 缺点：玩家可能没看完

**选项B：玩家点击关闭**
- 视频播放完成后显示关闭按钮
- 优点：玩家控制
- 缺点：需要额外UI

**选项C：自动隐藏 + 可手动关闭**
- 视频播放完成后自动隐藏，但播放过程中可以点击关闭
- 优点：兼顾两者
- 缺点：需要处理点击事件

**推荐**：选项C（自动隐藏 + 可手动关闭），体验最好
