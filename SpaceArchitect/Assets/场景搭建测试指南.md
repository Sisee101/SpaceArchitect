## 场景准备

### 第一步：创建新场景

1. 在 Unity 编辑器中，点击 `File` → `New Scene`
2. 选择 `Basic (Built-in)` 或 `URP` 模板（根据项目设置）
3. 保存场景为 `02_Gameplay.unity`

### 第二步：创建基础层级结构

创建以下空 GameObject 作为组织节点：
```
Scene
├── Managers (管理对象)
├── Ship (飞船)
├── LaunchStation (发射台)
├── Planets (行星)
├── Obstacles (障碍物)
└── Environment (环境，如地面等)
```

## EventManager 设置

### 创建 EventManager

1. **创建 GameObject**
   - 在 `Hierarchy` 中右键 → `Create Empty`
   - 重命名为 `EventManager`
   - 移动到 `Managers` 节点下（如果创建了）

2. **添加组件**
   - 选中 `EventManager` GameObject
   - 点击 `Add Component`
   - 搜索并添加 `EventManager` 脚本

3. **配置说明**
   - EventManager 是单例，会自动创建
   - 无需任何参数配置
   - 建议勾选 `DontDestroyOnLoad`（在 Inspector 中无法直接设置，代码中已自动处理）

4. **验证**
   - 运行场景后，检查 Console 是否有错误
   - EventManager 会自动初始化

## 发射台（LaunchStation）设置

### 创建发射台 GameObject

1. **创建基础对象**
   ```
   在 Hierarchy 中右键 → 3D Object → Cylinder
   重命名为 "LaunchStation"
   移动到 "LaunchStation" 节点下
   ```

2. **设置 Transform**
   ```
   Position: (0, 0, 0)
   Rotation: (0, 0, 0)
   Scale: (1, 0.2, 1)  // 让它看起来像一个平台
   ```

3. **添加组件**
   - 选中 `LaunchStation` GameObject
   - 点击 `Add Component` 按钮
   - 在搜索框中输入 `Launch Station` 或 `LaunchStation`
   - 如果找不到脚本，请按照下面的"故障排除"步骤操作

### 配置 LaunchStation 参数

**飞船引用（Ship）**
- 暂时留空，稍后配置飞船后会自动查找

**拖拽发射参数（Drag Launch Parameters）**
```
✓ Enable Drag Launch: true
  Drag To Velocity Multiplier: 1.0
  Min Launch Velocity: 1.0
  Max Launch Velocity: 50.0
  Min Drag Distance: 0.5
✓ Lock To Horizontal Plane: true
  Horizontal Plane Height: 0.0
```

**方向指示器（Direction Indicator）**
```
✓ Show Direction Indicator: true
  Direction Indicator Object: (留空，会自动创建)
  Direction Indicator Color: Yellow (255, 255, 0, 255)
  Direction Indicator Width: 0.1
  Direction Indicator Max Length: 20.0
✓ Use Line Renderer: true
```

**摄像机设置（Camera Settings）**
- Camera: (留空，会自动查找 Main Camera)

## 飞船（ShipController）设置

### 创建飞船 GameObject

1. **创建基础对象**
   ```
   在 Hierarchy 中右键 → 3D Object → Capsule
   重命名为 "Ship"
   移动到 "Ship" 节点下（如果创建了组织节点）
   ```
   **注意：** `Ship` 就是 Capsule 对象本身，不是空物体。所有组件都直接添加到这个 Capsule 上。

2. **设置 Transform**
   ```
   Position: (0, 0, 0)  // Y坐标会由ShipController自动设置为水平面高度（默认0）
   Rotation: (0, 0, 0)
   Scale: (0.5, 0.5, 1)  // 让它看起来像飞船
   ```
   **注意：** 飞船的Y坐标会在游戏开始时自动设置到水平面（Y=0），之后的运动也会锁定在此水平面上。

### 添加物理组件

**重要：** 以下所有组件都直接添加到名为 `Ship` 的 Capsule 对象上，不是添加到空物体。

1. **添加 Rigidbody**
   - 选中 `Ship` GameObject（就是那个 Capsule）
   - `Add Component` → `Rigidbody`
   - **重要配置**：
     ```
     Mass: 1
     Use Gravity: false  // 禁用Unity重力，使用自定义引力
     Is Kinematic: false  // 注意：ShipController会自动设置为true
     ```

2. **添加碰撞体**
   - 继续在同一个 `Ship` Capsule 对象上
   - `Add Component` → `Capsule Collider`
   - 配置：
     ```
     Radius: 0.5
     Height: 1.0
     Is Trigger: false
     ```
   **注意：** Capsule 默认已经有 Capsule Collider，如果已有可以调整参数，无需重复添加。

### 添加 ShipController 脚本

**重要：** ShipController 脚本也直接添加到名为 `Ship` 的 Capsule 对象上。

1. **添加组件**
   - 继续在同一个 `Ship` Capsule 对象上
   - `Add Component` → `Ship Controller`

2. **配置物理参数（Physics Parameters）**
   ```
   Mass: 1.0
   ```

3. **配置水平面参数（Horizontal Plane Parameters）**
   ```
   Horizontal Plane Height: 0.0  // 水平面Y坐标，飞船将锁定在此高度
   ```
   **重要：** 飞船会在游戏开始时自动设置到Y=0的水平面，并始终在此水平面上运动。

4. **配置引力参数（Gravity Parameters）**
   ```
   Gravity Constant: 100.0  // 与Planet保持一致
   Max Gravity Distance: 1000.0
   ```

4. **配置捕获参数（Capture Parameters）**
   - 这些参数主要供 Planet 使用，飞船本身保持默认即可

5. **配置 Boost 技能参数（Boost Skill Parameters）**
   ```
   Boost Cooldown: 2.0
   Boost Duration: 0.5
   Boost Force: 50.0
   ```

6. **配置碰撞检测（Collision Detection）**
   ```
   Collision Tag: "Obstacle"
   Destination Tag: "Destination"
   Capture Trigger Tag: "PlanetCapture"
   ```

7. **配置边界检测（Boundary Detection）**
   ```
   Boundary Size: 1000.0
   Boundary Center: (0, 0, 0)
   ```

### 设置飞船标签和层级

1. **创建标签**（如果还没有）
   - `Edit` → `Project Settings` → `Tags and Layers`
   - 在 `Tags` 中添加：`Ship`

2. **设置标签**
   - 选中 `Ship` GameObject
   - 在 Inspector 顶部将 Tag 设置为 `Ship`

## 行星（Planet）设置

### 创建行星 GameObject

1. **创建基础对象**
   ```
   在 Hierarchy 中右键 → 3D Object → Sphere
   重命名为 "Planet"
   移动到 "Planets" 节点下
   ```

2. **设置 Transform**
   ```
   Position: (20, 0, 20)  // 距离发射台一定距离
   Rotation: (0, 0, 0)
   Scale: (2, 2, 2)  // 行星大小
   ```

### 添加 Planet 脚本

1. **添加组件**
   - `Add Component` → `Planet`

2. **配置引力参数（Gravity Parameters）**
   ```
   Mass: 100.0
   Gravity Constant: 100.0  // 与ShipController保持一致
   Max Gravity Distance: 1000.0
   Min Gravity Distance: 0.1
   ```

3. **配置捕获系统参数（Capture System Parameters）**
   ```
   Capture Radius: 50.0
   Min Capture Speed: 2.0
   Max Capture Speed: 20.0
   Capture Angle Threshold: 60.0
   ✓ Enable Capture: true
   ```

4. **配置碰撞体设置（Collider Settings）**
   ```
   Collision Radius: 2.0  // 行星实际大小
   Capture Trigger Tag: "PlanetCapture"
   ```

### 配置碰撞体和触发器

1. **主碰撞体（已自动添加）**
   - Planet 脚本会自动配置主 Sphere Collider
   - 确保 `Is Trigger = false`（用于碰撞检测）

2. **捕获触发器（自动创建）**
   - Planet 脚本会在 Awake 时自动创建子对象 `CaptureTrigger`
   - 自动添加 Sphere Collider 并设置为 Trigger
   - **重要：** 代码会尝试自动设置标签为 `PlanetCapture`，但前提是标签必须先存在

3. **创建标签（必须先做这一步！）**
   - **在运行场景之前**，先在 Unity 编辑器中创建 `PlanetCapture` 标签：
     ```
     Edit → Project Settings → Tags and Layers
     在 Tags 列表中添加 "PlanetCapture"
     ```
   - 如果标签已存在，Planet 脚本会在运行时自动将 `CaptureTrigger` 的标签设置为 `PlanetCapture`
   - 如果标签不存在，代码会显示警告，需要先创建标签后重新运行场景

4. **验证标签设置（可选）**
   - 运行场景后，在 Hierarchy 中展开 Planet 对象
   - 找到 `CaptureTrigger` 子对象
   - 检查其 Tag 是否为 `PlanetCapture`
   - 如果标签未设置，可以手动设置（但通常代码会自动设置）

## 障碍物（Obstacle）设置

### 创建障碍物 GameObject

1. **创建基础对象**
   ```
   在 Hierarchy 中右键 → 3D Object → Cube
   重命名为 "Obstacle"
   移动到 "Obstacles" 节点下
   ```

2. **设置 Transform**
   ```
   Position: (10, 0.5, 10)  // 飞船路径上的障碍
   Rotation: (0, 45, 0)
   Scale: (2, 2, 2)
   ```

### 添加 Obstacle 脚本

1. **添加组件**
   - `Add Component` → `Obstacle`

2. **配置碰撞体配置（Collider Configuration）**
   ```
   Collision Type: Collider  // 使用实心碰撞体
   Obstacle Tag: "Obstacle"
   ✓ Auto Add Collider: true
   Collider Shape: Box
   Sphere Radius: 1.0  // Box形状时不影响
   Box Size: (2, 2, 2)
   ```

3. **配置碰撞检测（Collision Detection）**
   ```
   ✓ Enable Collision Detection: true
   ✓ Only Detect Ship: true
   ✗ Trigger Event On Collision: false  // 由ShipController处理
   ```

### 设置障碍物标签

1. **创建标签**
   - 在 Unity 中创建 `Obstacle` 标签

2. **设置标签**
   - 选中 `Obstacle` GameObject
   - 将 Tag 设置为 `Obstacle`

## 测试流程

### 第一阶段：基础发射测试

1. **启动场景**
   - 点击 Play 按钮
   - 检查 Console 是否有错误

2. **测试发射**
   - 在 Game 视图中点击并拖拽鼠标
   - 应该看到黄色方向指示器
   - 松开鼠标发射飞船

3. **预期结果**
   - 飞船应该按照拖拽方向移动
   - 飞船受引力影响开始曲线运动
   - Console 显示 "飞船发射！" 日志

### 第二阶段：引力测试

1. **观察飞船运动**
   - 飞船应该被行星吸引
   - 运动轨迹应该呈现曲线

2. **调整行星位置**
   - 在 Scene 视图中移动行星
   - 观察引力影响的变化

### 第三阶段：捕获测试

1. **调整飞船初始速度**
   - 拖拽时改变方向和距离
   - 尝试让飞船以合适的速度接近行星

2. **测试捕获条件**
   - 速度在 2-20 范围内
   - 角度接近切向（90度）
   - 距离在捕获范围内

3. **预期结果**
   - 飞船被行星捕获
   - 飞船围绕行星做圆周运动
   - Console 显示捕获日志

### 第四阶段：Boost 技能测试

1. **发射飞船**
   - 正常发射飞船

2. **测试 Boost**
   - 按下 `E` 键
   - 飞船应该加速

3. **测试捕获时 Boost**
   - 让飞船被捕获
   - 按下 `E` 键
   - 飞船应该脱离捕获状态

### 第五阶段：碰撞测试

1. **碰撞障碍物**
   - 让飞船撞击障碍物
   - 飞船应该触发坠毁

2. **碰撞行星**
   - 让飞船撞击行星表面
   - 飞船应该触发坠毁

3. **预期结果**
   - Console 显示 "飞船坠毁！" 日志
   - 触发 `OnShipCrashed` 事件

### 第六阶段：边界测试

1. **让飞船飞出边界**
   - 发射飞船向边界外
   - 飞船超出 `Boundary Size` 范围

2. **预期结果**
   - Console 显示 "飞船逃逸出游戏边界！"
   - 触发 `OnShipEscaped` 事件

## 常见问题解决

### 问题0：无法添加脚本组件

**错误信息：**
```
Can't add script component 'LaunchStation' because the script class cannot be found.
```

**可能原因：**
- Unity 还未编译脚本
- 脚本有编译错误
- Unity 需要刷新资源
- 脚本文件路径或类名不匹配

**解决方法：**

1. **等待 Unity 编译完成**
   - 查看 Unity 编辑器右下角的编译进度条
   - 等待所有脚本编译完成（通常会自动进行）

2. **检查 Console 是否有编译错误**
   - 打开 `Window → General → Console`
   - 查看是否有红色错误信息
   - 如果有错误，先修复这些错误

3. **手动刷新资源**
   - 在 Unity 菜单栏：`Assets → Refresh` (或按 `Ctrl+R`)
   - 或右键点击 `Assets` 文件夹 → `Reimport All`

4. **重新编译脚本**
   - `Assets → Reimport All`
   - 或者关闭并重新打开 Unity 编辑器

5. **验证脚本文件**
   - 确保 `Assets/Scripts/Gameplay/LaunchStation.cs` 文件存在
   - 确保类名是 `LaunchStation`
   - 确保文件名是 `LaunchStation.cs`（大小写匹配）

6. **检查命名空间**
   - 脚本在 `SpaceArchitect.Gameplay` 命名空间下
   - Unity 应该能自动识别，但如果找不到，尝试：
     - 在搜索框中输入完整路径：`SpaceArchitect.Gameplay.LaunchStation`
     - 或者直接搜索文件名：`LaunchStation`

7. **如果以上都不行**
   - 关闭 Unity 编辑器
   - 删除 `Library` 文件夹（Unity 会自动重建）
   - 重新打开 Unity 项目

**验证脚本是否可用：**
- 打开 Console（`Window → General → Console`）
- 查看是否有任何错误
- 在 Project 窗口中搜索 `LaunchStation`
- 双击脚本文件，确保能正常打开

### 问题1：飞船不发射

**可能原因：**
- 飞船状态不是 PreLaunch
- 拖拽距离太短

**解决方法：**
1. 检查飞船的 `CurrentState` 是否为 `PreLaunch`
2. 增加拖拽距离（至少 0.5 单位）
3. 检查 LaunchStation 是否找到了飞船

### 问题2：飞船不受引力影响

**可能原因：**
- 引力常数不一致
- 飞船未找到引力源

**解决方法：**
1. 确保 ShipController 和 Planet 的 `Gravity Constant` 相同（都是 100.0）
2. 检查 Console 是否有 "找到 X 个引力源" 的日志
3. 运行 `ShipController.RefreshGravitySources()` 手动刷新

### 问题3：捕获不工作

**可能原因：**
- 速度不在捕获范围
- 角度不合适
- 捕获触发器未正确设置

**解决方法：**
1. 检查行星的捕获参数：
   - `Min Capture Speed: 2.0`
   - `Max Capture Speed: 20.0`
   - `Capture Angle Threshold: 60.0`
2. 确保捕获触发器标签为 `PlanetCapture`
3. 查看 Console 的捕获判定日志

### 问题4：碰撞不检测

**可能原因：**
- 标签不匹配
- 碰撞体未正确设置

**解决方法：**
1. 确保障碍物标签为 `Obstacle`
2. 确保 ShipController 的 `Collision Tag` 为 `"Obstacle"`
3. 检查碰撞体 `Is Trigger` 设置（应该是 false）

### 问题5：方向指示器不显示

**可能原因：**
- LineRenderer 未启用
- 拖拽距离太短

**解决方法：**
1. 检查 `Show Direction Indicator` 是否勾选
2. 检查 `Use Line Renderer` 是否勾选
3. 增加拖拽距离

### 问题6：EventManager 找不到

**可能原因：**
- EventManager 未在场景中
- 脚本未正确添加

**解决方法：**
1. EventManager 会自动创建，检查 Hierarchy 中是否有
2. 确保 EventManager 脚本在 `SpaceArchitect.Core` 命名空间下

## 调试技巧

### 使用 Gizmos 可视化

1. **在 Scene 视图中查看**
   - 飞船速度向量（绿色）
   - 行星引力范围（蓝色圆圈）

在运行时可以通过 Inspector 查看：
- ShipController 的 `Current State`
- ShipController 的 `Velocity`
- Planet 的 `Has Captured Ship`
- LaunchStation 的 `Is Dragging` 和 `Is Ready To Launch`
