# 行星图鉴脚本配置指南

## 一、脚本文件说明

已创建以下脚本文件：

1. **PlanetCard.cs** - 行星卡片脚本（`Assets/Scripts/UI/PlanetCard.cs`）
2. **DetailCard.cs** - 介绍卡片脚本（`Assets/Scripts/UI/DetailCard.cs`）
3. **PlanetEncyclopediaPanel.cs** - 主控制器脚本（已更新，`Assets/Scripts/UI/PlanetEncyclopediaPanel.cs`）

## 二、创建预制体步骤

### 步骤 1：创建 PlanetCard 预制体

1. **准备场景中的卡片**：
   - 在 Hierarchy 中找到 `Content` 下的测试卡片（如果还没有，先创建一个临时测试卡片）
   - 右键点击 `Content` → `UI` → `Image` → 重命名为 `PlanetCard`

2. **配置 PlanetCard 的基础组件**：
   - 选中 `PlanetCard` GameObject
   - **Rect Transform**：
     - 不需要手动设置尺寸（会被 LayoutElement 控制）
     - 确保锚点为 `Left Middle` 或其他合适的锚点
   
   - **LayoutElement 组件**（必须）：
     - `Add Component` → 搜索 `Layout Element` → 添加组件
     - `Preferred Width`: 300（行星卡片宽度）
     - `Preferred Height`: 500（行星卡片高度）
     - 其他参数保持默认
   
   - **Image 组件**：
     - `Source Image`: 可以先设置一个测试图片，或留空（代码中会设置）
     - `Color`: 白色
     - `Raycast Target`: ✅ 勾选（用于点击检测）
   
   - **Image 组件**：
     - `Raycast Target`: ✅ **必须勾选**（用于检测点击，如果不勾选，点击将无效）
     - `Source Image`: 可以先设置一个测试图片，或留空（代码中会设置）
     - `Color`: 白色
   
   **⚠️ 重要说明**：
   - **不需要** `Button` 组件！代码使用 `IPointerClickHandler` 接口来处理点击，卡片本身任何部位都可以点击
   - 只需要确保 `Image` 组件的 `Raycast Target` 已勾选，这样点击检测才能工作
   - 这样卡片就不会有任何额外的UI元素（如Button的背景、边框等），只有图片本身

3. **挂载 PlanetCard 脚本**：
   - 选中 `PlanetCard` GameObject
   - `Add Component` → 搜索 `Planet Card` → 添加组件
   - 配置字段：
     - `Planet Image`: 拖拽 `PlanetCard` 的 `Image` 组件到该字段

4. **创建预制体**：
   - 在 Project 窗口中，找到或创建 `Assets/Prefeb` 文件夹（或你的预制体文件夹）
   - 将 Hierarchy 中的 `PlanetCard` GameObject **拖拽**到 `Assets/Prefeb` 文件夹
   - Unity 会自动创建预制体文件 `PlanetCard.prefab`
   - **重要**：创建预制体后，Hierarchy 中的 `PlanetCard` 会变成**蓝色**（表示它是预制体实例）
   - 如果 Hierarchy 中还有其他的测试 `PlanetCard`，可以删除它们（后面会通过代码动态创建）

### 步骤 2：创建 DetailCard 预制体

1. **创建临时测试卡片**：
   - 右键点击 `Content` → `UI` → `Image` → 重命名为 `DetailCard`
   - **注意**：这个卡片不会显示在场景中（运行时动态创建），所以可以临时放在任何地方，或者直接创建预制体

2. **配置 DetailCard 的基础组件**：
   - 选中 `DetailCard` GameObject
   - **Rect Transform**：
     - 不需要手动设置尺寸（会被 LayoutElement 控制）
   
   - **LayoutElement 组件**（必须）：
     - `Add Component` → 搜索 `Layout Element` → 添加组件
     - `Preferred Width`: 600（**较大宽度**）
     - `Preferred Height`: 700（**较大高度**）
     - 其他参数保持默认
   
   - **Image 组件**：
     - `Source Image`: 可以先设置一个测试图片，或留空（代码中会设置）
     - `Color`: 白色
     - `Raycast Target`: ✅ 勾选
   
   - **注意**：DetailCard **不需要** Button 组件（不会直接点击）

3. **挂载 DetailCard 脚本**：
   - 选中 `DetailCard` GameObject
   - `Add Component` → 搜索 `Detail Card` → 添加组件
   - 配置字段：
     - `Detail Image`: 拖拽 `DetailCard` 的 `Image` 组件到该字段

4. **创建预制体**：
   - 将 Hierarchy 中的 `DetailCard` GameObject **拖拽**到 `Assets/Prefeb` 文件夹
   - Unity 会自动创建预制体文件 `DetailCard.prefab`
   - 创建预制体后，可以删除 Hierarchy 中的 `DetailCard`（运行时动态创建）

## 三、配置 PlanetEncyclopediaPanel 脚本

### 步骤 1：挂载脚本

1. **找到 PlanetEncyclopediaPanel GameObject**：
   - 在 Hierarchy 中找到 `PlanetEncyclopediaPanel`（应该在 `MainHubCanvas` 下）

2. **检查脚本是否已挂载**：
   - 选中 `PlanetEncyclopediaPanel`
   - 在 Inspector 中查看是否有 `Planet Encyclopedia Panel` 组件
   - 如果没有，`Add Component` → 搜索 `Planet Encyclopedia Panel` → 添加组件

### 步骤 2：配置脚本引用

在 Inspector 中的 `Planet Encyclopedia Panel` 组件中配置以下字段：

#### UI引用

1. **Back Button**：
   - 拖拽 `PlanetEncyclopediaPanel/TopBar/返回按钮`（或你的返回按钮）的 `Button` 组件

2. **Scroll Rect**：
   - 拖拽 `PlanetEncyclopediaPanel/CarouselContainer/ScrollView` 的 `ScrollRect` 组件

3. **Content**：
   - 拖拽 `PlanetEncyclopediaPanel/CarouselContainer/ScrollView/Viewport/Content` 的 `RectTransform` 组件

4. **Left Arrow**：
   - 拖拽 `PlanetEncyclopediaPanel/CarouselContainer/LeftArrow` 的 `Button` 组件

5. **Right Arrow**：
   - 拖拽 `PlanetEncyclopediaPanel/CarouselContainer/RightArrow` 的 `Button` 组件

#### 预制体引用

6. **Planet Card Prefab**：
   - 拖拽 `Assets/Prefeb/PlanetCard.prefab` 预制体

7. **Detail Card Prefab**：
   - 拖拽 `Assets/Prefeb/DetailCard.prefab` 预制体

#### 数据配置

8. **Planet Card Images**（13张行星卡片图片）：
   - `Size`: 设置为 `13`
   - `Element 0` ~ `Element 12`：分别拖拽13张行星卡片图片
   - **注意**：这些图片应该是对应13个行星的卡片图片（正常尺寸）

9. **Detail Card Images**（13张介绍卡片图片）：
   - `Size`: 设置为 `13`
   - `Element 0` ~ `Element 12`：分别拖拽13张介绍卡片图片
   - **重要**：索引必须与 `Planet Card Images` 一一对应
   - 例如：`Element 0` 的介绍图片应该对应 `Element 0` 的行星卡片

#### 布局参数（可选调整）

10. **Card Spacing**: `20`（卡片间距，应与 Horizontal Layout Group 的 Spacing 一致）

11. **Planet Card Width**: `300`（行星卡片宽度，应与 LayoutElement 的 Preferred Width 一致）

12. **Planet Card Height**: `500`（行星卡片高度）

13. **Detail Card Width**: `600`（介绍卡片宽度，应与 LayoutElement 的 Preferred Width 一致）

14. **Detail Card Height**: `700`（介绍卡片高度）

#### 动画参数（可选调整）

15. **Scroll Duration**: `0.3`（滚动动画时长）

16. **Insert Animation Duration**: `0.3`（插入动画时长，当前版本未使用，保留用于未来扩展）

## 六、常见问题

### Q1: 预制体创建后 Hierarchy 中的卡片变蓝

**原因**：这是正常的！表示该 GameObject 是预制体实例。

**解决**：这是正确的状态，不需要处理。如果不需要在场景中保留这个实例，可以删除它（代码会动态创建）。

### Q2: 脚本字段找不到对应的组件

**解决**：
- 检查 GameObject 的名称是否正确
- 检查路径是否正确
- 确保组件已添加到 GameObject 上
- 如果字段要求 `Button` 组件，确保拖拽的是 `Button` 组件，而不是 GameObject 本身

### Q3: 运行后卡片不显示

**解决**：
- 检查 `Planet Card Images` 列表是否已配置
- 检查图片是否已正确导入（Texture Type 应为 Sprite）
- 检查 Console 是否有错误信息
- 确保 `Planet Card Prefab` 已正确配置

### Q4: 点击卡片后介绍卡片不显示

**解决**：
- 检查 `Detail Card Prefab` 是否已配置
- 检查 `Detail Card Images` 列表是否已配置
- 检查 Console 是否有错误信息
- 确保 DetailCard 预制体有 `LayoutElement` 组件且 `Preferred Width` 设置正确

### Q5: 滚动不工作

**解决**：
- 检查 `Scroll Rect` 引用是否正确
- 检查 `Content` 引用是否正确
- 确保 ScrollRect 的 `Horizontal` 已勾选
- 检查 `Content` 的 `Width` 是否足够大（应该大于 Viewport 的宽度）

---

**提示**：如果遇到问题，首先检查 Unity 的 Console 窗口，通常会有详细的错误信息提示问题所在。
