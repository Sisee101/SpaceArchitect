# 主界面场景（01_MainHub）UI搭建和脚本挂载指南

本文档详细说明如何搭建主界面场景（01_MainHub）的UI界面，以及如何正确挂载和配置相关脚本。

---

## 📋 准备工作

### 1. 创建场景
1. 在Unity中，选择菜单：`File` → `New Scene`
2. 选择 `Basic (Built-in)` 模板
3. 保存场景：`File` → `Save As`
4. 保存路径：`Assets/Scenes/01_MainHub.unity`

### 2. 将场景添加到Build Settings
1. 菜单：`File` → `Build Settings`
2. 点击 `Add Open Scenes` 将当前场景添加到场景列表
3. 确保场景顺序：
   - Index 0: `00_MainMenu`（主菜单/开始页面）
   - Index 1: `01_MainHub`（主界面）
   - Index 2: `scene02`（游戏场景）

---

## 🎨 UI结构总览

主界面场景的UI层次结构如下：

```
Canvas
├── EventSystem（自动创建）
├── TopBar（顶部栏）
│   ├── GoldDisplay（金币显示）
│   └── FuelDisplay（燃料显示）
├── OrderButton（右上角订单按钮）
├── MainHubPanel（主界面面板）
│   └── BottomButtons（底部按钮组）
│       ├── EmployeeHandbookButton（员工手册按钮）

│       └── PlanetEncyclopediaButton（行星图鉴按钮）
├── EmployeeHandbookPanel（员工手册面板，默认隐藏）
├── StationLevelPanel（基站等级面板，默认隐藏）
└── PlanetEncyclopediaPanel（行星图鉴面板，默认隐藏）
```

## 📝 详细搭建步骤

### 步骤1：创建Canvas和EventSystem

1. **创建Canvas**
   - 右键点击 `Hierarchy` → `UI` → `Canvas`
   - 自动创建 `Canvas` 和 `EventSystem`
   - 选中 `Canvas`，检查设置：
     - `Render Mode`: `Screen Space - Overlay`
     - `Canvas Scaler` → `UI Scale Mode`: `Scale With Screen Size`
     - `Reference Resolution`: `1920 x 1080`（根据项目需求调整）
     - `Screen Match Mode`: `Match Width Or Height`，值为 `0.5`

2. **重命名Canvas**
   - 将 `Canvas` 重命名为 `MainHubCanvas`

---

### 步骤2：创建顶部资源显示栏（TopBar）

1. **创建TopBar容器**
   - 右键点击 `MainHubCanvas` → `UI` → `Panel`
   - 重命名为 `TopBar`
   - 设置 `RectTransform`：
     - `Anchor Presets`: 点击顶部中央（按住 `Alt` 键）
     - `Pos X`: `0`
     - `Pos Y`: `-50`（距离顶部50像素）
     - `Width`: `600`
     - `Height`: `80`
   - 移除 `Image` 组件（或设置 `Color` 透明度为0，只保留布局功能）

2. **创建金币显示（GoldDisplay）**
   - 右键点击 `TopBar` → `UI` → `Text - Text`
   - 重命名为 `GoldDisplay`
   - 设置 `RectTransform`：
     - `Anchor Presets`: 左侧中央
     - `Pos X`: `-250`
     - `Pos Y`: `0`
     - `Width`: `200`
     - `Height`: `50`
   - 设置 `Text` 组件：
     - `Text`: `金币: 1000`
     - `Font Size`: `30`
     - `Alignment`: 居左对齐
     - `Color`: 白色或金黄色

3. **创建燃料显示（FuelDisplay）**
   - 右键点击 `TopBar` → `UI` → `Text - Text`
   - 重命名为 `FuelDisplay`
   - 设置 `RectTransform`：
     - `Anchor Presets`: 右侧中央
     - `Pos X`: `250`
     - `Pos Y`: `0`
     - `Width`: `200`
     - `Height`: `50`
   - 设置 `Text` 组件：
     - `Text`: `燃料: 100.0`
     - `Font Size`: `30`
     - `Alignment`: 居右对齐
     - `Color`: 白色或蓝色

---

### 步骤3：创建订单按钮（OrderButton）

1. **创建订单按钮**
   - 右键点击 `MainHubCanvas` → `UI` → `Button - Button`
   - 重命名为 `OrderButton`
   - 设置 `RectTransform`：
     - `Anchor Presets`: 右上角（按住 `Alt` 键）
     - `Pos X`: `-150`
     - `Pos Y`: `-100`
     - `Width`: `200`
     - `Height`: `80`
   - 设置 `Button` 组件：
     - 可以选择性地修改按钮文本和样式

2. **配置订单按钮文本**
   - 选中 `OrderButton` 下的子对象 `Text`（或 `Text (TMP)`）
   - 修改文本内容为：`订单` 或 `查看订单`
   - 设置字体大小和颜色

---

### 步骤4：创建主界面面板（MainHubPanel）和底部按钮

1. **创建主界面面板**
   - 右键点击 `MainHubCanvas` → `UI` → `Panel`
   - 重命名为 `MainHubPanel`
   - 设置 `RectTransform`：
     - `Anchor Presets`: 拉伸全屏（按住 `Alt` 键）
     - 所有值设为 `0`，让面板占满整个屏幕
   - 可选：移除 `Image` 组件或设置透明度（如果不需要背景）

2. **创建底部按钮容器（BottomButtons）**
   - 右键点击 `MainHubPanel` → `UI` → `Panel`
   - 重命名为 `BottomButtons`
   - 设置 `RectTransform`：
     - `Anchor Presets`: 底部中央（按住 `Alt` 键）
     - `Pos X`: `0`
     - `Pos Y`: `100`（距离底部100像素）
     - `Width`: `800`
     - `Height`: `100`
   - 添加 `Horizontal Layout Group` 组件：
     - `Spacing`: `30`（按钮之间的间距）
     - `Child Alignment`: `Middle Center`
     - `Child Force Expand`: 取消勾选 `Width` 和 `Height`

3. **创建员工手册按钮**
   - 右键点击 `BottomButtons` → `UI` → `Button - Button`
   - 重命名为 `EmployeeHandbookButton`
   - 设置 `RectTransform`：
     - `Width`: `200`
     - `Height`: `80`
   - 修改按钮子对象 `Text` 的文本为：`员工手册`
   - 设置字体大小和颜色

4. **创建基站等级按钮**
   - 右键点击 `BottomButtons` → `UI` → `Button - Button`
   - 重命名为 `StationLevelButton`
   - 设置同上，文本改为：`基站等级`

5. **创建行星图鉴按钮**
   - 右键点击 `BottomButtons` → `UI` → `Button - Button`
   - 重命名为 `PlanetEncyclopediaButton`
   - 设置同上，文本改为：`行星图鉴`

---

### 步骤5：创建员工手册面板（EmployeeHandbookPanel）

1. **创建面板容器**
   - 右键点击 `MainHubCanvas` → `UI` → `Panel`
   - 重命名为 `EmployeeHandbookPanel`
   - 设置 `RectTransform`：
     - `Anchor Presets`: 拉伸全屏
     - 所有值设为 `0`
   - 设置 `Image` 组件：
     - `Color`: 半透明黑色背景（如 `RGBA: 0, 0, 0, 200`）

2. **创建内容区域**
   - 右键点击 `EmployeeHandbookPanel` → `UI` → `Panel`
   - 重命名为 `ContentArea`
   - 设置 `RectTransform`：
     - `Anchor Presets`: 中央
     - `Width`: `800`
     - `Height`: `600`
     - 居中显示

3. **创建标题**
   - 右键点击 `ContentArea` → `UI` → `Text - Text`
   - 重命名为 `Title`
   - 设置文本：`员工手册`
   - 设置字体大小：`40`
   - 位置：顶部居中

4. **创建内容文本**
   - 右键点击 `ContentArea` → `UI` → `Text - Text`
   - 重命名为 `ContentText`
   - 设置 `RectTransform`：
     - `Width`: `750`
     - `Height`: `500`
   - 设置 `Text` 组件：
     - `Text`: `员工手册功能开发中...\n\n这里将显示员工手册的相关信息`
     - `Font Size`: `24`
     - `Alignment`: 居中对齐
     - `Vertical Overflow`: `Overflow`

5. **创建返回按钮**
   - 右键点击 `ContentArea` → `UI` → `Button - Button`
   - 重命名为 `BackButton`
   - 设置 `RectTransform`：
     - `Anchor Presets`: 底部居中
     - `Pos Y`: `50`
     - `Width`: `150`
     - `Height`: `50`
   - 修改按钮文本为：`返回`

6. **默认隐藏面板**
   - 选中 `EmployeeHandbookPanel`
   - 在 `Inspector` 中取消勾选 `GameObject` 的 `Active` 复选框

---

### 步骤6：创建基站等级面板（StationLevelPanel）

1. **创建面板容器**（同员工手册面板）
   - 右键点击 `MainHubCanvas` → `UI` → `Panel`
   - 重命名为 `StationLevelPanel`
   - 设置 `RectTransform`：拉伸全屏
   - 设置半透明黑色背景

2. **创建内容区域**
   - 右键点击 `StationLevelPanel` → `UI` → `Panel`
   - 重命名为 `ContentArea`
   - 设置大小为 `800 x 600`，居中显示

3. **创建等级文本**
   - 右键点击 `ContentArea` → `UI` → `Text - Text`
   - 重命名为 `LevelText`
   - 设置文本：`当前基站等级: --`
   - 字体大小：`36`
   - 位置：顶部居中

4. **创建描述文本**
   - 右键点击 `ContentArea` → `UI` → `Text - Text`
   - 重命名为 `DescriptionText`
   - 设置文本：`基站等级功能开发中...\n\n这里将显示当前基站等级及相关信息`
   - 字体大小：`24`
   - 位置：中央

5. **创建返回按钮**（同员工手册面板）
   - 重命名为 `BackButton`
   - 设置文本：`返回`

6. **默认隐藏面板**
   - 取消勾选 `StationLevelPanel` 的 `Active` 复选框

---

### 步骤7：创建行星图鉴面板（PlanetEncyclopediaPanel）

   - 重命名为 `PlanetEncyclopediaPanel`

## 🔧 脚本挂载和配置

### 步骤8：挂载核心管理器脚本

#### 8.1 创建GameResourceManager（资源管理器）

1. **创建GameObject**
   - 右键点击 `Hierarchy` → `Create Empty`
   - 重命名为 `GameResourceManager`

2. **挂载脚本**
   - 选中 `GameResourceManager`
   - 在 `Inspector` 中点击 `Add Component`
   - 搜索并添加 `Game Resource Manager`

3. **配置资源初始值**（可选）
   - `Gold`: `1000`（默认值）
   - `Fuel`: `100`（默认值）

4. **设置为DontDestroyOnLoad**
   - 脚本会自动处理，确保单例模式正常工作

---

#### 8.2 创建SceneTransitionManager（场景切换管理器）

1. **检查是否已存在**
   - 如果主菜单场景中已有 `SceneTransitionManager`，它会通过 `DontDestroyOnLoad` 保留
   - 如果没有，创建新GameObject并挂载 `Scene Transition Manager`

2. **配置场景名称**
   - 脚本中已硬编码场景名称，无需额外配置
   - 确保场景名称正确：
     - 主菜单：`00_MainMenu`
     - 主界面：`01_MainHub`
     - 游戏场景：`scene02`

---

#### 8.3 创建UIManager（UI管理器）

1. **创建GameObject**
   - 右键点击 `Hierarchy` → `Create Empty`
   - 重命名为 `UIManager`

2. **挂载脚本**
   - 添加组件：`UI Manager`

3. **配置面板引用**
   - 在 `Inspector` 中，将对应的面板拖拽到对应的字段：
     - `Main Menu Panel`: **留空**（主界面场景不需要主菜单面板）
     - `Main Hub Controller`: 稍后配置（见步骤9.1）
     - `Planet Encyclopedia Panel`: 拖拽 `PlanetEncyclopediaPanel`
     - `Settings Panel`: **留空**（如果不需要设置面板）
     - `Employee Handbook Panel`: 拖拽 `EmployeeHandbookPanel`
     - `Station Level Panel`: 拖拽 `StationLevelPanel`

## 🐛 常见问题排查

### 问题1：资源显示不更新
- **检查**：`ResourceDisplay` 脚本是否正确挂载
- **检查**：`GoldDisplay` 和 `FuelDisplay` 文本引用是否正确
- **检查**：`GameResourceManager` 是否已创建且正常工作

### 问题2：按钮点击无反应
- **检查**：按钮的 `Interactable` 是否勾选
- **检查**：脚本是否正确挂载
- **检查**：按钮引用是否正确配置
- **检查**：`EventSystem` 是否存在（通常Canvas会自动创建）

### 问题3：面板无法显示/隐藏
- **检查**：面板的 `Active` 状态是否正确
- **检查**：`UIManager` 的面板引用是否正确
- **检查**：`HideAllPanels()` 方法是否包含所有面板

### 问题4：场景跳转失败
- **检查**：场景名称是否正确（`01_MainHub`）
- **检查**：场景是否已添加到 Build Settings
- **检查**：`SceneTransitionManager` 是否存在且正常工作

### 问题5：返回按钮回到错误场景
- **检查**：`PlanetEncyclopediaPanel` 的 `OnBackClicked()` 方法是否正确判断当前场景
- **检查**：`UIManager` 的 `ReturnToMainHub()` 方法是否被正确调用

## 📝 补充说明

### 关于GameResourceManager
- 当前是占位版本，使用默认值（金币1000，燃料100）
- 如果负责资源的同学还没有完成实现，这个版本可以正常工作
- 当完整版本完成后，只需要替换 `GameResourceManager.cs` 文件即可，UI代码无需修改

### 关于面板设计
- 当前面板都是基础版本，可以根据实际需求调整布局和样式
- 员工手册、基站等级、行星图鉴的具体内容可以后续补充
- 建议使用UI动画（如Fade In/Out）来提升用户体验

### 关于场景管理
- 确保 `SceneTransitionManager` 在所有场景中都存在，或者使用 `DontDestroyOnLoad` 保持单例
- 场景切换时，确保时间缩放（Time.timeScale）正确重置
