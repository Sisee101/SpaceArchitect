# 结算界面接口调用说明

## 📋 概述

本文档说明如何调用结算界面的各个接口，用于后续开发者接入数据和事件。

---

## 🎯 主要接口

### 1. OrderDetailPanel（结算界面主控制器）

**获取引用**：
```csharp
OrderDetailPanel settlementPanel = FindObjectOfType<OrderDetailPanel>();
// 或通过MainHubController获取
```

**显示/隐藏结算界面**：
```csharp
settlementPanel.Show();  // 显示结算界面
settlementPanel.Hide();  // 隐藏结算界面
settlementPanel.Toggle(); // 切换显示/隐藏
bool isShowing = settlementPanel.IsShowing(); // 检查是否显示
```

**播放印章动画**：
```csharp
settlementPanel.PlayStampAnimation(); // 播放印章出现动画
```

---

### 2. OrderImageListController（订单图片列表）

**获取引用**：
```csharp
OrderImageListController orderList = FindObjectOfType<OrderImageListController>();
// 或通过OrderDetailPanel获取
```

**设置订单图片列表**：
```csharp
List<Sprite> orderImages = new List<Sprite>();
// 添加3张订单图片
orderImages.Add(image1);
orderImages.Add(image2);
orderImages.Add(image3);

orderList.SetOrderImages(orderImages); // 替换占位图片
```

**滚动到指定订单**：
```csharp
orderList.ScrollToIndex(0); // 滚动到第1个订单（索引0）
orderList.ScrollToIndex(1); // 滚动到第2个订单（索引1）
orderList.ScrollToIndex(2); // 滚动到第3个订单（索引2）
```

**获取当前订单索引**：
```csharp
int currentIndex = orderList.GetCurrentIndex(); // 返回0、1或2
```

**订阅订单切换事件**：
```csharp
orderList.OnOrderIndexChanged += (index) => {
    Debug.Log($"订单切换到索引: {index}");
    // 在这里处理订单切换逻辑
    // 例如：更新订单详情、更新文字等
};
```

---

### 3. TextImageController（文字图片）

**获取引用**：
```csharp
TextImageController textImage = FindObjectOfType<TextImageController>();
// 或通过OrderDetailPanel获取
```

**设置文字图片列表（8张）**：
```csharp
List<Sprite> textImages = new List<Sprite>();
// 添加8张文字图片
for (int i = 0; i < 8; i++)
{
    textImages.Add(LoadTextImage(i));
}

textImage.SetTextImages(textImages); // 替换占位图片
```

**设置指定索引的文字图片**：
```csharp
textImage.SetTextImage(0); // 显示第1张（索引0）
textImage.SetTextImage(3); // 显示第4张（索引3）
textImage.SetTextImage(7); // 显示第8张（索引7）
```

**获取当前图片索引**：
```csharp
int currentIndex = textImage.GetCurrentIndex(); // 返回0-7
```

**注意**：
- A键切换功能由代码自动处理，无需手动调用
- 只有在结算界面显示时，A键才会切换文字图片

---

### 4. DynamicTextController（动态文字）

**获取引用**：
```csharp
DynamicTextController dynamicText = FindObjectOfType<DynamicTextController>();
// 或通过OrderDetailPanel获取
```

**设置订单ID**：
```csharp
dynamicText.SetOrderId(0); // 显示"订单ID: 0"
dynamicText.SetOrderId(1); // 显示"订单ID: 1"
dynamicText.SetOrderId(2); // 显示"订单ID: 2"
```

**设置自定义文字**：
```csharp
dynamicText.SetText("订单金额: 2000"); // 直接设置文字
```

**格式化文字**：
```csharp
dynamicText.UpdateText("订单金额: {0}, 配送金额: {1}", 2000, 1500);
// 显示："订单金额: 2000, 配送金额: 1500"
```

**获取当前文字**：
```csharp
string currentText = dynamicText.GetText();
```

---

### 5. StampAnimationController（印章动画）

**获取引用**：
```csharp
StampAnimationController stampAnim = FindObjectOfType<StampAnimationController>();
// 或通过OrderDetailPanel获取
```

**播放印章动画**：
```csharp
stampAnim.PlayStampAnimation(); // 播放动画
```

**播放动画（带完成回调）**：
```csharp
stampAnim.PlayStampAnimation(() => {
    Debug.Log("印章动画播放完成");
    // 在这里处理动画完成后的逻辑
});
```

**隐藏印章**：
```csharp
stampAnim.HideStamp(); // 隐藏印章
```

**检查动画状态**：
```csharp
bool isAnimating = stampAnim.IsAnimating(); // 是否正在播放动画
```

## 🔄 完整调用示例

### 示例1：显示结算界面并加载订单数据

```csharp
// 获取引用
OrderDetailPanel settlementPanel = FindObjectOfType<OrderDetailPanel>();
OrderImageListController orderList = settlementPanel.GetComponentInChildren<OrderImageListController>();
DynamicTextController dynamicText = settlementPanel.GetComponentInChildren<DynamicTextController>();

// 显示结算界面
settlementPanel.Show();

// 加载订单图片
List<Sprite> orderImages = LoadOrderImagesFromConfig();
orderList.SetOrderImages(orderImages);

// 更新订单ID
dynamicText.SetOrderId(0);

// 订阅订单切换事件
orderList.OnOrderIndexChanged += (index) => {
    // 订单切换时更新文字
    dynamicText.SetOrderId(index);
    
    // 可以在这里加载对应订单的其他数据
    LoadOrderData(index);
};
```

### 示例2：加载文字图片并播放印章动画

```csharp
// 获取引用
TextImageController textImage = FindObjectOfType<TextImageController>();
StampAnimationController stampAnim = FindObjectOfType<StampAnimationController>();

// 加载8张文字图片
List<Sprite> textImages = LoadTextImages();
textImage.SetTextImages(textImages);

// 播放印章动画
stampAnim.PlayStampAnimation(() => {
    Debug.Log("印章动画完成，可以执行后续操作");
});
```

### 示例3：根据订单数据更新所有信息

```csharp
// 假设有一个订单数据类
class OrderData
{
    public Sprite orderImage;
    public int orderId;
    public string orderAmount;
    public Sprite[] textImages; // 8张文字图片
}

// 加载订单数据
OrderData orderData = LoadOrderData(orderIndex);

// 更新订单图片
List<Sprite> images = new List<Sprite> { orderData.orderImage };
orderList.SetOrderImages(images);

// 更新订单ID
dynamicText.SetOrderId(orderData.orderId);

// 更新文字图片
textImage.SetTextImages(new List<Sprite>(orderData.textImages));

// 更新订单金额
dynamicText.SetText($"订单金额: {orderData.orderAmount}");
```

## 📝 注意事项

1. **获取引用**：
   - 可以通过 `FindObjectOfType<>()` 查找
   - 也可以通过 `OrderDetailPanel` 的子组件获取
   - 建议在 `Start()` 或 `Awake()` 中获取引用并缓存

2. **事件订阅**：
   - 使用 `+=` 订阅事件
   - 记得在不需要时使用 `-=` 取消订阅，避免内存泄漏

3. **调用时机**：
   - 显示结算界面后，再调用其他接口更新数据
   - 确保结算界面已显示（`settlementPanel.IsShowing() == true`）

4. **数据格式**：
   - 订单图片：`List<Sprite>`，当前支持3张
   - 文字图片：`List<Sprite>`，需要8张
   - 订单ID：`int` 类型

5. **A键切换**：
   - 文字图片的A键切换由代码自动处理
   - 无需手动调用切换方法
   - 只有在结算界面显示时才会响应A键
