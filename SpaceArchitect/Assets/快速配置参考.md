# 快速配置参考卡片

## 🚀 所有脚本的快速配置清单

### 1. EventManager
**创建：** 空GameObject + EventManager脚本  
**配置：** 无需配置，自动工作  
**标签：** 无要求  

---

### 2. LaunchStation（发射台）

**GameObject：** Cylinder  
**位置：** (0, 0, 0)  
**脚本：** LaunchStation  

**关键参数：**
```
✓ Enable Drag Launch: true
  Drag To Velocity Multiplier: 1.0
  Min Launch Velocity: 1.0
  Max Launch Velocity: 50.0
  Min Drag Distance: 0.5
✓ Lock To Horizontal Plane: true
✓ Show Direction Indicator: true
✓ Use Line Renderer: true
```

---

### 3. ShipController（飞船）

**GameObject：** Capsule  
**位置：** (0, 1, 0)  
**脚本：** ShipController  
**标签：** Ship  

**必需组件：**
- ✅ Rigidbody（Use Gravity = false）
- ✅ Collider（Capsule）

**关键参数：**
```
Mass: 1.0
Gravity Constant: 100.0  ⚠️ 必须与Planet一致
Max Gravity Distance: 1000.0
Collision Tag: "Obstacle"
Boundary Size: 1000.0
```

---

### 4. Planet（行星）

**GameObject：** Sphere  
**脚本：** Planet  
**标签：** 无特殊要求  

**必需组件：**
- ✅ SphereCollider（自动添加）

**关键参数：**
```
Mass: 100.0
Gravity Constant: 100.0  ⚠️ 必须与ShipController一致
Capture Radius: 50.0
Min Capture Speed: 2.0
Max Capture Speed: 20.0
Capture Angle Threshold: 60.0
✓ Enable Capture: true
```

**子对象：**
- CaptureTrigger（自动创建）
  - 标签：PlanetCapture
  - 触发器：是

---

### 5. Obstacle（障碍物）

**GameObject：** Cube  
**脚本：** Obstacle  
**标签：** Obstacle ⚠️ 必须  

**关键参数：**
```
Collision Type: Collider
Obstacle Tag: "Obstacle"
✓ Auto Add Collider: true
✓ Enable Collision Detection: true
✓ Only Detect Ship: true
✗ Trigger Event On Collision: false
```

---

## 📋 必需标签列表

在 `Edit → Project Settings → Tags and Layers` 中创建：

1. ✅ **Ship** - 飞船标签
2. ✅ **Obstacle** - 障碍物标签
3. ✅ **PlanetCapture** - 行星捕获触发器标签
4. ✅ **Destination** - 目的地标签（可选）

---

## 🎯 关键数值匹配

### 引力常数必须一致：
- ShipController.Gravity Constant = **100.0**
- Planet.Gravity Constant = **100.0**

### 碰撞标签必须匹配：
- ShipController.Collision Tag = **"Obstacle"**
- Obstacle.Obstacle Tag = **"Obstacle"**

---

## 🔧 快速搭建步骤

1. ✅ 创建 EventManager
2. ✅ 创建 LaunchStation
3. ✅ 创建 Ship（带 Rigidbody + Collider）
4. ✅ 创建 Planet
5. ✅ 创建 Obstacle
6. ✅ 创建所有标签
7. ✅ 配置摄像机为 MainCamera
8. ✅ 运行场景测试

---

## 🐛 常见问题快速检查

| 问题 | 检查项 |
|------|--------|
| 飞船不发射 | • 飞船状态是否为 PreLaunch<br>• 拖拽距离是否 ≥ 0.5 |
| 不受引力 | • Gravity Constant 是否一致<br>• Planet 是否实现了 IGravitySource |
| 捕获不工作 | • 速度是否在 2-20 范围内<br>• CaptureTrigger 标签是否为 PlanetCapture |
| 碰撞不检测 | • 标签是否匹配<br>• Collider 的 Is Trigger 设置 |

## 🎮 测试流程

1. **发射测试** - 拖拽鼠标，松开发射
2. **引力测试** - 观察飞船被行星吸引
3. **捕获测试** - 以合适速度接近行星
4. **Boost测试** - 按 E 键加速/脱离
5. **碰撞测试** - 撞击障碍物或行星
6. **边界测试** - 飞出边界范围

---
