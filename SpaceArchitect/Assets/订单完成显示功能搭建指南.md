# 订单完成显示功能搭建指南

## 功能概述

本指南将帮助你搭建**订单完成显示功能**，将原来的视频播放替换为显示订单图片和"已送达"印章。

**执行流程**：
1. 按下1/2/3键完成任务
2. 显示订单图片（淡入动画）
3. 1秒后显示"已送达"印章（叠在订单图片上方，带动画）
4. 保持显示1秒
5. 订单图片和印章一起消失（淡出动画）
6. 播放气泡消失动画

## 前置要求

- ✅ Unity 2022.3 或更高版本
- ✅ DOTween 插件（用于动画）
- ✅ 已完成任务完成系统的基础搭建
- ✅ 已有订单数据配置（`SphereOrderDataConfig`）

## 步骤1：创建UI结构

### 1.1 找到或创建Canvas

1. 在 Unity 中打开 `01_MainHub` 场景
2. 找到 `MainHubCanvas`（如果不存在，创建一个Canvas）

### 1.2 创建订单完成显示面板

1. **创建显示面板**：
   - 在 `MainHubCanvas` 下创建新的 GameObject
   - 命名为：`OrderCompletionDisplayPanel`
   - 添加 `Image` 组件作为背景（可选，如果需要半透明背景）
   - 设置 `RectTransform`：
     - `Anchor Presets`: 按住 `Alt` + `Shift`，点击 `Stretch Stretch`（全屏拉伸）
     - `Left/Right/Top/Bottom`: 0（全屏）
     - `Color`: 可以设置为半透明黑色（如 `RGBA: 0, 0, 0, 150`）作为背景

2. **创建订单图片显示**：
   - 在 `OrderCompletionDisplayPanel` 下创建新的 GameObject
   - 命名为：`OrderImageDisplay`
   - 添加 `Image` 组件
   - 设置 `RectTransform`：
     - `Anchor Presets`: `Middle Center`（屏幕中央）
     - `Width`: 400（根据你的订单图片尺寸调整）
     - `Height`: 600（根据你的订单图片尺寸调整）
     - `Pos X/Pos Y`: 0（居中）
   - 设置 `Image` 组件：
     - `Image Type`: `Simple`
     - `Preserve Aspect`: ✅ 勾选（保持图片比例）

3. **创建印章图片显示**：
   - 在 `OrderCompletionDisplayPanel` 下创建新的 GameObject
   - 命名为：`StampImageDisplay`
   - 添加 `Image` 组件
   - **重要**：确保 `StampImageDisplay` 在 Hierarchy 中位于 `OrderImageDisplay` **下方**（这样印章会显示在订单图片上方）
   - 设置 `RectTransform`：
     - `Anchor Presets`: `Middle Center`（屏幕中央）
     - `Width`: 200（根据你的印章图片尺寸调整）
     - `Height`: 200（根据你的印章图片尺寸调整）
     - `Pos X/Pos Y`: 0（居中，叠在订单图片上）
   - 设置 `Image` 组件：
     - `Image Type`: `Simple`
     - `Preserve Aspect`: ✅ 勾选（保持图片比例）

### 1.3 初始隐藏所有元素

1. 选中 `OrderCompletionDisplayPanel`
2. 在 Inspector 中，**取消勾选**左上角的复选框（初始隐藏）
3. 确保 `OrderImageDisplay` 和 `StampImageDisplay` 也是隐藏的（如果面板隐藏，子对象也会隐藏）

## 步骤2：添加脚本组件

### 2.1 添加 OrderCompletionDisplay 脚本

1. **选中 `OrderCompletionDisplayPanel` GameObject**
2. 在 Inspector 中点击 `Add Component`
3. 搜索并添加 `Order Completion Display (Script)` 组件

### 2.2 配置 OrderCompletionDisplay 脚本

在 Inspector 中配置以下字段：

**UI引用**：
- `Display Panel`: 拖入 `OrderCompletionDisplayPanel` GameObject
- `Order Image Display`: 拖入 `OrderImageDisplay` GameObject（Image组件）
- `Stamp Image Display`: 拖入 `StampImageDisplay` GameObject（Image组件）

**印章图片**：
- `Stamp Sprite`: 拖入"已送达"印章图片（Sprite资源）

**动画参数**（可根据需要调整）：
- `Order Image Appear Duration`: 0.3（订单图片出现动画时长，秒）
- `Stamp Appear Delay`: 1.0（印章出现延迟，秒）
- `Stamp Appear Duration`: 0.5（印章出现动画时长，秒）
- `Display Duration`: 1.0（保持显示时长，秒）
- `Hide Duration`: 0.3（消失动画时长，秒）

**动画缓动类型**（可选，使用默认值即可）：
- `Order Image Fade Ease`: `OutQuad`
- `Stamp Appear Ease`: `OutBack`
- `Hide Ease`: `InQuad`

**调试**：
- `Enable Debug Log`: ✅ 勾选（用于调试）

## 步骤3：修改 TaskCompletionHandler 配置

### 3.1 找到 TaskCompletionHandler

1. 在 Hierarchy 中找到 `TaskCompletionHandler` GameObject（通常在场景根目录或 `UIManager` 下）
2. 选中它，查看 Inspector 中的 `Task Completion Handler (Script)` 组件

### 3.2 配置新的引用

在 Inspector 中：

**订单完成显示（已替换视频播放）**：
- `Order Completion Display`: 拖入 `OrderCompletionDisplayPanel` GameObject（刚才创建的）

**移除旧的引用**（可选）：
- `Video Player` 字段可以留空或移除（不再使用）

**其他配置保持不变**：
- `Task Manager`: 保持不变
- `Icon Manager`: 保持不变
- `Order Data Config`: 保持不变
- `Bubble Animation Delay`: 保持不变（如果需要延迟，可以调整）

## 步骤4：准备"已送达"印章图片

### 4.1 导入印章图片

1. 将"已送达"印章图片导入到 Unity 项目中
2. 确保图片格式为 PNG 或其他 Unity 支持的格式
3. 在 Project 窗口中选中图片，在 Inspector 中：
   - `Texture Type`: `Sprite (2D and UI)`
   - 点击 `Apply`

### 4.2 配置印章图片

1. 在 `OrderCompletionDisplay` 脚本的 Inspector 中
2. 将印章图片（Sprite）拖入 `Stamp Sprite` 字段

## 步骤5：测试

### 5.1 运行游戏测试

1. **运行游戏**，进入 `01_MainHub` 场景
2. **按 T 键**显示气泡（如果气泡未自动显示）
3. **按 1 键**完成任务 1
4. **观察效果**：
   - ✅ 订单图片应该立即显示（淡入动画）
   - ✅ 1秒后，"已送达"印章应该出现在订单图片上方（缩放+淡入动画）
   - ✅ 再保持1秒后，订单图片和印章应该一起消失（淡出动画）
   - ✅ 消失后，气泡应该开始播放消失动画

### 5.2 检查 Console

查看 Console 输出，应该看到：
- `TaskCompletionHandler: 检测到订单...的CompleteOrder变为true，开始处理`
- `OrderCompletionDisplay: 开始显示订单完成序列`
- `OrderCompletionDisplay: 订单图片已显示`
- `OrderCompletionDisplay: 印章已显示`
- `OrderCompletionDisplay: 订单完成序列已结束`
- `TaskCompletionHandler: 气泡消失动画完成`

## 常见问题排查

### 问题1：订单图片不显示

**可能原因**：
- `OrderCompletionDisplay` 脚本未配置 `Order Image Display` 引用
- 订单数据配置中该订单的 `orderImage` 为空
- `Display Panel` 未配置或未激活

**解决方法**：
1. 检查 `OrderCompletionDisplay` 脚本的所有引用是否已配置
2. 检查 `SphereOrderDataConfig` 中对应订单的 `Order Image` 是否已配置
3. 检查 Console 是否有错误信息

### 问题2：印章不显示

**可能原因**：
- `Stamp Sprite` 未配置
- `Stamp Image Display` 引用未配置
- 印章图片在 Hierarchy 中的顺序不对（应该在订单图片下方）

**解决方法**：
1. 检查 `Stamp Sprite` 字段是否已配置
2. 检查 `Stamp Image Display` 引用是否已配置
3. 确保 `StampImageDisplay` 在 Hierarchy 中位于 `OrderImageDisplay` 下方

### 问题3：印章没有叠在订单图片上

**可能原因**：
- Hierarchy 顺序不对
- Canvas Group 的 Sort Order 设置不对

**解决方法**：
1. 确保 `StampImageDisplay` 在 Hierarchy 中位于 `OrderImageDisplay` **下方**
2. 如果使用多个 Canvas，检查 Canvas 的 `Sort Order`（印章所在的 Canvas 应该更高）

### 问题4：动画不流畅

**可能原因**：
- DOTween 未正确导入
- 动画时长设置不合理

**解决方法**：
1. 确保 DOTween 插件已正确导入
2. 调整动画参数（`Order Image Appear Duration`、`Stamp Appear Duration`、`Hide Duration`）

### 问题5：时序不对

**可能原因**：
- 延迟时间配置不正确

**解决方法**：
1. 调整 `Stamp Appear Delay`（印章出现延迟，默认1秒）
2. 调整 `Display Duration`（保持显示时长，默认1秒）

## 配置参数说明

### OrderCompletionDisplay 参数

| 参数 | 说明 | 默认值 | 建议值 |
|------|------|--------|--------|
| `Order Image Appear Duration` | 订单图片出现动画时长（秒） | 0.3 | 0.2-0.5 |
| `Stamp Appear Delay` | 印章出现延迟（秒） | 1.0 | 0.5-2.0 |
| `Stamp Appear Duration` | 印章出现动画时长（秒） | 0.5 | 0.3-0.8 |
| `Display Duration` | 保持显示时长（秒） | 1.0 | 0.5-2.0 |
| `Hide Duration` | 消失动画时长（秒） | 0.3 | 0.2-0.5 |

### 时序说明

```
时间轴：
0.0s  ── 订单图片开始显示（淡入）
0.3s  ── 订单图片显示完成
1.0s  ── 印章开始显示（缩放+淡入）
1.5s  ── 印章显示完成
2.5s  ── 开始消失（订单和印章一起淡出）
2.8s  ── 消失完成
      ── 气泡消失动画开始
```
