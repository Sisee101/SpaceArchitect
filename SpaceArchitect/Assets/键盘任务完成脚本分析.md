# 键盘任务完成脚本分析

本文档分析如何实现键盘输入（1, 2, 3...）触发任务完成信号，以及是否需要在SphereOrderInfo中扩展。

---

## 🎯 功能需求

- 按下键盘1 → 发送任务1完成信号
- 按下键盘2 → 发送任务2完成信号
- 按下键盘3 → 发送任务3完成信号
- 依次类推...

---

## ❓ 关键问题：键盘输入和taskId的映射关系

### 方案A：键盘输入作为索引（推荐）

**映射关系**：
- 键盘1 → 第1个任务（taskId可能是0, 1, 2...任意值）
- 键盘2 → 第2个任务
- 键盘3 → 第3个任务

**实现方式**：
- 获取所有已配置任务的列表（按配置顺序）
- 键盘输入作为列表索引
- 不需要扩展SphereOrderInfo

**优点**：
- ✅ 简单直观
- ✅ 不需要扩展SphereOrderInfo
- ✅ 支持taskId不连续的情况

**缺点**：
- ⚠️ 如果任务列表顺序改变，键盘映射也会改变

---

### 方案B：键盘输入直接对应taskId

**映射关系**：
- 键盘1 → taskId=1
- 键盘2 → taskId=2
- 键盘3 → taskId=3

**实现方式**：
- 键盘输入直接作为taskId
- 不需要扩展SphereOrderInfo

**优点**：
- ✅ 简单直接
- ✅ 不需要扩展SphereOrderInfo

**缺点**：
- ⚠️ 要求taskId必须从1开始，且连续
- ⚠️ 如果taskId=0, 2, 5，键盘1无法映射

---

### 方案C：键盘输入对应taskId（从0开始）

**映射关系**：
- 键盘1 → taskId=0
- 键盘2 → taskId=1
- 键盘3 → taskId=2

**实现方式**：
- 键盘输入-1作为taskId
- 不需要扩展SphereOrderInfo

**优点**：
- ✅ 简单直接
- ✅ 不需要扩展SphereOrderInfo
- ✅ 支持taskId从0开始

**缺点**：
- ⚠️ 要求taskId必须从0开始，且连续
- ⚠️ 如果taskId=1, 2, 3，键盘1无法映射

---

## ✅ 推荐方案：方案A（索引映射）

### 理由

1. **灵活性**：支持taskId不连续的情况（如taskId=0, 2, 5）
2. **直观性**：键盘1对应第1个任务，键盘2对应第2个任务
3. **不需要扩展**：不需要在SphereOrderInfo中添加额外字段

### 实现方式

```csharp
// 获取所有已配置任务的列表（按配置顺序）
List<SphereOrderInfo> allTasks = orderDataConfig.GetAllTaskOrders();

// 键盘1 → allTasks[0].taskId
// 键盘2 → allTasks[1].taskId
// 键盘3 → allTasks[2].taskId
```

## 📐 脚本实现

### TaskInputHandler脚本

```csharp
using UnityEngine;
using System.Collections.Generic;

/// <summary>
/// 任务输入处理器
/// 检测键盘输入（1, 2, 3...），触发对应的任务完成信号
/// </summary>
public class TaskInputHandler : MonoBehaviour
{
    [Header("数据配置")]
    [SerializeField] private SphereOrderDataConfig orderDataConfig;
    
    [Header("引用")]
    [SerializeField] private TaskManager taskManager; // 任务管理器（需要创建）
    
    [Header("调试")]
    [SerializeField] private bool enableDebugLog = true;
    
    // 缓存所有任务列表（按配置顺序）
    private List<SphereOrderInfo> allTasks = new List<SphereOrderInfo>();
    
    void Start()
    {
        // 验证引用
        if (orderDataConfig == null)
        {
            Debug.LogError("TaskInputHandler: orderDataConfig未配置！");
            return;
        }
        
        if (taskManager == null)
        {
            Debug.LogError("TaskInputHandler: taskManager未配置！");
            return;
        }
        
        // 获取所有已配置任务的列表
        RefreshTaskList();
    }
    
    void Update()
    {
        // 检测键盘输入 1-9
        for (int i = 1; i <= 9; i++)
        {
            if (Input.GetKeyDown(KeyCode.Alpha0 + i)) // Alpha1 = 1, Alpha2 = 2, ...
            {
                CompleteTaskByIndex(i - 1); // 索引从0开始，所以减1
                break; // 一次只处理一个按键
            }
        }
    }
    
    /// <summary>
    /// 刷新任务列表（当数据配置改变时调用）
    /// </summary>
    public void RefreshTaskList()
    {
        if (orderDataConfig == null)
        {
            allTasks.Clear();
            return;
        }
        
        allTasks = orderDataConfig.GetAllTaskOrders();
        
        if (enableDebugLog)
        {
            Debug.Log($"TaskInputHandler: 已加载 {allTasks.Count} 个任务");
            for (int i = 0; i < allTasks.Count; i++)
            {
                Debug.Log($"  任务 {i + 1} (键盘{i + 1}): taskId={allTasks[i].taskId}, Sphere={allTasks[i].sphereName}");
            }
        }
    }
    
    /// <summary>
    /// 根据索引完成任务（键盘输入作为索引）
    /// </summary>
    /// <param name="index">任务索引（0-based）</param>
    private void CompleteTaskByIndex(int index)
    {
        if (index < 0 || index >= allTasks.Count)
        {
            if (enableDebugLog)
            {
                Debug.LogWarning($"TaskInputHandler: 索引 {index} 超出范围（共 {allTasks.Count} 个任务）");
            }
            return;
        }
        
        SphereOrderInfo taskInfo = allTasks[index];
        
        if (taskInfo == null)
        {
            Debug.LogError($"TaskInputHandler: 索引 {index} 的任务信息为空！");
            return;
        }
        
        int taskId = taskInfo.taskId;
        
        if (enableDebugLog)
        {
            Debug.Log($"TaskInputHandler: 键盘 {index + 1} 按下，完成任务 taskId={taskId}, Sphere={taskInfo.sphereName}");
        }
        
        // 通过TaskManager完成任务
        if (taskManager != null)
        {
            taskManager.CompleteTask(taskId);
        }
        else
        {
            Debug.LogError("TaskInputHandler: taskManager未配置！");
        }
    }
    
    /// <summary>
    /// 根据taskId直接完成任务（备用方法）
    /// </summary>
    /// <param name="taskId">任务ID</param>
    public void CompleteTaskById(int taskId)
    {
        if (taskManager != null)
        {
            taskManager.CompleteTask(taskId);
        }
    }
}
```

## 🔄 完整流程

```
用户按下键盘1
    ↓
TaskInputHandler检测到KeyCode.Alpha1
    ↓
CompleteTaskByIndex(0) // 索引0（键盘1对应第1个任务）
    ↓
从allTasks[0]获取任务信息
    ↓
获取taskId（可能是0, 1, 2...任意值）
    ↓
调用TaskManager.CompleteTask(taskId)
    ↓
触发任务完成事件
    ↓
TaskCompletionHandler接收事件
    ↓
播放气泡消失动画和胜利视频
```

## ❌ 不需要扩展SphereOrderInfo

### 原因

1. **已有taskId字段**：已经可以唯一标识任务
2. **索引映射足够**：通过任务列表的索引就能实现键盘映射
3. **保持简洁**：不需要添加额外的映射字段

### 如果一定要扩展（不推荐）

如果用户希望键盘输入直接对应taskId（而不是索引），可以考虑添加：

```csharp
[Header("键盘映射（可选）")]
[Tooltip("键盘输入对应的键值（如果为-1，使用列表索引）")]
public int keyboardKey = -1; // 键盘1=1, 键盘2=2, ...
```

但这种方式：
- ❌ 增加了配置复杂度
- ❌ 需要手动配置每个任务的键盘映射
- ❌ 如果taskId不连续，仍然需要索引映射

**结论**：不推荐扩展，使用索引映射更简单。

## ✅ 总结

### 答案：不需要扩展SphereOrderInfo

**理由**：
1. ✅ 已有`taskId`字段，可以唯一标识任务
2. ✅ 通过任务列表的索引可以实现键盘映射
3. ✅ 索引映射更灵活，支持taskId不连续的情况

### 实现方式

1. **创建TaskInputHandler脚本**：
   - 检测键盘输入（1-9）
   - 通过索引获取任务信息
   - 调用TaskManager完成任务

2. **使用索引映射**：
   - 键盘1 → allTasks[0]
   - 键盘2 → allTasks[1]
   - 键盘3 → allTasks[2]

3. **需要的方法**：
   - `SphereOrderDataConfig.GetAllTaskOrders()`：获取所有任务列表（按配置顺序）
