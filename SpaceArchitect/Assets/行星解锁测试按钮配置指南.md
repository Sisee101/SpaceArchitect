# 行星解锁测试按钮配置指南

## 概述

本指南将帮助您配置测试按钮，用于一键重置所有行星的解锁状态。这个功能主要用于测试，可以快速将所有13个行星的解锁状态重置为未解锁。

## 功能特性

- **一键重置**：点击按钮即可重置所有13个行星的解锁状态
- **立即更新**：重置后所有PlanetCard会立即更新显示为未解锁状态
- **持久化清除**：会清除PlayerPrefs中保存的所有解锁状态
- **事件驱动**：通过EventManager事件系统自动更新所有卡片显示

---

## 一、配置步骤

### 1.1 创建测试按钮

1. **在场景中创建Button**
   - 打开需要添加测试按钮的场景
   - 在Hierarchy中右键 → UI → Button
   - 或使用现有的Button GameObject

2. **重命名按钮（可选）**
   - 建议命名为：`TestButton_ResetAllPlanets` 或 `重置所有行星按钮`

### 1.2 添加PlanetUnlockTestButton脚本

1. **选中按钮GameObject**
   - 在Hierarchy中选中刚才创建的Button

2. **添加脚本组件**
   - 在Inspector中点击 `Add Component`
   - 搜索并添加 `PlanetUnlockTestButton` 脚本

3. **配置选项（可选）**
   - 在Inspector中找到 `Planet Unlock Test Button` 组件
   - **Show Confirmation**：是否在重置前显示确认提示
     - 勾选：重置前会在Console中显示警告信息
     - 不勾选：直接重置，无提示

### 1.3 绑定到按钮onClick事件

1. **选中按钮GameObject**
   - 确保按钮GameObject被选中

2. **找到Button组件**
   - 在Inspector中找到 `Button` 组件
   - 找到 **"On Click ()"** 事件列表

3. **添加事件**
   - 点击 **"+"** 添加新事件

4. **绑定方法**
   - 将带有 `PlanetUnlockTestButton` 脚本的GameObject拖入对象槽
   - 在下拉菜单中选择：`PlanetUnlockTestButton -> ResetAllUnlocks()`

### 1.4 配置完成检查

确保以下配置正确：
- [ ] Button GameObject已创建
- [ ] PlanetUnlockTestButton脚本已添加到Button上
- [ ] Button的onClick事件已绑定到 `ResetAllUnlocks()` 方法
- [ ] Show Confirmation选项已根据需要配置

## 二、使用方法

### 2.1 测试流程

1. **运行游戏**
   - 进入包含测试按钮的场景
   - 或进入行星图鉴场景

2. **解锁一些行星**
   - 使用解锁按钮解锁几个行星（例如：解锁索引0、1、2的行星）
   - 观察行星卡片显示为已解锁状态

3. **点击测试按钮**
   - 点击配置好的重置按钮
   - 观察Console日志，应该看到：
     - "PlanetUnlockManager: 已重置所有行星解锁状态并触发事件"
     - "PlanetUnlockTestButton: 已触发重置所有行星解锁状态"
     - 每个PlanetCard的日志："PlanetCard: 索引 X 已响应重置事件，当前状态: 未解锁"

4. **验证结果**
   - 所有行星卡片应该立即切换为未解锁图片
   - 点击未解锁的卡片，应该无法展开详情
   - 关闭游戏后重新打开，所有行星应该仍然是未解锁状态

### 2.2 在代码中调用（可选）

如果需要在代码中直接调用重置功能：

```csharp
using UnityEngine;

public class MyScript : MonoBehaviour
{
    void Start()
    {
        // 直接调用重置方法
        PlanetUnlockManager.ResetAllUnlocks();
    }
}
```

## 三、工作原理

### 3.1 数据流

```
[测试按钮点击]
    ↓
[PlanetUnlockTestButton.ResetAllUnlocks()]
    ↓
[PlanetUnlockManager.ResetAllUnlocks()]
    ↓
[清除所有解锁状态，删除PlayerPrefs]
    ↓
[EventManager.TriggerAllPlanetsReset()]
    ↓
[EventManager.OnAllPlanetsReset事件触发]
    ↓
[所有PlanetCard监听事件]
    ↓
[PlanetCard.OnAllPlanetsReset()重新查询状态]
    ↓
[PlanetCard.SetUnlockState(false)]
    ↓
[所有卡片立即更新为未解锁图片]
```

### 3.2 关键组件

1. **PlanetUnlockTestButton**
   - 提供 `ResetAllUnlocks()` 公共方法
   - 可以拖拽到按钮的onClick事件上

2. **PlanetUnlockManager**
   - `ResetAllUnlocks()` 静态方法
   - 清除所有解锁状态
   - 触发 `OnAllPlanetsReset` 事件

3. **EventManager**
   - `OnAllPlanetsReset` 事件
   - 通知所有订阅者重置已完成

4. **PlanetCard**
   - 订阅 `OnAllPlanetsReset` 事件
   - 重置时重新查询自己的解锁状态
   - 自动更新显示

## 四、注意事项

### 4.1 测试用途

- **此按钮主要用于测试**，发布版本可以考虑：
  - 移除按钮
  - 隐藏按钮（设置 `SetActive(false)`）
  - 添加条件判断（例如：只在Debug模式下显示）

### 4.2 数据清除

- 重置会**永久清除**所有解锁状态
- 包括PlayerPrefs中保存的数据
- 重置后无法恢复，除非重新解锁

### 4.3 事件订阅

- PlanetCard需要在激活状态（OnEnable）才能接收到重置事件
- 如果图鉴面板未打开，卡片可能不会立即更新
- 打开图鉴面板时，卡片会从PlanetUnlockManager查询最新状态

### 4.4 性能考虑

- 重置操作会触发13个PlanetCard的更新
- 如果图鉴面板未打开，不会有性能影响
- 如果图鉴面板已打开，所有卡片会同时更新，但操作很轻量

## 五、常见问题排查

### 5.1 点击按钮没有反应

**可能原因**：
- 按钮onClick事件未正确绑定
- PlanetUnlockTestButton脚本未添加到GameObject上

**解决方法**：
1. 检查Button的onClick事件是否正确绑定到 `ResetAllUnlocks()` 方法
2. 确认GameObject上有 `PlanetUnlockTestButton` 组件
3. 查看Console中是否有错误信息

### 5.2 重置后卡片不更新

**可能原因**：
- EventManager实例不存在
- PlanetCard未正确订阅事件
- 图鉴面板未打开（卡片未激活）

**解决方法**：
1. 确认场景中有EventManager（会自动创建）
2. 检查Console中是否有错误信息
3. 确保图鉴面板已打开，卡片处于激活状态
4. 如果图鉴面板未打开，打开后卡片会自动显示正确状态

### 5.3 重置后状态不持久

**可能原因**：
- PlayerPrefs保存失败
- 游戏没有正常退出

**解决方法**：
1. 确保游戏正常退出（不要直接关闭窗口）
2. 检查Console中是否有保存相关的错误信息
3. 使用PlanetUnlockManager的调试功能查看状态

## 六、扩展建议

如果需要扩展功能，可以考虑：

1. **确认对话框**
   - 添加UI确认对话框，防止误操作
   - 使用Unity的Dialog系统或自定义UI

2. **部分重置**
   - 添加功能，只重置指定范围的行星
   - 例如：只重置索引0-5的行星

3. **重置动画**
   - 在重置时添加动画效果
   - 例如：卡片闪烁或渐变动画

4. **重置音效**
   - 在重置时播放提示音
   - 在 `PlanetUnlockTestButton.ResetAllUnlocks()` 中添加音效播放

5. **条件重置**
   - 添加条件判断，只在特定情况下允许重置
   - 例如：只在Debug模式下或特定场景中
