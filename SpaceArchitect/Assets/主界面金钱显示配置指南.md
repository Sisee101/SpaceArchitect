# 主界面金钱显示配置指南

## 📋 功能概述

本指南说明如何在主界面（MainHubPanel）上显示 MoneyManager 的金钱数值，并实现实时更新。

---

## 🎯 实现内容

- 在主界面面板上添加文字显示金钱数值
- 支持 Unity UI Text 和 TextMeshPro 两种文本组件
- 自动检测金钱变化并实时更新显示
- 从子面板返回主界面时自动刷新显示

---

## 📐 配置步骤

### 第一步：在 MainHubPanel 中添加文字组件

#### 方式A：使用 Unity UI Text（推荐用于简单显示）

1. **选中 MainHubPanel GameObject**
   - 在 Hierarchy 中找到 `MainHubPanel` GameObject
   - 选中它

2. **添加 Text 组件**
   - 在 Inspector 中点击 **Add Component**
   - 搜索 `Text`
   - 选择 **UI → Text** 并添加

3. **配置 Text 组件**
   - **Text**：可以暂时留空或输入 "0"（会在运行时自动更新）
   - **Font**：选择你喜欢的字体
   - **Font Size**：设置字体大小（建议 24-36）
   - **Color**：设置文字颜色（建议白色或黄色）
   - **Alignment**：设置对齐方式（建议左上或右上）

4. **设置位置**
   - 使用 RectTransform 工具（快捷键 T）调整位置
   - 建议放在右上角或顶部中央
   - 设置合适的 Anchors 和 Pivot

---

#### 方式B：使用 TextMeshPro（推荐用于更好的视觉效果）

1. **选中 MainHubPanel GameObject**

2. **添加 TextMeshPro 组件**
   - 在 Inspector 中点击 **Add Component**
   - 搜索 `TextMeshPro`
   - 选择 **UI → TextMeshPro - Text (UI)** 并添加
   - 如果是第一次使用，Unity 会提示导入 TMP Essentials，点击 **Import TMP Essentials**

3. **配置 TextMeshPro 组件**
   - **Text**：可以暂时留空或输入 "0"
   - **Font Asset**：选择或创建字体资源
   - **Font Size**：设置字体大小
   - **Color**：设置文字颜色
   - **Alignment**：设置对齐方式

4. **设置位置**
   - 使用 RectTransform 工具调整位置
   - 建议放在右上角或顶部中央

---

### 第二步：在 MainHubController 中配置引用

1. **选中包含 MainHubController 的 GameObject**
   - 在 Hierarchy 中找到包含 `MainHubController` 脚本的 GameObject
   - 选中它

2. **配置金钱显示引用**
   - 在 Inspector 中找到 `MainHubController` 组件
   - 展开 **Money Display** 部分
   - 根据你使用的文本组件类型：
     - **如果使用 Unity UI Text**：将 Text 组件拖拽到 `Money Text` 字段
     - **如果使用 TextMeshPro**：将 TextMeshPro 组件拖拽到 `Money Text Mesh Pro` 字段
     - 也可以两个都配置，系统会同时更新两个组件

3. **配置更新选项**
   - **Enable Real Time Update**：勾选后会在每帧检测金钱变化并更新（推荐）
   - 如果不勾选，只在初始化时和返回主界面时更新

---

### 第三步：验证配置

1. **检查配置完整性**
   - [ ] MainHubPanel 上已添加 Text 或 TextMeshPro 组件
   - [ ] MainHubController 中已配置对应的文本组件引用
   - [ ] 文本组件的位置和样式已设置好

2. **运行测试**
   - 运行场景
   - 检查主界面是否显示金钱数值（应该显示 `MoneyManager.money` 的初始值，默认是 20000）
   - 如果金钱值发生变化（例如在技能解锁系统中），检查显示是否自动更新

---

## 🔧 高级配置

### 自定义显示格式

如果需要自定义显示格式（如添加货币符号、千位分隔符等），可以修改 `MainHubController.cs` 中的 `UpdateMoneyDisplay()` 方法：

```csharp
public void UpdateMoneyDisplay()
{
    // 示例1：添加货币符号
    string moneyString = "$" + MoneyManager.money.ToString();
    
    // 示例2：添加千位分隔符
    string moneyString = MoneyManager.money.ToString("N0"); // 输出：20,000
    
    // 示例3：组合格式
    string moneyString = "$" + MoneyManager.money.ToString("N0");
    
    // 更新文本
    if (moneyText != null)
    {
        moneyText.text = moneyString;
    }
    
    if (moneyTextMeshPro != null)
    {
        moneyTextMeshPro.text = moneyString;
    }
}
```

### 手动更新显示

如果需要手动触发更新（例如在特定事件后），可以调用：

```csharp
MainHubController controller = FindObjectOfType<MainHubController>();
if (controller != null)
{
    controller.UpdateMoneyDisplay();
}
```

## ⚠️ 注意事项

### 1. 文本组件选择

- **Unity UI Text**：简单易用，但性能稍差，字体效果有限
- **TextMeshPro**：性能更好，字体效果更丰富，但需要额外的字体资源

### 2. 性能考虑

- 如果启用了 `Enable Real Time Update`，系统会在每帧检测金钱变化
- 由于只是简单的整数比较，性能影响很小
- 如果不需要实时更新，可以取消勾选，只在必要时手动调用 `UpdateMoneyDisplay()`

### 3. 自动查找功能

- 如果未在 Inspector 中配置文本组件引用，系统会尝试自动查找
- 自动查找会搜索当前 GameObject 及其子对象中的 Text 或 TextMeshPro 组件
- **建议**：手动配置引用，避免自动查找可能找到错误的组件

### 4. 多个文本组件

- 可以同时配置 Text 和 TextMeshPro 两个组件
- 系统会同时更新两个组件（如果都配置了）
- 通常只需要配置一个即可

## 🐛 常见问题

### 问题1：金钱显示为空白或 "0"

**可能原因**：
1. 文本组件引用未配置
2. MoneyManager 未初始化
3. 文本组件的 Text 字段被清空

**解决方法**：
1. 检查 Inspector 中的文本组件引用是否配置
2. 确认场景中有 MoneyManager GameObject
3. 检查文本组件的 Text 字段

---

### 问题2：金钱显示不更新

**可能原因**：
1. `Enable Real Time Update` 未勾选
2. 文本组件引用配置错误
3. MoneyManager.money 值未变化

**解决方法**：
1. 勾选 `Enable Real Time Update`
2. 检查文本组件引用是否正确
3. 在 Console 中检查 MoneyManager.money 的值是否真的变化了

---

### 问题3：显示位置不对

**解决方法**：
1. 选中文本组件 GameObject
2. 使用 RectTransform 工具（快捷键 T）调整位置
3. 设置合适的 Anchors 和 Pivot
4. 调整 Pos X 和 Pos Y 值

---

### 问题4：文字样式不理想

**解决方法**：
1. 在 Inspector 中调整 Text 或 TextMeshPro 组件的样式设置
2. 调整 Font Size、Color、Alignment 等属性
3. 如果使用 TextMeshPro，可以创建自定义 Font Asset 以获得更好的效果

---
