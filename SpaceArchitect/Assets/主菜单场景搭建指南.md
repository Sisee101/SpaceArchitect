# 主菜单场景搭建指南

本指南将详细说明如何在Unity编辑器中搭建主菜单场景的基础结构。

## 前置准备

确保以下脚本已创建：
- ✅ `SceneTransitionManager.cs` (Scripts/Core/) - 场景切换管理器
- ✅ `UIManager.cs` (Scripts/UI/) - UI管理器
- ✅ `MainMenuPanel.cs` (Scripts/UI/) - 主菜单面板
- ✅ `SettingsPanel.cs` (Scripts/UI/) - 设置面板
- ✅ `PlanetEncyclopediaPanel.cs` (Scripts/UI/) - 行星图鉴面板

> **注意**：本指南只涵盖主菜单场景（00_MainMenu）的搭建。  
> 游戏场景（scene02）中的暂停功能请参考：**`游戏暂停功能搭建指南.md`**

---

## 第一步：创建主菜单场景

1. 在Unity编辑器中，点击 `File` → `New Scene`
2. 选择 `Basic (Built-in)` 或 `URP` 模板（根据项目设置）
3. 保存场景：
   - 点击 `File` → `Save As...`
   - 保存到 `Assets/Scenes/00_MainMenu.unity`

---

## 第二步：创建Canvas和基础UI结构

### 2.1 创建Canvas

1. 在 `Hierarchy` 中右键 → `UI` → `Canvas`
2. 重命名为 `MainMenuCanvas`
3. 在 `Canvas` 组件中：
   - `Render Mode`: `Screen Space - Overlay`（默认）
   - `Canvas Scaler` → `UI Scale Mode`: `Scale With Screen Size`
   - `Reference Resolution`: `1920 x 1080`

### 2.2 创建EventSystem（如果不存在）

1. 检查 `Hierarchy` 中是否有 `EventSystem`
2. 如果没有，Unity会自动创建（创建Canvas时会自动创建）

---

## 第三步：创建主菜单面板（MainMenuPanel）

### 3.1 创建主菜单面板容器

1. 在 `MainMenuCanvas` 下右键 → `UI` → `Panel`
2. 重命名为 `MainMenuPanel`
3. 添加组件：`MainMenuPanel` 脚本

### 3.2 创建标题（可选）

1. 在 `MainMenuPanel` 下右键 → `UI` → `Text`
2. 重命名为 `TitleText`
3. 设置文本内容：`Space Architect`（或你的游戏名称）
4. 调整位置和大小（建议在顶部居中）

### 3.3 创建按钮容器

1. 在 `MainMenuPanel` 下右键 → `Create Empty`
2. 重命名为 `ButtonsContainer`
3. 添加组件：`Vertical Layout Group`
   - `Spacing`: `20`
   - `Child Alignment`: `Middle Center`
   - `Child Force Expand`: 取消勾选 Width 和 Height

### 3.4 创建四个按钮

在 `ButtonsContainer` 下创建四个按钮：

#### 按钮1：开始游戏

1. 右键 `ButtonsContainer` → `UI` → `Button`
2. 重命名为 `StartGameButton`
3. 在 `Button` 组件中：
   - 点击 `OnClick()` 下方的 `+` 添加事件（脚本会自动绑定，这里先留空）
4. 修改按钮文本：
   - 选中 `StartGameButton` 下的 `Text`
   - 修改文本为：`开始游戏`

#### 按钮2：行星图鉴

1. 右键 `ButtonsContainer` → `UI` → `Button`
2. 重命名为 `PlanetEncyclopediaButton`
3. 修改按钮文本为：`行星图鉴`

#### 按钮3：设置

1. 右键 `ButtonsContainer` → `UI` → `Button`
2. 重命名为 `SettingsButton`
3. 修改按钮文本为：`设置`

#### 按钮4：退出

1. 右键 `ButtonsContainer` → `UI` → `Button`
2. 重命名为 `QuitButton`
3. 修改按钮文本为：`退出`

### 3.5 配置MainMenuPanel脚本

1. 选中 `MainMenuPanel` GameObject
2. 在 `Inspector` 中找到 `MainMenuPanel` 组件
3. 将按钮拖拽到对应字段：
   - `Start Game Button` → 拖入 `StartGameButton`
   - `Planet Encyclopedia Button` → 拖入 `PlanetEncyclopediaButton`
   - `Settings Button` → 拖入 `SettingsButton`
   - `Quit Button` → 拖入 `QuitButton`

---

## 第四步：创建行星图鉴面板（PlanetEncyclopediaPanel）

### 4.1 创建图鉴面板容器

1. 在 `MainMenuCanvas` 下右键 → `UI` → `Panel`
2. 重命名为 `PlanetEncyclopediaPanel`
3. 添加组件：`PlanetEncyclopediaPanel` 脚本
4. **重要**：默认隐藏此面板
   - 在 `Inspector` 中取消勾选 `Active`（或代码中会自动处理）

### 4.2 创建顶部栏

1. 在 `PlanetEncyclopediaPanel` 下右键 → `UI` → `Panel`
2. 重命名为 `TopBar`
3. 调整位置到顶部

#### 创建返回按钮

1. 在 `TopBar` 下右键 → `UI` → `Button`
2. 重命名为 `BackButton`
3. 修改按钮文本为：`返回` 或 `Back`
4. 调整位置到左上角

### 4.3 创建占位文本（临时）

1. 在 `PlanetEncyclopediaPanel` 下右键 → `UI` → `Text`
2. 重命名为 `PlaceholderText`
3. 设置文本：`行星图鉴功能开发中...`
4. 调整位置到中心

### 4.4 配置PlanetEncyclopediaPanel脚本

1. 选中 `PlanetEncyclopediaPanel` GameObject
2. 在 `Inspector` 中找到 `PlanetEncyclopediaPanel` 组件
3. 将UI元素拖拽到对应字段：
   - `Back Button` → 拖入 `BackButton`
   - `Placeholder Text` → 拖入 `PlaceholderText`

---

## 第五步：创建设置面板（SettingsPanel）

### 5.1 创建设置面板容器

1. 在 `MainMenuCanvas` 下右键 → `UI` → `Panel`
2. 重命名为 `SettingsPanel`
3. 添加组件：`SettingsPanel` 脚本
4. **重要**：默认隐藏此面板

### 5.2 创建顶部栏和返回按钮

1. 在 `SettingsPanel` 下右键 → `UI` → `Panel`
2. 重命名为 `TopBar`
3. 在 `TopBar` 下创建返回按钮（参考图鉴面板的步骤）

### 5.3 创建设置内容区域

1. 在 `SettingsPanel` 下右键 → `Create Empty`
2. 重命名为 `SettingsContent`
3. 添加组件：`Vertical Layout Group`
   - `Spacing`: `30`
   - `Child Alignment`: `Upper Center`

#### 创建BGM音量控制

1. 在 `SettingsContent` 下右键 → `Create Empty`
2. 重命名为 `BGMVolumeControl`
3. 添加组件：`Horizontal Layout Group`
   - `Spacing`: `10`
   - `Child Alignment`: `Middle Left`

4. 在 `BGMVolumeControl` 下创建：
   - `Text`：文本为 `BGM音量`
   - `Slider`：重命名为 `BGMVolumeSlider`
   - `Text`：重命名为 `BGMVolumeText`，文本为 `70%`

#### 创建SFX音量控制

1. 复制 `BGMVolumeControl`，重命名为 `SFXVolumeControl`
2. 修改文本为 `SFX音量`
3. 重命名Slider为 `SFXVolumeSlider`
4. 重命名Text为 `SFXVolumeText`

### 5.4 配置SettingsPanel脚本

1. 选中 `SettingsPanel` GameObject
2. 在 `Inspector` 中找到 `SettingsPanel` 组件
3. 将UI元素拖拽到对应字段：
   - `Back Button` → 拖入返回按钮
   - `BGM Volume Slider` → 拖入 `BGMVolumeSlider`
   - `SFX Volume Slider` → 拖入 `SFXVolumeSlider`
   - `BGM Volume Text` → 拖入 `BGMVolumeText`
   - `SFX Volume Text` → 拖入 `SFXVolumeText`

---

## 第六步：创建管理器对象

### 6.1 创建SceneTransitionManager

1. 在 `Hierarchy` 中右键 → `Create Empty`
2. 重命名为 `SceneTransitionManager`
3. 添加组件：`SceneTransitionManager` 脚本
4. **重要**：此对象会自动设置为 `DontDestroyOnLoad`

### 6.2 创建UIManager

1. 在 `Hierarchy` 中右键 → `Create Empty`
2. 重命名为 `UIManager`
3. 添加组件：`UIManager` 脚本

### 6.3 配置UIManager脚本

1. 选中 `UIManager` GameObject
2. 在 `Inspector` 中找到 `UIManager` 组件
3. 将面板拖拽到对应字段：
   - `Main Menu Panel` → 拖入 `MainMenuPanel`
   - `Planet Encyclopedia Panel` → 拖入 `PlanetEncyclopediaPanel`
   - `Settings Panel` → 拖入 `SettingsPanel`

---

## 第七步：配置场景构建设置

1. 点击 `File` → `Build Settings...`
2. 点击 `Add Open Scenes` 添加当前场景
3. 确保 `00_MainMenu.unity` 在索引 0 的位置（作为启动场景）
4. 如果 `02_Gameplay.unity` 不在列表中，也添加它

---

## 第八步：测试场景

### 8.1 运行测试

1. 点击 Unity 编辑器顶部的 `Play` 按钮
2. 测试以下功能：
   - ✅ 主菜单显示正常
   - ✅ 点击"开始游戏"按钮（会尝试加载游戏场景，如果场景不存在会报错，这是正常的）
   - ✅ 点击"行星图鉴"按钮 → 应该显示图鉴面板
   - ✅ 在图鉴面板点击"返回" → 应该返回主菜单
   - ✅ 点击"设置"按钮 → 应该显示设置面板
   - ✅ 在设置面板调整音量滑块 → 应该更新百分比文本
   - ✅ 在设置面板点击"返回" → 应该返回主菜单
   - ✅ 点击"退出"按钮 → 在编辑器中会停止播放，在构建版本中会退出游戏

### 8.2 常见问题

**问题1：按钮点击没有反应**
- 检查按钮是否正确拖拽到脚本的字段中
- 检查Console是否有错误信息

**问题2：面板切换不正常**
- 检查UIManager是否正确配置了所有面板引用
- 检查面板的初始状态（主菜单显示，其他隐藏）

**问题3：场景切换失败**
- 确保 `scene02.unity` 场景存在
- 确保场景名称正确（`00_MainMenu` 和 `scene02`）
- 确保场景已添加到 Build Settings 中

