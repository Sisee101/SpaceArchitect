# 行星图鉴卡片不显示排查指南

## 问题：卡片已创建但不显示在画面上

### 可能原因和解决方法

#### 1. Content 的宽度不够

**现象**：卡片创建了，但因为Content宽度太小，所有卡片重叠在一起或者都在Viewport外面

**解决方法**：
1. 选中 `Content` GameObject（`ScrollView/Viewport/Content`）
2. 在 Inspector 中检查 Rect Transform：
   - 如果使用 `Content Size Fitter`：确保 `Horizontal Fit` 设置为 `Preferred Size`
   - 如果没有 `Content Size Fitter`：手动设置一个足够大的 `Width`
     - 计算公式：`卡片数量(13) × 卡片宽度(400) + 间距(20) × (13-1) + 左右Padding(40) = 5560`
     - 或者设置为一个更大的值，如 `6000` 或 `7000`

3. **推荐方法**：添加 `Content Size Fitter` 组件：
   - 选中 `Content` GameObject
   - `Add Component` → 搜索 `Content Size Fitter` → 添加组件
   - 设置 `Horizontal Fit` = `Preferred Size`
   - 设置 `Vertical Fit` = `Unconstrained`
   - 这样Content的宽度会根据子对象（卡片）自动调整

#### 2. Horizontal Layout Group 配置问题

**检查**：
1. 选中 `Content` GameObject
2. 在 Inspector 中检查 `Horizontal Layout Group` 组件：
   - `Child Control Width`：✅ 已勾选
   - `Child Control Height`：✅ 已勾选
   - `Child Force Expand Width`：❌ 未勾选
   - `Child Force Expand Height`：❌ 未勾选
   - `Spacing`：设置为 `20`（或你设置的间距值）

#### 3. 卡片重叠在一起

**可能原因**：
- LayoutElement 的 Preferred Width/Height 未设置
- Horizontal Layout Group 未正确配置

**解决方法**：
1. 打开 `PlanetCard.prefab` 预制体
2. 检查 `LayoutElement` 组件：
   - `Preferred Width` = 400（与你的设置一致）
   - `Preferred Height` = 500（与你的设置一致）
3. 确保预制体已保存

#### 4. 卡片都在Viewport外面

**现象**：卡片创建了，但因为Content的位置不对，所有卡片都在Viewport的可见区域外

**检查**：
1. 选中 `Content` GameObject
2. 在 Inspector 中检查 Rect Transform：
   - `Anchor`：应该设置为 `Left Middle`（左侧中间）
   - `Pos X`：应该设置为 `0` 或接近 `0`
   - `Pos Y`：应该设置为 `0`（垂直居中）

#### 5. 场景中仍有手动创建的测试卡片

**问题**：如果场景中还有手动创建的测试卡片（不是在Content下的），可能会干扰布局

**解决方法**：
1. 在 Hierarchy 中检查 `Content` 下的所有子对象
2. 删除所有不是通过代码创建的测试卡片
3. 只保留代码动态创建的卡片（名称会包含 `(Clone)`）

### 调试步骤

1. **运行游戏**，打开 Console 窗口

2. **打开行星图鉴面板**，查看 Console：
   - 应该看到："PlanetEncyclopediaPanel: 开始初始化 13 张卡片"
   - 应该看到："PlanetEncyclopediaPanel: 成功创建 13 张卡片"
   - 应该看到："PlanetEncyclopediaPanel: 设置Content宽度为 XXXX"

3. **在 Hierarchy 中检查**：
   - 展开 `Content` GameObject
   - 应该看到13个 `PlanetCard (Clone)` 子对象
   - 如果只有1-2个，说明图片列表配置不足

4. **在 Scene 视图中检查**：
   - 选中 `Content` GameObject
   - 查看它的边框（应该是一个很宽的矩形）
   - 如果Content很窄，说明宽度设置不对
   - 检查卡片是否都在Content范围内

5. **检查 ScrollView**：
   - 选中 `ScrollView` GameObject
   - 在 Inspector 中检查 `Scroll Rect` 组件
   - 确保 `Content` 引用已配置
   - 尝试手动拖拽ScrollView，看看是否能滚动到卡片位置

### 快速修复方法

如果上述方法都不行，尝试以下步骤：

1. **添加 Content Size Fitter**（推荐）：
   ```
   选中 Content
   → Add Component
   → Content Size Fitter
   → Horizontal Fit: Preferred Size
   → Vertical Fit: Unconstrained
   ```

2. **手动设置 Content 宽度**（如果不用 Content Size Fitter）：
   ```
   选中 Content
   → Rect Transform
   → Width: 6000（足够大的值）
   ```

3. **强制刷新布局**（代码已自动处理）：
   - 代码已经在创建卡片后调用 `LayoutRebuilder.ForceRebuildLayoutImmediate`
   - 如果还是不行，检查是否有其他问题

### 检查清单

- ✅ Content 有 `Horizontal Layout Group` 组件
- ✅ Content 的 `Horizontal Layout Group` 配置正确
- ✅ Content 的宽度足够大（或使用 Content Size Fitter）
- ✅ Content 的锚点设置为 `Left Middle`
- ✅ Content 的 `Pos X` = 0, `Pos Y` = 0
- ✅ PlanetCard 预制体有 `LayoutElement` 组件
- ✅ PlanetCard 的 `LayoutElement.Preferred Width` = 400
- ✅ PlanetCard 的 `LayoutElement.Preferred Height` = 500
- ✅ 场景中没有手动创建的测试卡片（只有代码创建的 `(Clone)` 对象）
- ✅ Console 显示创建了13张卡片

### 如果仍然不显示

1. **检查 Console 是否有错误信息**
2. **在 Hierarchy 中查看卡片数量**：展开Content，数一数有几个 `PlanetCard (Clone)`
3. **在 Scene 视图中查看**：选中Content，看看它的尺寸和位置
4. **尝试手动滚动 ScrollView**：在Scene视图中，尝试移动Content的位置，看看卡片是否出现
