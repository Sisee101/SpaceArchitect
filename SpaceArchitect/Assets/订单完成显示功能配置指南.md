# 订单完成显示功能配置指南

## 概述

本指南说明在UI搭建完成后，如何配置脚本引用和参数，使订单完成显示功能正常工作。

## 前置条件

- ✅ UI结构已创建完成（`OrderCompletionDisplayPanel`、`OrderImageDisplay`、`StampImageDisplay`）
- ✅ 所有UI元素初始隐藏
- ✅ "已送达"印章图片已导入到项目中

## 配置步骤

### 步骤1：配置 OrderCompletionDisplay 脚本

#### 1.1 找到 OrderCompletionDisplayPanel

1. 在 Unity 中打开 `01_MainHub` 场景
2. 在 Hierarchy 中找到 `MainHubCanvas` → `OrderCompletionDisplayPanel`
3. 选中 `OrderCompletionDisplayPanel` GameObject

#### 1.2 添加脚本组件

1. 在 Inspector 中点击 `Add Component`
2. 搜索 `Order Completion Display`
3. 点击添加 `Order Completion Display (Script)` 组件

#### 1.3 配置 UI 引用

在 Inspector 的 `Order Completion Display (Script)` 组件中，展开各个部分：

**UI引用**：
1. `Display Panel`：
   - 将 `OrderCompletionDisplayPanel` GameObject 拖入此字段
   - 或者点击右侧的圆形图标，选择 `OrderCompletionDisplayPanel`

2. `Order Image Display`：
   - 将 `OrderImageDisplay` GameObject 拖入此字段
   - 或者点击右侧的圆形图标，选择 `OrderImageDisplay`

3. `Stamp Image Display`：
   - 将 `StampImageDisplay` GameObject 拖入此字段
   - 或者点击右侧的圆形图标，选择 `StampImageDisplay`

**印章图片**：
1. `Stamp Sprite`：
   - 在 Project 窗口中找到"已送达"印章图片（Sprite资源）
   - 将图片拖入此字段
   - 或者点击右侧的圆形图标，选择对应的 Sprite

#### 1.4 配置动画参数（可选，使用默认值即可）

**动画参数**：
- `Order Image Appear Duration`: `0.3`（订单图片出现动画时长，秒）
- `Stamp Appear Delay`: `1.0`（印章出现延迟，秒）
- `Stamp Appear Duration`: `0.5`（印章出现动画时长，秒）
- `Display Duration`: `1.0`（保持显示时长，秒）
- `Hide Duration`: `0.3`（消失动画时长，秒）

**动画缓动类型**（可选，使用默认值即可）：
- `Order Image Fade Ease`: `OutQuad`
- `Stamp Appear Ease`: `OutBack`
- `Hide Ease`: `InQuad`

**调试**：
- `Enable Debug Log`: ✅ **勾选**（用于调试，可以看到详细日志）

### 步骤2：配置 TaskCompletionHandler 脚本

#### 2.1 找到 TaskCompletionHandler

1. 在 Hierarchy 中找到 `TaskCompletionHandler` GameObject
   - 可能在场景根目录
   - 或者在 `UIManager` 下
   - 或者在 `MainHubCanvas` 下

2. 选中 `TaskCompletionHandler` GameObject

#### 2.2 配置 OrderCompletionDisplay 引用

在 Inspector 的 `Task Completion Handler (Script)` 组件中：

**订单完成显示（已替换视频播放）**：
1. `Order Completion Display`：
   - 将 `OrderCompletionDisplayPanel` GameObject 拖入此字段
   - 或者点击右侧的圆形图标，选择 `OrderCompletionDisplayPanel`

#### 2.3 检查其他引用（应该已经配置好）

确保以下引用已配置：
- `Task Manager`: 应该已配置
- `Icon Manager`: 应该已配置（`SphereIconManager`）
- `Order Data Config`: 应该已配置（`SphereOrderDataConfig` ScriptableObject）

**注意**：`Video Player` 字段可以留空（不再使用）

### 步骤3：验证配置

#### 3.1 检查 OrderCompletionDisplay 配置

在 `OrderCompletionDisplayPanel` 的 Inspector 中，确认：
- ✅ `Display Panel` 已配置（显示 `OrderCompletionDisplayPanel`）
- ✅ `Order Image Display` 已配置（显示 `OrderImageDisplay`）
- ✅ `Stamp Image Display` 已配置（显示 `StampImageDisplay`）
- ✅ `Stamp Sprite` 已配置（显示印章图片名称）

#### 3.2 检查 TaskCompletionHandler 配置

在 `TaskCompletionHandler` 的 Inspector 中，确认：
- ✅ `Order Completion Display` 已配置（显示 `OrderCompletionDisplayPanel`）
- ✅ `Task Manager` 已配置
- ✅ `Icon Manager` 已配置
- ✅ `Order Data Config` 已配置

#### 3.3 检查订单数据配置

1. 在 Project 窗口中找到 `SphereOrderDataConfig` ScriptableObject 资源
2. 选中它，在 Inspector 中查看 `Order Data List`
3. 确保每个订单的 `Order Image` 字段都已配置：
   - 找到 `taskId = 0` 的订单，检查 `Order Image` 是否已配置
   - 找到 `taskId = 1` 的订单，检查 `Order Image` 是否已配置
   - 找到 `taskId = 2` 的订单，检查 `Order Image` 是否已配置

## 常见配置问题

### 问题1：OrderCompletionDisplay 显示 "未配置" 警告

**原因**：引用字段未配置

**解决方法**：
1. 检查 `Display Panel`、`Order Image Display`、`Stamp Image Display` 是否都已配置
2. 确保拖入的是正确的 GameObject

### 问题2：印章不显示

**原因**：`Stamp Sprite` 未配置

**解决方法**：
1. 检查 `Stamp Sprite` 字段是否已配置
2. 确保图片的 `Texture Type` 设置为 `Sprite (2D and UI)`

### 问题3：订单图片显示错误

**原因**：订单数据配置中的 `Order Image` 未配置或配置错误

**解决方法**：
1. 检查 `SphereOrderDataConfig` 中对应订单的 `Order Image` 是否已配置
2. 确保图片的 `Texture Type` 设置为 `Sprite (2D and UI)`

### 问题4：显示的是错误的订单图片

**原因**：订单的 `taskId` 与按键不对应

**解决方法**：
1. 检查 `SphereOrderDataConfig` 中订单的 `Task Id` 是否正确
2. 按键1对应 `taskId=0`（第一个任务）
3. 按键2对应 `taskId=1`（第二个任务）
4. 按键3对应 `taskId=2`（第三个任务）

## 快速配置检查

运行以下检查，确保配置正确：

1. **选中 `OrderCompletionDisplayPanel`**：
   - Inspector 中 `Order Completion Display (Script)` 组件
   - 所有 `UI引用` 字段都不应为 `None`
   - `Stamp Sprite` 不应为 `None`

2. **选中 `TaskCompletionHandler`**：
   - Inspector 中 `Task Completion Handler (Script)` 组件
   - `Order Completion Display` 不应为 `None`
   - 其他引用字段都不应为 `None`

3. **选中 `SphereOrderDataConfig` ScriptableObject**：
   - Inspector 中 `Order Data List`
   - 每个订单的 `Order Image` 都不应为 `None`

完成以上配置后，订单完成显示功能就可以正常工作了！
