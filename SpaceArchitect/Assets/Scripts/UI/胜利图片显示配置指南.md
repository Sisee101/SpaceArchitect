# 胜利图片显示配置指南

## 概述

本指南将帮助您配置任务完成后的胜利图片+印章显示功能。该功能会在玩家按下按键1、2、3完成任务后，显示订单图片，0.5秒后显示印章，2秒后同时消失，然后播放气泡消失动画。

## 功能流程

1. 按键检测：TaskInputHandler 检测按键1、2、3
2. 任务完成：调用 TaskManager.CompleteTask()
3. 流程协调：TaskCompletionHandler 监听完成事件
4. 显示图片：使用 orderImage，立即显示（淡入动画）
5. 显示印章：0.5秒后显示印章图片，盖在图片上方（缩放+淡入动画）
6. 同时消失：2秒后图片和印章同时消失（淡出动画）
7. 气泡消失：调用 SphereIconManager.HideIconForSphere() 播放消失动画

## 配置步骤

### 步骤1：创建 VictoryImageDisplay GameObject

1. 在场景中创建一个新的 GameObject，命名为 `VictoryImageDisplay`
2. 添加 `VictoryImageDisplay` 脚本组件

### 步骤2：配置 UI 结构

#### 2.1 创建显示面板

1. 在 `VictoryImageDisplay` GameObject 下创建一个子对象，命名为 `DisplayPanel`
2. 添加 `RectTransform` 组件（如果使用 Canvas）
3. 设置合适的尺寸和位置（建议覆盖整个屏幕或居中显示）

#### 2.2 创建图片显示组件

1. 在 `DisplayPanel` 下创建一个子对象，命名为 `ImageDisplay`
2. 添加 `Image` 组件（Unity UI）
3. 设置 `Image` 的 `RectTransform`：
   - 设置合适的尺寸（建议与订单图片尺寸一致）
   - 设置锚点（建议居中）
   - 设置位置（建议 (0, 0, 0)）

#### 2.3 创建印章显示组件

1. 在 `DisplayPanel` 下创建一个子对象，命名为 `StampImageDisplay`
2. 添加 `Image` 组件（Unity UI）
3. 设置 `Image` 的 `RectTransform`：
   - 设置合适的尺寸（建议比图片稍小）
   - 设置锚点（建议居中）
   - 设置位置（建议 (0, 0, 0)，与图片重叠）
   - **重要**：确保 `StampImageDisplay` 在 Hierarchy 中的顺序在 `ImageDisplay` 之后，这样印章会显示在图片上方

#### 2.4 配置 Canvas（如果使用 Screen Space）

如果使用 Screen Space Canvas：
1. 确保 `DisplayPanel` 是 Canvas 的子对象
2. 或者创建一个新的 Canvas（如果还没有）

如果使用 World Space Canvas：
1. 确保 `DisplayPanel` 是 World Space Canvas 的子对象
2. 调整 Canvas 的 Scale（World Space 通常需要很小的 Scale，如 0.01）

### 步骤3：配置 VictoryImageDisplay 组件

在 `VictoryImageDisplay` GameObject 的 Inspector 中配置：

#### 3.1 UI 引用

- **Display Panel**：拖拽 `DisplayPanel` GameObject
- **Image Display**：拖拽 `ImageDisplay` GameObject 的 Image 组件
- **Stamp Image Display**：拖拽 `StampImageDisplay` GameObject 的 Image 组件

#### 3.2 印章配置

- **Stamp Sprite**：拖拽印章图片资源（所有任务共用，只需配置一次）

#### 3.3 时间参数（可选调整）

- **Stamp Appear Delay**：`0.5`（印章出现延迟，秒）
- **Display Duration**：`2.0`（显示时长，从印章出现后开始计算，秒）
- **Fade In Duration**：`0.3`（图片淡入动画时长，秒）
- **Fade Out Duration**：`0.3`（图片和印章淡出动画时长，秒）
- **Stamp Appear Duration**：`0.5`（印章出现动画时长，秒）

#### 3.4 动画缓动类型（可选调整）

- **Fade In Ease**：`OutQuad`（图片淡入缓动）
- **Fade Out Ease**：`InQuad`（淡出缓动）
- **Stamp Appear Ease**：`OutBack`（印章出现缓动，带弹性效果）

#### 3.5 调试

- **Enable Debug Log**：`true`（启用调试日志，方便排查问题）

### 步骤4：配置 TaskCompletionHandler

在场景中找到 `TaskCompletionHandler` GameObject（或包含该组件的 GameObject）：

#### 4.1 更新引用

1. 在 Inspector 中找到 `Task Completion Handler` 组件
2. 找到 **Victory Feedback Display Mono** 字段
3. 拖拽 `VictoryImageDisplay` GameObject 到该字段
4. **移除或清空** `Video Player` 字段（如果存在）

#### 4.2 验证其他引用

确保以下引用已正确配置：
- **Task Manager**：已配置
- **Icon Manager**：已配置（SphereIconManager）
- **Order Data Config**：已配置（SphereOrderDataConfig）

### 步骤5：验证 SphereOrderDataConfig

在 `SphereOrderDataConfig` ScriptableObject 中：

1. 确保每个订单的 **Order Image** 已配置（这是胜利图片，使用同一张图片）
2. **不需要配置**印章图片（印章在 VictoryImageDisplay 组件中统一配置）
3. `Victory Video Clip` 可以留空（如果不再使用视频）

## 配置检查清单

- [ ] VictoryImageDisplay GameObject 已创建
- [ ] DisplayPanel 已创建并配置
- [ ] ImageDisplay 已创建并添加 Image 组件
- [ ] StampImageDisplay 已创建并添加 Image 组件
- [ ] StampImageDisplay 在 Hierarchy 中位于 ImageDisplay 之后（确保印章显示在上方）
- [ ] VictoryImageDisplay 组件的所有 UI 引用已配置

## 测试步骤

1. **运行游戏**
2. **按下按键 1、2 或 3**（根据任务配置）
3. **观察效果**：
   - 图片应立即显示（淡入动画）
   - 0.5秒后印章应显示在图片上方（缩放+淡入动画）
   - 2秒后图片和印章应同时消失（淡出动画）
   - 然后气泡应开始消失动画

## 常见问题

### Q1: 图片不显示

**可能原因：**
- DisplayPanel 未激活
- ImageDisplay 的 Image 组件未配置
- VictoryImageDisplay 组件的引用未正确配置

**解决方法：**
- 检查 DisplayPanel 的 activeSelf 状态
- 检查 ImageDisplay 的 Image 组件是否存在
- 检查 VictoryImageDisplay 组件的 UI 引用是否正确

### Q2: 印章不显示

**可能原因：**
- StampSprite 未配置
- StampImageDisplay 的 Image 组件未配置
- StampImageDisplay 在 Hierarchy 中的顺序不正确

**解决方法：**
- 检查 Stamp Sprite 是否已配置
- 检查 StampImageDisplay 的 Image 组件是否存在
- 确保 StampImageDisplay 在 Hierarchy 中位于 ImageDisplay 之后

### Q3: 印章显示在图片下方

**解决方法：**
- 调整 Hierarchy 中的顺序，确保 StampImageDisplay 在 ImageDisplay 之后
- 或者调整 Canvas 的 Sorting Order（如果使用多个 Canvas）

### Q4: 图片和印章消失后气泡不消失

**可能原因：**
- IconManager 未配置
- SphereIconManager.HideIconForSphere() 调用失败

**解决方法：**
- 检查 TaskCompletionHandler 的 Icon Manager 引用是否正确
- 检查 Console 中的错误信息

### Q5: 时间参数不生效

**解决方法：**
- 确保在 VictoryImageDisplay 组件的 Inspector 中修改时间参数
- 修改后需要重新运行游戏才能生效

## 时间参数说明

- **总时长** = Fade In Duration + Stamp Appear Delay + Stamp Appear Duration + Display Duration + Fade Out Duration
- **默认总时长** ≈ 0.3 + 0.5 + 0.5 + 2.0 + 0.3 = **3.6秒**

如果需要调整总时长，主要修改 **Display Duration** 参数。

## 技术说明

### 解耦设计

- 使用 `IVictoryFeedbackDisplay` 接口实现解耦
- `TaskCompletionHandler` 只依赖接口，不依赖具体实现
- `VictoryImageDisplay` 完全独立，不依赖其他组件
- `SphereIconManager` 完全独立，气泡消失动画不受影响

### 数据复用

- 使用 `orderImage` 作为胜利图片（不需要单独的 victoryImage 字段）
- 印章图片在 `VictoryImageDisplay` 组件中统一配置（所有任务共用）

### 向后兼容

- 如果配置了 `victoryVideoClip` 但没有 `orderImage`，仍可以播放视频（如果 VictoryVideoPlayer 实现了接口）
- 如果两者都配置，优先使用图片+印章

## 后续扩展

如果需要支持视频播放，可以让 `VictoryVideoPlayer` 实现 `IVictoryFeedbackDisplay` 接口，然后在 `TaskCompletionHandler` 中切换引用即可。
