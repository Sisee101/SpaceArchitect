# 设置滑动列表仅垂直滚动指南

## 一、问题描述

左侧滑动列表（MailScrollView）需要设置为只能垂直滑动，不能左右滑动。

## 二、解决方案

在Unity编辑器中配置ScrollRect组件，禁用水平滚动。

### 方法：在Unity编辑器中配置ScrollRect

1. **找到MailScrollView**：
   - 在 Hierarchy 中找到 `MailPanel` → `LeftPanel` → `MailScrollView`

2. **选中MailScrollView**：
   - 点击 `MailScrollView` GameObject

3. **配置ScrollRect组件**：
   - 在 Inspector 中，找到 `Scroll Rect` 组件
   - 找到 `Movement Type` 设置（通常在组件顶部）
   - 找到滚动方向设置：
     - **Horizontal**：❌ 取消勾选（禁用水平滚动）
     - **Vertical**：✅ 勾选（启用垂直滚动）

4. **移除水平滚动条（可选）**：
   - 如果存在水平滚动条（Horizontal Scrollbar），可以删除或禁用它
   - 在 Hierarchy 中找到 `MailScrollView` 下的 `Horizontal Scrollbar`（如果存在）
   - 可以删除它，或者在 Inspector 中禁用（取消勾选 GameObject 的激活状态）

5. **测试效果**：
   - 运行游戏，打开邮箱面板
   - 尝试在左侧列表上拖动：
     - ✅ 上下拖动应该可以滚动
     - ❌ 左右拖动不应该滚动

## 三、详细步骤

### 步骤1：打开ScrollRect配置

```
1. 在 Hierarchy 中找到 MailPanel → LeftPanel → MailScrollView
2. 选中 MailScrollView
3. 在 Inspector 中找到 Scroll Rect 组件
```

### 步骤2：禁用水平滚动

在 `Scroll Rect` 组件中：
- 找到 `Horizontal` 复选框
- **取消勾选** `Horizontal`（禁用水平滚动）
- **确保勾选** `Vertical`（启用垂直滚动）

### 步骤3：检查滚动条

如果存在水平滚动条：
- 在 Hierarchy 中找到 `MailScrollView` → `Horizontal Scrollbar`（如果存在）
- 可以删除它，或者禁用它

### 步骤4：测试

```
1. 运行游戏
2. 打开邮箱面板
3. 在左侧列表上尝试拖动
4. 确认只能垂直滚动，不能水平滚动
```

## 四、ScrollRect组件关键设置

### 必须的设置

| 设置项 | 值 | 说明 |
|--------|-----|------|
| **Horizontal** | ❌ 取消勾选 | 禁用水平滚动 |
| **Vertical** | ✅ 勾选 | 启用垂直滚动 |
| **Movement Type** | Elastic 或 Clamped | 滚动类型（通常使用默认值） |

### 可选设置

| 设置项 | 说明 |
|--------|------|
| **Horizontal Scrollbar** | 设置为 None（如果存在） |
| **Vertical Scrollbar** | 可以保留或设置为 None（根据需求） |

## 五、常见问题

### Q1：设置后还是可以左右滑动

**原因**：可能还有其他设置影响，或Content的宽度设置有问题

**解决**：
- 再次检查 `Scroll Rect` 组件的 `Horizontal` 是否已取消勾选
- 检查 Content 的宽度是否固定（不应该比Viewport宽太多）
- 确保 Content 的 `Rect Transform` 宽度设置合理

### Q2：垂直滚动不流畅

**原因**：可能Content的布局设置有问题

**解决**：
- 检查 Content 的 `Vertical Layout Group` 是否正确配置
- 检查 Content 的 `Content Size Fitter` 是否正确配置
- 确保按钮尺寸设置合理

### Q3：滚动条显示不正确

**原因**：滚动条引用配置错误

**解决**：
- 如果不需要滚动条，可以在 `Scroll Rect` 组件中将 `Vertical Scrollbar` 设置为 None
- 如果需要滚动条，确保 `Vertical Scrollbar` 引用正确

## 六、完成检查

配置完成后，检查：
- [ ] ScrollRect的 `Horizontal` 已取消勾选
- [ ] ScrollRect的 `Vertical` 已勾选
- [ ] 水平滚动条已移除或禁用（如果存在）
- [ ] 测试时只能垂直滚动，不能水平滚动

## 七、快速操作步骤

### 最简单的方法

```
1. 找到 MailPanel → LeftPanel → MailScrollView
2. 选中 MailScrollView
3. Scroll Rect 组件 → Horizontal: ❌ 取消勾选
4. Scroll Rect 组件 → Vertical: ✅ 勾选
5. 完成
```

配置完成后，左侧滑动列表将只能垂直滚动！
