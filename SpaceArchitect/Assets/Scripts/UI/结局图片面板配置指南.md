# 结局图片面板配置指南

本文档说明如何配置和使用结局图片面板系统。

## 📁 文件说明

1. **EndingImagePanel.cs** - 主面板控制器脚本
   - 位置：`Assets/Scripts/UI/EndingImagePanel.cs`
   - 功能：管理图片显示、切换和按钮控制

2. **ShowEndingImageButton.cs** - 触发按钮脚本（可选）
   - 位置：`Assets/Scripts/UI/ShowEndingImageButton.cs`
   - 功能：点击后显示结局图片面板

## 🖼️ 图片准备

您的结局图片已经放在：
- **路径**：`Assets/UI/NewSprites/结局/`
- **文件**：Group 344.png, Group 345.png, ... Group 352.png

如果需要添加更多图片，请继续放在这个目录下。

## 📋 配置步骤

### 步骤1：创建UI面板结构

在Unity Editor中：

1. **创建面板GameObject**
   - 在场景中右键 → UI → Canvas（如果场景还没有Canvas）
   - 在Canvas下创建一个空的GameObject，命名为 `EndingImagePanel`
   - 设置RectTransform：
     - Anchor: Stretch Stretch（全屏覆盖）
     - Left/Right/Top/Bottom: 0

2. **添加背景遮罩（可选）**
   - 在 `EndingImagePanel` 下创建一个 Image
   - 命名为 `Background`
   - 设置：
     - Color: 黑色，Alpha: 200（半透明遮罩）
     - Anchor: Stretch Stretch
     - Left/Right/Top/Bottom: 0

3. **创建图片容器**
   - 在 `EndingImagePanel` 下创建一个空的GameObject，命名为 `ImageContainer`
   - 设置RectTransform：
     - Anchor: Middle Center
     - Pos X/Y: 0
     - Width: 1920, Height: 1080（根据您的图片尺寸调整）

4. **添加显示图片的Image组件**
   - 在 `ImageContainer` 下创建一个 Image
   - 命名为 `CurrentImage`
   - 设置：
     - Anchor: Stretch Stretch
     - Left/Right/Top/Bottom: 0
     - Image Type: Simple
     - Preserve Aspect: ✓（保持图片比例）

5. **添加切换图片按钮**
   - 在 `ImageContainer` 下创建一个 Button
   - 命名为 `NextImageButton`
   - 设置：
     - Anchor: Stretch Stretch（覆盖整个图片区域）
     - Left/Right/Top/Bottom: 0
     - 可以选择：
       - 方式A：透明按钮（只设置Text组件为空白，背景透明）
       - 方式B：图片上的特定区域按钮（根据您的设计调整位置和大小）
   - **注意**：这个按钮在最后一张图片时会自动隐藏

6. **添加退出游戏按钮**
   - 在 `ImageContainer` 下创建一个 Button
   - 命名为 `ExitGameButton`
   - 设置：
     - Anchor: Stretch Stretch（覆盖整个图片区域，或根据设计调整位置）
     - Left/Right/Top/Bottom: 0（或根据您的设计调整）
     - 设置按钮文字为"退出游戏"（或根据设计）
   - **注意**：这个按钮默认隐藏，只在最后一张图片时显示

### 步骤2：配置EndingImagePanel脚本

1. **添加脚本组件**
   - 选中 `EndingImagePanel` GameObject
   - Add Component → 搜索 `EndingImagePanel` → 添加

2. **配置脚本参数**
   
   **图片配置**：
   - 展开 `Ending Images` 列表
   - 设置 Size 为图片数量（例如：9）
   - 从 Project 窗口拖拽图片到列表中：
     - Element 0: `Assets/UI/NewSprites/结局/Group 344.png`
     - Element 1: `Assets/UI/NewSprites/结局/Group 345.png`
     - Element 2: `Assets/UI/NewSprites/结局/Group 346.png`
     - ...（按顺序添加所有图片）
     - Element 8: `Assets/UI/NewSprites/结局/Group 352.png`
   
   **UI引用**：
   - `Current Image Display`：拖拽 `CurrentImage` GameObject
   - `Next Image Button`：拖拽 `NextImageButton` GameObject
   - `Exit Game Button`：拖拽 `ExitGameButton` GameObject
   
   **音效（可选）**：
   - `Audio Source`：如果需要音效，可以拖拽AudioSource组件（脚本会自动创建）
   - `Button Click Sound`：拖拽按钮点击音效文件（可选）
   - `Image Switch Sound`：拖拽图片切换音效文件（可选）
   - `Click Sound Delay`：音效播放延迟时间（默认0.15秒）
   
   **调试**：
   - `Enable Debug Log`：勾选以启用调试日志（推荐开启）

3. **默认隐藏面板**
   - 在Hierarchy中，取消勾选 `EndingImagePanel` GameObject（使其默认隐藏）

### 步骤3：配置触发按钮

有两种方式触发显示图片面板：

#### 方式1：使用ShowEndingImageButton脚本（推荐）

1. **在触发按钮上添加脚本**
   - 选中您的触发按钮（例如：游戏成功/失败后的按钮）
   - Add Component → 搜索 `ShowEndingImageButton` → 添加

2. **配置脚本参数**
   - `Ending Image Panel`：拖拽 `EndingImagePanel` GameObject
   - `Enable Debug Log`：勾选以启用调试日志（可选）

3. **完成！** 脚本会自动绑定按钮点击事件

#### 方式2：手动绑定按钮事件

1. **选中触发按钮**
   - 在Inspector中找到Button组件的 `On Click()` 事件

2. **添加事件**
   - 点击 `+` 添加新事件
   - 拖拽 `EndingImagePanel` GameObject到Object字段
   - 在下拉菜单中选择 `EndingImagePanel` → `Show()`

## 🎨 UI结构示例

```
Canvas
└── EndingImagePanel (GameObject, 默认隐藏)
    ├── Background (Image, 可选，半透明遮罩)
    └── ImageContainer (GameObject)
        ├── CurrentImage (Image, 显示当前图片)
        ├── NextImageButton (Button, 切换按钮，覆盖图片)
        └── ExitGameButton (Button, 退出按钮，默认隐藏，覆盖图片)
```

## 🔧 常见问题

### Q1: 图片不显示？
- 检查 `Current Image Display` 是否已正确分配
- 检查 `Ending Images` 列表中是否有图片，且图片不为null
- 检查Image组件的 `Source Image` 是否正确设置

### Q2: 按钮不响应？
- 检查按钮是否正确分配
- 检查按钮的 `Interactable` 是否为true
- 检查按钮是否被其他UI元素遮挡

### Q3: 最后一张图片时按钮状态不对？
- 检查图片列表的顺序是否正确
- 检查 `UpdateButtonVisibility()` 是否在切换时被调用

### Q4: 退出游戏不工作？
- 检查是否有 `SceneTransitionManager` 在场景中
- 在编辑器中运行时，`Application.Quit()` 不会工作，这是正常的
- 检查Console是否有错误信息

## 📝 使用技巧

1. **图片顺序**
   - 确保图片按正确顺序添加到列表中
   - 第一张图片索引为0，最后一张索引为（总数-1）

2. **按钮设计**
   - 切换按钮可以设置为透明，点击图片任意位置切换
   - 退出按钮可以设计为明显的按钮样式，放在图片的特定位置

3. **音效**
   - 音效是可选的，如果不配置也不会影响功能
   - 如果需要音效，确保AudioSource组件存在

4. **调试**
   - 启用 `Enable Debug Log` 可以帮助排查问题
   - 查看Console中的日志信息
