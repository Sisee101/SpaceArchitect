# 全局视窗配置指南

本指南将帮助你在游戏中添加一个左上角的全局总览小视窗，显示大范围的全局视图。

## 功能说明

全局视窗系统包含两个主要组件：
1. **GlobalOverviewCamera**：用于渲染全局视图的摄像机
2. **GlobalOverviewUI**：用于在UI上显示摄像机画面的组件

## 配置步骤

### 步骤1：创建全局总览摄像机

1. 在 Hierarchy 中创建一个新的 GameObject，命名为 `GlobalOverviewCamera`
2. 添加 `Camera` 组件（如果还没有）
3. 添加 `GlobalOverviewCamera` 脚本组件

#### 配置 GlobalOverviewCamera 组件

在 Inspector 中配置以下参数：

**摄像机设置：**
- **Overview Camera**：如果为空，将自动使用当前GameObject的Camera组件
- **Render Texture**：可以留空，脚本会自动创建
- **Render Texture Width**：渲染纹理宽度（默认512像素）
- **Render Texture Height**：渲染纹理高度（默认512像素）

**视图设置：**
- **Auto Calculate View Range**：是否自动计算视图范围（推荐启用）
  - 如果启用：自动查找所有Station和Destination，计算合适的视图范围
  - 如果禁用：使用手动指定的视图中心点和大小
- **Manual View Center**：手动视图中心点（仅在自动计算禁用时使用）
- **Manual View Size**：手动视图大小（仅在自动计算禁用时使用）
- **View Padding**：视图边距（在计算出的范围基础上增加边距，默认5单位）
- **Station Tag**：Station的Tag（用于自动计算，默认"Station"）
- **Destination Tag**：Destination的Tag（用于自动计算，默认"Destination"）

**更新设置：**
- **Update Every Frame**：是否每帧更新视图（如果为false，只在Start时计算一次）
- **Update Interval**：视图更新间隔（秒，仅在Update Every Frame启用时有效）

**调试：**
- **Show Debug Log**：是否显示调试信息

#### 摄像机组件设置

确保摄像机的以下设置：
- **Projection**：设置为 **Orthographic**（正交）
- **Depth**：设置为 **-1**（比主摄像机低，确保主摄像机渲染在上层）
- **Culling Mask**：确保能看到需要显示的对象（通常与主摄像机相同）
- **Clear Flags**：可以设置为 **Solid Color** 或 **Skybox**

### 步骤2：创建全局视窗UI

1. 在场景中创建一个新的 GameObject，命名为 `GlobalOverviewUI`
2. 添加 `GlobalOverviewUI` 脚本组件

#### 配置 GlobalOverviewUI 组件

在 Inspector 中配置以下参数：

**UI引用：**
- **Overview Image**：可以留空，脚本会自动创建
- **Overview Camera**：如果为空，将自动查找场景中的GlobalOverviewCamera

**显示设置：**
- **Show On Start**：是否在游戏开始时自动显示（默认启用）
- **Allow Toggle**：是否可以通过按键切换显示/隐藏（默认启用）
- **Toggle Key**：切换显示/隐藏的按键（默认Tab键）

**位置和大小设置：**
- **Screen Position**：视窗在屏幕上的位置（0-1，相对于屏幕）
  - 默认值：`(0.05, 0.95)` 表示左上角，距离左边缘5%，距离上边缘5%
- **Size Ratio**：视窗大小（相对于屏幕宽度的比例，0-1）
  - 默认值：`0.25` 表示屏幕宽度的25%
- **Aspect Ratio**：视窗宽高比（宽度/高度）
  - 如果为0，则使用RenderTexture的宽高比
  - 例如：`1.0` 表示1:1，`16/9` 表示16:9

**外观设置：**
- **Background Sprite**：视窗背景图片（优先级高于背景颜色）
  - 如果设置了背景图片，将使用图片作为背景
  - 如果未设置图片，则使用背景颜色
  - 支持9-slice缩放（Sliced类型），适合使用带边框的UI图片
- **Background Color**：视窗背景颜色（仅在未设置背景图片时使用）
  - 如果Alpha为0则无背景
  - 默认值：`(0, 0, 0, 0.5)` 表示半透明黑色
- **Show Border**：是否显示边框（默认启用）
- **Border Color**：边框颜色（默认白色）
- **Border Width**：边框宽度（像素，默认2）

**调试：**
- **Show Debug Log**：是否显示调试信息

### 步骤3：测试

1. 运行游戏
2. 全局视窗应该自动显示在画面左上角
3. 按 **Tab键**（或你设置的按键）可以切换显示/隐藏
4. 检查视窗是否正确显示全局视图

## 使用说明

### 自动计算视图范围

如果启用了 **Auto Calculate View Range**，脚本会自动：
1. 查找场景中所有Tag为"Station"的GameObject
2. 查找场景中所有Tag为"Destination"的GameObject
3. 计算这些对象的边界
4. 设置摄像机位置和大小，确保能看到所有对象

### 手动设置视图范围

如果禁用了 **Auto Calculate View Range**，可以手动设置：
- **Manual View Center**：视图中心点的世界坐标
- **Manual View Size**：视图大小（世界单位）

### 运行时调整

可以通过代码在运行时调整视窗：

```csharp
// 获取GlobalOverviewUI组件
GlobalOverviewUI overviewUI = FindObjectOfType<GlobalOverviewUI>();

// 设置视窗大小比例（0-1）
overviewUI.SetSizeRatio(0.3f); // 设置为屏幕宽度的30%

// 设置视窗位置（0-1，相对于屏幕）
overviewUI.SetScreenPosition(new Vector2(0.1f, 0.9f)); // 距离左边缘10%，距离上边缘10%

// 设置背景图片
Sprite backgroundSprite = Resources.Load<Sprite>("UI/BackgroundFrame");
overviewUI.SetBackgroundSprite(backgroundSprite);

// 设置背景颜色（仅在未设置背景图片时生效）
overviewUI.SetBackgroundColor(new Color(0f, 0f, 0f, 0.7f));

// 显示/隐藏
overviewUI.Show();
overviewUI.Hide();
overviewUI.Toggle();
```

## 常见问题

### 视窗不显示

1. 检查 `GlobalOverviewCamera` 是否已正确配置
2. 检查 `GlobalOverviewUI` 的 `Show On Start` 是否启用
3. 检查控制台是否有错误信息
4. 确保场景中有Station或Destination对象（如果使用自动计算）

### 视窗显示不正确

1. 检查 `GlobalOverviewCamera` 的视图范围设置
2. 如果使用自动计算，确保Station和Destination的Tag正确
3. 调整 `View Padding` 参数，增加边距
4. 检查摄像机的 `Culling Mask` 设置

### 视窗位置不对

1. 调整 `Screen Position` 参数
2. 检查Canvas的设置（如果使用自定义Canvas）

### 视窗大小不对

1. 调整 `Size Ratio` 参数
2. 调整 `Aspect Ratio` 参数（如果需要固定宽高比）

### 背景图片不显示

1. 检查 `Background Sprite` 是否已正确设置
2. 确保图片的 `Texture Type` 设置为 `Sprite (2D and UI)`
3. 检查图片的 `Import Settings`，确保 `Max Size` 足够大
4. 如果使用9-slice，确保图片的 `Border` 设置正确

### 性能问题

1. 如果 `Update Every Frame` 启用，尝试增加 `Update Interval`
2. 降低 `Render Texture Width` 和 `Render Texture Height`
3. 禁用 `Show Debug Log` 以减少日志输出

## 高级配置

### 使用自定义Canvas

如果你想使用自定义Canvas而不是自动创建的Canvas：

1. 在场景中创建一个Canvas（如果需要）
2. 修改 `GlobalOverviewUI.cs` 的 `CreateUIElements()` 方法，使用指定的Canvas

### 自定义视图范围计算

如果你想自定义视图范围的计算逻辑：

1. 修改 `GlobalOverviewCamera.cs` 的 `CalculateViewRangeFromObjects()` 方法
2. 添加更多对象类型（如Planet、Core等）到计算中

### 添加更多控制选项

你可以扩展 `GlobalOverviewUI` 脚本，添加：
- 缩放功能（鼠标滚轮）
- 拖拽功能（移动视窗位置）
- 点击视窗切换主摄像机视角
- 等等

## 总结

配置完成后，你应该能看到：
- 画面左上角有一个小视窗
- 显示全局总览视图
- 可以通过Tab键切换显示/隐藏
- 视图范围自动适应Station和Destination的位置

如果遇到问题，请检查控制台的调试信息，或参考上面的常见问题部分。
