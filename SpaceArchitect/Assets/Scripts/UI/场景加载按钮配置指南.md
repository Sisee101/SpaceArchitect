# 场景加载按钮配置指南

## 概述

`SceneLoadButton.cs` 是一个可复用的按钮脚本，用于在点击按钮时加载指定的场景。脚本会自动使用项目中的 `SceneTransitionManager` 来管理场景切换。

## 功能特性

- ✅ 可配置的目标场景名称（在 Inspector 中设置）
- ✅ 支持可选的点击音效和延迟
- ✅ 自动查找和使用 `SceneTransitionManager`
- ✅ 完整的错误处理和调试日志
- ✅ 运行时动态设置目标场景名称

## 配置步骤

### 步骤 1：创建 GameObject 并添加脚本

1. 在 Unity 编辑器中，打开需要添加按钮的场景
2. 在 Hierarchy 中，找到或创建包含按钮的 GameObject
   - 如果按钮已经存在，直接在该 GameObject 上添加脚本
   - 如果按钮不存在，可以创建一个空的 GameObject（如 "SceneLoadButton"）
3. 在 Inspector 中，点击 "Add Component"
4. 搜索并添加 `SceneLoadButton` 组件

### 步骤 2：配置按钮引用

1. 在 Inspector 中找到 `SceneLoadButton` 组件
2. 找到 **"按钮引用"** 部分
3. 将场景中的 UI Button 拖拽到 **"Load Scene Button"** 字段
   - 如果按钮在同一个 GameObject 上，可以点击右侧的圆形图标选择
   - 如果按钮在其他 GameObject 上，从 Hierarchy 拖拽到字段中

### 步骤 3：配置目标场景

1. 找到 **"场景配置"** 部分
2. 在 **"Target Scene Name"** 字段中输入目标场景名称
   - 场景名称必须与 Build Settings 中的场景名称**完全一致**（区分大小写）
   - 常见场景名称示例：
     - `00_MainMenu` - 主菜单场景
     - `01_MainHub` - 主界面场景
     - `02_MainHub` - 第二个主界面场景
     - `scene02` - 游戏场景
   - **重要**：确保场景已添加到 Build Settings（File → Build Settings → Scenes In Build）

### 步骤 4：配置音效（可选）

如果需要按钮点击时播放音效：

1. 找到 **"音效（可选）"** 部分
2. **Audio Source**（可选）：
   - 如果按钮所在的 GameObject 已有 `AudioSource` 组件，可以拖拽到此处
   - 如果未指定，脚本会自动获取或创建 `AudioSource` 组件
3. **Button Click Sound**：
   - 从 Project 窗口拖拽音频文件（AudioClip）到此字段
   - 如果未配置，点击按钮会直接加载场景（无延迟）
4. **Click Sound Delay**：
   - 设置音效播放后的延迟时间（秒）
   - 默认值：`0.15` 秒
   - 用于确保音效播放完成后再切换场景

### 步骤 5：配置调试选项（可选）

1. 找到 **"调试"** 部分
2. **Enable Debug Log**：
   - 勾选：在 Console 中显示详细的调试信息
   - 取消勾选：不显示调试信息（生产环境建议关闭）

### 步骤 6：确保 SceneTransitionManager 存在

`SceneLoadButton` 依赖 `SceneTransitionManager` 来加载场景。确保场景中存在 `SceneTransitionManager`：

1. 在 Hierarchy 中查找是否有 `SceneTransitionManager` GameObject
2. 如果不存在：
   - 创建一个空的 GameObject，命名为 `SceneTransitionManager`
   - 添加 `SceneTransitionManager` 组件（`Assets/Scripts/Core/SceneTransitionManager.cs`）
   - `SceneTransitionManager` 是单例，会自动 `DontDestroyOnLoad`
3. 如果场景中没有 `SceneTransitionManager`，脚本会在运行时自动创建一个（但建议手动创建）

## 运行时 API

脚本提供了公共方法，可以在运行时动态修改目标场景：

### `SetTargetSceneName(string sceneName)`

设置目标场景名称（可在运行时调用）

```csharp
SceneLoadButton button = GetComponent<SceneLoadButton>();
button.SetTargetSceneName("02_MainHub");
```

### `GetTargetSceneName()`

获取当前目标场景名称

```csharp
SceneLoadButton button = GetComponent<SceneLoadButton>();
string sceneName = button.GetTargetSceneName();
Debug.Log($"当前目标场景: {sceneName}");
```

## 常见问题

### Q1: 点击按钮后没有反应？

**检查清单**：
- ✅ 按钮引用是否已配置？
- ✅ 目标场景名称是否正确（区分大小写）？
- ✅ 场景是否已添加到 Build Settings？
- ✅ Console 中是否有错误信息？
- ✅ `SceneTransitionManager` 是否存在？

### Q2: 场景名称错误

**错误信息**：`SceneTransitionManager: 场景 XXX 不存在或未添加到Build Settings！`

**解决方法**：
1. 打开 File → Build Settings
2. 检查场景是否在 "Scenes In Build" 列表中
3. 检查场景名称是否与输入的名称完全一致（区分大小写）
4. 场景名称应该是场景文件的名称（不含 .unity 扩展名）

### Q3: SceneTransitionManager 未找到

**错误信息**：`SceneLoadButton: SceneTransitionManager 未找到！无法加载场景。`

**解决方法**：
1. 在场景中创建 `SceneTransitionManager` GameObject
2. 添加 `SceneTransitionManager` 组件
3. 或者让脚本自动创建（不推荐，建议手动创建）

### Q4: 音效没有播放

**检查清单**：
- ✅ `Button Click Sound` 是否已配置？
- ✅ `Audio Source` 是否已配置或自动创建？
- ✅ 音频文件是否有效？
- ✅ AudioSource 的 Volume 是否大于 0？

### Q5: 场景切换太快，音效被中断

**解决方法**：
1. 增加 `Click Sound Delay` 的值（如 0.3 秒）
2. 确保延迟时间足够音效播放完成

## 技术细节

### 场景切换流程

1. 用户点击按钮
2. 验证配置（按钮引用、场景名称）
3. 如果配置了音效：
   - 播放点击音效
   - 等待延迟时间（`clickSoundDelay`）
4. 调用 `SceneTransitionManager.Instance.LoadSceneByName(targetSceneName)`
5. `SceneTransitionManager` 会：
   - 验证场景是否存在
   - 设置 `Time.timeScale = 1f`（确保时间正常）
   - 更新游戏状态（如果匹配已知场景）
   - 加载场景

### 与 SceneTransitionManager 的集成

`SceneLoadButton` 使用 `SceneTransitionManager` 的 `LoadSceneByName()` 方法，该方法会：
- 验证场景是否存在
- 正确处理时间缩放
- 更新游戏状态
- 提供统一的场景切换接口

## 注意事项

1. **场景名称必须准确**：场景名称必须与 Build Settings 中的场景名称完全一致（区分大小写）
2. **Build Settings**：确保目标场景已添加到 Build Settings（File → Build Settings）
3. **SceneTransitionManager**：确保场景中存在 `SceneTransitionManager` 实例
4. **音效延迟**：如果使用音效，确保延迟时间足够音效播放完成
5. **调试日志**：生产环境建议关闭调试日志（`Enable Debug Log = false`）
