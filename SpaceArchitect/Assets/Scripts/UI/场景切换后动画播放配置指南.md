# 场景切换后动画播放配置指南

## 概述

本指南说明如何配置场景切换后自动播放盖章动画和气泡消失动画的功能。当用户通过 `OrderCompleteAndLoadSceneButton` 完成订单并切换场景后，新场景会自动检测并播放与按键版本完全一致的动画效果。

## 功能说明

### 动画播放流程

场景切换后的动画播放流程与按键版本完全一致：

1. **显示胜利图片**（淡入动画）
2. **等待延迟**（`stampAppearDelay` 秒）
3. **显示印章**（缩放+淡入动画）
4. **保持显示**（`displayDuration` 秒）
5. **图片和印章同时淡出**
6. **等待延迟**（`bubbleAnimationDelay` 秒）
7. **播放气泡消失动画**（缩放+淡出）

### 工作原理

1. `OrderCompleteAndLoadSceneButton` 完成订单时，将订单信息存储到静态变量
2. 场景切换后，`TaskCompletionHandler` 在 `Start()` 中检查静态变量
3. 如果发现新完成的订单，直接调用 `HandleTaskCompletionSequence()` 播放动画
4. 动画播放完成后，从静态变量中移除订单信息

## 配置步骤

### 步骤 1：确认 OrderCompleteAndLoadSceneButton 配置

确保 `OrderCompleteAndLoadSceneButton` 组件已正确配置：

1. **按钮引用**
   - 在 Inspector 中找到 `OrderCompleteAndLoadSceneButton` 组件
   - 将 UI Button 拖入 `Action Button` 字段

2. **数据配置**
   - 将 `SphereOrderDataConfig` ScriptableObject 拖入 `Order Data Config` 字段

3. **订单选择**
   - 在 `Selected Order Index` 下拉框中选择要完成的订单

4. **场景配置**
   - 在 `Target Scene Name` 中输入目标场景名称（必须在 Build Settings 中）

5. **任务管理器（可选）**
   - 如果有 `TaskManager`，将其拖入 `Task Manager` 字段
   - 这样可以通过 `TaskManager` 持久化任务状态

### 步骤 2：确认 TaskCompletionHandler 配置

确保 `TaskCompletionHandler` 组件已正确配置：

1. **引用配置**
   - **Task Manager**：将 `TaskManager` 组件拖入此字段（必须）
   - **Icon Manager**：将 `SphereIconManager` 组件拖入此字段（必须）
   - **Victory Feedback Display Mono**：将 `VictoryImageDisplay` 组件拖入此字段（必须）
   - **Order Data Config**：将 `SphereOrderDataConfig` ScriptableObject 拖入此字段（必须）

2. **检测设置**
   - **Check Interval**：检测 `CompleteOrder` 变化的轮询间隔（秒），默认 `0.1`
   - 如果为 `0`，则每帧检测

3. **执行顺序**
   - **Bubble Animation Delay**：视频消失后，气泡动画开始前的延迟时间（秒），默认 `0`

4. **调试**
   - **Enable Debug Log**：是否启用调试日志，建议在测试时启用

### 步骤 3：确认 VictoryImageDisplay 配置

确保 `VictoryImageDisplay` 组件已正确配置（这是播放盖章动画的关键组件）：

1. **UI引用**
   - **Display Panel**：显示面板（包含图片和印章的父对象）
   - **Image Display**：图片显示组件
   - **Stamp Image Display**：印章图片显示组件（叠在图片上方）

2. **印章配置**
   - **Stamp Sprite**：印章图片（所有任务共用，统一配置）

3. **时间参数**
   - **Stamp Appear Delay**：印章出现延迟时间（秒，从图片显示后开始计算），默认 `0.5`
   - **Display Duration**：显示时长（秒，从印章出现后开始计算），默认 `2.0`
   - **Fade In Duration**：图片淡入动画时长（秒），默认 `0.3`
   - **Fade Out Duration**：图片和印章淡出动画时长（秒），默认 `0.3`
   - **Stamp Appear Duration**：印章出现动画时长（秒），默认 `0.5`

4. **动画缓动类型**
   - **Fade In Ease**：图片淡入缓动类型，默认 `OutQuad`
   - **Fade Out Ease**：图片和印章淡出缓动类型，默认 `InQuad`
   - **Stamp Appear Ease**：印章出现缓动类型，默认 `OutBack`

### 步骤 4：确认 SphereIconManager 配置

确保 `SphereIconManager` 组件已正确配置（这是播放气泡消失动画的关键组件）：

1. **气泡消失动画设置**
   - **Hide Animation Duration**：气泡消失动画的时长（秒），默认 `0.5`

2. **其他配置**
   - 确保 `SphereIconManager` 的其他配置（Sphere引用、UI引用等）已正确设置

## 常见问题

### Q1: 场景切换后没有播放动画

**可能原因：**
- `TaskCompletionHandler` 未正确配置
- `VictoryImageDisplay` 未正确配置
- 订单信息未正确存储到静态变量

**解决方法：**
1. 检查 Console 日志，查看是否有错误信息
2. 确认所有引用都已正确配置
3. 确认 `Enable Debug Log` 已启用，查看详细日志

### Q2: 动画播放了，但效果与按键版本不一致

**可能原因：**
- `VictoryImageDisplay` 的时间参数配置不一致
- 动画缓动类型配置不一致

**解决方法：**
1. 对比 `VictoryImageDisplay` 的配置参数
2. 确保 `stampAppearDelay`、`displayDuration` 等参数与按键版本一致
3. 确保动画缓动类型（`stampAppearEase` 等）与按键版本一致

### Q3: 动画播放了，但气泡没有消失

**可能原因：**
- `SphereIconManager` 未正确配置
- 气泡不存在或已被隐藏

**解决方法：**
1. 检查 `SphereIconManager` 的配置
2. 确认气泡在场景中存在
3. 检查 Console 日志，查看是否有错误信息

### Q4: 多次切换场景后，动画不播放了

**可能原因：**
- 静态变量未正确清理
- 订单已被标记为已处理

**解决方法：**
1. 检查 `TaskCompletionHandler` 的 `CleanupPendingOrdersAfterDelay()` 方法是否正常工作
2. 确认订单的 `CompleteOrder` 状态正确
3. 重启游戏，清除所有状态

## 技术细节

### 静态变量机制

- `OrderCompleteAndLoadSceneButton` 使用静态变量存储新完成的订单信息
- 使用 `HashSet<int>` 存储有 `taskId` 的订单
- 使用 `HashSet<string>` 存储没有 `taskId` 的订单（使用 `sphereName`）
- 场景切换后，`TaskCompletionHandler` 检查这些静态变量
- 动画播放完成后，从静态变量中移除订单信息

### 动画调用机制

- 场景切换后，`TaskCompletionHandler.Start()` 在标记已处理订单之前，先检查静态变量
- 如果发现新完成的订单，直接调用 `HandleTaskCompletionSequence(sphereName)`
- 这与按键版本使用的方法完全相同，确保动画效果一致

### 清理机制

- 动画播放后，立即从静态变量中移除订单信息
- 延迟 1 秒后，清理所有待播放列表（避免残留数据）
- 这确保了多次场景切换时不会出现问题
