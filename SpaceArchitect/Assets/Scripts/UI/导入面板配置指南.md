# 导入面板配置指南

本指南将帮助您在 `01_MainHub` 场景中配置游戏导入面板。导入面板会在每次进入主界面时显示，包含8张图片，每张图片上有按钮，点击后切换到下一张，最后一张点击后进入主界面。

## 一、准备工作

### 1. 确认脚本已创建

确保以下脚本文件已存在：
- `Assets/Scripts/UI/IntroductionPanel.cs` ✅
- `Assets/Scripts/UI/MainHubController.cs` ✅（已修改）

### 2. 准备导入图片

准备8张导入图片（Sprite格式），建议：
- 图片尺寸：1920x1080（或其他适合您屏幕分辨率的尺寸）
- 格式：PNG（支持透明）或 JPG
- 导入到 Unity 后，确保 Texture Type 设置为 `Sprite (2D and UI)`

## 二、在 01_MainHub 场景中创建导入面板 UI

### 步骤 1：创建导入面板 GameObject

1. 打开 `01_MainHub` 场景
2. 在 Hierarchy 中找到 Canvas（如果没有，创建一个）
3. 在 Canvas 下创建一个新的 GameObject，命名为 `IntroductionPanel`
4. 确保 `IntroductionPanel` 的 RectTransform 设置为：
   - **Anchor Presets**: 按住 Alt + Shift，点击右下角的 "stretch-stretch"（全屏）
   - **Width**: 1920（或您的屏幕宽度）
   - **Height**: 1080（或您的屏幕高度）

### 步骤 2：添加背景（可选）

1. 在 `IntroductionPanel` 下创建一个子 GameObject，命名为 `Background`
2. 添加 `Image` 组件（如果没有自动添加）
3. 设置背景：
   - **Color**: 黑色，Alpha 设为 255（完全不透明）或 200（半透明）
   - 或者使用您自己的背景图片

### 步骤 3：创建图片显示区域

1. 在 `IntroductionPanel` 下创建一个子 GameObject，命名为 `ImageDisplay`
2. 添加 `Image` 组件
3. 设置图片显示：
   - **Image Type**: Simple
   - **Preserve Aspect**: ✅ 勾选（保持图片比例）
   - **Color**: 白色，Alpha 255（完全不透明）
   - **RectTransform**: 
     - **Anchor Presets**: 居中（middle-center）
     - **Width**: 1920（或您的图片宽度）
     - **Height**: 1080（或您的图片高度）

### 步骤 4：创建图片按钮

1. 在 `IntroductionPanel` 下创建一个子 GameObject，命名为 `ImageButton`
2. 添加 `Button` 组件
3. 添加 `Image` 组件（Button 会自动添加，如果没有则手动添加）
4. 设置按钮：
   - **RectTransform**: 
     - **Anchor Presets**: 按住 Alt + Shift，点击 "stretch-stretch"（全屏覆盖）
     - **Width**: 1920
     - **Height**: 1080
   - **Image 组件**:
     - **Color**: 白色，Alpha 0（完全透明，这样按钮不可见但可点击）
     - 或者移除 Image 组件，只保留 Button 组件
   - **Button 组件**:
     - **Transition**: Color Tint（默认）
     - **Interactable**: ✅ 勾选

### 步骤 5：设置 Hierarchy 顺序

确保 Hierarchy 中的顺序如下（从下到上，下面的会被上面的遮挡）：
```
IntroductionPanel
├── Background (最下层)
├── ImageDisplay (中间层)
└── ImageButton (最上层，可点击)
```

## 三、配置 IntroductionPanel 脚本

### 步骤 1：添加脚本

1. 选中 `IntroductionPanel` GameObject
2. 在 Inspector 中点击 `Add Component`
3. 搜索并添加 `Introduction Panel` 脚本

### 步骤 2：配置脚本参数

在 Inspector 中找到 `Introduction Panel` 组件，配置以下参数：

#### 【导入图片列表】
- **Introduction Images**: 
  - **Size**: 8
  - 依次拖入8张导入图片（按顺序：Element 0 = 第1张，Element 1 = 第2张，...，Element 7 = 第8张）

#### 【UI引用】
- **Image Display**: 拖入 `ImageDisplay` GameObject（或它的 Image 组件）
- **Image Button**: 拖入 `ImageButton` GameObject（或它的 Button 组件）

#### 【动画参数】
- **Image Switch Duration**: 0.3（图片切换动画时长，秒）
  - 设为 0 则无动画，立即切换

#### 【音效】（可选）
- **Audio Source**: 
  - 如果 `IntroductionPanel` GameObject 上有 AudioSource 组件，会自动使用
  - 如果没有，脚本会自动添加一个
- **Button Click Sound**: 拖入按钮点击音效 AudioClip（可选）

#### 【调试】
- **Enable Debug Log**: 
  - ✅ 勾选：显示调试日志（开发时使用）
  - ❌ 不勾选：不显示日志（发布时使用）

## 四、配置 MainHubController 脚本

### 步骤 1：找到 MainHubController

1. 在 `01_MainHub` 场景中找到 `MainHubController` GameObject
2. 在 Inspector 中找到 `Main Hub Controller` 组件

### 步骤 2：配置导入面板引用

在 Inspector 中找到 `Main Hub Controller` 组件的 **【导入面板】** 部分：

- **Introduction Panel**: 拖入 `IntroductionPanel` GameObject

## 七、常见问题

### Q1: 导入面板没有显示

**可能原因：**
- `MainHubController` 中的 `Introduction Panel` 引用未配置
- `IntroductionPanel` GameObject 未激活
- 导入图片列表为空

**解决方法：**
1. 检查 `MainHubController` 的 `Introduction Panel` 字段是否已拖入 `IntroductionPanel` GameObject
2. 确保 `IntroductionPanel` GameObject 在 Hierarchy 中是激活状态
3. 检查 `IntroductionPanel` 脚本的 `Introduction Images` 列表是否已配置8张图片

### Q2: 点击图片没有反应

**可能原因：**
- `Image Button` 引用未配置
- `ImageButton` GameObject 未激活
- `ImageButton` 的 Button 组件被禁用

**解决方法：**
1. 检查 `IntroductionPanel` 脚本的 `Image Button` 字段是否已配置
2. 确保 `ImageButton` GameObject 是激活状态
3. 检查 `ImageButton` 的 Button 组件的 `Interactable` 是否勾选

### Q3: 图片显示不正确（变形、太小等）

**可能原因：**
- `ImageDisplay` 的 RectTransform 设置不正确
- 图片的 `Preserve Aspect` 未勾选

**解决方法：**
1. 检查 `ImageDisplay` 的 RectTransform：
   - 设置为居中（middle-center）
   - 设置合适的 Width 和 Height（与图片原始尺寸一致）
2. 在 `ImageDisplay` 的 Image 组件中勾选 `Preserve Aspect`

### Q4: 导入完成后主界面没有显示

**可能原因：**
- `MainHubController` 的 `Main Hub Panel` 引用未配置
- 事件订阅/取消订阅有问题

**解决方法：**
1. 检查 `MainHubController` 的 `Main Hub Panel` 字段是否已配置
2. 查看控制台是否有错误日志
3. 确保 `IntroductionPanel` 脚本正确触发了 `OnIntroductionCompleted` 事件

### Q5: 图片切换没有动画效果

**可能原因：**
- `Image Switch Duration` 设置为 0
- DOTween 未正确导入

**解决方法：**
1. 检查 `IntroductionPanel` 脚本的 `Image Switch Duration` 是否大于 0（建议 0.3）
2. 确保项目中已导入 DOTween（如果未导入，图片会立即切换，无动画）

## 八、高级配置

### 自定义背景

如果您想使用自定义背景图片：
1. 在 `Background` GameObject 的 Image 组件中
2. 将 `Source Image` 设置为您的背景图片 Sprite
3. 调整 `Color` 的 Alpha 值控制透明度

### 添加跳过按钮（可选）

如果您想添加跳过按钮，可以：
1. 在 `IntroductionPanel` 下创建一个 `SkipButton` GameObject
2. 添加 Button 组件
3. 在 `IntroductionPanel.cs` 中添加跳过逻辑（需要修改脚本）

### 调整图片切换动画

在 `IntroductionPanel` 脚本中：
- **Image Switch Duration**: 调整动画时长
  - 较小值（0.1-0.2）：快速切换
  - 较大值（0.5-1.0）：缓慢切换

## 十、注意事项

1. **每次进入都显示**：根据需求，导入面板会在每次进入 `01_MainHub` 场景时显示。如果将来需要改为"仅首次显示"，需要修改代码添加 PlayerPrefs 记录。

2. **图片顺序**：确保导入图片按正确顺序配置（Element 0 = 第1张，Element 7 = 第8张）。

3. **按钮覆盖**：`ImageButton` 必须覆盖整个屏幕，确保点击图片任意位置都能触发切换。

4. **性能优化**：如果图片很大，建议压缩图片或使用合适的压缩格式。

5. **其他场景**：如果需要在 `02_MainHub`、`03_MainHub` 等场景中也使用导入面板，可以：
   - 将 `IntroductionPanel` 制作成 Prefab
   - 在其他场景中实例化并配置
   - 确保每个场景的 `MainHubController` 都配置了导入面板引用

---

配置完成后，每次从主菜单进入 `01_MainHub` 场景时，都会先显示导入面板，用户点击图片切换，最后一张点击后进入主界面。

如有问题，请检查控制台日志或参考上述常见问题部分。
