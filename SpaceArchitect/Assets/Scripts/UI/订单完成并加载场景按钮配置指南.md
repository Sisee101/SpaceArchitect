# 订单完成并加载场景按钮配置指南

## 概述

`OrderCompleteAndLoadSceneButton.cs` 是一个组合功能按钮脚本，结合了订单完成和场景加载功能。点击按钮后，会：
1. 修改选中订单的 `CompleteOrder` 状态为 `true`
2. 通过 `TaskManager` 持久化保存状态（跨场景和跨游戏会话）
3. 加载到指定的目标场景
4. 在新场景中，`TaskCompletionHandler` 会自动检测订单完成并播放盖章动画和气泡消失动画

## 功能特性

- ✅ 在 Inspector 中通过下拉框选择订单（使用 `OrderSelector` 属性）
- ✅ 自动修改选中订单的 `CompleteOrder` 状态
- ✅ 通过 `TaskManager` 持久化保存（如果订单有 `taskId`）
- ✅ 直接保存到 PlayerPrefs（如果订单没有 `taskId`）
- ✅ 加载到指定场景
- ✅ 支持可选的点击音效和延迟
- ✅ 完整的错误处理和调试日志

## 配置步骤

### 步骤 1：创建 GameObject 并添加脚本

1. 在 Unity 编辑器中，打开需要添加按钮的场景
2. 在 Hierarchy 中，找到或创建包含按钮的 GameObject
   - 如果按钮已经存在，直接在该 GameObject 上添加脚本
   - 如果按钮不存在，可以创建一个空的 GameObject（如 "OrderCompleteAndLoadSceneButton"）
3. 在 Inspector 中，点击 "Add Component"
4. 搜索并添加 `OrderCompleteAndLoadSceneButton` 组件

### 步骤 2：配置按钮引用

1. 在 Inspector 中找到 `OrderCompleteAndLoadSceneButton` 组件
2. 找到 **"按钮引用"** 部分
3. 将场景中的 UI Button 拖拽到 **"Action Button"** 字段
   - 如果按钮在同一个 GameObject 上，可以点击右侧的圆形图标选择
   - 如果按钮在其他 GameObject 上，从 Hierarchy 拖拽到字段中

### 步骤 3：配置数据配置

1. 找到 **"数据配置"** 部分
2. 将 `SphereOrderDataConfig` 资源拖拽到 **"Order Data Config"** 字段
   - 从 Project 窗口找到 `SphereOrderDataConfig` ScriptableObject 资源
   - 拖拽到字段中

### 步骤 4：配置订单选择

1. 找到 **"订单选择"** 部分
2. 在 **"Selected Order Index"** 下拉框中选择要完成的订单
   - 下拉框会自动显示所有订单，格式为：`"Sphere名称 [TaskId: X]"` 或 `"Sphere名称 [无任务]"`
   - 选择后，点击按钮时会完成该订单

### 步骤 5：配置场景

1. 找到 **"场景配置"** 部分
2. 在 **"Target Scene Name"** 字段中输入目标场景名称
   - 场景名称必须与 Build Settings 中的场景名称**完全一致**（区分大小写）
   - 常见场景名称示例：
     - `00_MainMenu` - 主菜单场景
     - `01_MainHub` - 主界面场景
     - `02_MainHub` - 第二个主界面场景
     - `scene02` - 游戏场景
   - **重要**：确保场景已添加到 Build Settings（File → Build Settings → Scenes In Build）

### 步骤 6：配置任务管理器（可选）

1. 找到 **"任务管理器（可选）"** 部分
2. **Task Manager**：
   - 如果场景中存在 `TaskManager`，可以拖拽到此处
   - 如果未配置，脚本会自动查找场景中的 `TaskManager`
   - **推荐**：手动配置，确保正确引用

### 步骤 7：配置持久化设置（可选）

1. 找到 **"持久化设置"** 部分
2. **Use Persistent Storage**：
   - 勾选：启用持久化（默认）
   - 取消勾选：禁用持久化，状态只在当前游戏会话中有效
   - **注意**：如果订单有 `taskId`，会通过 `TaskManager` 持久化；如果没有 `taskId`，会直接保存到 PlayerPrefs

### 步骤 8：配置音效（可选）

如果需要按钮点击时播放音效：

1. 找到 **"音效（可选）"** 部分
2. **Audio Source**（可选）：
   - 如果按钮所在的 GameObject 已有 `AudioSource` 组件，可以拖拽到此处
   - 如果未指定，脚本会自动获取或创建 `AudioSource` 组件
3. **Button Click Sound**：
   - 从 Project 窗口拖拽音频文件（AudioClip）到此字段
   - 如果未配置，点击按钮会直接执行操作（无延迟）
4. **Click Sound Delay**：
   - 设置音效播放后的延迟时间（秒）
   - 默认值：`0.15` 秒
   - 用于确保音效播放完成后再执行后续操作

### 步骤 9：配置调试选项（可选）

1. 找到 **"调试"** 部分
2. **Enable Debug Log**：
   - 勾选：在 Console 中显示详细的调试信息
   - 取消勾选：不显示调试信息（生产环境建议关闭）

### 步骤 10：确保依赖组件存在

#### A. SceneTransitionManager

`OrderCompleteAndLoadSceneButton` 依赖 `SceneTransitionManager` 来加载场景。确保场景中存在 `SceneTransitionManager`：

1. 在 Hierarchy 中查找是否有 `SceneTransitionManager` GameObject
2. 如果不存在：
   - 创建一个空的 GameObject，命名为 `SceneTransitionManager`
   - 添加 `SceneTransitionManager` 组件（`Assets/Scripts/Core/SceneTransitionManager.cs`）
   - `SceneTransitionManager` 是单例，会自动 `DontDestroyOnLoad`

#### B. TaskCompletionHandler（目标场景需要）

在新加载的场景中，需要 `TaskCompletionHandler` 来监听订单完成并播放动画：

1. 在目标场景的 Hierarchy 中查找是否有 `TaskCompletionHandler` GameObject
2. 如果不存在，需要创建并配置：
   - 创建一个空的 GameObject，命名为 `TaskCompletionHandler`
   - 添加 `TaskCompletionHandler` 组件
   - 配置以下引用：
     - **Task Manager**：拖入 `TaskManager` 引用
     - **Icon Manager**：拖入 `SphereIconManager` 引用
     - **Victory Feedback Display Mono**：拖入 `VictoryImageDisplay` 组件
     - **Order Data Config**：拖入 `SphereOrderDataConfig` 资源

#### C. VictoryImageDisplay（目标场景需要）

在新加载的场景中，需要 `VictoryImageDisplay` 来显示盖章动画：

1. 确保目标场景中有 `VictoryImageDisplay` 组件
2. 配置以下引用：
   - **Display Panel**：显示面板 GameObject
   - **Image Display**：图片显示 Image 组件
   - **Stamp Image Display**：印章图片显示 Image 组件
   - **Stamp Sprite**：印章图片资源

#### D. SphereIconManager（目标场景需要）

在新加载的场景中，需要 `SphereIconManager` 来播放气泡消失动画：

1. 确保目标场景中有 `SphereIconManager` 组件
2. 配置 Sphere 列表和其他必要引用

## 工作流程

### 完整流程

```
用户点击按钮
    ↓
1. 播放点击音效（如果配置）
    ↓
2. 等待延迟时间（如果配置了音效）
    ↓
3. 设置 orderInfo.CompleteOrder = true
    ↓
4. 调用 TaskManager.CompleteTask(taskId)
    ├─ 更新 taskCompletionStatus（运行时字典）
    ├─ 更新 persistentTaskStatus（静态字典，跨场景保持）
    ├─ 保存到 PlayerPrefs（如果启用持久化）
    └─ 触发 OnTaskCompleted 事件
    ↓
5. 加载目标场景（SceneTransitionManager.LoadSceneByName()）
    ↓
6. 新场景加载后：
    ├─ TaskManager.Start() 从 persistentTaskStatus 恢复 CompleteOrder
    ├─ TaskCompletionHandler 检测到 CompleteOrder = true
    ├─ 播放盖章动画（VictoryImageDisplay.ShowImage()）
    │   ├─ 显示订单图片（淡入）
    │   ├─ 延迟后显示印章（缩放+淡入）
    │   └─ 图片和印章消失（淡出）
    └─ 播放气泡消失动画（SphereIconManager.HideIconForSphere()）
```

### 持久化机制

1. **有 taskId 的订单**：
   - 通过 `TaskManager.CompleteTask()` 持久化
   - 保存到 `persistentTaskStatus`（静态字典，跨场景保持）
   - 如果 `TaskManager.usePersistentStorage = true`，保存到 PlayerPrefs（键：`"TaskCompleted_" + taskId`）

2. **没有 taskId 的订单**：
   - 如果 `usePersistentStorage = true`，直接保存到 PlayerPrefs（键：`"OrderCompleted_" + sphereName + "_" + index`）

3. **场景切换时**：
   - `TaskManager.Start()` 会从 `persistentTaskStatus` 恢复所有订单的 `CompleteOrder` 状态
   - 确保状态在场景切换时保持不变

## 运行时 API

脚本提供了公共方法，可以在运行时动态修改配置：

### `SetSelectedOrderIndex(int index)`

设置选中的订单索引

```csharp
OrderCompleteAndLoadSceneButton button = GetComponent<OrderCompleteAndLoadSceneButton>();
button.SetSelectedOrderIndex(2); // 选择第3个订单（索引从0开始）
```

### `SetSelectedOrderBySphereName(string sphereName)`

根据 Sphere 名称设置选中的订单索引

```csharp
OrderCompleteAndLoadSceneButton button = GetComponent<OrderCompleteAndLoadSceneButton>();
button.SetSelectedOrderBySphereName("Sphere (1)");
```

### `SetTargetSceneName(string sceneName)`

设置目标场景名称

```csharp
OrderCompleteAndLoadSceneButton button = GetComponent<OrderCompleteAndLoadSceneButton>();
button.SetTargetSceneName("01_MainHub");
```

### `GetTargetSceneName()`

获取当前目标场景名称

```csharp
OrderCompleteAndLoadSceneButton button = GetComponent<OrderCompleteAndLoadSceneButton>();
string sceneName = button.GetTargetSceneName();
Debug.Log($"当前目标场景: {sceneName}");
```

## 常见问题

### Q1: 点击按钮后没有反应？

**检查清单**：
- ✅ 按钮引用是否已配置？
- ✅ 订单数据配置是否已配置？
- ✅ 目标场景名称是否正确（区分大小写）？
- ✅ 场景是否已添加到 Build Settings？
- ✅ Console 中是否有错误信息？
- ✅ `SceneTransitionManager` 是否存在？

### Q2: 订单状态没有持久化？

**检查清单**：
- ✅ `Task Manager` 是否已配置（如果订单有 taskId）？
- ✅ `Use Persistent Storage` 是否已勾选？
- ✅ `TaskManager` 的 `Use Persistent Storage` 是否已勾选（如果订单有 taskId）？
- ✅ Console 中是否有持久化相关的日志？

### Q3: 新场景中没有播放动画？

**检查清单**：
- ✅ 目标场景中是否有 `TaskCompletionHandler` 组件？
- ✅ `TaskCompletionHandler` 的引用是否都已配置？
- ✅ 目标场景中是否有 `VictoryImageDisplay` 组件？
- ✅ `VictoryImageDisplay` 的引用是否都已配置？
- ✅ 目标场景中是否有 `SphereIconManager` 组件？
- ✅ Console 中是否有动画相关的日志？

### Q4: 场景名称错误

**错误信息**：`SceneTransitionManager: 场景 XXX 不存在或未添加到Build Settings！`

**解决方法**：
1. 打开 File → Build Settings
2. 检查场景是否在 "Scenes In Build" 列表中
3. 检查场景名称是否与输入的名称完全一致（区分大小写）
4. 场景名称应该是场景文件的名称（不含 .unity 扩展名）

### Q5: 订单选择下拉框为空

**解决方法**：
1. 确保 `Order Data Config` 已配置
2. 确保 `SphereOrderDataConfig` 资源中的 `orderDataList` 不为空
3. 重新选择组件或刷新 Inspector

## 技术细节

### 持久化键名格式

- **有 taskId**：`"TaskCompleted_0"`, `"TaskCompleted_1"`, ...
- **没有 taskId**：`"OrderCompleted_Sphere (1)_0"`, `"OrderCompleted_Sphere (2)_1"`, ...

### 与 TaskManager 的协调

- 如果订单有 `taskId` 且配置了 `TaskManager`：
  - `OrderCompleteAndLoadSceneButton` 会调用 `TaskManager.CompleteTask()`
  - `TaskManager` 会处理所有持久化逻辑
  - 两者使用相同的 PlayerPrefs 键（`"TaskCompleted_" + taskId`）

- 如果订单没有 `taskId`：
  - `OrderCompleteAndLoadSceneButton` 会直接保存到 PlayerPrefs
  - 使用 Sphere 名称和索引的组合作为键

### 场景切换时的状态恢复

1. 新场景加载后，`TaskManager.Start()` 被调用
2. `TaskManager` 从 `persistentTaskStatus`（静态字典）恢复所有订单的 `CompleteOrder` 状态
3. `TaskCompletionHandler` 在 `Start()` 中标记已完成的订单为已处理（避免重复播放动画）
4. `TaskCompletionHandler` 在 `Update()` 中检测新完成的订单（`CompleteOrder` 从 `false` 变为 `true`）
5. 如果检测到新完成的订单，播放盖章动画和气泡消失动画

## 注意事项

1. **场景名称必须准确**：场景名称必须与 Build Settings 中的场景名称完全一致（区分大小写）
2. **Build Settings**：确保目标场景已添加到 Build Settings（File → Build Settings）
3. **SceneTransitionManager**：确保场景中存在 `SceneTransitionManager` 实例
4. **TaskCompletionHandler**：确保目标场景中有 `TaskCompletionHandler` 组件并正确配置
5. **持久化**：如果订单有 `taskId`，确保 `TaskManager` 已配置且 `Use Persistent Storage` 已启用
6. **调试日志**：生产环境建议关闭调试日志（`Enable Debug Log = false`）
