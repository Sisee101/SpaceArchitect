SGP4
====

The code in this directory is a port of code to import Earth satellite information in the form of two line elements and
evolve them using a sophisticated model that includes atmospheric drag and the non-spherical shape of the earth. 

It corresponds to the communnity code described in https://celestrak.com/publications/AIAA/2006-6753/ and available in Java 
from that site. 

The included unit tests with the Java code have been ported and run without errors. It is likely that any errors that are found
are a result of the port and not with the original source code.
