## 二、新增记录信息

### 2.1 速度变化（velChange）

**含义**：
- CoreDeflector 应用效果后，速度的变化大小
- 单位：m/s

**计算方式**：
- 预测：`velChange = currentVel - oldVel`（应用前后）
- 实际：`velChange = currentVel - lastVelocity`（当前帧 - 上一帧）

**用途**：
- 对比预测和实际中 CoreDeflector 对速度的影响
- 如果差异很大，说明预测算法有问题

### 2.2 加速度（accel）

**含义**：
- CoreDeflector 产生的加速度大小
- 单位：m/s²

**计算方式**：
- `accel = velChange / deltaTime`
- `deltaTime` 在预测中是 `fixedUnscaledDeltaTime`
- `deltaTime` 在实际中是 `Time.fixedUnscaledDeltaTime`

**用途**：
- 对比预测和实际中 CoreDeflector 产生的加速度
- 如果差异很大，说明加速度计算有问题

## 三、激活时机控制

### 3.1 可配置参数

**位置**：`TrajectoryPredictor` Inspector 面板

**参数**：
- **Trigger Delay Frames**：Unity Trigger 的延迟帧数
- **默认值**：6 帧（0.12秒）
- **调整方法**：
  - 如果预测中激活太早（距离太小），**增大**此值
  - 如果预测中激活太晚（距离太大），**减小**此值

### 3.2 如何调整

**步骤**：
1. 运行游戏，生成预测和实际日志
2. 对比首次激活时的距离：
   - 实际：距离 9.20 时激活
   - 预测：距离 9.48 时激活
   - **差异**：0.28（预测中激活稍晚）
3. **调整策略**：
   - 如果差异为正（预测激活更晚），**减小** `triggerDelayFrames`
   - 如果差异为负（预测激活更早），**增大** `triggerDelayFrames`
4. 重新测试，验证调整效果

### 3.3 调整公式（参考）

**经验公式**：
```
新值 = 当前值 - (预测距离 - 实际距离) / 速度 / fixedDeltaTime
```

**示例**：
- 当前值：6 帧
- 预测距离：9.48
- 实际距离：9.20
- 差异：0.28
- 速度：约 15 m/s
- fixedDeltaTime：0.02 秒
- 调整：6 - (0.28 / 15 / 0.02) ≈ 6 - 0.93 ≈ 5 帧

### 4.1 记录格式

**预测日志**：
```

```

**实际日志**：
```

```

### 4.2 对比项

| 项目 | 预测 | 实际 | 差异 | 说明 |
|------|------|------|------|------|
| 距离 | 9.48 | 9.20 | 0.28 | 激活时机的差异 |
| 引力加速度 | 5.560 | 5.905 | 0.345 | 距离不同导致 |
| 引导强度 | 0.20 | 0.20 | 0 | ✅ 一致 |
| **速度变化** | **0.123** | **0.125** | **0.002** | **新增：可以对比效果** |
| **加速度** | **6.150** | **6.250** | **0.100** | **新增：可以对比效果** |

### 4.3 分析价值

**新增信息的作用**：
1. **速度变化对比**：
   - 如果差异很小（< 0.01），说明效果一致
   - 如果差异很大（> 0.1），说明预测算法有问题

2. **加速度对比**：
   - 如果差异很小（< 0.1），说明加速度计算一致
   - 如果差异很大（> 1.0），说明加速度计算有问题

3. **效果差异诊断**：
   - 如果速度变化和加速度都一致，但位置差异很大
   - 说明问题在累积误差，而不是 CoreDeflector 效果本身

## 六、使用建议

### 6.1 首次使用

1. **保持默认值**：`triggerDelayFrames = 6`
2. **运行测试**：生成预测和实际日志
3. **对比分析**：检查激活时机和效果差异
4. **根据差异调整**：如果差异较大，调整 `triggerDelayFrames`

### 6.2 调整激活时机

**如果预测中激活太早**：
- 增大 `triggerDelayFrames`（例如：7 或 8）
- 重新测试，检查是否改善

**如果预测中激活太晚**：
- 减小 `triggerDelayFrames`（例如：5 或 4）
- 重新测试，检查是否改善

### 6.3 分析效果差异

**如果速度变化差异很大**：
1. 检查 `ApplyCoreDeflector` 方法
2. 确保与实际代码一致
3. 检查时间步长是否正确

**如果加速度差异很大**：
1. 检查加速度计算
2. 确保使用 `fixedUnscaledDeltaTime`
3. 检查引力加速度和引导加速度的计算

## 七、注意事项

### 7.1 速度变化计算

- 预测中：在应用效果前后计算
- 实际中：在当前帧和上一帧之间计算
- **注意**：实际中的速度变化可能包含其他因素的影响（如基础引力）

### 7.2 加速度计算

- 使用 `fixedUnscaledDeltaTime` 作为时间步长
- 确保预测和实际使用相同的时间步长
- **注意**：加速度是速度变化除以时间，不是直接计算的

### 7.3 激活时机

- `triggerDelayFrames` 是经验值
- 可能需要根据场景调整
- **建议**：先使用默认值，根据测试结果调整
