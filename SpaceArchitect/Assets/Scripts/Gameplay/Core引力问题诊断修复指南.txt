========================
Core 引力问题诊断与修复指南
========================

## ❗ 问题描述

**症状：**
- ✅ 轨迹预测显示 Core 的引力（预测线弯曲）
- ✗ 实际飞行时 Core 不产生引力（飞船不弯曲）

**原因：**
Core 的 NBody 没有被 GravityEngine 正确注册

========================

## 🔍 诊断步骤

### 步骤1：检查 Core 配置

选中 Core GameObject，检查：

```
1. GameObject 是否激活？
   - Hierarchy 中名字前有勾选框 ✓
   
2. 是否有 NBody 组件？
   - Inspector 中看到 NBody (Script)
   
3. NBody 是否启用？
   - NBody 组件前的勾选框 ✓
   
4. NBody.mass > 0？
   - mass: 应该 > 0（例如 1000）
```

### 步骤2：检查引擎注册状态

```
1. 选中 Core
2. 在 Inspector 中找到 CoreGravitySetup 组件
3. 右键 → "显示引力信息"
4. 查看 Console 输出
```

**期望看到：**
```
✅ "已注册到引擎: 是 ✓"
✅ "引擎索引: X"
✅ "有效质量: XXX"
```

**如果看到：**
```
✗ "已注册到引擎: 否 ✗"
✗ "Core 不会对飞船产生引力！"
→ 需要修复！
```

### 步骤3：查看运行时日志

运行游戏后，查看 Console：

**正常情况：**
```
✅ "[CoreGravitySetup] Core_01 配置完成 - mass: 1000"
✅ "[CoreGravitySetup] ✓ Core_01 已被 GravityEngine 识别"
✅ "[CoreGravitySetup]   → 引擎索引: 2, 质量: 1000"
```

**异常情况：**
```
⚠️ "[CoreGravitySetup] ⚠️ Core_01 未被识别！尝试手动添加..."
✅ "[CoreGravitySetup] ✓ 手动添加成功！"
```

**严重异常：**
```
✗ "[CoreGravitySetup] ✗ 手动添加失败！"
→ 需要手动修复
```

========================

## 🛠️ 修复方法

### 方法1：自动修复（推荐）⭐

**更新的 CoreGravitySetup 会自动尝试修复**

1. 运行游戏
2. 查看 Console 日志
3. 如果看到"手动添加成功"→ 修复完成 ✓
4. 如果看到"手动添加失败"→ 使用方法2

### 方法2：手动强制注册

```
1. 运行游戏（进入 Play 模式）
2. 选中 Core GameObject
3. 右键 CoreGravitySetup 组件
4. 选择 "强制重新注册到引擎"
5. 查看 Console：
   ✅ "✓ 手动添加成功"
```

### 方法3：检查场景设置

如果自动修复失败，检查：

#### 3.1 GravityEngine 配置

```
1. 在 Hierarchy 中找到 GravityEngine
2. 确保 GameObject 激活
3. 确保 GravityEngine 组件启用
4. 检查设置：
   - massScale: 应该 > 0（通常是 1.0）
```

#### 3.2 Core 时序问题

```
如果 Core 是运行时创建的：

A. 创建后立即添加到引擎：
   GameObject core = Instantiate(corePrefab);
   GravityEngine.Instance().AddBody(core);

B. 或确保 Core 在场景中预先存在
   → 不要运行时动态创建
```

#### 3.3 Layer/Tag 检查

```
1. 检查 Core 的 Layer
   → 应该是 Default 或其他可见 Layer
   
2. 不要使用特殊的 Layer
   → 可能被 GravityEngine 过滤
```

### 方法4：重新配置 Core

```
1. 删除 Core 的 NBody 组件
2. 删除 CoreGravitySetup 组件
3. 重新添加 CoreGravitySetup
4. 它会自动创建和配置 NBody
5. 运行测试
```

========================

## ✅ 验证修复

### 验证1：查看日志

运行游戏后，Console 应该显示：

```

✅ "[CoreGravitySetup]   → 引擎索引: X, 质量: XXX"

```

```
1. 拖拽飞船
2. 观察轨迹预测线：
   ✅ 轨迹弯曲经过 Core
   
3. 发射飞船
4. 观察实际飞行：
   ✅ 飞船轨迹与预测一致
   ✅ 飞船受 Core 引力影响弯曲
```

### 验证3：对比测试

```
A. 记下 Core 的位置
B. 发射飞船，观察路径
C. 移除 Core 或设置 mass=0
D. 再次发射（相同参数）
E. 对比：
   ✅ 有 Core: 飞船轨迹弯曲
   ✅ 无 Core: 飞船轨迹笔直
   → 证明 Core 有效！
```

## 🎯 常见问题

### Q1: 日志显示"未被识别"？

**原因：**
- Core 在 GravityEngine 初始化后创建
- 或 NBody 配置有问题

**解决：**
1. 自动修复会尝试手动添加
2. 查看后续日志是否成功
3. 如失败，使用"强制重新注册"

### Q2: "手动添加失败"？

**检查：**
1. GravityEngine 是否存在？
2. GravityEngine 是否激活？
3. Core 是否激活？
4. NBody 是否启用？
5. 是否有其他脚本冲突？

**解决：**
1. 修复上述问题
2. 使用"强制重新注册"

### Q3: 轨迹预测有 Core，实际飞行没有？

**确认问题：**
```
1. 右键 CoreGravitySetup
2. "显示引力信息"
3. 查看"已注册到引擎"
```

**如果 "否"：**
→ 按修复步骤操作

**如果 "是"：**
→ 可能是其他问题：
  - 检查 mass 是否 > 0
  - 检查飞船是否太远
  - 检查 speedMultiplier

### Q4: 修复后还是不行？

**深度检查：**

1. **检查 GravityEngine 设置：**
   ```
   - massScale: 应该 > 0
   - 检查是否有特殊过滤
   ```

2. **检查飞船配置：**
   ```
   - 飞船是否有 NBody？
   - 飞船是否被添加到引擎？
   - ShipState 是否正确配置？
   ```

3. **检查 Core 数量：**
   ```
   - 是否所有 Core 都有问题？
   - 还是只有某些 Core？
   - 尝试创建新的测试 Core
   ```

4. **检查项目设置：**
   ```
   - Physics 设置
   - Layer 碰撞矩阵
   - Time Scale
   ```
