# 初始速度不一致问题修复说明

## 一、问题诊断

### 1.1 问题发现

从最新日志对比发现：
- **预测初始速度**: (14.96, 1.32, 0.00)
- **实际初始速度**: (14.94, 1.32, 0.00)
- **差异**: X方向相差 0.02

### 1.2 根本原因

**问题**：
- 预测日志在预览时就开始记录了（使用预览速度）
- 实际发射时虽然调用了 `OnShipLaunched`，但预测日志已经在预览时记录了
- 导致预测日志记录的初始速度是预览速度，而不是实际发射速度

**工作流程问题**：
1. **预览阶段**：
   - `SetPreviewTrajectory(launchPosition, previewVelocity)` 被调用
   - `PredictFullTrajectory` 开始执行
   - 如果 `enablePredictionLogging` 为 true，**立即开始记录日志**（使用预览速度）
   
2. **实际发射阶段**：
   - `OnShipLaunched` 事件触发
   - 调用 `SetPreviewTrajectory(launchPosition, actualLaunchVelocity)`
   - 但之前的日志可能已经记录了预览速度

## 二、修复方案

### 2.1 核心思路

**只在实际发射时才开始记录预测日志**

### 2.2 实现方法

1. **添加标志**：
   - 添加 `shouldLogPrediction` 标志
   - 默认值为 `false`（预览时不记录）

2. **在事件中设置标志**：
   - 在 `OnShipLaunched` 事件中，设置 `shouldLogPrediction = true`
   - 这样标记应该记录预测日志（使用实际发射速度）

3. **在预测中检查标志**：
   - 在 `PredictFullTrajectory` 中，只有当 `shouldLogPrediction` 为 true 时才开始记录日志
   - 记录后重置标志，避免重复记录

## 三、修复代码

### 3.1 添加标志

```csharp
/// <summary>
/// 标记是否应该记录预测日志（只在实际发射时记录）
/// </summary>
private bool shouldLogPrediction = false;
```

### 3.2 在事件中设置标志

```csharp
private void OnShipLaunched(Vector3 actualLaunchVelocity, GameObject ship)
{
    // 只处理自己的飞船
    if (ship != gameObject) return;
    
    // 使用实际发射速度重新预测
    Vector3 launchPosition = transform.position;
    SetPreviewTrajectory(launchPosition, actualLaunchVelocity);
    
    // 关键修复：标记应该记录预测日志（使用实际发射速度）
    if (enablePredictionLogging)
    {
        // 停止之前的记录（如果有，可能是预览时的记录）
        if (isLoggingPrediction)
        {
            StopPredictionLogging();
        }
        // 标记应该记录预测日志
        shouldLogPrediction = true;
        Debug.Log($"[预测] 已标记使用实际发射速度记录 - 位置: {launchPosition}, 速度: {actualLaunchVelocity}");
    }
}
```

### 3.3 在预测中检查标志

```csharp
// 关键修复：只在 shouldLogPrediction 为 true 时才开始记录
// shouldLogPrediction 只在 OnShipLaunched 事件中设置为 true
// 这样可以确保预测日志记录使用的是实际发射速度，而不是预览速度
if (enablePredictionLogging && shouldLogPrediction && !isLoggingPrediction)
{
    StartPredictionLogging(startPos, startVel, dt);
    // 记录后重置标志，避免重复记录
    shouldLogPrediction = false;
}
```

### 3.4 在结束时重置标志

```csharp
// 结束预测数据记录（只在实际记录时才停止）
if (enablePredictionLogging && isLoggingPrediction)
{
    StopPredictionLogging();
    // 重置标志
    shouldLogPrediction = false;
}
```

## 四、修复效果

### 4.1 修复前

- **预览时**：`SetPreviewTrajectory` → `PredictFullTrajectory` → **立即开始记录日志**（使用预览速度）
- **实际发射时**：`OnShipLaunched` → `SetPreviewTrajectory` → 但日志已经记录了预览速度
- **问题**：预测日志记录的初始速度是预览速度，不是实际发射速度

### 4.2 修复后

- **预览时**：`SetPreviewTrajectory` → `PredictFullTrajectory` → **不记录日志**（`shouldLogPrediction = false`）
- **实际发射时**：`OnShipLaunched` → 设置 `shouldLogPrediction = true` → `SetPreviewTrajectory` → `PredictFullTrajectory` → **开始记录日志**（使用实际发射速度）
- **优势**：预测日志记录的初始速度是实际发射速度

## 六、注意事项

### 6.1 预览功能

- 预览功能不受影响
- 预览时仍然会计算和显示轨迹
- 只是不会记录日志（这是正确的）

### 6.2 日志记录

- 日志只在实际发射时记录一次
- 使用实际发射速度
- 确保预测数据和实际数据使用相同的初始条件

### 6.3 性能影响

- 修复不会影响性能
- 只是添加了一个标志检查
- 日志记录的逻辑没有改变
