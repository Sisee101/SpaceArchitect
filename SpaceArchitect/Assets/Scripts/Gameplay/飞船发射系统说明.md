# 飞船发射系统修复说明

## 🔧 问题诊断

### 问题1：PreLaunch状态下飞船仍受引力影响

**根本原因：**
GravityEngine在初始化时会自动检测场景中所有带有NBody组件的GameObject，并将它们添加到物理模拟中。即使禁用NBody组件，只要GameObject是激活的，就会被添加。

**解决方案：**
1. **Awake阶段临时禁用GameObject** - 在GravityEngine初始化前就隐藏飞船
2. **Start阶段重新激活并立即检查** - 如果被自动添加，立即移除
3. **FixedUpdate持续监控** - 每帧检查`nBody.engineRef`，确保PreLaunch状态下始终未添加到引擎
4. **强制位置锁定** - 在PreLaunch状态下强制保持初始位置

## 📋 修复内容

### ShipState.cs 关键修改

#### 1. 添加新的成员变量
```csharp
private bool hasInitialized = false;     // 初始化标记
private Vector3 initialPosition;         // 初始位置（用于锁定）
private Rigidbody rb;                    // Rigidbody组件（用于重置速度）
```

#### 2. Awake - 防止自动添加
```csharp
void Awake()
{
    // 保存初始位置
    initialPosition = transform.position;
    
    // 临时禁用GameObject，防止GravityEngine自动检测
    gameObject.SetActive(false);
}
```

#### 3. Start - 移除自动添加
```csharp
void Start()
{
    // 重新激活
    gameObject.SetActive(true);
    
    // 检查是否被自动添加
    if (nBody.engineRef != null)
    {
        gravityEngine.RemoveBody(gameObject);
        nBody.engineRef = null;
    }
}
```

#### 4. FixedUpdate - 持续监控和锁定
```csharp
void FixedUpdate()
{
    if (currentState == State.PreLaunch)
    {
        // 强制位置锁定
        if (Vector3.Distance(transform.position, initialPosition) > 0.01f)
        {
            transform.position = initialPosition;
            if (rb != null)
            {
                rb.velocity = Vector3.zero;
                rb.angularVelocity = Vector3.zero;
            }
        }
        
        // 持续检查是否被意外添加
        if (nBody.engineRef != null)
        {
            gravityEngine.RemoveBody(gameObject);
            nBody.engineRef = null;
        }
    }
}
```

#### 5. 判断标准改进
使用 `nBody.engineRef != null` 作为判断是否已添加到引擎的标准，而不是自定义的布尔标记。

## 🎮 使用说明

### 正确的工作流程

1. **游戏启动**
   - Awake: 飞船GameObject被禁用
   - GravityEngine初始化（不会检测到飞船）
   - Start: 飞船重新激活，确保未在引擎中

2. **PreLaunch状态**
   - 飞船位置被锁定在初始位置
   - 每帧检查并防止被添加到引擎
   - 完全不受引力影响

3. **拖拽发射**
   - 鼠标拖拽生成箭头
   - 松开鼠标触发Launch()

4. **Launch执行**
   - 设置 `nBody.vel`
   - 切换到Flying状态（添加到引擎）
   - 延迟一帧后使用 `gravityEngine.SetVelocity()` 确保速度应用

5. **Flying状态**
   - 飞船受引力影响
   - 按照弹道飞行

### 如果仍有问题

1. **检查GameObject是否意外激活**
   - 确保没有其他脚本在Awake中重新激活飞船

2. **检查GravityEngine设置**
   - 查看GravityEngine的"Detect Bodies"设置
   - 确认是否使用了自动检测模式

3. **检查NBody组件**
   - 确保NBody组件的mass > 0
   - 查看初始velocity是否为0

4. **增加调试日志**
   - 在FixedUpdate中添加更详细的日志
   - 监控 `nBody.engineRef` 的变化

## ⚙️ 参数调整

### ShipLauncher参数

- `launchForceMultiplier`: 5-10 (力量系数，越大飞得越快)
- `maxDragDistance`: 200 (最大拖拽距离，像素)
- `arrowColor`: 黄色 (箭头颜色)
- `arrowWidth`: 0.1 (箭头宽度)

### 推荐配置

```
launchForceMultiplier = 8f
maxDragDistance = 250f
```

## 📝 技术要点

1. **GravityEngine的NBody检测机制**
   - 在Setup阶段查找所有NBody组件
   - 只要GameObject激活就会被检测
   - `nBody.engineRef` 是判断是否已添加的关键

2. **速度设置的正确方式**
   - 先设置 `nBody.vel`（初始值）
   - 添加到引擎后使用 `gravityEngine.SetVelocity()`（内部状态）
   - 两步都必须执行

3. **坐标转换注意事项**
   - 屏幕到世界坐标需要深度值
   - 使用相机到物体的实际距离
   - 确保Z轴为0（2D平面）
