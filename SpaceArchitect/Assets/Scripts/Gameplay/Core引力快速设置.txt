========================
Core 引力快速设置指南
========================

## ✅ 确保 Core 产生引力的两种方法

### 方法1：手动配置（简单）⭐

**步骤：**

1. 选中 Core GameObject
2. 在 Inspector 中：
   - Add Component → NBody
3. 配置 NBody：
   ```
   mass: 1000 (引力强度)
   vel: (0, 0, 0)
   isFixed: true (可选)
   ```
4. 完成！

### 方法2：使用辅助脚本（推荐）⭐⭐

**步骤：**

1. 选中 Core GameObject
2. Add Component → CoreGravitySetup
3. 配置参数：
   ```
   Gravity Mass: 1000 (引力强度)
   Is Fixed: true
   Show Gravity Range: true (显示范围)
   ```
4. 运行游戏，检查 Console：
   ```
   ✅ "Core_01 配置完成 - mass: 1000"
   ✅ "✓ Core_01 已被 GravityEngine 识别，正在产生引力"
   ```

**优点：**
- 自动添加和配置 NBody
- 验证是否被 GravityEngine 识别
- 显示引力范围（调试用）
- 运行时可调整参数

## ❗ 常见问题

### Q1: Core 不产生引力？

**检查：**
1. Core 有 NBody 组件吗？
2. NBody.mass > 0 吗？
3. Core GameObject 是激活的吗？
4. Console 有错误信息吗？

**解决：**
- 添加 CoreGravitySetup 组件
- 查看 Console 日志
- 检查 GravityEngine 是否存在

### Q2: 轨迹不经过 Core？

**原因：**
- Core 的 mass 太小
- Core 离飞船太远
- Gravity Multiplier 设置不当

**解决：**
- 增大 Core 的 mass
- 调整 Core 位置
- 检查 TrajectoryPredictor 配置

### Q3: 引力太强/太弱？

**调整：**
```
太强 → 减小 NBody.mass
太弱 → 增大 NBody.mass

或调整：
TrajectoryPredictor.Gravity Multiplier
```

### Q4: Console 显示"未被识别"？

**检查：**
1. GravityEngine 是否在场景中？
2. GravityEngine 是否激活？
3. Core 是否在 GravityEngine 初始化后才创建？

**解决：**
- 确保 GravityEngine 存在
- 重启游戏
- 检查执行顺序
