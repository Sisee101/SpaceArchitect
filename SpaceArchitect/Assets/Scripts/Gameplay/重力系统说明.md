# 重力系统说明

## 1. 飞船是否还会受到 GravityEngine 的影响？

**答案：是的，飞船仍然会受到 GravityEngine 的完整重力影响。**

`lockToXYPlane` 功能只是限制了飞船在 Z 方向的运动（强制 Z=0），但**不影响重力计算本身**。

### 工作原理：
- 重力计算在物理空间中正常进行（包括所有三个方向）
- 在位置更新时，如果启用了 `lockToXYPlane`，才会强制将 Z 设为 0
- 这样飞船仍然会受到其他物体的引力作用，但运动被限制在 XY 平面上

## 2. 为什么没有挂捕获脚本的物体不能对飞船造成引力影响？

**答案：不是因为没有捕获脚本，而是因为物体没有 `NBody` 组件或没有被 GravityEngine 检测到。**

### GravityEngine 的工作原理：

1. **自动检测**：GravityEngine 在启动时会通过 `FindObjectsOfType(typeof(NBody))` 自动检测场景中所有带有 `NBody` 组件的物体。

2. **参与重力计算的条件**：
   - 物体必须有 `NBody` 组件
   - `NBody` 组件必须被 GravityEngine 检测到（如果 `detectNbodies = true`，会自动检测）
   - 物体的质量（`NBody.mass`）必须大于 0

3. **`PlanetGravityCapture` 脚本的作用**：
   - 这个脚本**不产生引力**，它只是一个辅助工具
   - 它的作用是：当飞船进入捕获范围时，轻微调整飞船的速度，使其更容易进入轨道
   - 真正的引力是由 GravityEngine 根据 `NBody` 组件的质量计算的

### 如何让物体产生引力：

1. **给物体添加 `NBody` 组件**：
   ```
   - 选择物体
   - 在 Inspector 中添加 Component -> NBody
   - 设置 mass（质量）值
   ```

2. **确保被 GravityEngine 检测到**：
   - 如果 GravityEngine 的 `Detect Nbodies` 选项为 true（默认），会自动检测
   - 如果为 false，需要手动将物体添加到 GravityEngine 的 `Bodies` 列表中

3. **设置合适的质量**：
   - 质量越大，引力越强
   - 建议：行星质量 100-1000，飞船质量 1-10

### 示例：

```csharp
// 要让一个物体产生引力，只需要：
GameObject planet = ...;
NBody nbody = planet.AddComponent<NBody>();
nbody.mass = 500f; // 设置质量

// GravityEngine 会自动检测并计算引力
```

## 3. 关于 `lockToXYPlane` 的注意事项

- ✅ 重力计算正常进行（所有方向）
- ✅ 位置更新时强制 Z=0
- ✅ 速度的 Z 分量也会被清零
- ⚠️ 这可能会影响某些轨道动力学，但对于 2D 平面游戏是合适的

## 4. 调试建议

如果发现物体不产生引力，检查：
1. 物体是否有 `NBody` 组件？
2. `NBody.mass` 是否大于 0？
3. GravityEngine 的 `Detect Nbodies` 是否为 true？
4. 物体是否在场景启动时就存在？（动态添加的需要调用 `GravityEngine.AddBody()`）
