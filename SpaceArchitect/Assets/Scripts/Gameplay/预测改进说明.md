# 预测改进说明

## 一、关键修复

### 1.1 时间步长修复（最重要）

**问题**：
- 预测使用 0.01 秒时间步长
- 实际游戏使用 0.02 秒（FixedUpdate）
- 导致累积误差，后期完全偏离

**修复**：
- 将 `predictionTimeStep` 从 `0.01f` 改为 `0.02f`
- 现在预测和实际使用相同的时间步长

**预期效果**：
- ✅ 消除时间步长不一致导致的累积误差
- ✅ 预测应该更接近实际轨迹

## 二、进一步改进建议

### 2.1 使用 GravityEngine 内置预测（最佳方案）

**如果当前修复还不够准确**，可以考虑：

1. **启用 GravityEngine 的轨迹预测**：
   ```csharp
   gravityEngine.trajectoryPrediction = true;
   ```

2. **使用 Trajectory 组件**：
   - 在飞船 GameObject 上添加 `Trajectory` 组件
   - 自动显示预测轨迹

3. **手动应用 CoreDeflector 效果**：
   - 从 `trajectoryState` 获取预测点
   - 对每个点检查是否在 CoreDeflector 范围内
   - 如果在，应用 CoreDeflector 的效果

**优势**：
- ✅ 使用完全相同的物理引擎和积分器
- ✅ 只需要处理 CoreDeflector，其他都由 GravityEngine 处理
- ✅ 精度和实际游戏完全一致

### 2.2 如果必须手动模拟

**关键改进点**：
1. ✅ **时间步长一致**（已修复：0.02秒）
2. **完全复制 LeapFrog 积分**（从 `LeapFrogIntegrator.cs`）
3. **更精确的 trigger 检测**
4. **更精确的组件执行顺序**

## 三、测试建议

3. **如果还不够准确**：
   - 考虑使用 GravityEngine 内置预测方案
