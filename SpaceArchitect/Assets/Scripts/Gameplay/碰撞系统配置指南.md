# 碰撞系统配置指南

## 📋 概述

本指南说明如何配置飞船碰撞系统，使飞船在与Planet或Obstacle碰撞时切换到Crashed状态，并产生真实的物理碰撞效果。

---

## 🚀 飞船（Ship）配置

### 1. 必需组件

飞船GameObject需要以下组件：

#### ✅ Rigidbody组件

**配置步骤：**
1. 选中飞船GameObject
2. `Add Component` → `Rigidbody`
3. 配置参数：
   ```
   Mass: 1.0
   Drag: 0.0
   Angular Drag: 0.5
   Use Gravity: ❌ false（重要！飞船使用GravityEngine，不使用Unity重力）
   Is Kinematic: ⚠️ 见下方说明
   Interpolate: Interpolate（可选，平滑运动）
   Collision Detection: Continuous（重要！避免高速穿透）
   ```

**重要说明：**
- **Is Kinematic设置：**
  - **Flying状态时**：可以设置为`true`（由GravityEngine控制位置）
  - **Crashed状态时**：自动切换为`false`（由Unity物理引擎控制）
  - 或者始终设置为`false`，让GravityEngine和Unity物理引擎协同工作

#### ✅ CapsuleCollider组件

**配置步骤：**
1. 选中飞船GameObject
2. `Add Component` → `Capsule Collider`
3. 配置参数：
   ```
   Is Trigger: ❌ false（必须！需要真实物理碰撞）
   Material: 见下方"物理材质"部分
   Center: (0, 0, 0)
   Radius: 0.5（根据飞船模型大小调整）
   Height: 2.0（根据飞船模型大小调整）
   Direction: Y-Axis（通常）
   ```

#### ✅ 脚本组件

确保飞船有以下脚本：
- `ShipState`
- `Crash`
- `NBody`（GravityEngine需要）
- `ShipController`（可选）
- `ShipBoost`（可选）
- `ShipLauncher`（可选）

## 🌍 行星（Planet）配置

### 1. 标签设置

**必需：** Planet GameObject的标签必须设置为`Planet`

**步骤：**
1. 选中Planet GameObject
2. 在Inspector顶部，将Tag设置为`Planet`
3. 如果标签不存在，先创建：
   ```
   Edit → Project Settings → Tags and Layers
   在Tags列表中添加 "Planet"
   ```

### 2. Collider配置

Planet需要有Collider组件用于碰撞检测：

#### ✅ SphereCollider（推荐用于球形行星）

**配置步骤：**
1. 选中Planet GameObject
2. `Add Component` → `Sphere Collider`（如果还没有）
3. 配置参数：
   ```
   Is Trigger: ❌ false（必须！需要真实物理碰撞）
   Material: 见下方"物理材质"部分
   Center: (0, 0, 0)
   Radius: 根据行星大小调整（例如：2.0）
   ```

#### ✅ Rigidbody（可选，但推荐）

**配置步骤：**
1. 选中Planet GameObject
2. `Add Component` → `Rigidbody`
3. 配置参数：
   ```
   Mass: 100.0（或更大，行星质量应该很大）
   Drag: 0.0
   Angular Drag: 0.0
   Use Gravity: ❌ false（行星通常固定）
   Is Kinematic: ✅ true（行星通常不动，或设置为false让它受物理影响）
   ```

**说明：**
- 如果行星是固定的，设置`Is Kinematic = true`
- 如果行星需要受物理影响，设置`Is Kinematic = false`并设置较大的Mass

## 🚧 障碍物（Obstacle）配置

**步骤：**
1. 选中Obstacle GameObject
2. 在Inspector顶部，将Tag设置为`Obstacle`

   ```
   Edit → Project Settings → Tags and Layers
   在Tags列表中添加 "Obstacle"
   ```

### 2. Collider配置

Obstacle需要有Collider组件：

#### ✅ BoxCollider（用于立方体障碍物）

**配置步骤：**
1. 选中Obstacle GameObject
2. `Add Component` → `Box Collider`（如果还没有）
3. 配置参数：
   ```
   Is Trigger: ❌ false（必须！需要真实物理碰撞）
   Material: 见下方"物理材质"部分
   Center: (0, 0, 0)

   或
   Is Kinematic: ❌ false（如果障碍物需要受物理影响）
   ```

## 🎯 物理材质（Physics Material）

为了获得更好的碰撞效果，建议创建物理材质：

### 创建物理材质

1. 在Project窗口中右键 → `Create` → `Physic Material`
2. 命名为 `ShipMaterial`、`PlanetMaterial`、`ObstacleMaterial`等

### 配置物理材质

#### 飞船材质（ShipMaterial）

```
Dynamic Friction: 0.6
Static Friction: 0.6
Bounciness: 0.3（轻微反弹）
Friction Combine: Average
Bounce Combine: Average
```

#### 行星材质（PlanetMaterial）

```
Dynamic Friction: 0.8
Static Friction: 0.8
Bounciness: 0.1（几乎不反弹）
Friction Combine: Average
Bounce Combine: Average
```

#### 障碍物材质（ObstacleMaterial）

```
Dynamic Friction: 0.7
Static Friction: 0.7
Bounciness: 0.2
Friction Combine: Average
Bounce Combine: Average
```

### 应用物理材质

1. 选中GameObject（飞船/行星/障碍物）
2. 在Collider组件中，将`Material`字段设置为对应的物理材质

---

## ⚙️ 物理设置（Project Settings）

### 检查物理设置

1. `Edit` → `Project Settings` → `Physics`
2. 确保以下设置：
   ```
   Gravity: (0, -9.81, 0)（Unity默认重力，飞船不使用）
   Default Material: 可以设置为创建的物理材质
   Bounce Threshold: 2.0
   Sleep Threshold: 0.005
   Default Solver Iterations: 6
   Default Solver Velocity Iterations: 1
   ```

## 🧪 测试步骤

### 1. 基础碰撞测试

1. 运行场景
2. 发射飞船
3. 让飞船撞向Planet或Obstacle
4. 检查Console日志：
   - 应该看到 "飞船碰撞！" 的日志
   - 应该看到 "飞船状态改变: Flying -> Crashed" 的日志

### 2. 物理效果测试

1. 观察碰撞后的行为：
   - 飞船应该停止受GravityEngine控制
   - 飞船应该能够进行物理碰撞和反弹
   - 如果配置了Rigidbody，飞船应该受物理影响

### 3. 状态检查

1. 在Inspector中查看飞船的`ShipState`组件
2. `Current State`应该显示为`Crashed`
3. 飞船的`NBody.engineRef`应该为`null`（已从GravityEngine移除）

## ⚠️ 常见问题

### 问题1：碰撞没有触发

**可能原因：**
- Collider的`Is Trigger`设置为`true`（应该为`false`）
- 标签未正确设置
- 飞船或障碍物缺少Collider组件

**解决方法：**
- 检查所有Collider的`Is Trigger`设置
- 确认标签正确
- 确保所有对象都有Collider

### 问题2：碰撞后飞船继续运动

**可能原因：**
- GravityEngine仍在控制飞船
- `ShipState`未正确切换到Crashed状态

**解决方法：**
- 检查Console日志，确认状态切换
- 检查`ShipState.HandleGravityForState`是否正确执行

### 问题3：碰撞效果不真实

**可能原因：**
- 缺少物理材质
- Rigidbody配置不正确
- 碰撞检测模式设置不当

**解决方法：**
- 创建并应用物理材质
- 调整Rigidbody参数
- 将Collision Detection设置为`Continuous`

### 问题4：高速穿透

**可能原因：**
- Collision Detection设置为`Discrete`（默认）

**解决方法：**
- 将Rigidbody的`Collision Detection`设置为`Continuous`或`Continuous Dynamic`
