# 轨迹预测系统全面分析

## 一、系统架构梳理

### ⚠️ 重要发现：遗漏的脚本

在深入搜索后，发现以下**也会修改飞船速度**的脚本：

1. **ShipBoost.cs** - 飞船加速器（玩家按E键触发）
   - 在 `Update()` 中检测输入
   - 直接通过 `gravityEngine.SetVelocity()` 修改速度
   - 添加速度增量：`newVelocity = currentVelocity + boostVelocity`
   - **影响**：玩家主动触发，预测中**不考虑**（除非需要预测玩家操作）

2. **ShipBoostAim.cs** - 飞船瞄准推进（玩家按特定键触发）
   - 时停瞄准系统，玩家选择方向后加速
   - 直接通过 `gravityEngine.SetVelocity()` 修改速度
   - **影响**：玩家主动触发，预测中**不考虑**

3. **GravityHubDeflector.cs** - 引力枢纽偏转器（另一个偏转系统！）
   - 在 `Update()` 中运行（不是 FixedUpdate）
   - 使用距离检测（不是 Collider）
   - 通过 `ge.SetVelocity()` 修改速度
   - 使用 `Vector3.Lerp` 调整速度方向
   - **影响**：**需要添加到预测系统！**

### 1. 核心物理引擎：GravityEngine

**关键参数：**
- `physToWorldFactor`: 物理空间到世界空间的缩放因子
  - 影响：距离缩放 → 引力强度变化（立方关系）
  - 位置转换：`worldPosition = physicsPosition * physToWorldFactor`
  - 引力影响：`a ∝ (physToWorldFactor)³`（因为距离在物理空间计算）
  
- `massScale`: 质量缩放因子
  - 所有 NBody 的质量在计算引力时会被乘以 `massScale`
  - 有效质量：`effectiveMass = nbody.mass * massScale`

**坐标系统：**
- 内部使用"物理空间"（physics space）
- `GetVelocity()` 返回物理空间速度（Unity单位）
- `SetVelocity()` 设置物理空间速度
- 位置在更新时乘以 `physToWorldFactor` 转换到世界空间

**引力计算：**
- 公式：`a = GM / r²`（G已包含在质量中）
- 在物理空间计算，然后转换到世界空间

### 2. CoreDeflector（核心偏转器）

**执行时机：**
- `FixedUpdate()` 中运行
- 使用 `Time.fixedUnscaledDeltaTime` 作为时间步长（不受时停影响）

**引力计算：**
- 使用自己的 `coreEffectiveMass`（**不应用** `massScale`）
- 引力加速度：`gravitationalAcceleration = coreEffectiveMass / (distance * distance)`
- 径向引力：`radialGravity = -radialDirection * gravitationalAcceleration`

**引导计算：**
- 切向方向：选择与当前速度方向更接近的切向
- 理想切向速度：`idealTangentialVel = tangentialDirection * shipVelocity.magnitude`
- 引导加速度：`guidanceAcceleration = (idealTangentialVel - shipVelocity) * guidanceStrength / deltaTime`
- 如果有目标轨道半径：`radiusCorrection = -radialDirection * radiusError * guidanceStrength * 0.5f`

**最终加速度：**
```
totalAcceleration = radialGravity * (1 - guidanceStrength) + guidanceAcceleration * guidanceStrength
```

**速度限制：**
- 最大角度改变：`maxAngularVelocity`（度/秒）
- 如果角度改变超过限制，使用旋转限制

**应用方式：**
- 直接通过 `gravityEngine.SetVelocity()` 修改速度
- 在 trigger 范围内生效

### 3. GravityHubDeflector（引力枢纽偏转器）

**执行时机：**
- `Update()` 中运行（不是 FixedUpdate）
- 使用 `Time.time` 和 `detectionInterval` 控制检测频率

**检测方式：**
- 使用距离检测（不是 Collider）
- `deflectRadius`: 开始偏转的距离
- `releaseRadius`: 停止偏转的距离

**偏转逻辑：**
- 计算切向方向（垂直于径向）
- 理想速度：`idealVelocity = tangent * currentSpeed`（保持速度大小，改变方向）
- 速度调整：`adjustedVelocity = Lerp(currentVelocity, idealVelocity, deflectionStrength)`
- 限制速度变化：`maxVelocityChange`
- 确保最小速度：`minVelocity`

**应用方式：**
- 直接通过 `gravityEngine.SetVelocity()` 修改速度

### 4. PlanetGravityCapture（行星捕获）

**执行时机：**
- `Update()` 中运行（不是 FixedUpdate）
- 使用 `Time.time` 和 `detectionInterval` 控制检测频率

**检测方式：**
- 使用距离检测（不是 Collider）
- `captureRadius`: 开始捕获的距离
- `releaseRadius`: 释放捕获的距离

**轨道引导：**
- 理想轨道速度：`idealOrbitSpeed = sqrt(planetMass / distance)`
- 切向方向：根据当前速度方向选择（逆时针/顺时针）
- 速度调整：
  - 切向速度：`adjustedTangentialVel = Lerp(currentTangentialVel, idealTangentialVel, orbitGuidanceStrength)`
  - 径向速度：`adjustedRadialVel = Lerp(radialVel, Vector3.zero, orbitGuidanceStrength * 0.5f)`
- 最终速度：`newVelocity = adjustedRadialVel + adjustedTangentialVel`

**应用方式：**
- 直接通过 `gravityEngine.SetVelocity()` 修改速度

### 5. ShipState（飞船状态）

**速度缩放：**
- `speedMultiplier`: 速度缩放系数
- 在 `FixedUpdate()` 中应用
- 每帧获取当前速度，乘以 `speedMultiplier`，然后重新设置
- 使用 `lastScaledVelocity` 避免重复缩放

**状态管理：**
- `PreLaunch`: 发射前，不受引力影响
- `Flying`: 飞行中，受所有引力影响
- `Captured`: 被捕获，受引力影响

### 6. ShipBoost / ShipBoostAim（玩家主动加速）

**状态：**
- 玩家主动触发（按E键或特定键）
- 不在预测范围内（除非需要预测玩家操作）
- **暂不实现**

### 7. 当前 TrajectoryPredictor 的问题

**缺失的关键因素：**
1. ❌ 没有考虑 `physToWorldFactor` 的影响
2. ❌ 没有考虑 `CoreDeflector` 的影响
3. ❌ 没有考虑 `GravityHubDeflector` 的影响 ⚠️ **新发现**
4. ❌ 没有考虑 `PlanetGravityCapture` 的影响
5. ❌ 速度缩放应用不正确（在积分中应用，而不是每帧）
6. ❌ 引力源位置是静态的（所有 NBody 都有 FixedObject，位置固定）
7. ❌ 时间步长不匹配（预测使用固定步长，实际使用 FixedUpdate）

## 二、解决方案设计

### 核心思路

**完全复制游戏的实际物理计算流程**，包括：
1. GravityEngine 的基础引力
2. CoreDeflector 的偏转效果
3. PlanetGravityCapture 的捕获效果
4. ShipState 的速度缩放

### 实现步骤

#### 步骤1：正确计算基础引力

```csharp
private Vector3 CalculateGravityAcceleration(Vector3 position)
{
    Vector3 totalAcceleration = Vector3.zero;
    if (gravityEngine == null) return totalAcceleration;
    
    float physToWorldFactor = gravityEngine.physToWorldFactor;
    float massScale = gravityEngine.massScale;
    
    // 检查是否在 CoreDeflector 范围内
    bool isInCoreDeflectorRange = false;
    foreach (CoreDeflector deflector in coreDeflectors)
    {
        if (deflector != null && IsPointInTrigger(position, deflector.GetComponent<Collider>()))
        {
            isInCoreDeflectorRange = true;
            break;
        }
    }
    
    // 遍历所有引力源（NBody）
    foreach (NBody source in gravitySources)
    {
        if (source == null) continue;
        
        // 获取源的位置（固定，因为都有 FixedObject）
        Vector3 sourcePos = source.transform.position;
        Vector3 toSource = sourcePos - position;
        float distance = toSource.magnitude;
        
        if (distance < 0.01f) continue;
        
        // 检查是否有 CoreDeflector
        CoreDeflector coreDeflector = source.GetComponent<CoreDeflector>();
        if (coreDeflector != null && isInCoreDeflectorRange)
        {
            // CoreDeflector 会处理这个引力，跳过
            continue;
        }
        
        // 计算引力加速度
        // 注意：GravityEngine 在物理空间计算，然后转换
        // 但我们在世界空间计算，需要应用 physToWorldFactor 的立方影响
        float mass = source.mass * massScale;
        float factor3 = physToWorldFactor * physToWorldFactor * physToWorldFactor;
        float accelerationMagnitude = (mass * factor3) / (distance * distance);
        
        totalAcceleration += toSource.normalized * accelerationMagnitude;
    }
    
    return totalAcceleration;
}
```

#### 步骤2：应用 CoreDeflector 效果

```csharp
private void ApplyCoreDeflectorEffects(ref Vector3 position, ref Vector3 velocity, float dt)
{
    foreach (CoreDeflector deflector in coreDeflectors)
    {
        if (deflector == null) continue;
        
        Collider trigger = deflector.GetComponent<Collider>();
        if (trigger == null || !IsPointInTrigger(position, trigger)) continue;
        
        // 获取 Core 位置（CoreDeflector 挂载在 Core 上）
        Vector3 corePos = deflector.transform.position;
        Vector3 toCore = corePos - position;
        float distance = toCore.magnitude;
        
        if (distance < 0.01f) continue;
        
        // 获取参数（通过反射）
        float coreEffectiveMass = GetPrivateField<float>(deflector, "coreEffectiveMass");
        float guidanceStrength = GetPrivateField<float>(deflector, "guidanceStrength");
        float maxAngularVelocity = GetPrivateField<float>(deflector, "maxAngularVelocity");
        float targetOrbitRadius = GetPrivateField<float>(deflector, "targetOrbitRadius");
        float minDistance = GetPrivateField<float>(deflector, "minDistance");
        
        if (distance < minDistance) continue;
        
        Vector3 radialDirection = -toCore.normalized; // 指向 Core
        Vector3 velocityDirection = velocity.normalized;
        
        // 1. 计算径向引力
        float gravitationalAcceleration = coreEffectiveMass / (distance * distance);
        Vector3 radialGravity = radialDirection * gravitationalAcceleration;
        
        // 2. 计算引导加速度
        Vector3 tangentialDirection = GetTangentialDirection(-radialDirection, velocityDirection);
        Vector3 guidanceAcceleration = Vector3.zero;
        
        if (guidanceStrength > 0f)
        {
            Vector3 idealTangentialVel = tangentialDirection * velocity.magnitude;
            Vector3 velocityToTangential = idealTangentialVel - velocity;
            guidanceAcceleration = velocityToTangential * guidanceStrength / dt;
            
            if (targetOrbitRadius > 0f)
            {
                float radiusError = distance - targetOrbitRadius;
                Vector3 radiusCorrection = radialDirection * radiusError * guidanceStrength * 0.5f;
                guidanceAcceleration += radiusCorrection;
            }
        }
        
        // 3. 混合引力和引导
        Vector3 totalAcceleration = radialGravity * (1f - guidanceStrength) + guidanceAcceleration * guidanceStrength;
        
        // 4. 应用加速度
        Vector3 velocityChange = totalAcceleration * dt;
        Vector3 newVelocity = velocity + velocityChange;
        newVelocity.z = 0f;
        
        // 5. 限制最大角度改变
        if (maxAngularVelocity > 0f)
        {
            float currentSpeed = velocity.magnitude;
            float maxRotationPerFrame = maxAngularVelocity * Mathf.Deg2Rad * dt;
            
            Vector3 currentDir = velocityDirection;
            Vector3 targetDir = newVelocity.normalized;
            float angleChange = Vector3.Angle(currentDir, targetDir) * Mathf.Deg2Rad;
            
            if (angleChange > maxRotationPerFrame)
            {
                Vector3 rotationAxis = Vector3.Cross(currentDir, targetDir);
                if (rotationAxis.magnitude < 0.001f)
                {
                    rotationAxis = Vector3.forward;
                }
                rotationAxis = rotationAxis.normalized;
                
                Quaternion limitedRotation = Quaternion.AngleAxis(maxAngularVelocity * dt, rotationAxis);
                Vector3 limitedDir = limitedRotation * currentDir;
                newVelocity = limitedDir * currentSpeed;
            }
        }
        
        velocity = newVelocity;
    }
}
```

#### 步骤3：应用 GravityHubDeflector 效果

```csharp
private void ApplyGravityHubDeflectorEffects(ref Vector3 position, ref Vector3 velocity, float dt)
{
    foreach (GravityHubDeflector deflector in gravityHubDeflectors)
    {
        if (deflector == null) continue;
        
        // 获取枢纽 NBody
        NBody hubNBody = deflector.GetComponent<NBody>();
        if (hubNBody == null) continue;
        
        Vector3 hubPos = hubNBody.transform.position;
        Vector3 toHub = hubPos - position;
        float distance = toHub.magnitude;
        
        if (distance < 0.01f) continue;
        
        // 获取参数
        float deflectRadius = GetPrivateField<float>(deflector, "deflectRadius");
        float releaseRadius = GetPrivateField<float>(deflector, "releaseRadius");
        float deflectionStrength = GetPrivateField<float>(deflector, "deflectionStrength");
        float maxVelocityChange = GetPrivateField<float>(deflector, "maxVelocityChange");
        float minVelocity = GetPrivateField<float>(deflector, "minVelocity");
        
        // 检查是否在偏转范围内
        if (distance <= deflectRadius)
        {
            float currentSpeed = velocity.magnitude;
            
            if (currentSpeed < minVelocity) continue;
            
            Vector3 radialDir = toHub.normalized;
            Vector3 tangent = GetTangent(radialDir);
            
            // 计算理想速度（保持速度大小，改变方向）
            Vector3 idealVelocity = tangent * currentSpeed;
            
            // 轻微调整方向
            Vector3 adjustedVelocity = Vector3.Lerp(velocity, idealVelocity, deflectionStrength);
            
            // 限制速度变化
            Vector3 velocityChange = adjustedVelocity - velocity;
            if (velocityChange.magnitude > maxVelocityChange)
            {
                velocityChange = velocityChange.normalized * maxVelocityChange;
                adjustedVelocity = velocity + velocityChange;
            }
            
            // 确保速度不会太小
            if (adjustedVelocity.magnitude < minVelocity)
            {
                adjustedVelocity = adjustedVelocity.normalized * minVelocity;
            }
            
            adjustedVelocity.z = 0f;
            velocity = adjustedVelocity;
        }
    }
}
```

```csharp
private void ApplyPlanetCaptureEffects(ref Vector3 position, ref Vector3 velocity, float dt)
{
    foreach (PlanetGravityCapture capture in planetCaptures)
    {
        if (capture == null) continue;
        
        // 获取行星 NBody
        NBody planetNBody = capture.GetComponent<NBody>();
        if (planetNBody == null) continue;
        
        Vector3 planetPos = planetNBody.transform.position;
        Vector3 toPlanet = planetPos - position;
        float distance = toPlanet.magnitude;
        
        if (distance < 0.01f) continue;
        
        // 获取参数
        float captureRadius = GetPrivateField<float>(capture, "captureRadius");
        float releaseRadius = GetPrivateField<float>(capture, "releaseRadius");
        float orbitGuidanceStrength = GetPrivateField<float>(capture, "orbitGuidanceStrength");
        bool forceCounterClockwise = GetPrivateField<bool>(capture, "forceCounterClockwise");
        
        // 检查是否在捕获范围内
        if (distance <= captureRadius && distance <= releaseRadius)
        {
            float planetMass = planetNBody.mass;
            
            // 计算理想轨道速度
            Vector3 radialDir = toPlanet.normalized;
            Vector3 tangent = GetOrbitTangent(radialDir, velocity, forceCounterClockwise);
            float idealOrbitSpeed = Mathf.Sqrt(planetMass / Mathf.Max(distance, 0.1f));
            
            // 分解速度
            float radialSpeed = Vector3.Dot(velocity, radialDir);
            Vector3 radialVel = radialDir * radialSpeed;
            Vector3 tangentialVel = velocity - radialVel;
            
            // 计算理想切向速度
            Vector3 idealTangentialVel = tangent * idealOrbitSpeed;
            
            // 调整速度
            Vector3 adjustedTangentialVel = Vector3.Lerp(
                tangentialVel.normalized * Mathf.Max(tangentialVel.magnitude, 0.1f),
                idealTangentialVel,
                orbitGuidanceStrength
            );
            
            Vector3 adjustedRadialVel = Vector3.Lerp(radialVel, Vector3.zero, orbitGuidanceStrength * 0.5f);
            
            velocity = adjustedRadialVel + adjustedTangentialVel;
        }
    }
}
```

#### 步骤4：正确应用速度缩放

```csharp
private void SimulateTrajectory(Vector3 startPosition, Vector3 startVelocity)
{
    Vector3 position = startPosition;
    Vector3 velocity = startVelocity;
    
    float speedMultiplier = GetSpeedMultiplier();
    float dt = predictionTimeStep;
    
    // 注意：speedMultiplier 在 ShipState.FixedUpdate 中每帧应用
    // 所以我们需要在每个时间步后应用，而不是在积分中
    
    for (int i = 0; i < predictionSteps; i++)
    {
        // 1. 计算基础引力加速度
        Vector3 acceleration = CalculateGravityAcceleration(position);
        
        // 2. 应用加速度（使用 Verlet 积分）
        velocity += acceleration * (dt * 0.5f);
        position += velocity * dt;
        velocity += CalculateGravityAcceleration(position) * (dt * 0.5f);
        
        // 3. 应用 CoreDeflector 效果（在 FixedUpdate 中运行）
        // 注意：CoreDeflector 使用 Time.fixedUnscaledDeltaTime
        // 我们需要模拟 FixedUpdate 的调用频率
        if (i % Mathf.RoundToInt(Time.fixedUnscaledDeltaTime / dt) == 0)
        {
            ApplyCoreDeflectorEffects(ref position, ref velocity, Time.fixedUnscaledDeltaTime);
        }
        
        // 4. 应用 PlanetGravityCapture 效果（在 Update 中运行）
        // 注意：PlanetGravityCapture 使用 detectionInterval
        // 我们需要模拟 Update 的调用频率
        float detectionInterval = 0.1f; // 默认值
        if (i % Mathf.RoundToInt(detectionInterval / dt) == 0)
        {
            ApplyPlanetCaptureEffects(ref position, ref velocity, dt);
        }
        
        // 6. 应用速度缩放（在 ShipState.FixedUpdate 中每帧应用）
        // 注意：这应该在所有物理计算之后
        if (speedMultiplier != 1.0f)
        {
            velocity *= speedMultiplier;
        }
        
        // 限制在 XY 平面
        position.z = 0f;
        velocity.z = 0f;
        
        points.Add(position);
    }
}
```

### 关键注意事项

1. **时间步长匹配**：
   - 预测使用固定步长 `predictionTimeStep`
   - CoreDeflector 使用 `Time.fixedUnscaledDeltaTime`
   - PlanetGravityCapture 使用 `detectionInterval`
   - 需要模拟这些不同的更新频率

2. **坐标系统**：
   - 所有计算在世界空间进行
   - 需要正确应用 `physToWorldFactor` 的影响

3. **执行顺序**：
   - GravityEngine 基础引力
   - CoreDeflector 效果（在 FixedUpdate）
   - GravityHubDeflector 效果（在 Update）
   - PlanetGravityCapture 效果（在 Update）
   - ShipState 速度缩放（在 FixedUpdate）

4. **性能优化**：
   - 缓存所有组件引用
   - 使用反射缓存字段信息
   - 减少不必要的计算

## 四、补充因素说明

### 1. 多重偏转器重叠

**发现：**
- 每个 `CoreDeflector` 维护自己的 `shipsInTrigger` 字典
- 在 `FixedUpdate` 中，每个 `CoreDeflector` 独立处理飞船
- 如果多个 `CoreDeflector` 的 trigger 重叠，飞船会被多个 `CoreDeflector` 同时处理

**结论：**
- **效果是叠加的**，不是取第一个或平均值
- 实现中需要遍历所有重叠的 `CoreDeflector`，依次应用效果

**实现：**
```csharp
// 收集所有重叠的 CoreDeflector
List<CoreDeflector> activeDeflectors = new List<CoreDeflector>();
foreach (CoreDeflector deflector in coreDeflectors)
{
    if (IsPointInTrigger(position, deflector.GetComponent<Collider>()))
    {
        activeDeflectors.Add(deflector);
    }
}

// 叠加所有效果
foreach (CoreDeflector deflector in activeDeflectors)
{
    ApplyDeflectorEffect(deflector, ref position, ref velocity, dt);
}
```

### 2. 最大预测长度限制

**问题：**
- 飞船可能被弹射到无穷远，导致预测死循环
- 需要熔断机制防止性能问题

**实现：**
- `maxPredictionDistance`: 最大预测距离（Unity单位）
- `maxPredictionStepsHardLimit`: 最大步数硬限制
- 在每步后检查距离和速度，超过限制立即停止

**代码：**
```csharp
// 检查最大距离限制
float distanceFromStart = Vector3.Distance(position, startPos);
if (distanceFromStart > maxPredictionDistance)
{
    Debug.LogWarning($"[预测] 轨迹预测超过最大距离，停止");
    break;
}

// 检查速度异常
if (velocity.magnitude > 10000f || float.IsNaN(velocity.magnitude))
{
    Debug.LogWarning($"[预测] 速度异常，停止");
    break;
}
```

### 3. 层级掩码（LayerMask）

**用途：**
- 允许只受特定 Layer 的行星影响
- 提供更精细的控制

**实现：**
- 添加 `gravitySourceLayerMask` 字段
- 在计算引力和应用效果时检查层级
- 默认值为 -1（所有层）

**代码：**
```csharp
// 检查层级掩码
if (gravitySourceLayerMask != -1 && 
    (gravitySourceLayerMask & (1 << source.gameObject.layer)) == 0)
{
    continue; // 跳过此引力源
```
