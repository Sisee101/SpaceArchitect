# 预测数据记录功能说明

## 功能概述

新增了预测数据记录功能，可以记录预测过程中的所有关键数据，方便与实际的飞行数据进行对比分析。

## 使用方法

### 1. 启用预测数据记录

在 Unity Inspector 中：
1. 找到 `TrajectoryPredictor` 组件
2. 展开 **"预测数据记录"** 部分
3. 勾选 **"启用预测数据记录"**
4. 设置 **"预测日志文件路径"**（默认：`PredictionDataLog.txt`）
5. 设置 **"预测日志记录间隔"**（默认：1，表示每步都记录）

### 2. 运行游戏并触发预测

- 预测会在每次调用 `PredictFullTrajectory` 时自动记录
- 记录会在预测完成后自动保存到文件

### 3. 查看日志文件

日志文件保存在项目根目录（与 `FlightDataLog.txt` 同级），格式与 `FlightDataLog.txt` 一致，方便对比。

  - physToWorldFactor: 1
  - massScale: 1

  - CoreDeflector[1]: 位置=(4.61, -8.29, 0.00), 质量=500, 引导强度=0.195
---

### 数据行格式
```
[步数] t=时间 pos=(x,y,z) vel=(vx,vy,vz) speed=速度大小 gravAcc=(ax,ay,az) Core[...]:dist=距离,grav=引力,guidance=引导强度,ACTIVE speedMult=缩放系数
```

## 对比分析方法

### 1. 时间对齐
- 预测日志中的时间是从开始预测的时间（t=0）计算的
- 实际日志中的时间是从游戏开始的时间计算的
- 需要找到实际日志中飞船开始飞行的时刻，然后对齐时间

### 2. 关键指标对比
- **位置差异**：比较相同时间点的位置
- **速度差异**：比较相同时间点的速度
- **CoreDeflector 触发时机**：比较 CoreDeflector 何时开始生效
- **速度变化**：比较速度变化的时间点和幅度

### 3. 使用 Excel 或 Python 分析
1. 将两个日志文件导入 Excel 或 Python
2. 按时间对齐数据
3. 计算位置和速度的差异
4. 绘制差异曲线，找出问题所在

## 注意事项

1. **性能影响**
   - 启用预测数据记录会增加内存和磁盘 I/O
   - 如果 `predictionLogInterval` 设置为 1，文件会很大
   - 建议在调试时使用，正式发布时关闭

2. **文件路径**
   - 日志文件保存在项目根目录（`Application.dataPath/../`）
   - 确保有写入权限

3. **时间同步**
   - 预测日志中的时间是从开始预测的时间计算的
   - 实际日志中的时间是从游戏开始的时间计算的
   - 需要手动对齐时间才能对比

4. **记录间隔**
   - `predictionLogInterval = 1`：每步都记录（最详细，文件最大）
   - `predictionLogInterval = 5`：每5步记录一次（平衡）
   - `predictionLogInterval = 10`：每10步记录一次（文件较小）

## 预期效果

通过对比预测和实际的数据，可以：
1. 找出预测不准确的具体原因
2. 定位 CoreDeflector 触发时机的差异
3. 发现速度变化的时间点差异
4. 验证修复效果
