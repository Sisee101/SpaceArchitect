# 预测简化修复方案

## 核心思路

**简化！简化！再简化！**

当前代码太复杂了，有太多可能出错的地方。让我们回到最基本的方法。

## 三步修复法

### 第一步：移除所有延迟机制

**问题：** `triggerDelayFrames` 很难准确，而且增加了复杂性

**修复：** 进入 trigger 后立即应用效果

```csharp
// 简化版本：移除所有延迟逻辑
if (inTrigger)
{
    // 立即检查是否应该应用（基于 physicsUpdateInterval）
    if (i % deflectorUpdateInterval == 0)
    {
        currentVel = ApplyCoreDeflector(...);
    }
}
```

### 第二步：只使用距离检测

**问题：** AABB 检测和距离检测可能不一致

**修复：** 只使用距离检测，简单可靠

```csharp
// 简化版本：只使用距离检测
float distToCore = Vector3.Distance(currentPos, source.deflector.corePosition);
bool inTrigger = distToCore <= source.deflector.triggerRadius;
```

### 第三步：增大 trigger 半径（补偿误差）

**问题：** 检测可能不够准确

**修复：** 增大 trigger 半径 30-50%，确保能检测到

```csharp
// 在 CacheGravitySources 中
triggerRadius *= 1.5f; // 增大 50%
```

## 快速修复代码

### 修改 TrajectoryPredictor.cs 的 CoreDeflector 部分

```csharp
// ========== 2. CoreDeflector 阶段（简化版本）==========
if (i % fixedUpdateInterval == 0)
{
    foreach (var source in cachedSources)
    {
        if (source.hasDeflector)
        {
            // 简化：只使用距离检测
            Vector3 toCore = source.deflector.corePosition - currentPos;
            float distToCore = toCore.magnitude;
            float triggerRadius = source.deflector.triggerRadius;
            
            // 简化：移除延迟，进入后立即应用
            bool inTrigger = distToCore <= triggerRadius;
            
            if (inTrigger)
            {
                // 检查 physicsUpdateInterval
                int deflectorUpdateInterval = Mathf.Max(1, 
                    Mathf.RoundToInt(source.deflector.physicsUpdateInterval / fixedUnscaledDeltaTime));
                
                if (i % deflectorUpdateInterval == 0)
                {
                    currentVel = ApplyCoreDeflector(currentPos, currentVel, source.deflector, fixedUnscaledDeltaTime);
                }
            }
        }
    }
}
```

## 如果还是不准

```csharp
// 临时禁用 CoreDeflector
if (false && source.hasDeflector) // 临时禁用
{
    // ...
}
```

## 最简化的测试版本

如果你想快速测试，可以使用这个最简化的版本：

```csharp
// 最简化版本：只计算基础引力，不处理 CoreDeflector
// 这样可以先验证基础预测是否准确
for (int i = 0; i < actualSteps; i++)
{
    // 1. 计算基础引力
    Vector3 totalGravityAcc = Vector3.zero;
    foreach (var source in cachedSources)
    {
        Vector3 toSource = source.position - currentPos;
        float distSq = toSource.sqrMagnitude;
        if (distSq < 0.01f) continue;
        float mag = source.nbodyEffectiveMass / distSq;
        totalGravityAcc += toSource.normalized * mag;
    }
    
    // 2. 更新速度和位置（LeapFrog）
    currentVel += totalGravityAcc * (dt * 0.5f);
    currentPos += currentVel * dt;
    
    // 重新计算加速度
    totalGravityAcc = Vector3.zero;
    foreach (var source in cachedSources)
    {
        Vector3 toSource = source.position - currentPos;
        float distSq = toSource.sqrMagnitude;
        if (distSq < 0.01f) continue;
        float mag = source.nbodyEffectiveMass / distSq;
        totalGravityAcc += toSource.normalized * mag;
    }
    currentVel += totalGravityAcc * (dt * 0.5f);
    
    predictionPoints.Add(currentPos);
}
```
