# 引力枢纽弹飞问题解决方案

## 🔍 问题分析

### 现象描述
飞船被引力枢纽吸引后会被**弹飞**，而不是进行平滑的方向偏转。

### 可能的原因

#### 1. **速度过大导致飞越**
```
飞船速度太快 → 直接飞过引力枢纽 → 获得过大速度 → 被弹飞
```

#### 2. **缺乏切向速度**
```
飞船直接朝向引力枢纽 → 获得过大径向速度 → 飞过中心 → 被弹飞
```

#### 3. **质量比例不当**
```
引力枢纽质量太大 → 引力过强 → 飞船获得过大加速度 → 被弹飞
```

#### 4. **碰撞检测问题**
```
飞船撞到引力枢纽的碰撞体 → 触发物理反弹 → 被弹飞
```

---

## 🛠️ 解决方案

### 方案1：使用 GravityHubDeflector 脚本（推荐）

**特点：**
- ✅ 只做方向偏转，不直接修改速度大小
- ✅ 限制速度变化，防止弹飞
- ✅ 保持速度在合理范围内
- ✅ 与 `lockToXYPlane` 兼容

**使用方法：**
1. 在引力枢纽物体上添加 `GravityHubDeflector` 组件
2. 调整参数：
   - `deflectRadius = 20f`：偏转范围
   - `deflectionStrength = 0.05f`：偏转强度（越小越自然）
   - `maxVelocityChange = 5f`：最大速度变化（防止弹飞）
   - `minVelocity = 0.5f`：最小速度保持

**工作原理：**
```
1. 检测飞船是否在偏转范围内
2. 计算切向方向（垂直于径向）
3. 将当前速度方向逐渐偏转到切向方向
4. 限制速度变化，防止突然加速
5. 保持速度大小基本不变
```

## ⚠️ 注意事项

### 1. 执行顺序
- `GravityHubDeflector` 在 `Update` 中运行
- 确保在 `GravityEngine` 的物理更新之后执行
- 如果出现问题，考虑使用 `FixedUpdate`

### 2. 与 lockToXYPlane 的兼容性
- ✅ 脚本已经确保 Z=0
- ✅ 与 `lockToXYPlane` 完全兼容

### 3. 多个引力枢纽
- 如果场景中有多个引力枢纽，它们会**同时作用**
- 可能导致飞船运动复杂
- 建议：调整 `deflectRadius`，避免重叠

### 4. 性能考虑
- 每 0.1 秒检测一次飞船
- 如果飞船数量多，可能影响性能
- 建议：使用对象池或缓存机制

## 🎮 参数调整建议

### 温和偏转（推荐）
```
deflectionStrength = 0.03f
maxVelocityChange = 3f
```
- 非常自然，几乎不影响重力
- 适合大多数情况

### 中等偏转
```
deflectionStrength = 0.05f
maxVelocityChange = 5f
```
- 平衡自然度和效果
- 适合需要明显偏转的情况

### 强偏转
```
deflectionStrength = 0.1f
maxVelocityChange = 8f
```
- 明显的方向改变
- 可能感觉不够自然

## 📝 总结

### 问题根源：
飞船被弹飞主要是因为：
1. 速度过大
2. 缺乏切向速度
3. 质量比例不当
4. 直接飞过引力枢纽中心

### 解决方案：
1. ✅ 使用 `GravityHubDeflector` 脚本（推荐）
2. ✅ 调整质量比例
3. ✅ 调整初始速度
4. ✅ 限制速度变化

### 关键参数：
- `deflectionStrength`：控制偏转强度
- `maxVelocityChange`：防止弹飞的关键参数
- `deflectRadius`：控制影响范围
