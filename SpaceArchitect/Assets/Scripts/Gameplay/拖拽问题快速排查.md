# 拖拽问题快速排查指南

## 🔍 快速检查清单

### 1. 检查 Tag（最重要！）

**在 Inspector 中检查：**
- ✅ 物体的 Tag 必须是 `"Core"`
- ❌ 如果是 `Untagged` 或其他，拖拽不会工作

**如何设置：**
1. 选中 Gravity Core 物体
2. 在 Inspector 顶部找到 Tag 下拉菜单
3. 选择 `"Core"`（如果没有，需要先在 Tag Manager 中添加）

---

### 2. 检查 Collider 组件

**必须条件：**
- ✅ 物体必须有 Collider 组件
- ✅ Collider 必须启用（Enabled = true）

**检查方法：**
1. 选中 Gravity Core 物体
2. 在 Inspector 中查看是否有 Collider 组件
3. 确保 Collider 的勾选框是勾选的

**常见问题：**
- ❌ 没有 Collider → 添加 BoxCollider 或 SphereCollider
- ❌ Collider 被禁用 → 勾选 Enabled

---

### 3. 检查 Camera.main

**必须条件：**
- ✅ 场景中必须有 Tag 为 `"MainCamera"` 的相机

**检查方法：**
1. 在 Hierarchy 中找到主相机
2. 确保它的 Tag 是 `"MainCamera"`

---

### 4. 使用诊断工具

**方法1：右键菜单诊断**
1. 在 Hierarchy 中选中 Gravity Core 物体
2. 在 Inspector 中找到 `CoreDragger` 组件
3. 点击组件右上角的三个点（⋮）
4. 选择 `"诊断拖拽功能"`

**方法2：查看 Console**
- 运行游戏后，查看 Console 窗口
- 应该看到 `[CoreDragger] Start:` 的日志
- 如果看到错误信息，根据提示修复

---

## 🐛 常见问题及解决方案

### 问题1：完全没有反应

**可能原因：**
1. Tag 不是 "Core"
2. 没有 Collider
3. Collider 被禁用

**解决：**
- 检查 Console 中的诊断日志
- 根据错误信息修复

---

### 问题2：点击时没有反应

**可能原因：**
1. 被其他物体遮挡
2. UI 元素遮挡
3. 相机看不到物体

**解决：**
- 检查物体是否在相机视野内
- 检查是否有 UI Canvas 遮挡
- 尝试从不同角度点击

---

### 问题3：点击时有反应但无法拖拽

**可能原因：**
1. Camera.main 为 null
2. 鼠标坐标转换失败

**解决：**
- 检查 Console 是否有错误
- 确保主相机 Tag 是 "MainCamera"

---

### 问题4：拖拽时物体不移动

**可能原因：**
1. Transform 被锁定
2. 其他脚本控制位置
3. Rigidbody 设置错误

**解决：**
- 检查 Transform 的 Position 是否被锁定
- 检查是否有其他脚本在控制位置
- 确保 Rigidbody 是运动学的

---

## 🔧 修复步骤

### 步骤1：检查基本设置

1. **Tag 设置**
   ```
   Inspector → Tag → 选择 "Core"
   ```

2. **Collider 设置**
   ```
   Inspector → Add Component → Box Collider
   或使用现有的 Collider，确保启用
   ```

3. **Camera 设置**
   ```
   Hierarchy → 主相机 → Tag → "MainCamera"
   ```

### 步骤2：运行诊断

1. 运行游戏
2. 查看 Console 日志
3. 根据错误信息修复

### 步骤3：测试拖拽

1. 点击 Gravity Core
2. 查看 Console 是否有 `OnMouseDown` 日志
3. 如果没有，检查上述设置

## 💡 提示

1. **右键诊断功能**：在 Inspector 中右键点击 `CoreDragger` 组件，选择 "诊断拖拽功能"
2. **查看 Console**：运行游戏后立即查看 Console，会有详细的诊断信息
3. **检查层级**：确保 Gravity Core 在正确的 Layer，没有被忽略射线检测

---

## 🔄 如果仍然无法拖拽

1. **禁用其他脚本**：临时禁用其他可能冲突的脚本
2. **检查事件系统**：确保没有 EventSystem 拦截鼠标事件
3. **检查物理层**：确保 Collider 在正确的物理层
4. **重新添加组件**：删除并重新添加 `CoreDragger` 组件
