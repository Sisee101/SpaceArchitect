  轨迹预测精度优化指南
═══════════════════════════════════════════════════════════════════

问题现象：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  ✓ 前半段轨迹预测准确
  ✗ 后半段轨迹误差越来越大
  ✗ 离出发点越远，误差越大

问题原因：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  数值积分误差累积问题：
  - 每一步积分都有小误差
  - 误差会逐步累积
  - 时间越长，累积误差越大
  - 简单欧拉法精度有限

解决方案：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

┌────────────────────────────────────────────────────────────┐
│  方案1：减小时间步长（最简单）⭐                         │
└────────────────────────────────────────────────────────────┘

  原理：
    步长越小 → 每步误差越小 → 总误差越小

  设置：
    1. 选中飞船
    2. 找到 Trajectory Predictor 组件
    3. 调整 Prediction Time Step：
       
       ┌────────────────────────────────────────┐
       │  推荐值               适用场景        │
       ├────────────────────────────────────────┤
       │  0.005 - 0.008    最高精度（高性能）  │
       │  0.008 - 0.01     高精度（推荐）      │
       │  0.01 - 0.02      标准精度            │
       │  0.02 - 0.03      低精度（快速）      │
       └────────────────────────────────────────┘

  优点：
    ✓ 简单直接
    ✓ 立即见效
    ✓ 不改变算法

  缺点：
    ✗ 步长太小会增加计算量
    ✗ 可能影响性能（FPS）

  建议：
    → 先尝试 0.01
    → 如果还不够准确，再降到 0.008 或 0.005
    → 如果 FPS 下降，适当提高步长

┌────────────────────────────────────────────────────────────┐
│  方案2：使用高精度积分方法 ⭐⭐（推荐）                   │
└────────────────────────────────────────────────────────────┘

  原理：
    高精度算法 → 每步误差更小 → 即使步长大也能保持精度

  设置：
    1. 选中飞船
    2. 找到 Trajectory Predictor 组件
    3. 找到 Integration Method 参数
    4. 选择合适的方法：

       ┌───────────────────────────────────────────────┐
       │  方法     精度    性能    适用场景            │
       ├───────────────────────────────────────────────┤
       │  Euler    中等    最快    简单场景            │
       │  Verlet   高      中等    引力系统（推荐）⭐  │
       │  RK2      高      慢      复杂场景            │
       └───────────────────────────────────────────────┘

  推荐配置：
    ╔═══════════════════════════════════════════════╗
    ║  Integration Method: Verlet                  ║
    ║  Prediction Time Step: 0.01                  ║
    ╚═══════════════════════════════════════════════╝

  为什么推荐 Verlet？
    ✓ 专门为引力系统设计
    ✓ 能量守恒更好
    ✓ 长时间模拟更稳定
    ✓ 性能和精度平衡

  各方法详解：

    【Euler（欧拉法）】
      特点：最简单的积分方法
      公式：
        v(t+dt) = v(t) + a(t) * dt
        x(t+dt) = x(t) + v(t) * dt
      
      优点：
        ✓ 计算速度最快
        ✓ 实现简单
      
      缺点：
        ✗ 精度中等
        ✗ 长时间会累积误差
        ✗ 能量不守恒

    【Verlet（Velocity Verlet）】⭐
      特点：专为物理模拟设计
      公式：
        v(t+dt/2) = v(t) + a(t) * dt/2
        x(t+dt) = x(t) + v(t+dt/2) * dt
        v(t+dt) = v(t+dt/2) + a(t+dt) * dt/2
      
      优点：
        ✓ 高精度
        ✓ 能量守恒好
        ✓ 适合引力系统
        ✓ 时间可逆
      
      缺点：
        ✗ 需要计算两次加速度
        ✗ 比 Euler 慢约 2 倍

    【RK2（龙格库塔二阶/中点法）】
      特点：通用高精度方法
      公式：
        k1 = f(x, v)
        k2 = f(x + k1*dt/2, v + k1*dt/2)
        新值 = 旧值 + k2 * dt
      
      优点：
        ✓ 高精度
        ✓ 适用范围广
      
      缺点：
        ✗ 需要计算两次加速度
        ✗ 比 Verlet 稍慢

┌────────────────────────────────────────────────────────────┐
│  方案3：组合优化（最佳效果）⭐⭐⭐                        │
└────────────────────────────────────────────────────────────┘

  同时使用方案1和方案2：

    ╔═══════════════════════════════════════════════╗
    ║  推荐配置：                                  ║
    ║                                              ║
    ║  Integration Method: Verlet                  ║
    ║  Prediction Time Step: 0.01                  ║
    ║  Prediction Steps: 500                       ║
    ║  Max Prediction Time: 10                     ║
    ╚═══════════════════════════════════════════════╝

  效果：
    ✓ 预测精度极高
    ✓ 长时间轨迹准确
    ✓ 性能消耗可接受

  如果性能还有余量（FPS > 60）：
    → 可以降低 Time Step 到 0.008
    → 或增加 Prediction Steps

  如果性能不足（FPS < 30）：
    → 提高 Time Step 到 0.015
    → 或减少 Prediction Steps

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  【测试步骤】

    1. 进入 Preview 模式：
       - Prediction Mode = Preview

    2. 拖拽发射器：
       - 观察预测轨迹线

    3. 发射飞船：
       - 观察实际飞行路径

    4. 对比：
       - 前段应该重合
       - 中段应该接近
       - 后段应该趋势一致

  【精度判断标准】

    优秀（⭐⭐⭐）：
      ✓ 前80%轨迹几乎完全重合
      ✓ 后20%轨迹趋势一致，偏差 < 1个飞船宽度

    良好（⭐⭐）：
      ✓ 前60%轨迹基本重合
      ✓ 后40%轨迹趋势一致，偏差 < 2个飞船宽度

    及格（⭐）：
      ✓ 前50%轨迹基本重合
      ✓ 后50%轨迹大致方向正确

    不及格（✗）：
      ✗ 前半段就开始明显偏离

  性能优化建议
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  【性能影响因素】

    计算量 = Prediction Steps × 积分方法复杂度

    积分方法复杂度：
      Euler:  1x
      Verlet: 2x
      RK2:    2x

  【优化策略】

    1. 平衡步数和步长：
       
       ┌──────────────────────────────────────┐
       │  同样的总预测时间：                 │
       │  500 steps × 0.02s = 10s            │
       │  1000 steps × 0.01s = 10s           │
       │                                      │
       │  后者更精确，但计算量是前者的 2 倍  │
       └──────────────────────────────────────┘

    2. 根据场景调整：
       
       简单场景（只有1-2个引力源）：
         → 可以用更小的步长
         → 或更多的步数

       复杂场景（多个引力源）：
         → 适当增加步长
         → 减少步数
         → 优先用 Verlet 而不是更小步长

    3. 动态调整：
       
       发射前（Preview 模式）：
         → 可以用更高精度
         → 用户有时间等待

       飞行中（RealTimeTrack 模式）：
         → 需要实时计算
         → 适当降低精度

  【性能监控】

    在 Unity Profiler 中查看：
      - TrajectoryPredictor.UpdateTrajectory
      - TrajectoryPredictor.SimulateTrajectory

    如果这些方法占用 > 5ms：
      → 考虑降低精度
      → 或优化引力源数量

  常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Q: 为什么切换到 Verlet 后反而不准了？
  ───────────────────────────────────────────────
  A: 可能原因：
     1. GravityEngine 本身用的是 Euler
        → 需要匹配
        → 或者 Verlet 会更准但与实际不符
     
     2. 检查其他参数：
        → Speed Multiplier 是否正确
        → Mass Scale 是否一致
        → Gravity Multiplier 是否为 1.0

  Q: 设置了 0.01 步长，为什么 FPS 掉了很多？
  ───────────────────────────────────────────────
  A: 步长减半 = 计算量翻倍
     优化方法：
     1. 减少 Prediction Steps（如 500 → 300）
     2. 切换到 Euler（如果精度够用）
     3. 只在必要时显示轨迹

  Q: Verlet 和 RK2 哪个更好？
  ───────────────────────────────────────────────
  A: 对于引力系统，推荐 Verlet：
     - Verlet 保持能量守恒
     - RK2 更通用但不一定更好
     - 性能相近

  Q: 能否达到 100% 准确？
  ───────────────────────────────────────────────
  A: 理论上不可能，因为：
     1. GravityEngine 和预测用的算法可能不同
     2. 浮点数精度限制
     3. 数值积分固有误差
     
     但可以做到"视觉上完美"：
     → 使用 Verlet + 0.008 步长
     → 误差 < 1 像素

  ✅ 如果需要更高精度：
     → Time Step: 0.008 或 0.005

     → 检查其他参数（Mass Scale, Speed Multiplier）
     → 确保 Core 的引力设置正确
