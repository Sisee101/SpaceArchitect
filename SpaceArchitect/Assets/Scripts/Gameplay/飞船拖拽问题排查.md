# 飞船拖拽问题排查指南

## 🔍 问题现象

飞船发射前的拖拽（drag）功能无法使用。

## 🛠️ 已修复内容

### 1. ShipLauncher 优化

添加了与 `CoreDragger` 的冲突检测：
- 如果鼠标明确点击在 Core 上，跳过飞船拖拽
- 如果鼠标在飞船附近，优先处理飞船拖拽

### 2. CoreDragger 优化

添加了更严格的检查：
- 只处理 Tag 为 "Core" 的物体
- 检查是否有 Collider（OnMouseDown 需要 Collider）

## 🔧 排查步骤

### 步骤1：检查飞船状态

```csharp
// 在 Console 中检查
Debug.Log($"飞船状态: {shipState.CurrentState}");
// 应该是 PreLaunch
```

**如果状态不是 PreLaunch：**
- 飞船可能已经发射
- 检查 `ShipState` 组件的初始状态

### 步骤2：检查 ShipLauncher 组件

在 Inspector 中检查：
- ✅ `ShipLauncher` 组件存在
- ✅ `Ship State` 引用正确
- ✅ `Arrow Line` 和 `Arrow Head` 引用（可选）

### 步骤3：检查鼠标位置

```csharp
// 在 ShipLauncher.StartDrag() 中添加
Debug.Log($"鼠标位置: {Input.mousePosition}");
Debug.Log($"飞船屏幕位置: {shipScreenPosition}");
Debug.Log($"距离: {distanceToShip}");
```

**如果距离 > 100：**
- 鼠标不在飞船附近
- 尝试将鼠标移到飞船更近的位置

### 步骤4：检查 Tag 设置

确保：
- ✅ 飞船的 Tag **不是** "Core"
- ✅ 飞船的 Tag 应该是 "Spaceship" 或 "Ship"
- ✅ Gravity Core 的 Tag 是 "Core"

### 步骤5：检查 Collider

**飞船：**
- 飞船**不需要** Collider 来拖拽（ShipLauncher 使用距离检测）
- 但如果飞船有 Collider，确保 Tag 不是 "Core"

**Gravity Core：**
- Gravity Core **需要** Collider（CoreDragger 使用 OnMouseDown）
- Collider 应该是 Trigger 或普通 Collider

### 步骤6：检查 Console 日志

正常拖拽时应该看到：
```
开始拖拽飞船，距离: 45.2
```

如果没有看到日志：
- `StartDrag()` 没有被调用
- 检查 `CanLaunch()` 是否返回 true
- 检查鼠标是否在飞船附近

## 🐛 常见问题

### 问题1：完全没有反应

**可能原因：**
1. 飞船状态不是 PreLaunch
2. `ShipLauncher` 组件缺失
3. `ShipState` 引用错误

**解决：**
```csharp
// 检查组件
Debug.Log($"ShipState: {shipState != null}");
Debug.Log($"CanLaunch: {shipState.CanLaunch()}");
```

### 问题2：鼠标在飞船附近但无法拖拽

**可能原因：**
1. 距离检测阈值太小（默认 100 像素）
2. 鼠标被 Core 物体遮挡
3. UI 元素遮挡

**解决：**
- 增大检测范围（修改 `distanceToShip < 100f` 为更大的值）
- 检查是否有 UI 元素遮挡
- 确保飞船在 Core 前面（Z 轴或渲染顺序）

### 问题3：拖拽时箭头不显示

**可能原因：**
1. `arrowLine` 引用为空
2. LineRenderer 组件未正确初始化

**解决：**
- 检查 `arrowLine` 是否已初始化
- 查看 Console 是否有错误

### 问题4：拖拽被 Core 拦截

**可能原因：**
1. 飞船和 Core 重叠
2. Core 在飞船前面

**解决：**
- 调整 Core 的 Z 轴位置，让它在飞船后面
- 或者调整渲染顺序
- 或者增大飞船的检测范围

## 💡 建议

如果问题仍然存在：

1. **临时禁用 CoreDragger**
   - 在 Gravity Core 上禁用 `CoreDragger` 组件
   - 测试飞船拖拽是否恢复
   - 如果恢复，说明是冲突问题

2. **检查执行顺序**
   - `ShipLauncher` 在 `Update` 中运行
   - `CoreDragger` 在 `OnMouseDown` 中运行
   - Unity 事件系统可能先于 Update 执行

3. **使用 Script Execution Order**
   - 在 Project Settings 中设置执行顺序
   - 让 `ShipLauncher` 先执行

## 📝 技术细节

### 拖拽检测机制

**ShipLauncher：**
- 使用 `Input.GetMouseButtonDown(0)`（全局输入）
- 使用屏幕坐标距离检测
- **不依赖 Collider**

**CoreDragger：**
- 使用 `OnMouseDown`（Unity 事件系统）
- **需要 Collider**
- 只处理 Tag 为 "Core" 的物体

### 冲突处理

当鼠标点击时：
1. `CoreDragger.OnMouseDown` 先执行（如果击中 Core）
2. `ShipLauncher.Update` 后执行
3. 如果鼠标在飞船附近，`ShipLauncher` 也会处理

**解决方案：**
- `ShipLauncher` 检查是否击中 Core
- 如果击中 Core 且距离飞船较远，跳过飞船拖拽
- 如果距离飞船很近，优先处理飞船拖拽
