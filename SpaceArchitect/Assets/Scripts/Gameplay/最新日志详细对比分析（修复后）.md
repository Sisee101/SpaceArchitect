## 二、问题诊断

### 2.1 初始速度不一致

**问题**：
- 实际：14.98
- 预测：14.99
- 差异：0.01

**可能原因**：
1. **速度获取时机不同**：
   - 实际日志在 `FixedUpdate` 中记录
   - 预测日志在 `PredictFullTrajectory` 开始时记录
   - 可能存在一帧的延迟

2. **精度问题**：
   - 浮点数精度导致的微小差异
   - 速度计算过程中的舍入误差

3. **速度缩放系数**：
   - 实际中可能已经应用了速度缩放
   - 预测中可能还没有应用

### 2.2 激活时机差异

**问题**：
- 实际：距离 9.22 时激活
- 预测：距离 9.51 时激活
- 差异：0.29

**可能原因**：
1. **TRIGGER_DELAY_FRAMES 设置不准确**：
   - 当前值：6 帧
   - 可能需要调整

2. **位置计算差异**：
   - 实际使用 `GravityEngine.GetScenePosition`
   - 预测使用计算的位置
   - 可能存在累积误差

3. **Trigger 检测逻辑差异**：
   - 实际使用 Unity 的 `OnTriggerEnter`
   - 预测使用 AABB 或距离检测
   - 检测时机可能不同

### 2.3 效果差异巨大（严重问题）

**问题**：
- 实际：velChange=0.018, accel=0.911
- 预测：velChange=0.848, accel=42.389
- **差异：47 倍和 46 倍**

**可能原因**：

1. **速度变化计算方式不同**：
   - **实际中**：`velChange = currentVel - lastVelocity`（当前帧 - 上一帧）
   - **预测中**：`velChange = currentVel - oldVel`（应用效果后 - 应用效果前）
   - **关键差异**：实际的 velChange 包含了所有因素的影响（基础引力、CoreDeflector等），而预测的 velChange 只包含 CoreDeflector 的效果

2. **加速度计算方式不同**：
   - **实际中**：`accel = velChange / fixedUnscaledDeltaTime`（总速度变化 / 时间）
   - **预测中**：`accel = velChange / fixedUnscaledDeltaTime`（CoreDeflector 效果 / 时间）
   - **关键差异**：实际的 accel 是总加速度，预测的 accel 只是 CoreDeflector 的加速度

3. **时间步长差异**：
   - 实际：使用 `Time.fixedUnscaledDeltaTime`（0.02秒）
   - 预测：使用 `fixedUnscaledDeltaTime`（应该也是 0.02秒）
   - 但可能在某些情况下不一致
