# 行星图鉴解锁系统搭建指南

## 概述

本指南将帮助您为行星图鉴系统添加解锁功能。系统支持13个行星的解锁状态管理，未解锁的行星卡片会显示统一的锁定图片，且无法点击展开详情卡片。解锁状态会自动持久化保存。

## 功能特性

- **解锁状态管理**：13个行星（索引0-12）的解锁状态独立管理
- **状态持久化**：使用PlayerPrefs自动保存，游戏重启后状态保持
- **事件驱动**：通过EventManager实现松耦合的事件通信
- **自动更新**：解锁后卡片自动切换显示状态
- **点击限制**：未解锁卡片无法点击展开详情

## 二、UI配置步骤

### 2.1 配置PlanetEncyclopediaPanel

1. **打开行星图鉴面板场景**
   - 在Unity编辑器中找到包含 `PlanetEncyclopediaPanel` 的场景

2. **选中PlanetEncyclopediaPanel GameObject**
   - 在Hierarchy中找到 `PlanetEncyclopediaPanel` GameObject
   - 选中后在Inspector中查看 `PlanetEncyclopediaPanel` 组件

3. **配置未解锁图片**
   - 找到 **"Locked Planet Image"** 字段
   - 从Project窗口拖入**未解锁状态的共用图片**
   - 这张图片将用于所有未解锁的行星卡片

   > **重要提示**：
   > - 未解锁图片只需要一张，所有未解锁的卡片共用
   > - 已解锁图片仍然使用 `Planet Card Images` 列表中的对应图片（索引0-12）

4. **确认已解锁图片配置**
   - 检查 **"Planet Card Images"** 列表
   - 确保有13张图片（索引0-12对应13个行星）
   - 这些是解锁后显示的行星卡片图片

### 2.2 创建PlanetUnlockManager（自动创建）

**PlanetUnlockManager会自动创建，无需手动配置**：

- 如果场景中没有 `PlanetUnlockManager`，会在首次访问时自动创建
- 会自动设置为 `DontDestroyOnLoad`，跨场景保持存在
- 在 `Awake()` 中自动加载已保存的解锁状态

**可选：手动创建（用于调试）**

如果需要手动创建：

1. 在场景中创建一个空GameObject
2. 命名为 `PlanetUnlockManager`
3. 添加 `PlanetUnlockManager` 脚本组件

### 2.3 配置解锁按钮

#### 方法一：使用PlanetUnlockButton脚本（推荐）

1. **创建按钮GameObject**
   - 在需要解锁功能的场景中创建Button
   - 或使用现有的按钮

2. **添加PlanetUnlockButton脚本**
   - 选中按钮GameObject
   - 在Inspector中点击 `Add Component`
   - 搜索并添加 `PlanetUnlockButton` 脚本

3. **配置行星索引**
   - 在Inspector中找到 `Planet Unlock Button` 组件
   - 找到 **"Planet Index"** 字段
   - 使用滑块选择要解锁的行星索引（0-12）
     - 0 = 第1个行星
     - 1 = 第2个行星
     - ...
     - 12 = 第13个行星

4. **绑定到按钮onClick**
   - 选中按钮GameObject
   - 在Inspector中找到 `Button` 组件
   - 找到 **"On Click ()"** 事件列表
   - 点击 **"+"** 添加新事件
   - 将带有 `PlanetUnlockButton` 脚本的GameObject拖入对象槽
   - 在下拉菜单中选择：`PlanetUnlockButton -> UnlockPlanet()`

#### 方法二：直接调用PlanetUnlockManager（代码方式）

如果需要在代码中解锁行星：

```csharp
// 解锁索引为0的行星
PlanetUnlockManager.UnlockPlanet(0);

// 解锁索引为5的行星
PlanetUnlockManager.UnlockPlanet(5);
```

## 三、图片资源准备

### 3.1 图片需求

您需要准备以下图片：

1. **未解锁状态图片（1张）**
   - 所有未解锁的行星卡片共用
   - 建议命名：`PlanetCard_Locked.png` 或类似

2. **已解锁状态图片（13张）**
   - 每个行星一张，对应索引0-12
   - 建议命名：`PlanetCard_0.png`, `PlanetCard_1.png`, ... `PlanetCard_12.png`

### 3.2 图片导入设置

1. **导入图片到Unity**
   - 将图片文件放入项目的UI资源目录（例如：`Assets/UI/Sprites/`）

2. **Texture Type设置**
   - 选中图片，在Inspector中设置：
     - **Texture Type**: `Sprite (2D and UI)`
     - **Pixels Per Unit**: 100（根据项目需求调整）
     - **Filter Mode**: `Bilinear`
   - 点击 `Apply` 应用设置

### 3.3 图片配置到PlanetEncyclopediaPanel

1. **配置未解锁图片**
   - 选中 `PlanetEncyclopediaPanel` GameObject
   - 在Inspector中找到 `Locked Planet Image` 字段
   - 拖入未解锁状态图片

2. **配置已解锁图片列表**
   - 找到 `Planet Card Images` 列表
   - 确保 `Size` 为 `13`
   - 按顺序拖入13张已解锁的行星卡片图片：
     - `Element 0`: 第1个行星的解锁图片
     - `Element 1`: 第2个行星的解锁图片
     - ...
     - `Element 12`: 第13个行星的解锁图片

## 四、测试和验证

### 4.1 初始状态测试

1. **运行游戏**
   - 进入包含行星图鉴的场景
   - 打开行星图鉴面板

2. **验证初始显示**
   - 所有行星卡片应该显示未解锁图片（如果之前没有解锁过）
   - 点击未解锁的卡片，应该无法展开详情卡片
   - Console中应该显示："PlanetCard: 索引 X 未解锁，无法点击展开"

### 4.2 解锁功能测试

1. **测试解锁按钮**
   - 点击配置好的解锁按钮
   - 观察对应索引的行星卡片
   - 卡片应该立即切换为已解锁图片
   - 点击已解锁的卡片，应该可以展开详情卡片

2. **测试事件系统**
   - 解锁一个行星
   - 观察Console日志，应该看到：
     - "PlanetUnlockManager: 行星 X 已解锁并触发事件"
     - "PlanetCard: 索引 X 解锁状态已更新为 已解锁"

3. **测试持久化**
   - 解锁几个行星
   - 关闭游戏
   - 重新打开游戏
   - 进入行星图鉴，之前解锁的行星应该仍然显示为已解锁状态

### 4.3 调试功能

**PlanetUnlockManager提供调试方法**：

1. **显示解锁状态**
   - 在场景中选中 `PlanetUnlockManager` GameObject
   - 右键点击组件
   - 选择 **"显示解锁状态"**
   - Console会显示所有13个行星的解锁状态

2. **重置所有解锁状态**
   - 在场景中选中 `PlanetUnlockManager` GameObject
   - 右键点击组件
   - 选择 **"重置所有解锁状态"**
   - 所有解锁状态会被清除（用于测试或新游戏）

## 五、常见问题排查

### 5.1 未解锁图片不显示

**可能原因**：
- `PlanetEncyclopediaPanel` 的 `Locked Planet Image` 未配置
- 图片的Texture Type不是 `Sprite (2D and UI)`

**解决方法**：
1. 检查 `PlanetEncyclopediaPanel` 的 `Locked Planet Image` 字段是否已配置
2. 检查图片的Texture Type设置
3. 查看Console中的警告信息

### 5.2 解锁后卡片不更新

**可能原因**：
- EventManager实例不存在
- PlanetCard未正确订阅事件
- 图片引用配置错误

**解决方法**：
1. 确认场景中有EventManager（会自动创建）
2. 检查Console中是否有错误信息
3. 确认 `PlanetEncyclopediaPanel` 的图片列表配置正确
4. 检查PlanetCard的 `OnEnable` 是否被调用（确保GameObject处于激活状态）

### 5.3 解锁状态不持久化

**可能原因**：
- PlayerPrefs保存失败
- 游戏没有正常退出（直接关闭可能导致保存失败）

**解决方法**：
1. 确保游戏正常退出（不要直接关闭窗口）
2. 检查PlayerPrefs的Key是否正确（应该是 `PlanetUnlockStatus_0` 到 `PlanetUnlockStatus_12`）
3. 使用调试功能查看解锁状态

### 5.4 按钮无法解锁

**可能原因**：
- PlanetUnlockButton脚本未添加到GameObject
- 按钮onClick事件未正确绑定
- 行星索引配置错误

**解决方法**：
1. 确认GameObject上有 `PlanetUnlockButton` 组件
2. 检查按钮的onClick事件是否正确绑定到 `UnlockPlanet()` 方法
3. 确认 `Planet Index` 字段的值在0-12范围内
4. 查看Console中是否有警告信息

## 六、使用示例

### 6.1 在代码中解锁行星

```csharp
using UnityEngine;

public class MyScript : MonoBehaviour
{
    void Start()
    {
        // 解锁索引为0的行星
        PlanetUnlockManager.UnlockPlanet(0);
        
        // 检查行星是否已解锁
        bool isUnlocked = PlanetUnlockManager.IsPlanetUnlocked(0);
        Debug.Log($"行星0是否解锁: {isUnlocked}");
    }
}
```

### 6.2 监听解锁事件

```csharp
using UnityEngine;

public class MyListener : MonoBehaviour
{
    void OnEnable()
    {
        if (EventManager.Instance != null)
        {
            EventManager.Instance.OnPlanetUnlocked += OnPlanetUnlocked;
        }
    }
    
    void OnDisable()
    {
        if (EventManager.Instance != null)
        {
            EventManager.Instance.OnPlanetUnlocked -= OnPlanetUnlocked;
        }
    }
    
    private void OnPlanetUnlocked(int planetIndex)
    {
        Debug.Log($"行星 {planetIndex} 被解锁了！");
        // 在这里添加解锁后的逻辑
    }
}
```

### 6.3 动态设置解锁按钮的目标行星

```csharp
using UnityEngine;
using UnityEngine.UI;

public class DynamicUnlockButton : MonoBehaviour
{
    [SerializeField] private Button unlockButton;
    [SerializeField] private PlanetUnlockButton planetUnlockButton;
    
    void Start()
    {
        // 动态设置要解锁的行星索引
        planetUnlockButton.SetPlanetIndex(5);
        
        // 绑定按钮
        unlockButton.onClick.AddListener(() => {
            planetUnlockButton.UnlockPlanet();
        });
    }
}
```

## 八、技术说明

### 8.1 数据流

```
[按钮点击/代码调用]
    ↓
[PlanetUnlockButton.UnlockPlanet()]
    ↓
[PlanetUnlockManager.UnlockPlanet(index)]
    ↓
[保存到PlayerPrefs]
    ↓
[EventManager.TriggerPlanetUnlocked(index)]
    ↓
[EventManager.OnPlanetUnlocked事件触发]
    ↓
[PlanetCard.OnPlanetUnlocked()接收事件]
    ↓
[PlanetCard.SetUnlockState(true)]
    ↓
[更新图片显示，启用点击功能]
```

### 8.2 持久化机制

- **存储方式**：使用Unity的PlayerPrefs
- **Key格式**：`"PlanetUnlockStatus_0"` 到 `"PlanetUnlockStatus_12"`
- **值格式**：`1` 表示已解锁，`0` 表示未解锁
- **保存时机**：每次解锁时立即保存
- **加载时机**：PlanetUnlockManager的Awake()中自动加载

### 8.3 事件系统

- **事件定义**：`EventManager.OnPlanetUnlocked` (Action<int>)
- **触发方式**：通过 `EventManager.TriggerPlanetUnlocked(int planetIndex)`
- **订阅方式**：在 `OnEnable()` 中订阅，`OnDisable()` 中取消订阅
- **参数**：行星索引（0-12）
