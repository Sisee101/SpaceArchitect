# 订单详情场景功能分析

## 📋 功能需求

创建一个订单详情场景，包含三个主要区域：
1. **左侧**：订单图片滑动列表（可通过箭头切换）
2. **右上**：文字图片PNG显示（8张图片，可切换）
3. **右下**：实时更新的文字内容

---

## 🎯 功能分析

### 1. 左侧订单图片滑动列表

#### 功能描述
- 显示订单图片列表
- 通过左右箭头按钮切换
- 支持滑动查看
- **当前版本**：默认显示前三个任务的订单图片（taskId=0,1,2）
- **后续扩展**：支持显示更多订单（可配置显示数量）

#### 实现思路

**UI结构**：
```
Canvas
└── OrderDetailPanel
    └── LeftPanel
        ├── ScrollRect (水平滚动)
        │   └── Content
        │       ├── OrderImageItem1 (Image)
        │       ├── OrderImageItem2 (Image)
        │       ├── OrderImageItem3 (Image)
        │       └── ... (后续可扩展更多)
        ├── LeftArrowButton
        └── RightArrowButton
```

**数据来源**：
- 从 `SphereOrderDataConfig` 获取订单数据
- 使用 `GetAllTaskOrders()` 获取所有任务订单
- **当前版本**：筛选前三个任务（taskId=0,1,2）
- **后续扩展**：支持显示更多订单（可配置数量，如：前5个、前10个等）
- 提取每个订单的 `orderImage` (Sprite)

**核心组件**：
- `ScrollRect`：水平滚动视图
- `Content` (RectTransform)：内容容器
- `Horizontal Layout Group`：自动排列订单图片
- `Image` 组件：显示订单图片

**交互逻辑**：
- 左箭头：向左滚动（显示上一个订单）
- 右箭头：向右滚动（显示下一个订单）
- 鼠标滚轮：支持滚轮滑动（可选）
- 滚动动画：使用DOTween实现平滑滚动
- **当前订单跟踪**：记录当前显示的订单索引，用于更新右下文字

**参考实现**：
- 可以参考 `PlanetEncyclopediaPanel` 的滚动实现
- 使用类似的箭头点击和滚动逻辑

**扩展性设计**：
- 使用可配置参数控制显示订单数量
- 支持动态添加/移除订单图片项
- 预留接口支持后续功能扩展

---

### 2. 右上文字图片PNG显示

#### 功能描述
- 显示文字图片（PNG格式）
- 共有8张图片
- 通过空格键切换下一张
- 默认显示第一张（索引0）
- 循环切换（第8张后回到第1张）

#### 实现思路

**UI结构**：
```
Canvas
└── OrderDetailPanel
    └── TopRightPanel
        └── TextImageDisplay (Image组件)
```

**数据管理**：
- 使用 `List<Sprite>` 存储8张文字图片（在Inspector中配置）
- 当前显示索引（0-7）
- 默认索引为0（第一张）

**切换机制**：
- **空格键切换**：在 `Update()` 中监听 `Input.GetKeyDown(KeyCode.Space)`
- 按下空格键：切换到下一张图片（索引+1）
- 循环逻辑：到达第8张（索引7）后，回到第1张（索引0）
- 提供 `NextTextImage()` 方法处理切换逻辑

**核心组件**：
- `Image` 组件：显示PNG图片
- `Sprite` 资源：8张文字图片（List<Sprite>，在Inspector中配置）

**注意事项**：
- 图片需要预先导入为Sprite格式
- 建议使用统一的命名规范（如：TextImage_01.png, TextImage_02.png...）
- 需要在Inspector中配置8张图片的列表

### 3. 右下实时更新文字

#### 功能描述
- 显示订单相关信息
- 目前先显示订单ID
- 后续可以扩展显示其他订单信息

#### 实现思路

**UI结构**：
```
Canvas
└── OrderDetailPanel
    └── BottomRightPanel
        └── DynamicText (Text或TextMeshPro)
```

**数据来源**：
- 从当前选中的订单数据中读取
- 显示订单ID（taskId）
- 后续可以扩展显示：订单金额、配送要求、订单状态等

**更新机制**：
- **订单切换时更新**：当左侧订单图片切换时，同步更新右下文字
- **显示格式**：`订单ID: {taskId}` 或 `Order ID: {taskId}`

**核心组件**：
- `Text` 或 `TextMeshPro` 组件：显示文字
- 数据源：当前选中的订单信息（SphereOrderInfo）

**文字内容**：
- **当前版本**：订单ID（taskId）
- **后续扩展**：订单金额、配送要求、订单状态、订单备注等

- 在 `Update()` 中监听空格键输入

**DynamicTextController.cs**（动态文字控制器）：
- 管理右下订单信息文字显示

- 从当前选中的订单信息中提取数据

## 📊 数据流设计

### 数据来源

1. **订单图片**：
   ```
   SphereOrderDataConfig
       → GetAllTaskOrders()
       → 筛选前三个任务（taskId=0,1,2）
       → 提取 orderImage (Sprite)
       → 显示在左侧列表
   ```

2. **文字图片**：
   ```
   8张PNG图片资源
       → 导入为Sprite
       → 存储在List<Sprite>中
       → 根据索引显示
   ```

3. **动态文字**：
   ```
   当前选中的订单信息（SphereOrderInfo）
       → 提取订单ID（taskId）
       → 格式化文字：`订单ID: {taskId}`
       → 更新到Text组件
   ```

## 🔧 技术实现要点

### 1. 订单图片列表

**关键点**：
- 使用 `ScrollRect` + `Horizontal Layout Group` 实现水平滚动列表
- 使用 `DOTween` 实现平滑滚动动画
- 参考 `PlanetEncyclopediaPanel` 的实现方式
- 支持箭头按钮和鼠标滚轮

**布局参数**：
- 订单图片大小（宽度、高度）
- 图片间距
- 滚动步长（每次切换的距离）
- 滚动动画时长

### 2. 文字图片切换

**关键点**：
- 使用 `Image.sprite` 切换图片
- 管理图片索引（0-7）
- **空格键监听**：在 `Update()` 中检测 `Input.GetKeyDown(KeyCode.Space)`
- **循环切换**：索引到达8时重置为0
- 可以添加切换动画（淡入淡出，可选）

**图片管理**：
- 使用 `List<Sprite>` 存储8张图片
- **在Inspector中配置**：提供8个字段或一个列表供配置
- 建议命名：`textImageList` 或 `textImages`

**切换逻辑**：
```csharp
void Update()
{
    if (Input.GetKeyDown(KeyCode.Space))
    {
        currentIndex = (currentIndex + 1) % 8; // 循环切换
        image.sprite = textImageList[currentIndex];
    }
}
```

### 3. 动态文字更新

**关键点**：
- **数据来源**：当前选中的订单信息（SphereOrderInfo）
- **当前版本**：显示订单ID（taskId）
- 使用 `Text.text` 或 `TextMeshPro.text` 更新文字
- 可以添加更新动画（淡入淡出，可选）
- 支持格式化文字

**更新方式**：
- **订单切换时更新**：当左侧订单列表切换时，同步更新右下文字
- 提供 `UpdateOrderText(SphereOrderInfo orderInfo)` 方法
- 从订单信息中提取taskId并格式化显示

**文字格式**：
- 当前版本：`订单ID: {taskId}` 或 `Order ID: {taskId}`
- 后续扩展：可以显示订单金额、配送要求、订单状态等

**更新触发**：
- 订单列表切换时（左/右箭头点击）
- 订单列表初始化时（显示第一个订单的信息）

## 📐 UI布局建议

### 布局结构

```
Canvas (Screen Space - Overlay)
└── OrderDetailPanel (Panel，全屏)
    ├── LeftPanel (左侧区域，约40%宽度)
    │   ├── ScrollRect
    │   │   └── Content
    │   │       └── OrderImageItems
    │   ├── LeftArrowButton
    │   └── RightArrowButton
    │
    ├── TopRightPanel (右上区域，约30%宽度，30%高度)
    │   └── TextImageDisplay (Image)
    │
    └── BottomRightPanel (右下区域，约30%宽度，70%高度)
        └── DynamicText (Text/TextMeshPro)
```

### 布局参数

- **LeftPanel**：
  - Anchor: `Left Stretch`
  - Width: 40%屏幕宽度
  - Height: 100%屏幕高度

- **TopRightPanel**：
  - Anchor: `Top Right`
  - Width: 30%屏幕宽度
  - Height: 30%屏幕高度

- **BottomRightPanel**：
  - Anchor: `Bottom Right`
  - Width: 30%屏幕宽度
  - Height: 70%屏幕高度

```

    ↓
```

```
    ↓
更新当前显示的订单索引
```

```

    ↓

    ↓
如果索引 >= 8，重置为0（循环）

设置Image.sprite = textImageList[当前索引]
    ↓

```

```
获取当前选中的订单信息
    ↓
提取订单ID（taskId）
    ↓
格式化文字：`订单ID: {taskId}`

    ↓
```
