# 行星图鉴系统尺寸修改指南

## 📋 系统组件说明

### PlanetEncyclopediaPanel
**功能**：管理行星图鉴面板的显示、滚动和卡片布局  
**位置**：Hierarchy → 找到包含 `Planet Encyclopedia Panel` 脚本的GameObject

---

## 🔊 音效配置

### 音效类型

1. **按钮点击音效**（Button Click Sound）
   - 用于：返回按钮、左箭头按钮、右箭头按钮
   - 触发时机：点击这些按钮时

2. **卡片展开/收起音效**（Card Toggle Sound）
   - 用于：点击行星卡片展开/收起详情卡片
   - 触发时机：点击行星卡片时（无论展开还是收起）

### 配置步骤

1. **找到PlanetEncyclopediaPanel GameObject**：
   - 在Hierarchy中搜索 `PlanetEncyclopediaPanel` 或 `行星图鉴`

2. **添加AudioSource组件**（如果还没有）：
   - 选中GameObject
   - 在Inspector中点击 **Add Component**
   - 搜索并添加：`Audio Source`
   - 配置AudioSource参数（Volume、Spatial Blend等）

3. **配置音效引用**：
   - 在Inspector中找到 `Planet Encyclopedia Panel` 脚本组件
   - 展开 "音效" 部分
   - **Audio Source**：拖拽GameObject上的AudioSource组件到该字段（或留空，脚本会自动添加）
   - **Button Click Sound**：拖拽按钮点击音效文件到该字段
   - **Card Toggle Sound**：拖拽卡片展开/收起音效文件到该字段

### 音效参数位置

**Inspector位置**：`Planet Encyclopedia Panel` 脚本 → "音效" 部分

- **Audio Source**：音频源组件（可选，脚本会自动添加）
- **Button Click Sound**：按钮点击音效（返回键、左右翻页键）
- **Card Toggle Sound**：卡片展开/收起音效

### 注意事项

- 如果未配置AudioSource，脚本会自动添加一个
- 如果音效文件未配置，不会播放音效，但不会报错
- 音效使用 `PlayOneShot()` 播放，可以同时播放多个音效

## 📐 可修改的尺寸参数

### 1. 布局参数（Layout Parameters）

#### Card Spacing（卡片间距）
**位置**：Inspector → "布局参数" → Card Spacing  
**默认值**：20  
**说明**：行星卡片之间的间距（像素）  
**建议范围**：10 - 50

#### Planet Card Width（行星卡片宽度）
**位置**：Inspector → "布局参数" → Planet Card Width  
**默认值**：300  
**说明**：行星卡片的宽度（像素）  
**建议范围**：200 - 500

#### Planet Card Height（行星卡片高度）
**位置**：Inspector → "布局参数" → Planet Card Height  
**默认值**：500  
**说明**：行星卡片的高度（像素）  
**建议范围**：300 - 800

#### Detail Card Width（介绍卡片宽度）
**位置**：Inspector → "布局参数" → Detail Card Width  
**默认值**：600  
**说明**：介绍卡片（详情卡片）的宽度（像素）  
**建议范围**：400 - 1000

#### Detail Card Height（介绍卡片高度）
**位置**：Inspector → "布局参数" → Detail Card Height  
**默认值**：700  
**说明**：介绍卡片（详情卡片）的高度（像素）  
**建议范围**：500 - 1200

---

### 2. 滚动位置调整（Scroll Position Adjustment）

#### Scroll Center Offset（滚动中心偏移量）
**位置**：Inspector → "滚动位置调整" → Scroll Center Offset  
**默认值**：0  
**说明**：点击卡片展开详情时，滚动到中心位置的偏移量（像素）  
**调整方向**：
- **负值**：向左偏移（整体向左移）
- **正值**：向右偏移（整体向右移）
- **0**：无偏移（默认居中）
**建议范围**：-200 到 200

#### Arrow Scroll Distance（箭头滚动距离）
**位置**：Inspector → "滚动位置调整" → Arrow Scroll Distance  
**默认值**：0（自动计算）  
**说明**：点击左右箭头时，每次滚动的距离（像素）  
**使用方式**：
- **0**：自动使用（行星卡片宽度 + 卡片间距）作为滚动距离
- **> 0**：使用自定义的滚动距离（像素）
**建议范围**：100 - 500（如果设置为0，则自动计算）

### 3. 动画参数（Animation Parameters）

#### Scroll Duration（滚动动画时长）
**位置**：Inspector → "动画参数" → Scroll Duration  
**默认值**：0.3  
**说明**：点击箭头按钮时，滚动动画的时长（秒）  
**建议范围**：0.1 - 1.0

#### Insert Animation Duration（插入动画时长）
**位置**：Inspector → "动画参数" → Insert Animation Duration  
**默认值**：0.3  
**说明**：插入介绍卡片时的动画时长（秒）  
**建议范围**：0.1 - 1.0

---

## 🎯 参数关系说明

### 卡片尺寸关系
- **行星卡片**：较小，用于列表展示
- **介绍卡片**：较大，用于详情展示
- **建议比例**：介绍卡片通常是行星卡片的 1.5-2 倍

### 滚动步长计算
- **滚动步长** = `Planet Card Width` + `Card Spacing`
- 点击左右箭头时，每次滚动的距离基于此计算

## 📝 修改步骤

1. **打开场景**：打开包含行星图鉴面板的场景（通常是 `01_MainHub`）

2. **找到GameObject**：
   - 在Hierarchy中搜索 `PlanetEncyclopediaPanel` 或 `行星图鉴`
   - 选中该GameObject

3. **查看Inspector**：
   - 在Inspector窗口找到 `Planet Encyclopedia Panel` 脚本组件
   - 展开 "布局参数" 或 "动画参数" 部分

4. **修改参数**：
   - 直接修改数值
   - Unity会自动保存场景

5. **测试效果**：
   - 运行场景
   - 打开行星图鉴面板
   - 检查卡片尺寸和间距是否符合预期

---

## ⚠️ 注意事项

1. **预制体尺寸**：
   - 如果修改了卡片尺寸，确保预制体（PlanetCardPrefab、DetailCardPrefab）的RectTransform设置正确
   - 建议使用LayoutElement组件来控制尺寸

2. **Content容器**：
   - Content容器的宽度会自动根据卡片数量和间距计算
   - 无需手动调整Content的宽度

3. **滚动视图**：
   - ScrollRect的Viewport大小影响可见区域
   - 如果卡片太大，可能需要调整Viewport的宽度

4. **图片适配**：
   - 确保行星卡片图片和介绍卡片图片的宽高比与设置的尺寸匹配
   - 图片会按RectTransform的尺寸自动缩放
