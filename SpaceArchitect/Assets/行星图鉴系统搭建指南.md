# 行星图鉴系统搭建指南

## 一、功能说明

实现行星图鉴轮播系统：
- 13张行星卡片水平排列，可通过左右箭头或鼠标滚轮切换
- 点击某张卡片后，在该卡片右侧插入一张介绍卡片（尺寸较大）
- 后面的卡片自动右移（通过Horizontal Layout Group自动处理）
- 点击其他卡片或收起时，移除当前介绍卡片

## 二、UI 结构要求

```
PlanetEncyclopediaPanel (主面板)
├── BackButton (返回按钮 - 已有)
└── CarouselContainer (轮播容器)
    ├── LeftArrow (左箭头按钮)
    ├── ScrollView (ScrollRect)
    │   ├── Viewport (RectTransform - 自动创建)
    │   │   └── Content (Content容器)
    │   │       ├── Horizontal Layout Group (水平布局组件)
    │   │       ├── PlanetCard_0 (行星卡片实例)
    │   │       ├── PlanetCard_1
    │   │       ├── ...
    │   │       └── PlanetCard_12
    │   └── Scrollbar Horizontal (水平滚动条 - 可选，通常隐藏)
    └── RightArrow (右箭头按钮)
```

**重要说明**：
- `Content` 容器必须有 `Horizontal Layout Group` 组件
- 每个行星卡片需要有 `LayoutElement` 组件控制尺寸
- 介绍卡片（DetailCard）会在运行时动态插入，不需要预先创建

## 三、Unity 编辑器操作步骤

### 步骤 1：创建轮播容器结构

1. **找到 `PlanetEncyclopediaPanel` GameObject**（应该在主菜单场景的Canvas下）

2. **创建 `CarouselContainer` 容器**：
   - 右键点击 `PlanetEncyclopediaPanel` → `UI` → `Panel` → 重命名为 `CarouselContainer`
   - **Rect Transform** 设置：
     - `Anchor`: 根据需要设置（如 `Stretch Stretch` 填充整个面板）
     - `Left/Right/Top/Bottom`: 根据设计需求设置边距（如各留50px给箭头）
     - 或者使用 `Center Middle`，设置合适的 `Width` 和 `Height`

3. **创建 `ScrollView`**：
   - 右键点击 `CarouselContainer` → `UI` → `Scroll View` → 重命名为 `ScrollView`
   - Unity会自动创建以下结构：
     - `ScrollView`
     -   └── `Viewport`（带Mask组件）
     -   └── `Content`（这是我们需要配置的容器）
     -   └── `Scrollbar Horizontal`（可以删除或隐藏）

4. **配置 `ScrollView` 的尺寸（重要：如果ScrollView太小，Viewport也会小）**：
   - 选中 `ScrollView` GameObject
   - **Rect Transform** 设置：
     - **方式A（推荐）：使用Stretch填充父容器**
       - `Anchor`: `Stretch Stretch`（填充整个CarouselContainer）
       - `Left/Right/Top/Bottom`: 都设置为 0（填充父容器）
       - 这样ScrollView会填充CarouselContainer，Viewport会填充ScrollView
     - **方式B：手动设置尺寸**
       - `Anchor`: `Left Middle` 或其他合适的锚点
       - `Width`: 800-1200（根据设计需求，这是可视区域的宽度）
       - `Height`: 600-800（根据设计需求，这是可视区域的高度）
   
   **⚠️ 关键提示**：如果ScrollView的尺寸太小，即使Viewport设置为Stretch Stretch，Viewport也会很小，导致内容被裁剪。需要确保ScrollView有足够大的尺寸。

5. **配置 `Viewport` 的尺寸（确保填充ScrollView）**：
   - 选中 `Viewport` GameObject（路径：`ScrollView/Viewport`）
   - **Rect Transform** 设置：
     - `Anchor`: 通常设置为 `Stretch Stretch`（填充整个 ScrollView）
     - `Left/Right/Top/Bottom`: 都设置为 0（填充父容器）
     - 或者使用 `Left Middle`，手动设置 `Width` 和 `Height`
   
   **⚠️ 关键提示**：`Viewport` 的尺寸决定了 ScrollView 的可视区域大小。如果内容被遮挡，需要**增大 `Viewport` 的 Width 和 Height**。
   
   - `Viewport` 通常带有 `Mask` 组件（用于裁剪超出区域的内容）
   - 如果 `Viewport` 的尺寸太小，`Content` 中的内容会被裁剪（看起来被遮挡）
   - 调整 `Viewport` 的 `Width` 和 `Height` 可以增加可视区域

6. **配置 `ScrollView` 的 ScrollRect 组件**：
   - 选中 `ScrollView`
   - **Scroll Rect** 组件设置：
     - `Content`: 拖拽 `ScrollView/Viewport/Content` 到该字段
     - `Horizontal`: ✅ 勾选（启用水平滚动）
     - `Vertical`: ❌ 取消勾选（禁用垂直滚动）
     - `Movement Type`: Elastic（弹性滚动，可选Unrestricted）
     - `Elasticity`: 0.1（弹性系数）
     - `Inertia`: ✅ 勾选（惯性滚动）
     - `Deceleration Rate`: 0.135（减速速率）
     - `Scroll Sensitivity`: 1（滚动灵敏度，鼠标滚轮）
     - `Viewport`: 应该自动设置为 `Viewport`
     - `Horizontal Scrollbar`: 设置为 `None`（隐藏滚动条）或保留
     - `Vertical Scrollbar`: 设置为 `None`

7. **（可选）删除或隐藏滚动条**：
   - 如果不需要滚动条，可以删除 `Scrollbar Horizontal` GameObject
   - 或者保留但设置为不可见（Image组件禁用，或CanvasGroup alpha = 0）

### 步骤 2：配置 Content 容器（关键步骤）

1. **选中 `Content` GameObject**（路径：`PlanetEncyclopediaPanel/CarouselContainer/ScrollView/Viewport/Content`）

2. **添加 `Horizontal Layout Group` 组件**：
   - `Add Component` → 搜索 `Horizontal Layout Group` → 添加组件
   - 配置参数：
     - `Padding`: 根据需求设置（如 `Left: 20, Right: 20, Top: 0, Bottom: 0`）
       - **注意**：如果希望卡片垂直居中，`Top` 和 `Bottom` 可以设置为 0 或相同值
     - `Spacing`: 20（卡片之间的间距，根据设计调整）
     - `Child Alignment`: `Middle Left` 或 `Middle Center`（**垂直居中，水平左对齐或居中**）
       - **推荐**：`Middle Left`（垂直居中，水平左对齐，适合水平滚动）
       - 或者：`Middle Center`（垂直和水平都居中）
     - `Child Control Width`: ✅ 勾选（由LayoutElement控制宽度）
     - `Child Control Height`: ✅ 勾选（由LayoutElement控制高度）
     - `Child Force Expand Width`: ❌ 取消勾选（不强制拉伸）
     - `Child Force Expand Height`: ❌ 取消勾选

3. **配置 `Content` 的 Rect Transform**（重要：控制垂直居中）：
   - `Anchor`: `Left Middle`（左侧中间锚点，这样卡片会在垂直方向居中）
   - `Pivot`: `0, 0.5`（左侧中间，与锚点一致）
   - `Pos Y`: 0（确保Y位置为0，这样会与Viewport的中间对齐）
   - `Width`: 先设置为一个较大的值（如3000，因为13张卡片 + 间距）
   - `Height`: 根据卡片高度设置（如600，应该与卡片高度一致或略大）
   - **注意**：
     - `Width` 会在运行时根据卡片数量动态调整，这里只是初始值
     - `Anchor` 设置为 `Left Middle` 和 `Pos Y = 0` 可以确保卡片在Viewport中垂直居中

4. **（可选）添加 `Content Size Fitter` 组件**：
   - `Add Component` → 搜索 `Content Size Fitter` → 添加组件
   - `Horizontal Fit`: `Preferred Size`（根据内容自动调整宽度）
   - `Vertical Fit`: `Unconstrained`（高度由卡片控制）
   - **注意**：如果使用Content Size Fitter，需要在代码中调用 `LayoutRebuilder.ForceRebuildLayoutImmediate()` 来强制刷新

### 步骤 3：创建行星卡片预制体（PlanetCard Prefab）

1. **创建临时测试卡片**：
   - 右键点击 `Content` → `UI` → `Image` → 重命名为 `PlanetCard`
   
   **⚠️ 重要提示**：如果 `Content` 已经有 `Horizontal Layout Group` 且 `Child Control Width/Height` 已勾选，Rect Transform 的 Width/Height 会被布局组件控制，无法直接修改。这是正常现象！我们需要使用 `LayoutElement` 组件来控制尺寸。
   
   **可选：如果想让 Rect Transform 显示具体数值**，可以先将 `PlanetCard` 临时移出 `Content`，设置好尺寸后再移回。

2. **添加 `LayoutElement` 组件**（必须步骤）：
   - 选中 `PlanetCard` → `Add Component` → 搜索 `Layout Element` → 添加组件
   - 配置参数：
     - `Ignore Layout`: ❌ 取消勾选（参与布局）
     - `Min Width`: 0（最小宽度）
     - `Min Height`: 0（最小高度）
     - `Preferred Width`: 300（**这是卡片的实际宽度**，Horizontal Layout Group 会使用这个值）
     - `Preferred Height`: 500（**这是卡片的实际高度**，Horizontal Layout Group 会使用这个值）
     - `Flexible Width`: 0（不弹性拉伸）
     - `Flexible Height`: 0
   
   **说明**：添加 `LayoutElement` 后，Rect Transform 会显示 "Some values driven by Horizontal Layout Group"，Width/Height 可能显示为 0 或灰色，这是正常的。实际尺寸由 `LayoutElement.Preferred Width/Height` 控制。

3. **添加 `Button` 组件**（用于点击检测）：
   - 选中 `PlanetCard` → `Add Component` → 搜索 `Button` → 添加组件
   - **Button** 组件设置：
     - `Interactable`: ✅ 勾选
     - `Transition`: `Color Tint`（颜色过渡，或根据需要选择其他）
     - `Target Graphic`: 拖拽 `PlanetCard` 的 `Image` 组件
     - `OnClick`: 留空（代码中会绑定）

4. **设置 `Image` 组件**：
   - `Source Image`: 可以先设置一个测试图片，或留空（代码中会设置）
   - `Color`: 白色（或根据设计）
   - `Raycast Target`: ✅ 勾选（用于点击检测）

5. **创建 `PlanetCard` 脚本**（稍后会提供代码）：
   - 选中 `PlanetCard` → `Add Component` → 搜索 `Planet Card` → 添加组件
   - 配置字段（稍后在代码中说明）

6. **创建预制体**：
   - 将 `PlanetCard` GameObject 从 Hierarchy 拖拽到 `Assets/Prefabs` 文件夹（或你的预制体文件夹）
   - 删除 Hierarchy 中的 `PlanetCard` 实例（后面会通过代码动态创建）

## 五、常见问题

### Q1: ScrollView 的内容被遮挡（即使Viewport设置为0）

**原因**：`ScrollView` 本身的尺寸太小，导致 `Viewport`（即使设置为Stretch Stretch填充ScrollView）也小，从而裁剪了内容。

**解决步骤**：
1. **首先检查 `ScrollView` 的尺寸**：
   - 选中 `ScrollView` GameObject（`CarouselContainer/ScrollView`）
   - 在 **Rect Transform** 中检查：
     - 如果使用 `Stretch Stretch`：检查 `Left/Right/Top/Bottom` 是否都设置为 0（填充父容器）
     - 如果使用手动尺寸：检查 `Width` 和 `Height` 是否足够大（如800-1200宽度，600-800高度）

2. **如果ScrollView是Stretch填充，检查父容器 `CarouselContainer` 的尺寸**：
   - 选中 `CarouselContainer` GameObject
   - 在 **Rect Transform** 中检查尺寸：
     - 如果使用 `Stretch Stretch`：检查 `Left/Right/Top/Bottom` 是否设置合理
     - 如果使用手动尺寸：检查 `Width` 和 `Height` 是否足够大

3. **调整方案**：
   - **方案A（推荐）**：让 `CarouselContainer` 和 `ScrollView` 都使用 `Stretch Stretch` + `Left/Right/Top/Bottom = 0`，这样会自动填充
   - **方案B**：手动设置 `ScrollView` 的 `Width` 和 `Height` 为足够大的值（如 `Width: 1000, Height: 700`）

4. **验证**：
   - 在Scene视图中，灰色的矩形（ScrollView/Viewport）应该足够大，能显示完整的卡片
   - 如果灰色的矩形太小，说明ScrollView的尺寸需要增大

### Q2: 卡片上下位置不居中

**原因**：`Content` 容器的锚点或位置设置不正确，或者 `Horizontal Layout Group` 的 `Child Alignment` 设置不对。

**解决步骤**：
1. **检查 `Content` 的 Rect Transform**：
   - 选中 `Content` GameObject
   - 确保 `Anchor` 设置为 `Left Middle`（左侧中间锚点）
   - 确保 `Pivot` 设置为 `0, 0.5`（左侧中间）
   - 确保 `Pos Y` 设置为 `0`（与Viewport的中间对齐）

2. **检查 `Horizontal Layout Group` 的 `Child Alignment`**：
   - 选中 `Content` GameObject
   - 在 `Horizontal Layout Group` 组件中，将 `Child Alignment` 设置为：
     - `Middle Left`（推荐，垂直居中，水平左对齐）
     - 或 `Middle Center`（垂直和水平都居中）

3. **检查 `Content` 的 `Height`**：
   - 确保 `Content` 的 `Height` 与卡片高度一致或略大
   - 如果 `Content` 的 `Height` 太大，卡片可能会靠上或靠下显示

4. **验证**：
   - 在Scene视图中，卡片应该在Viewport的垂直方向居中显示
   - 如果还是不居中，可以尝试调整 `Content` 的 `Pos Y` 值（微调）

### Q3: 无法修改 Rect Transform 的 Width/Height

**原因**：当 GameObject 作为 `Horizontal Layout Group` 的子对象时，如果 `Child Control Width/Height` 已勾选，Rect Transform 的尺寸会被布局组件控制。

**解决**：
- 这是正常现象！使用 `LayoutElement` 组件的 `Preferred Width/Height` 来控制卡片尺寸
- 如果确实需要修改 Rect Transform，可以临时将 GameObject 移出 `Content`，设置完后再移回

### Q4: 卡片排列不整齐

**解决**：
- 检查 `Horizontal Layout Group` 的 `Spacing` 设置
- 确保所有卡片都有 `LayoutElement` 组件
- 检查 `LayoutElement` 的 `Preferred Width/Height` 是否一致（除了介绍卡片）
- 如果卡片尺寸不对，检查 `LayoutElement.Preferred Width/Height` 而不是 Rect Transform

### Q5: 滚动不流畅或无法滚动

**解决**：
- 检查 `ScrollRect` 的 `Content` 和 `Viewport` 引用是否正确
- 检查 `Content` 的 `Width` 是否足够大（应该大于Viewport的宽度）
- 确保 `Horizontal` 已勾选，`Vertical` 已取消勾选
- 检查是否有其他UI元素遮挡了 `ScrollView`

### Q6: 介绍卡片插入后布局混乱

**解决**：
- 确保介绍卡片有 `LayoutElement` 组件
- 检查介绍卡片的 `Preferred Width` 是否比行星卡片大
- 在代码中插入卡片后调用 `LayoutRebuilder.ForceRebuildLayoutImmediate()`

### Q7: 点击卡片没有反应

**解决**：
- 检查卡片是否有 `Button` 组件
- 检查 `Button` 的 `Interactable` 是否勾选
- 检查 `Image` 的 `Raycast Target` 是否勾选
- 确保场景中有 `EventSystem` GameObject

### Q8: 箭头按钮不显示或位置不对

**解决**：
- 检查箭头按钮的 `Rect Transform` 设置
- 确保箭头按钮在 `CarouselContainer` 下，而不是在 `ScrollView` 内
- 检查箭头按钮的 `Anchor` 设置是否正确
- 检查是否有其他UI元素遮挡

### Q9: 鼠标滚轮不工作

**解决**：
- 确保 `ScrollRect` 的 `Scroll Sensitivity` > 0
- 检查鼠标是否在 `ScrollView` 区域内
- 如果使用自定义滚轮处理，确保代码正确实现
