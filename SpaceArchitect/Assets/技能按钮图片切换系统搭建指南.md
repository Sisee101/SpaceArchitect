# 技能按钮图片切换系统搭建指南

## 📋 功能概述

本系统实现了技能按钮的自动图片切换功能：当技能成功解锁后，按钮会自动从"未解锁"状态（锁定/灰色图片）切换到"已解锁"状态（激活/彩色图片）。

---

## 🎯 系统架构

### 核心组件

1. **SkillButtonController**（技能按钮控制器）
   - 位置：`Assets/Scripts/UI/SkillButtonController.cs`
   - 作用：管理单个技能按钮的图片切换逻辑
   - 每个技能按钮都需要添加此组件

2. **SkillManager**（技能管理器）
   - 位置：`Assets/Scenes/SkillTestScene/SkillManager.cs`
   - 作用：管理技能解锁逻辑，解锁成功后通知按钮更新图片
   - 已自动集成图片更新通知功能

---

## 📐 搭建步骤

### 第一步：准备图片资源

1. **准备两套按钮图片**：
   - **未解锁状态图片**（Locked Sprite）：
     - 灰色/锁定版本的按钮图片
     - 表示技能尚未解锁
   - **已解锁状态图片**（Unlocked Sprite）：
     - 彩色/激活版本的按钮图片
     - 表示技能已解锁

2. **图片要求**：
   - 如果使用 **Sliced** 类型，确保两套图片的 **Border** 设置一致
   - 图片尺寸可以不同，但建议保持一致以获得更好的视觉效果
   - 图片格式：PNG、JPG 等 Unity 支持的格式

3. **导入图片到 Unity**：
   - 将图片文件拖拽到 `Assets/UI/Sprites/` 目录（或你的图片资源目录）
   - 确保图片已正确导入为 Sprite 类型

---

### 第二步：为技能按钮添加 SkillButtonController 组件

#### 2.1 选择技能按钮

1. 在 Unity 编辑器中，打开包含技能按钮的场景（如 `LevelStation1`）
2. 在 Hierarchy 中找到需要配置的技能按钮 GameObject
3. 选中该按钮

#### 2.2 添加组件

1. 在 Inspector 面板中，点击 **Add Component** 按钮
2. 搜索 `SkillButtonController`
3. 选择并添加 `SkillButtonController` 组件

---

### 第三步：配置 SkillButtonController 参数

在 Inspector 面板中配置以下参数：

#### 3.1 技能类型（Skill Type）

- **位置**：Inspector → Skill Button Controller → Skill Type
- **作用**：选择此按钮对应的技能类型
- **选项**：
  - `Station1`, `Station2`, `Station3`（基站解锁）
  - `Boost1`, `Core1`（Station1 技能）
  - `Boost2`, `Core2`, `AntiHeat`, `Predict`（Station2 技能）
  - `Boost3`, `Core3`, `AntiCollision`（Station3 技能）
- **操作**：从下拉菜单中选择对应的技能类型

#### 3.2 图片资源

- **Locked Sprite**（未解锁图片）：
  - **位置**：Inspector → Skill Button Controller → Locked Sprite
  - **作用**：技能未解锁时显示的按钮图片
  - **操作**：从 Project 窗口拖拽未解锁状态的图片到此字段

- **Unlocked Sprite**（已解锁图片）：
  - **位置**：Inspector → Skill Button Controller → Unlocked Sprite
  - **作用**：技能已解锁时显示的按钮图片
  - **操作**：从 Project 窗口拖拽已解锁状态的图片到此字段

#### 3.3 组件引用（自动获取）

- **Button Image**（按钮 Image 组件）：
  - **位置**：Inspector → Skill Button Controller → Button Image
  - **作用**：按钮的 Image 组件引用
  - **说明**：如果为空，脚本会自动获取按钮上的 Image 组件
  - **操作**：通常无需手动配置，脚本会自动查找

#### 3.4 调试选项（可选）

- **Enable Debug Log**（启用调试日志）：
  - **位置**：Inspector → Skill Button Controller → Enable Debug Log
  - **作用**：是否在 Console 中输出调试信息
  - **操作**：勾选后可以在 Console 中查看图片切换的日志

---

### 第四步：配置按钮的 Image 组件

确保按钮的 Image 组件设置正确：

1. **选中按钮 GameObject**
2. 在 Inspector 中找到 **Image** 组件
3. **检查 Image Type**：
   - 如果使用 **Sliced** 类型，确保图片的 Border 设置正确
   - 如果使用 **Simple** 类型，无需额外设置

---

### 第五步：验证配置

#### 5.1 检查配置完整性

确保以下配置已完成：

- [ ] SkillButtonController 组件已添加到按钮
- [ ] Skill Type 已正确选择
- [ ] Locked Sprite 已配置
- [ ] Unlocked Sprite 已配置
- [ ] 按钮有 Image 组件

#### 5.2 测试功能

1. **运行场景**
2. **检查初始状态**：
   - 根据当前技能解锁状态，按钮应该显示对应的图片
   - 如果技能已解锁（如 `Core1`），应显示已解锁图片
   - 如果技能未解锁（如 `Boost1`），应显示未解锁图片

3. **测试解锁功能**：
   - 点击按钮尝试解锁技能
   - 如果解锁成功，按钮图片应立即切换到已解锁状态
   - 如果解锁失败（条件不满足），图片应保持不变

## 📝 批量配置技巧

如果需要配置多个技能按钮，可以：

1. **使用预制体**：
   - 配置好一个按钮后，将其保存为预制体
   - 其他按钮从预制体实例化，只需修改 Skill Type 和图片资源

2. **复制组件**：
   - 配置好一个按钮后，在 Inspector 中右键点击 `SkillButtonController` 组件
   - 选择 **Copy Component**
   - 选中另一个按钮，右键点击 Inspector，选择 **Paste Component Values**
   - 然后修改 Skill Type 和图片资源

## ⚠️ 常见问题

### 问题1：按钮图片没有切换

**可能原因**：
1. Skill Type 选择错误
2. Locked Sprite 或 Unlocked Sprite 未配置
3. 按钮没有 Image 组件
4. 技能解锁失败（条件不满足）

**解决方法**：
1. 检查 Inspector 中的配置是否完整
2. 查看 Console 是否有错误信息
3. 启用 **Enable Debug Log** 查看详细日志
4. 确认技能解锁条件是否满足（前置条件 + 金钱）

---

### 问题2：初始状态显示错误

**可能原因**：
1. 技能状态与预期不符
2. 图片资源配置错误

**解决方法**：
1. 检查 `SkillManager` 中的静态变量值（如 `Boost1`, `Core1` 等）
2. 确认 Locked Sprite 和 Unlocked Sprite 是否正确配置
3. 在 `Start()` 方法执行后检查按钮状态

---

### 问题3：使用 Sliced 类型时图片显示异常

**可能原因**：
1. 两套图片的 Border 设置不一致
2. RectTransform 尺寸不匹配

**解决方法**：
1. 在 Project 窗口中选择图片资源
2. 在 Inspector 中打开 **Sprite Editor**
3. 确保两套图片的 Border 值完全一致
4. 如果图片尺寸不同，调整 RectTransform 的 Width 和 Height

---

### 问题4：按钮图片切换有延迟

**可能原因**：
1. 场景中有多个 SkillManager 实例
2. 按钮 GameObject 被禁用

**解决方法**：
1. 确保场景中只有一个 SkillManager 实例
2. 确保按钮 GameObject 处于激活状态
3. 检查 `NotifyButtonUpdate()` 方法是否被正确调用

---

## 🔍 调试技巧

### 启用调试日志

1. 在 Inspector 中勾选 **Enable Debug Log**
2. 运行场景
3. 查看 Console 输出：
   - 初始化时的图片设置日志
   - 解锁成功后的图片切换日志

### 手动刷新按钮

如果需要手动刷新按钮图片（例如从存档加载后），可以：

```csharp
// 在代码中调用
SkillButtonController controller = button.GetComponent<SkillButtonController>();
if (controller != null)
{
    controller.Refresh();
}
```

## 📊 系统工作流程

```
场景启动
    ↓
SkillButtonController.Start()
    ↓
检查技能解锁状态（从 SkillManager 静态变量）
    ↓
根据状态设置初始图片
    ↓
用户点击按钮
    ↓
SkillManager.UnlockXXX() 方法
    ↓
检查解锁条件
    ↓
如果成功：
    - 设置技能状态为 true
    - 扣除金钱
    - 显示成功提示
    - 调用 NotifyButtonUpdate()
        ↓
    SkillButtonController.UpdateButtonImage()
        ↓
    切换 Image.sprite 为已解锁版本
```

## 🎨 图片资源建议

### 视觉设计建议

1. **未解锁状态**：
   - 使用灰色调或降低饱和度
   - 可以添加锁定图标或遮罩效果
   - 保持与已解锁状态的尺寸一致

2. **已解锁状态**：
   - 使用彩色/高饱和度
   - 可以添加发光或高亮效果
   - 与未解锁状态形成明显对比

3. **一致性**：
   - 所有技能按钮的视觉风格保持一致
   - 使用统一的配色方案
