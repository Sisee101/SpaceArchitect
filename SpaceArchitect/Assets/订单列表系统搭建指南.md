# 订单列表系统搭建指南

## 一、功能说明

### 核心交互
- ✅ **点击订单项**：展开/收起订单内容（切换）
- ✅ **鼠标/滚轮**：滚动列表（Unity ScrollRect 自动支持）
- ✅ **空格键**：完成当前展开的订单并向右滑出
- ✅ **开始配送按钮**：跳转到游戏场景
- ❌ **取消配送按钮**：已移除

## 二、UI 结构

```
MainHubCanvas
└── OrderListPanel (Panel - 固定大小)
    ├── ScrollView (Unity 自动创建的 ScrollRect)
    │   ├── Viewport (遮罩区域，带 Mask)
    │   └── Content (内容区域 - 需要添加 Vertical Layout Group)
    │       ├── OrderItem_1 (订单项1)
    │       │   ├── OrderHeader (Button - 整个头部可点击)
    │       │   │   ├── OrderNumberText (Text - "订单1")
    │       │   │   └── ExpandIcon (Image - 箭头图标)
    │       │   └── OrderContent (Panel - 默认隐藏)
    │       │       ├── OrderImage (Image)
    │       │       └── StartDeliveryButton (Button - "开始配送")
    │       ├── OrderItem_2
    │       ├── OrderItem_3
    │       ├── OrderItem_4
    │       └── OrderItem_5
    └── Scrollbar (可选，可以删除)
```

## 三、搭建步骤

### 步骤 1：创建 OrderListPanel

1. 在 `MainHubCanvas` 下创建 `Panel` → 重命名为 `OrderListPanel`
2. 设置 `Rect Transform`：
   - `Width`: 800
   - `Height`: 600
   - `Position`: 根据你的设计定位

### 步骤 2：创建 ScrollView

1. 右键点击 `OrderListPanel` → `UI` → `Scroll View`
2. Unity 会自动创建完整的 ScrollView 结构

3. **配置 ScrollView**：
   - 选中 `ScrollView` GameObject
   - `Scroll Rect` 组件：
     - `Horizontal`: 不勾选
     - `Vertical`: 勾选
     - `Movement Type`: Elastic (弹性滚动)
     - `Scroll Sensitivity`: 10

4. **删除 Scrollbar**（如果不需要）：
   - 选中 `Scrollbar` GameObject → 删除

### 步骤 3：配置 Content（内容区域）

1. 选中 `ScrollView/Viewport/Content` GameObject

2. **添加 `Vertical Layout Group` 组件**：
   - `Spacing`: 10（订单项之间的间距）
   - `Child Control Height`: ✅ 勾选
   - `Child Control Width`: ✅ 勾选
   - `Child Force Expand Width`: ✅ 勾选
   - `Child Force Expand Height`: ❌ 不勾选

3. **添加 `Content Size Fitter` 组件**：
   - `Vertical Fit`: Preferred Size（根据内容自动调整高度）

### 步骤 4：创建第一个订单项（OrderItem_1）作为模板

#### 4.1 创建 OrderItem 容器

1. 在 `Content` 下创建 `Panel` → 重命名为 `OrderItem_1`
2. **添加 `Vertical Layout Group` 组件**：
   - `Spacing`: 5
   - `Child Control Height`: ✅ 勾选
   - `Child Control Width`: ✅ 勾选
   - `Child Force Expand Width`: ✅ 勾选
   - `Child Force Expand Height`: ❌ 不勾选

3. **添加 `Layout Element` 组件**：
   - `Preferred Height`: 50（订单头部的默认高度）

#### 4.2 创建 OrderHeader（头部按钮）

1. 在 `OrderItem_1` 下右键 → `UI` → `Button` → 重命名为 `OrderHeader`

2. **移除 Button 的 Image 组件**（如果不需要背景）：
   - 或者设置 `Image` 组件的 `Color` 为透明

3. **添加 `Horizontal Layout Group` 组件**：
   - `Child Alignment`: Middle Left
   - `Spacing`: 10
   - `Padding`: Left=10, Right=10, Top=5, Bottom=5

4. **创建 OrderNumberText**：
   - 在 `OrderHeader` 下找到 `Text` 子对象 → 重命名为 `OrderNumberText`
   - `Text`: "订单1"
   - `Font Size`: 20
   - `Alignment`: Left, Middle

5. **创建 ExpandIcon**：
   - 在 `OrderHeader` 下创建 `Image` → 重命名为 `ExpandIcon`
   - `Source Image`: 拖拽箭头图标（或使用 Unity 的默认箭头）
   - `Color`: 白色
   - `Rect Transform`:
     - `Width`: 20, `Height`: 20
     - `Anchor`: Right, Middle
     - `Pos X`: -10

#### 4.3 创建 OrderContent（订单内容区域）

1. 在 `OrderItem_1` 下创建 `Panel` → 重命名为 `OrderContent`

2. **添加 `Vertical Layout Group` 组件**：
   - `Spacing`: 10
   - `Padding`: Left=10, Right=10, Top=10, Bottom=10
   - `Child Control Height`: ✅ 勾选（用于订单图片）
   - `Child Control Width`: ✅ 勾选

3. **添加 `Layout Element` 组件**：
   - `Preferred Height`: 0（初始隐藏，展开时通过代码设置）

4. **初始状态**：取消勾选 `Active`（默认隐藏）

5. **创建 OrderImage**：
   - 在 `OrderContent` 下创建 `Image` → 重命名为 `OrderImage`
   - `Source Image`: 留空（通过代码设置）
   - `Color`: 白色
   - `Preserve Aspect`: ✅ 勾选
   - `Rect Transform`:
     - `Height`: 350（根据你的订单图片尺寸调整）
     - `Width`: 由 `Layout Group` 自动控制

6. **创建 StartDeliveryButton**：
   - 在 `OrderContent` 下创建 `Button` → 重命名为 `StartDeliveryButton`
   - 修改子对象 `Text` → `Text`: "开始配送"
   - `Font Size`: 18
   - `Rect Transform`:
     - `Height`: 50

7. **创建盖章图层（可选）**：
   - 在 `OrderContent` 下创建 `Image` → 重命名为 `StampOverlay`
   - **重要**：确保 `StampOverlay` 是 `OrderImage` 的**兄弟对象**（不是子对象），这样它会在 `OrderImage` 上方显示
   - `Source Image`: 拖拽盖章图片
   - `Color`: 白色（或根据需要调整透明度）
   - `Rect Transform`:
     - `Anchor`: Bottom Right（根据你的图章位置调整）
     - `Pos X`: -50, `Pos Y`: 50（根据你的图章位置调整）
     - `Width`: 150, `Height`: 150（根据你的图章大小调整）
     - **注意**：位置需要相对于 `OrderContent` 定位，确保覆盖在订单图片的右下角
   - **初始状态**：取消勾选 `Active`（默认隐藏，完成订单时显示）

### 步骤 5：复制创建其他订单项

1. 选中 `OrderItem_1` → 右键 → `Duplicate`（或按 `Ctrl+D`）
2. 重命名为 `OrderItem_2`
3. 修改 `OrderHeader/OrderNumberText` → `Text`: "订单2"
4. 重复步骤 5，创建 `OrderItem_3`、`OrderItem_4`、`OrderItem_5`

### 步骤 6：挂载脚本

#### 6.1 挂载 OrderListItem.cs

1. 为每个 `OrderItem`（`OrderItem_1` 到 `OrderItem_5`）添加 `OrderListItem` 组件

2. **配置脚本引用**（以 `OrderItem_1` 为例）：
   - `Header Button`: 拖拽 `OrderItem_1/OrderHeader` GameObject
   - `Order Content`: 拖拽 `OrderItem_1/OrderContent` GameObject
   - `Order Number Text`: 拖拽 `OrderItem_1/OrderHeader/OrderNumberText` 的 `Text` 组件
   - `Expand Icon`: 拖拽 `OrderItem_1/OrderHeader/ExpandIcon` GameObject
   - `Order Image`: 拖拽 `OrderItem_1/OrderContent/OrderImage` 的 `Image` 组件
   - `Start Delivery Button`: 拖拽 `OrderItem_1/OrderContent/StartDeliveryButton` GameObject
   - `Stamp Overlay`（可选）: 拖拽 `OrderItem_1/OrderContent/StampOverlay` GameObject（如果有）
   - `Stamp Image`（可选）: 拖拽 `OrderItem_1/OrderContent/StampOverlay` 的 `Image` 组件（如果有）
   - `Expand Duration`: 0.3（展开/收起动画时长）

3. **为 OrderItem 添加 CanvasGroup 组件**（用于滑出动画的淡出效果）：
   - 选中每个 `OrderItem` → `Add Component` → `Canvas Group`
   - `Alpha`: 1
   - `Interactable`: ✅ 勾选
   - `Blocks Raycasts`: ✅ 勾选

#### 6.2 挂载 OrderListPanel.cs

1. 选中 `OrderListPanel` GameObject → `Add Component` → `OrderListPanel`

2. **配置脚本引用**：
   - `Scroll Rect`: 拖拽 `OrderListPanel/ScrollView` 的 `ScrollRect` 组件
   - `Content Transform`: 拖拽 `OrderListPanel/ScrollView/Viewport/Content` GameObject
   - `Order Item Prefab`: 留空（如果手动创建订单项）或拖拽预制体（如果需要动态生成）
   - `Stamp Display Duration`: 1.5（盖章显示时长）

### 步骤 7：配置 OrderManager（如果还没有）

1. 在 Hierarchy 中创建 Empty GameObject → 重命名为 `OrderManager`
2. `Add Component` → `OrderManager`
3. 在 Inspector 中配置 `Order Images` 列表（添加 4-5 个订单图片）

### 步骤 8：更新 UIManager 配置

1. 找到 `UIManager` GameObject（在 `01_MainHub` 场景中）

2. 在 Inspector 的 `UIManager` 组件中：
   - **`Order List Panel`**: 拖拽 `OrderListPanel` GameObject（这是新系统）
   - **注意**：旧的 `Order Panel` 和 `Order Transition Controller` 字段应该已经清理（如果没有，可以留空）

### 步骤 9：处理订单按钮（如果存在）

如果你在主界面中还有订单按钮（`OrderButton`），可以：

**方案 A：让订单按钮显示订单列表**
- 确保 `OrderButton.cs` 脚本已挂载
- `OrderButton.OnOrderButtonClicked()` 会自动调用 `UIManager.ShowOrderPanel()`
- `UIManager.ShowOrderPanel()` 现在会显示 `OrderListPanel`（新的订单列表）

**方案 B：如果不再需要订单按钮**
- 可以删除 `OrderButton` GameObject
- 或者让订单列表默认显示（在 `OrderListPanel.Start()` 中设置）

### 步骤 10：清理旧系统（可选）

如果确定不再使用旧的订单切换系统，可以删除：

1. **场景中的 GameObject**（在 `01_MainHub` 场景中）：
   - `CurrentOrderSet` → 删除
   - `NewOrderSet` → 删除
   - `OrderTransitionController` GameObject → 删除（如果不再使用）

2. **脚本文件**（可选，如果确定不再需要）：
   - `OrderSet.cs` → 可以保留作为参考，或删除
   - `OrderTransitionController.cs` → 可以保留作为参考，或删除
   - `OrderPanel.cs` → 如果不再使用，可以删除
   - `OrderButton.cs` → 如果不再需要订单按钮，可以删除

## 四、关键配置说明

### 1. 展开高度设置

在 `OrderListItem.cs` 中，`expandedHeight` 变量控制展开后的高度：
- 默认值：400f
- 根据实际订单图片尺寸调整
- 也可以改为通过代码动态计算（根据订单图片的实际尺寸）

### 2. 滚动配置

- `ScrollRect` 会自动处理鼠标滚轮和拖拽
- 如果需要禁用某个方向的滚动，在 `Scroll Rect` 组件中取消勾选对应选项

### 3. 动画参数

- `Expand Duration`: 展开/收起动画时长（默认 0.3 秒）
- `Stamp Display Duration`: 盖章显示时长（默认 1.5 秒）
- 可以在 Inspector 中调整这些参数

## 六、常见问题

### Q1: 订单项展开后列表没有自动调整
- **解决**：确保 `Content` 有 `Content Size Fitter` 组件，且 `Vertical Fit` 设置为 `Preferred Size`
- 确保每个 `OrderItem` 的 `Vertical Layout Group` 正确配置

### Q2: 滚动不工作
- **检查**：确保 `ScrollView` 有 `ScrollRect` 组件
- **检查**：确保 `Viewport` 有 `Mask` 组件
- **检查**：确保 `Content` 的高度大于 `Viewport` 的高度

### Q3: 空格键没有反应
- **检查**：确保 `OrderListPanel` 的 `OrderListPanel` 脚本已挂载
- **检查**：确保有订单项是展开的（或至少有一个订单项存在）
- **检查**：Console 是否有错误信息

### Q4: 订单图片不显示
- **检查**：确保 `OrderImage` 的 `Image` 组件引用正确
- **检查**：确保 `OrderManager` 的订单图片列表已配置（在 Inspector 中添加订单图片）
- **检查**：`OrderListItem.Initialize()` 方法是否被正确调用（在 `OrderListPanel.InitializeOrderList()` 中）
- **检查**：Console 是否有错误信息（如 "orderImage引用为空"）

### Q5: 订单项展开后，点击其他订单项时没有自动收起
- **检查**：确保 `OrderListItem.Expand()` 方法中调用了 `OrderListPanel.OnOrderItemExpanded()`
- **检查**：确保每个 `OrderItem` 都在 `OrderListPanel` 的 `Content` 下（作为子对象）

### Q6: 空格键完成订单后，订单项没有从列表中移除
- **检查**：确保 `OrderListItem.OnOrderCompleted` 事件已订阅
- **检查**：确保 `OrderListPanel.OnOrderItemCompleted()` 方法正确执行
- **检查**：Console 是否有错误信息
