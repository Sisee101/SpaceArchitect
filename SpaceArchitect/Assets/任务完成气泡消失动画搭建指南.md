# 任务完成气泡消失动画搭建指南

本指南将帮助你在01_MainHub场景中实现任务完成功能，包括键盘输入触发任务完成和气泡消失动画。

---

## 📋 功能说明

### 实现的功能

1. ✅ **键盘输入检测**：按下键盘1-9，触发对应任务完成
2. ✅ **任务完成事件**：TaskManager管理任务状态并触发事件
3. ✅ **气泡消失动画**：对应任务的气泡播放消失动画（缩放+淡出）

### 当前实现范围

- ✅ 扩展SphereOrderInfo（添加taskId字段）
- ✅ 键盘输入触发任务完成
- ✅ 气泡消失动画
- ⏳ 胜利视频播放（后续实现）

---

## 🔧 代码修改说明

### 1. SphereOrderDataConfig.cs（已修改）

**扩展内容**：
- ✅ 添加`taskId`字段（任务ID）
- ✅ 添加`victoryVideoClip`字段（胜利视频，后续使用）
- ✅ 添加`GetOrderInfoByTaskId()`方法
- ✅ 添加`GetAllTaskOrders()`方法
- ✅ 在`ValidateData()`中添加taskId唯一性检查

**新增字段**：
```csharp
[Header("任务信息")]
public int taskId = -1;  // 任务ID

[Header("胜利视频")]
public VideoClip victoryVideoClip;  // 胜利视频
```

---

### 2. SphereIconManager.cs（已扩展）

**新增方法**：
- ✅ `HideIconForSphere(string sphereName, Action onComplete)`：根据Sphere名称隐藏图标（播放消失动画）
- ✅ `PlayHideAnimation(GameObject iconObj, Action onComplete)`：播放图标消失动画（协程）

**动画效果**：
- 缩放：从当前大小缩放到0
- 淡出：透明度从1到0
- 时长：0.5秒
- 缓动：easeOut（三次方）

---

### 3. TaskManager.cs（新建）

**功能**：
- 管理任务完成状态（运行时）
- 触发任务完成事件
- 提供任务查询方法

**关键方法**：
- `CompleteTask(int taskId)`：完成任务
- `IsTaskCompleted(int taskId)`：检查任务是否完成
- `GetSphereNameByTaskId(int taskId)`：根据任务ID获取Sphere名称

**事件**：
- `OnTaskCompleted`：任务完成事件（Action<int>）

---

### 4. TaskInputHandler.cs（新建）

**功能**：
- 检测键盘输入（1-9）
- 通过索引映射到任务
- 调用TaskManager完成任务

**键盘映射**：
- 键盘1 → 第1个任务（allTasks[0]）
- 键盘2 → 第2个任务（allTasks[1]）
- 键盘3 → 第3个任务（allTasks[2]）
- ...

**注意**：键盘映射基于任务列表的顺序，而不是taskId的值。

---

### 5. TaskCompletionHandler.cs（新建）

**功能**：
- 监听任务完成事件
- 协调气泡消失动画
- 后续可以添加视频播放

**执行流程**：
1. 接收任务完成事件
2. 根据taskId获取Sphere名称
3. 播放气泡消失动画
4. 动画完成回调（后续可添加视频播放）

## 📐 场景配置步骤

### 步骤1：配置SphereOrderDataConfig资源

1. **打开SphereOrderDataConfig资源**：
   - 在Project窗口找到 `Assets/Resources/SphereOrderDataConfig.asset`（或你保存的位置）

2. **为每个订单添加taskId**：
   - 展开订单数据列表
   - 为每个订单配置`Task ID`：
     - 订单1（Sphere (1)）：`Task ID = 0`
     - 订单2（Sphere (5)）：`Task ID = 1`
     - 订单3（Sphere (3)）：`Task ID = 2`
   - **注意**：taskId必须唯一，建议从0开始递增

3. **配置Victory Video Clip**（可选，后续使用）：
   - 导入胜利视频文件（mp4格式）
   - 为每个订单配置对应的`Victory Video Clip`

4. **验证数据**：
   - 确保所有订单的`Task ID`都已配置（>= 0）
   - 确保taskId唯一（没有重复）

---

### 步骤2：在01_MainHub场景中创建TaskManager

1. **创建GameObject**：
   - 右键 Hierarchy → **Create Empty**
   - 命名为：`TaskManager`

2. **添加脚本组件**：
   - 选中 `TaskManager`
   - 在Inspector中点击 **Add Component**
   - 搜索并添加：`Task Manager`

3. **配置引用**：
   - **Order Data Config**：拖拽 `SphereOrderDataConfig` 资源到该字段

4. **检查配置**：
   - 运行场景，检查Console是否有错误
   - 应该看到：`TaskManager: 已初始化 X 个任务`

---

### 步骤3：在01_MainHub场景中创建TaskInputHandler

1. **创建GameObject**：
   - 右键 Hierarchy → **Create Empty**
   - 命名为：`TaskInputHandler`

2. **添加脚本组件**：
   - 选中 `TaskInputHandler`
   - 在Inspector中点击 **Add Component**
   - 搜索并添加：`Task Input Handler`

3. **配置引用**：
   - **Order Data Config**：拖拽 `SphereOrderDataConfig` 资源到该字段
   - **Task Manager**：拖拽场景中的 `TaskManager` GameObject到该字段

4. **检查配置**：
   - 运行场景，检查Console是否有错误
   - 应该看到：`TaskInputHandler: 已加载 X 个任务`，以及每个任务的映射信息

---

### 步骤4：在01_MainHub场景中创建TaskCompletionHandler

1. **创建GameObject**：
   - 右键 Hierarchy → **Create Empty**
   - 命名为：`TaskCompletionHandler`

2. **添加脚本组件**：
   - 选中 `TaskCompletionHandler`
   - 在Inspector中点击 **Add Component**
   - 搜索并添加：`Task Completion Handler`

3. **配置引用**：
   - **Task Manager**：拖拽场景中的 `TaskManager` GameObject到该字段
   - **Icon Manager**：拖拽场景中的 `SphereIconManager` GameObject到该字段

4. **配置参数**：
   - **Bubble Animation Delay**：气泡动画延迟时间（秒），默认0

---

### 步骤5：确保SphereIconManager已配置

1. **检查SphereIconManager**：
   - 在场景中找到 `SphereIconManager` GameObject
   - 确保所有引用都已配置：

     - World Space Canvas
     - Order Data Config
     - Info Panel

2. **测试图标显示**：

## ⚠️ 常见问题排查

### 问题1：按键盘没有反应

**可能原因**：
- TaskInputHandler未配置或未启用
- Order Data Config未配置
- Task Manager未配置

**解决方法**：
1. 检查TaskInputHandler GameObject是否激活
2. 检查所有引用是否已配置
3. 检查Console是否有错误信息

---

### 问题2：气泡不消失

**可能原因**：
- TaskCompletionHandler未配置
- Icon Manager未配置
- Sphere名称不匹配

**解决方法**：
1. 检查TaskCompletionHandler的引用配置
2. 检查Console中的Sphere名称是否与场景中的Sphere名称完全一致（区分大小写）
3. 检查SphereIconManager中Sphere引用是否正确

---

### 问题3：taskId重复

**可能原因**：
- 在SphereOrderDataConfig中配置了重复的taskId

**解决方法**：
1. 打开SphereOrderDataConfig资源
2. 检查每个订单的Task ID是否唯一
3. 运行ValidateData()检查（如果有编辑器脚本）

---

### 问题4：键盘映射错误

**可能原因**：
- 任务列表顺序与预期不符

**解决方法**：
1. 检查Console中的任务映射信息：
   ```
   TaskInputHandler: 已加载 3 个任务
     任务 1 (键盘1): taskId=0, Sphere=Sphere (1)
     任务 2 (键盘2): taskId=1, Sphere=Sphere (5)
     任务 3 (键盘3): taskId=2, Sphere=Sphere (3)
   ```
2. 确认键盘映射是否符合预期
3. 如果需要调整，可以重新排序SphereOrderDataConfig中的订单列表
