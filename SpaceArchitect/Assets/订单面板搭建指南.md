# 订单面板搭建详细指南

## 一、准备工作

### 1. 准备图片资源
- **订单图片**：准备多张订单图片（如 `Order1.png`, `Order2.png`, `Order3.png` 等）
  - 图片应包含所有文字和内容（包括"订单"标题）
  - 建议统一尺寸（如 800x600 或 1024x768）
  - 将图片放到 `Assets/Resources/Orders/` 文件夹（如果没有则创建）
  
- **盖章图片**：准备一张盖章图片（如 `Stamp.png`）
  - 透明底图的红色圆圈 + "配送成功"文字
  - 位置应该在订单图片的右下角
  - 将图片放到 `Assets/Resources/Stamps/` 文件夹

### 2. 确保 DOTween 插件已导入
- 确认项目中已导入 DOTween 插件
- 如果没有，请先导入 DOTween

## 二、UI 结构搭建

### 步骤 1：打开主界面场景
1. 打开 `01_MainHub` 场景
2. 在 Hierarchy 中找到 `Canvas`（如果还没有，创建一个 Canvas）

### 步骤 2：创建第一个订单面板（CurrentOrderPanel）

#### 2.1 创建订单面板主容器
1. 右键点击 `Canvas` → UI → Panel → 重命名为 `CurrentOrderPanel`
2. 在 Inspector 中设置：
   - `Rect Transform`：
     - `Anchor Presets` → 按住 `Alt + Shift` → 选择 `Stretch Stretch`（全屏覆盖）
     - `Left/Right/Top/Bottom`: 0（全屏）
   - `Image` 组件：
     - `Color`: 浅紫蓝色 `(200, 220, 255, 255)` 或根据你的设计调整
     - `Raycast Target`: 可以取消勾选（如果不需要点击背景关闭）

#### 2.2 创建订单图片区域
1. 右键点击 `CurrentOrderPanel` → UI → Image → 重命名为 `OrderImageArea`
2. 在 Inspector 中设置：
   - `Rect Transform`：
     - `Anchor Presets` → `Middle Center`
     - `Width`: 800
     - `Height`: 600（根据你的订单图片尺寸调整）
   - `Image` 组件：
     - `Color`: 浅紫蓝色 `(200, 220, 255, 255)`
     - `Image Type`: `Sliced`（如果需要圆角边框）
     - 如果需要边框，添加 `Outline` 组件或使用 `Border`（如果使用 Sliced）

#### 2.3 创建订单图片（显示实际订单内容）
1. 右键点击 `OrderImageArea` → UI → Image → 重命名为 `OrderImage`
2. 在 Inspector 中设置：
   - `Rect Transform`：
     - `Anchor Presets` → `Stretch Stretch`
     - `Left/Right/Top/Bottom`: 10-20（留边距）
   - `Image` 组件：
     - `Source Image`: 暂时留空，后续通过代码设置
     - `Color`: 白色 `(255, 255, 255, 255)`
     - `Image Type`: `Simple`
     - `Preserve Aspect`: 勾选（保持图片比例）
   - **重要**：记录这个 `Image` 组件，后续需要在 `OrderPanel.cs` 脚本中引用

#### 2.4 创建盖章图层（"配送成功"图章）
1. 右键点击 `OrderImageArea` → UI → Image → 重命名为 `StampOverlay`
2. 在 Inspector 中设置：
   - `Rect Transform`：
     - `Anchor Presets` → `Bottom Right`（右下角锚点）
     - `Pos X`: -50（距离右边缘50像素，根据你的图章位置调整）
     - `Pos Y`: 50（距离下边缘50像素，根据你的图章位置调整）
     - `Width`: 150（根据你的图章图片尺寸调整）
     - `Height`: 150（根据你的图章图片尺寸调整）
   - `Image` 组件：
     - `Source Image`: 拖拽你的盖章图片（`Stamp.png`）
     - `Color`: 白色 `(255, 255, 255, 255)`（保持原色）
     - `Image Type`: `Simple`
   - 默认状态：取消勾选 `Active`（默认隐藏）
   - **重要**：记录这个 GameObject，后续需要在 `OrderPanel.cs` 脚本中引用

#### 2.5 创建按钮区域
1. 右键点击 `CurrentOrderPanel` → UI → Panel → 重命名为 `ButtonArea`
2. 在 Inspector 中设置：
   - `Rect Transform`：
     - `Anchor Presets` → `Bottom Left`
     - `Pos X`: 50
     - `Pos Y`: 50
     - `Width`: 200
     - `Height`: 120
   - `Image` 组件：可以删除或设置为透明

#### 2.6 创建"开始配送"按钮
1. 右键点击 `ButtonArea` → UI → Button → 重命名为 `StartDeliveryButton`
2. 在 Inspector 中设置：
   - `Rect Transform`：
     - `Anchor Presets` → `Top Left`
     - `Pos X`: 0
     - `Pos Y`: 0
     - `Width`: 180
     - `Height`: 50
   - `Button` 组件：
     - `Interactable`: 勾选
   - 修改子对象 `Text`：
     - `Text`: "开始配送"
     - `Font Size`: 18
     - `Alignment`: 居中对齐
     - `Color`: 白色

#### 2.7 创建"取消选择"按钮
1. 右键点击 `ButtonArea` → UI → Button → 重命名为 `CancelButton`
2. 在 Inspector 中设置：
   - `Rect Transform`：
     - `Anchor Presets` → `Bottom Left`
     - `Pos X`: 0
     - `Pos Y`: 0
     - `Width`: 180
     - `Height`: 50
   - `Button` 组件：
     - `Interactable`: 勾选
   - 修改子对象 `Text`：
     - `Text`: "取消选择"
     - `Font Size`: 18
     - `Alignment`: 居中对齐
     - `Color`: 白色

#### 2.8 添加 CanvasGroup 组件
1. 选中 `CurrentOrderPanel` GameObject
2. 在 Inspector 中点击 `Add Component` → 搜索 `Canvas Group` → 添加
3. 设置参数：
   - `Alpha`: 1
   - `Interactable`: 勾选
   - `Blocks Raycasts`: 勾选
   - `Ignore Parent Groups`: 不勾选

### 步骤 3：创建第二个订单面板（NewOrderPanel）

#### 3.1 复制订单面板
1. 选中 `CurrentOrderPanel` GameObject
2. 右键 → `Duplicate`（或按 `Ctrl+D`）
3. 重命名为 `NewOrderPanel`

#### 3.2 设置初始位置（屏幕左侧外）
1. 选中 `NewOrderPanel`
2. 在 Inspector 中设置：
   - `Rect Transform` → `Pos X`: `-2200`（或更大的负值，确保在屏幕外）
   - 或者先设置为 `0`，后续通过代码在 `Start()` 中设置

#### 3.3 设置初始状态
1. 选中 `NewOrderPanel`
2. 确保 `CanvasGroup` 的 `Alpha` 为 `0`（初始透明）
3. 确保 `StampOverlay` 是隐藏的（取消勾选 `Active`）

### 步骤 4：挂载脚本并配置引用

#### 4.1 挂载 OrderPanel.cs 脚本到两个面板
1. 选中 `CurrentOrderPanel` GameObject
2. 在 Inspector 中点击 `Add Component` → 搜索 `OrderPanel` → 添加
3. 选中 `NewOrderPanel` GameObject
4. 同样添加 `OrderPanel` 组件

#### 4.2 配置 CurrentOrderPanel 的脚本引用
1. 选中 `CurrentOrderPanel` GameObject
2. 在 Inspector 的 `OrderPanel` 组件中，配置以下引用：
   - `Go To Delivery Button`: 拖拽 `StartDeliveryButton` 按钮
   - `Cancel Button`: 拖拽 `CancelButton` 按钮
   - `Order Image`: 拖拽 `OrderImageArea/OrderImage` 的 `Image` 组件
   - `Stamp Overlay`: 拖拽 `OrderImageArea/StampOverlay` GameObject
   - `Stamp Image`（可选）: 拖拽 `OrderImageArea/StampOverlay` 的 `Image` 组件（如果需要淡入动画）
   - `Canvas Group`: 拖拽 `CurrentOrderPanel` 的 `CanvasGroup` 组件

#### 4.3 配置 NewOrderPanel 的脚本引用（同样操作）
1. 选中 `NewOrderPanel` GameObject
2. 同样配置所有引用（确保引用到 `NewOrderPanel` 的子对象，不是 `CurrentOrderPanel` 的）

## 三、创建订单管理器

### 步骤 1：创建 OrderManager GameObject
1. 在 Hierarchy 中右键 → `Create Empty` → 重命名为 `OrderManager`
2. 挂载 `OrderManager.cs` 脚本：
   - 选中 `OrderManager` GameObject
   - 在 Inspector 中点击 `Add Component` → 搜索 `OrderManager` → 添加

### 步骤 2：配置订单图片列表
1. 选中 `OrderManager` GameObject
2. 在 Inspector 的 `OrderManager` 组件中：
   - 找到 `Order Images` 字段（这是一个列表）
   - 点击 `+` 添加元素
   - 根据你准备的订单图片数量，添加对应数量的元素
   - 将订单图片从 Project 窗口拖拽到对应的列表元素中
   - 例如：
     - `Element 0`: 拖拽 `Order1.png`
     - `Element 1`: 拖拽 `Order2.png`
     - `Element 2`: 拖拽 `Order3.png`
     - ... 添加更多订单图片

## 四、创建订单切换控制器

### 步骤 1：创建 OrderTransitionController GameObject
1. 在 Hierarchy 中右键 → `Create Empty` → 重命名为 `OrderTransitionController`
2. 挂载 `OrderTransitionController.cs` 脚本：
   - 选中 `OrderTransitionController` GameObject
   - 在 Inspector 中点击 `Add Component` → 搜索 `OrderTransitionController` → 添加

### 步骤 2：配置订单切换控制器引用
1. 选中 `OrderTransitionController` GameObject
2. 在 Inspector 的 `OrderTransitionController` 组件中，配置以下引用：
   - `Current Order Panel`: 拖拽 `CurrentOrderPanel` GameObject
   - `New Order Panel`: 拖拽 `NewOrderPanel` GameObject
   - `Stamp Display Duration`: 设置为 `1.5`（盖章显示时间，秒）
   - `Transition Duration`: 设置为 `0.6`（切换动画时长，秒）
   - `Transition Delay`: 设置为 `0.1`（新订单移入延迟，秒）

---

## 五、配置主界面控制器

### 步骤 1：找到 MainHubController
1. 在 Hierarchy 中找到 `MainHubController` GameObject（或创建它，如果还没有）
2. 确保已挂载 `MainHubController.cs` 脚本

### 步骤 2：配置订单切换控制器引用
1. 选中 `MainHubController` GameObject
2. 在 Inspector 的 `MainHubController` 组件中：
   - 找到 `Order Transition Controller` 字段
   - 拖拽 `OrderTransitionController` GameObject 到该字段

## 六、初始化第一个订单

**注意**：`OrderTransitionController.cs` 脚本已经包含了自动初始化第一个订单的逻辑（在 `Start()` 方法中的 `InitializeFirstOrder()` 方法），所以**你不需要手动添加代码**。

但是，你需要确保：
1. `OrderManager` 已正确配置订单图片列表（见步骤三）
2. `OrderTransitionController` 的 `Current Order Panel` 引用已正确配置（见步骤四）
3. 第一个订单面板（`CurrentOrderPanel`）在场景加载时是激活的（默认显示）

如果第一个订单仍然没有显示，请检查：
- Console 是否有错误信息
- `OrderManager` 中是否添加了订单图片
- `OrderTransitionController` 的引用配置是否正确

## 八、常见问题排查

### 问题 1：按下空格键没有反应
- **检查**：`MainHubController` 中是否已配置 `Order Transition Controller` 引用
- **检查**：Console 是否有错误信息
- **检查**：`OrderManager` 是否已初始化订单列表

### 问题 2：订单图片不显示
- **检查**：`OrderPanel` 脚本中 `Order Image` 引用是否正确
- **检查**：`OrderManager` 中是否已添加订单图片到列表
- **检查**：第一个订单是否在 `Start()` 或初始化方法中被正确设置

### 问题 3：盖章不显示
- **检查**：`OrderPanel` 脚本中 `Stamp Overlay` 引用是否正确
- **检查**：盖章图片是否正确导入
- **检查**：盖章 GameObject 的位置是否正确（右下角）

### 问题 4：动画不流畅或没有动画
- **检查**：DOTween 插件是否正确导入
- **检查**：Console 是否有 DOTween 相关的错误
- **检查**：`OrderTransitionController` 中的动画参数设置是否正确

### 问题 5：切换后订单不更新
- **检查**：`OrderTransitionController` 中的 `Current Order Panel` 和 `New Order Panel` 引用是否正确
- **检查**：`OrderManager` 是否正确返回下一个订单
- **检查**：Console 是否有相关错误信息

## 九、UI 层级结构参考

```
Canvas (主界面)
├── MainHubPanel (主界面面板)
│   └── OrderButton (订单按钮 - 右上角，已存在)
│
├── CurrentOrderPanel (当前订单面板 - 新建)
│   ├── OrderImageArea (订单图片区域)
│   │   ├── OrderImage (订单图片)
│   │   └── StampOverlay (盖章图层 - 默认隐藏)
│   └── ButtonArea (按钮区域)
│       ├── StartDeliveryButton ("开始配送" 按钮)
│       └── CancelButton ("取消选择" 按钮)
│
└── NewOrderPanel (新订单面板 - 新建，初始在屏幕左侧外)
    ├── OrderImageArea (订单图片区域)
    │   ├── OrderImage (订单图片)
    │   └── StampOverlay (盖章图层 - 默认隐藏)
    └── ButtonArea (按钮区域)
        ├── StartDeliveryButton ("开始配送" 按钮)
        └── CancelButton ("取消选择" 按钮)
```
