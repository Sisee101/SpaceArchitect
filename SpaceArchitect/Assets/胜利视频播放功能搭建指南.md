# 胜利视频播放功能搭建指南

本指南将帮助你在01_MainHub场景中实现胜利视频播放功能，包括视频播放UI搭建和脚本配置。

---

## 📋 功能说明

### 实现的功能

1. ✅ **胜利视频播放**：任务完成时播放对应的胜利结算视频
2. ✅ **视频自动隐藏**：视频播放完成后自动隐藏
3. ✅ **执行顺序**：按下键盘 → 播放胜利视频 → 视频播放完成 → 气泡消失动画

### 执行流程

```
按下键盘1
    ↓
TaskInputHandler检测到输入
    ↓
TaskManager.CompleteTask(taskId)
    ↓
触发OnTaskCompleted事件
    ↓
TaskCompletionHandler接收事件
    ↓
根据taskId获取订单信息（包含victoryVideoClip）
    ↓
VictoryVideoPlayer播放视频
    ↓
视频播放完成
    ↓
延迟（可选）
    ↓
SphereIconManager播放气泡消失动画
```

## 📐 场景配置步骤

### 步骤1：准备视频资源

1. **导入视频文件**：
   - 将胜利视频文件（.mp4格式）导入到Unity项目
   - 建议放在 `Assets/Resources/Videos/` 或 `Assets/Videos/` 目录

2. **配置视频导入设置**：
   - 选中视频文件，在Inspector中检查导入设置
   - **注意**：确保视频格式兼容（Unity支持mp4, mov, avi等）

---

### 步骤2：创建RenderTexture

1. **创建RenderTexture资源**：
   - 在Project窗口中右键 → **Create → Render Texture**
   - 命名为：`VictoryVideoRenderTexture`

2. **配置RenderTexture**：
   - 选中创建的RenderTexture
   - 在Inspector中设置：
     - **Size**: `1920 x 1080`（或根据视频分辨率调整）
     - **Color Format**: `R8G8B8A8_UNORM`（8位RGBA格式，适合视频播放）
     - **Depth Buffer**: `None` 或 `0`（视频不需要深度缓冲，选择最接近"无深度"的选项）
     - **Anti-aliasing**: `None`（可选）

---

### 步骤3：在01_MainHub场景中创建视频播放UI

#### 3.1 创建视频面板

1. **找到Canvas**：
   - 在Hierarchy中找到主Canvas（Screen Space - Overlay）

2. **创建视频面板GameObject**：
   - 右键 Canvas → **UI → Panel**
   - 命名为：`VictoryVideoPanel`

3. **配置Panel**：
   - 选中 `VictoryVideoPanel`
   - 在Inspector中设置：
     - **RectTransform**：
       - **Anchors**: `Stretch Stretch`（全屏）
       - **Left/Right/Top/Bottom**: `0`（全屏覆盖）
     - **Image组件**：
       - **Color**: `(0, 0, 0, 255)`（黑色背景，可选）
       - 或者禁用Image组件（透明背景）

4. **初始隐藏**：
   - 取消勾选 `VictoryVideoPanel` 的 **Active** 复选框（初始隐藏）

---

#### 3.2 创建RawImage（显示视频）

1. **创建RawImage**：
   - 右键 `VictoryVideoPanel` → **UI → Raw Image**
   - 命名为：`VideoDisplay`

2. **配置RawImage**：
   - 选中 `VideoDisplay`
   - 在Inspector中设置：
     - **RectTransform**：
       - **Anchors**: `Middle Center`（居中）
       - **Width**: `1920`（或根据视频宽高比调整）
       - **Height**: `1080`（或根据视频宽高比调整）
       - **Pos X/Y**: `0`（居中）
     - **Raw Image组件**：
       - **Texture**: `[留空，脚本会自动设置]`
       - **Color**: `(255, 255, 255, 255)`（白色，确保视频正常显示）

---

#### 3.3 创建VideoPlayer GameObject

1. **创建GameObject**：
   - 右键 `VictoryVideoPanel` → **Create Empty**
   - 命名为：`VideoPlayer`

2. **添加VideoPlayer组件**：
   - 选中 `VideoPlayer`
   - 在Inspector中点击 **Add Component**
   - 搜索并添加：`Video Player`

3. **配置VideoPlayer组件**：
   - **Source**: `Video Clip`（使用视频剪辑）
   - **Video Clip**: `[留空，脚本会自动设置]`
   - **Render Mode**: `Render Texture`（渲染到纹理）
   - **Target Texture**: 拖拽 `VictoryVideoRenderTexture` 到该字段
   - **Play On Awake**: `取消勾选`（不自动播放）
   - **Loop**: `取消勾选`（不循环播放）
   - **Skip On Drop**: `勾选`（性能优化）

---

### 步骤4：配置SphereOrderDataConfig资源

1. **打开SphereOrderDataConfig资源**：
   - 在Project窗口找到资源文件

2. **为每个订单配置Victory Video Clip**：
   - 展开订单数据列表
   - 为每个订单配置`Victory Video Clip`：
     - 拖拽对应的视频文件到该字段
   - **注意**：确保视频文件已正确导入

---

### 步骤5：在01_MainHub场景中创建VictoryVideoPlayer GameObject

1. **创建GameObject**：
   - 右键 Hierarchy → **Create Empty**
   - 命名为：`VictoryVideoPlayer`

2. **添加脚本组件**：
   - 选中 `VictoryVideoPlayer`
   - 在Inspector中点击 **Add Component**
   - 搜索并添加：`Victory Video Player`

3. **配置引用**：
   - **Video Player**：拖拽场景中的 `VideoPlayer` GameObject到该字段
   - **Video Display**：拖拽场景中的 `VideoDisplay` RawImage到该字段
   - **Render Texture**：拖拽 `VictoryVideoRenderTexture` 资源到该字段
   - **Video Panel**：拖拽场景中的 `VictoryVideoPanel` GameObject到该字段

4. **配置参数**：
   - **Hide Delay After Video**：视频播放完成后隐藏的延迟时间（秒），默认0.5

---

### 步骤6：更新TaskCompletionHandler配置

1. **找到TaskCompletionHandler GameObject**：
   - 在场景中找到之前创建的 `TaskCompletionHandler`

2. **添加引用**：
   - **Video Player**：拖拽场景中的 `VictoryVideoPlayer` GameObject到该字段
   - **Order Data Config**：拖拽 `SphereOrderDataConfig` 资源到该字段

3. **检查配置**：
   - 确保所有引用都已配置：
     - Task Manager ✓
     - Icon Manager ✓
     - Video Player ✓（新增）
     - Order Data Config ✓（新增）

## ⚠️ 常见问题排查

### 问题1：视频不播放

**可能原因**：
- VideoPlayer未配置
- RenderTexture未配置
- VideoClip未配置
- VideoPlayer的Target Texture未设置

**解决方法**：
1. 检查VictoryVideoPlayer的所有引用是否已配置
2. 检查VideoPlayer组件的Target Texture是否已设置
3. 检查SphereOrderDataConfig中是否已配置Victory Video Clip
4. 检查Console是否有错误信息

---

### 问题2：视频显示为黑色或空白

**可能原因**：
- RenderTexture未正确设置到RawImage
- RawImage的Texture未设置
- 视频文件格式不支持
- 视频分辨率与RenderTexture不匹配

**解决方法**：
1. 检查RawImage的Texture是否已设置（脚本会自动设置）
2. 检查RenderTexture的分辨率是否与视频匹配
3. 检查视频文件是否正确导入（在Project窗口中选中视频，查看Inspector）
4. 尝试重新导入视频文件

---

### 问题3：视频播放后不消失

**可能原因**：
- VideoPlayer的Loop选项被勾选
- 视频播放完成事件未触发
- HideVideoAfterDelay协程未执行

**解决方法**：
1. 检查VideoPlayer组件的Loop选项是否已取消勾选
2. 检查Console是否有视频播放完成的日志
3. 检查VictoryVideoPlayer的Hide Delay After Video参数

---

### 问题4：视频播放后气泡不消失

**可能原因**：
- TaskCompletionHandler的引用未配置
- 视频播放完成事件未触发
- HandleTaskCompletionSequence协程未执行

**解决方法**：
1. 检查TaskCompletionHandler的所有引用是否已配置
2. 检查Console是否有相关日志
3. 检查视频播放完成事件是否正常触发

---

### 问题5：视频播放卡顿或延迟

**可能原因**：
- 视频文件过大
- 视频分辨率过高
- RenderTexture分辨率过高
- 视频编码格式不兼容

**解决方法**：
1. 降低视频分辨率（建议1920x1080或更低）
2. 降低RenderTexture分辨率
3. 使用H.264编码的mp4格式
4. 检查视频文件的导入设置（Compression等）
