# 菜单高亮跟随效果搭建指南

## 一、功能说明

实现菜单按钮**鼠标悬停**时，底部高亮色块平滑移动到对应按钮下方的效果。

**注意**：现在高亮移动由鼠标悬停触发，而不是点击触发。点击按钮仍然会执行原有的功能（如跳转场景等）。

## 二、UI 结构要求

```
MainMenuCanvas
└── MainMenuPanel
    └── ButtonsContainer (必须有 Vertical Layout Group)
        ├── StartGameButton (Button)
        ├── PlanetEncyclopediaButton (Button)
        ├── SettingsButton (Button - 如果有)
        └── QuitButton (Button)
        └── HighlightBlock (Image - 高亮色块，需要在按钮下方)
```

**重要提示**：高亮色块 `HighlightBlock` 应该在 `ButtonsContainer` 下，作为按钮的兄弟对象，但要在 Hierarchy 中放在按钮之后（这样会在渲染时显示在按钮下方）。

## 三、Unity 编辑器操作步骤

### 步骤 1：确保高亮色块已创建

1. 在 `ButtonsContainer` 下找到或创建 `HighlightBlock` GameObject
   - 如果没有，右键点击 `ButtonsContainer` → `UI` → `Image` → 重命名为 `HighlightBlock`

2. **设置高亮色块的基础属性**：
   - 选中 `HighlightBlock`
   - **Rect Transform**：
     - `Anchor`: 设置为与按钮相同的锚点（通常为 Left, Middle 或 Center, Middle）
     - `Width`: 与按钮宽度一致（或略宽）
     - `Height`: 根据设计需求设置（如 30-50）
     - `Pos Y`: 初始位置应对齐到 `StartGameButton` 的 Y 坐标
   
3. **设置高亮色块的外观**：
   - `Image` 组件：
     - `Color`: 设置为紫色（或其他你想要的背景色）
     - `Source Image`: 可以留空（使用纯色），或使用带圆角的 Sprite
   
4. **调整渲染顺序**：
   - 在 Hierarchy 中，确保 `HighlightBlock` 在所有按钮**之后**（这样会渲染在按钮下方）
   - 或者调整 `Canvas Sort Order` 确保高亮块在按钮文字下方

### 步骤 2：挂载 MenuHighlightController 脚本

1. 选中 `ButtonsContainer` GameObject（或 `MainMenuPanel`，取决于你的结构）
   - **推荐**：将脚本挂载到 `ButtonsContainer` 上，因为这样可以更好地管理按钮和高亮块的关系

2. `Add Component` → 搜索 `Menu Highlight Controller` → 添加组件

3. **配置脚本引用**（在 Inspector 中）：
   
   **高亮色块引用**：
   - `Highlight Block`: 拖拽 `ButtonsContainer/HighlightBlock` 的 `RectTransform` 组件
   
   **菜单按钮列表**：
   - `Menu Buttons` (Size): 设置为 4（根据实际按钮数量，如果只有3个按钮就设置为3）
   - `Element 0`: 拖拽 `ButtonsContainer/StartGameButton` 的 `RectTransform` 组件
   - `Element 1`: 拖拽 `ButtonsContainer/PlanetEncyclopediaButton` 的 `RectTransform` 组件
   - `Element 2`: 拖拽 `ButtonsContainer/SettingsButton` 的 `RectTransform` 组件（如果有）
   - `Element 3`: 拖拽 `ButtonsContainer/QuitButton` 的 `RectTransform` 组件
   
   **动画参数**（可选调整）：
   - `Move Duration`: 0.3（移动动画时长，秒）
   - `Move Ease`: OutQuad（缓动曲线，可选择其他如 InOutQuad, OutCubic 等）
   - `Highlight Offset`: (0, 0)（高亮块相对按钮的偏移量，通常保持为0即可）

### 步骤 3：配置 MainMenuPanel 脚本

1. 找到 `MainMenuPanel` GameObject（应该在 `MainMenuCanvas` 下）

2. 在 Inspector 中找到 `Main Menu Panel` 组件

3. **配置高亮控制器引用**：
   - `Highlight Controller`: 拖拽刚才挂载了 `MenuHighlightController` 的 GameObject（`ButtonsContainer`）

**重要**：代码会自动为每个按钮添加 `EventTrigger` 组件来处理鼠标悬停事件，无需手动配置。脚本会在 `Start()` 时自动为所有按钮设置悬停高亮效果。

### 步骤 4：确保场景中有 EventSystem

**重要**：Unity UI 的鼠标事件需要 `EventSystem` GameObject 才能工作。

1. 在 Hierarchy 中检查是否有 `EventSystem` GameObject
2. 如果没有，Unity 会自动在第一次创建 UI 时创建，或者手动创建：
   - 右键点击 Hierarchy → `UI` → `Event System`
   - 这通常是自动创建的，不需要手动操作

### 步骤 5：检查按钮顺序

确保按钮在 `MenuHighlightController` 的 `Menu Buttons` 数组中的顺序与实际显示顺序一致：

- **索引 0**: `StartGameButton` ("开始游戏")
- **索引 1**: `PlanetEncyclopediaButton` ("行星图鉴")
- **索引 2**: `SettingsButton` ("设置") - 如果有
- **索引 3**: `QuitButton` ("退出游戏")

**注意**：如果某个按钮不存在（如 `SettingsButton`），在 `Menu Buttons` 数组中该索引位置可以留空，但需要在 `MainMenuPanel.cs` 中调整对应的按钮索引。

### 步骤 6：调整高亮色块初始位置

1. **运行游戏**，进入主菜单场景

2. 在 Game 视图中，观察高亮色块的位置

3. **如果不正确**：
   - 停止游戏
   - 选中 `HighlightBlock`
   - 手动调整 `Rect Transform` 的 `Pos Y`，使其对齐到 `StartGameButton` 的位置
   - 或者使用代码自动对齐（脚本会在 `Start()` 时自动对齐到第一个按钮）

## 四、代码说明

### MenuHighlightController.cs

**核心方法**：
- `MoveToButton(int buttonIndex)`: 移动到指定索引的按钮（带动画）
- `MoveToButton(RectTransform targetButton)`: 移动到指定按钮引用（带动画）
- `MoveToButtonInstant(int buttonIndex)`: 立即移动到指定按钮（无动画）
- `InitializeHighlightPosition()`: 初始化高亮位置（在 `Start()` 时自动调用）

### MainMenuPanel.cs

**修改内容**：
- 添加了 `highlightController` 字段引用
- 添加了 `using UnityEngine.EventSystems;` 引用（用于 EventTrigger）
- 在 `Start()` 中为每个按钮调用 `SetupButtonHoverHighlight()` 方法
- `SetupButtonHoverHighlight()` 方法会为每个按钮自动添加或获取 `EventTrigger` 组件
- 为每个按钮添加 `PointerEnter` 事件监听（鼠标进入时触发）
- `OnButtonHovered()` 方法处理鼠标悬停事件，调用 `MenuHighlightController.MoveToButton()`

**工作流程**：
1. 鼠标移动到按钮上 → `EventTrigger` 触发 `PointerEnter` 事件
2. 调用 `OnButtonHovered()` → 传递按钮的 `RectTransform`
3. 调用 `MenuHighlightController.MoveToButton()` → 高亮块移动到目标按钮位置

## 五、常见问题

### Q1: 高亮色块没有移动到正确位置

**解决**：
- 检查 `MenuHighlightController` 的 `Menu Buttons` 数组是否正确配置
- 检查按钮在数组中的顺序是否与实际显示顺序一致
- 检查 `Highlight Offset` 是否需要调整（通常保持为 0, 0）

### Q2: 高亮色块位置正确但宽度不对

**解决**：
- 脚本会自动调整宽度与目标按钮一致
- 如果宽度不对，检查目标按钮的 `RectTransform` 的 `Size Delta` 是否正确
- 确保 `HighlightBlock` 的 `Anchor` 设置与按钮一致

### Q3: 高亮色块显示在按钮文字上方

**解决**：
- 在 Hierarchy 中，将 `HighlightBlock` 移到所有按钮**之后**
- 或者调整 `Canvas Sort Order`，确保高亮块的排序值小于按钮文字
- Unity UI 的渲染顺序是：后创建的元素渲染在上方，但可以通过调整 Hierarchy 顺序改变

### Q4: 动画不够流畅

**解决**：
- 调整 `Move Duration`（建议 0.2-0.4 秒）
- 更换 `Move Ease` 缓动曲线（如 `OutCubic`, `InOutQuad` 等）

### Q5: 鼠标悬停后高亮没有移动

**解决**：
- 检查 `MainMenuPanel` 的 `Highlight Controller` 引用是否已配置
- 检查 Console 是否有错误信息
- 确保 `MenuHighlightController` 脚本已正确挂载到 GameObject 上
- 检查按钮 GameObject 是否有 `EventTrigger` 组件（脚本会自动添加，如果没有可能是因为代码未执行）
- 确保场景中有 `EventSystem` GameObject（Unity UI 需要它来处理鼠标事件）
- 检查按钮的 `Raycast Target` 是否启用（在 `Image` 或 `Button` 组件中，应该勾选 `Raycast Target`）

### Q6: 如果某个按钮不存在（如 SettingsButton）

**解决**：
- 在 `MenuHighlightController` 的 `Menu Buttons` 数组中，该索引位置可以留空（设置为 None）
- 但需要在 `MainMenuPanel.cs` 中调整按钮索引，确保索引连续：
  ```csharp
  // 例如，如果没有 SettingsButton，索引应该是：
  // 0 = StartGameButton
  // 1 = PlanetEncyclopediaButton
  // 2 = QuitButton（索引从2开始，而不是3）
  ```

## 六、测试步骤

1. **运行游戏**，进入 `00_MainMenu` 场景
2. **初始状态检查**：
   - 高亮色块应该显示在 `StartGameButton` 下方
3. **测试鼠标悬停切换**：
   - **将鼠标移动到** `PlanetEncyclopediaButton` → 高亮块应该平滑移动到该按钮下方
   - **将鼠标移动到** `QuitButton` → 高亮块应该移动到该按钮下方
   - **将鼠标移动到** `StartGameButton` → 高亮块应该移回第一个按钮
4. **测试动画效果**：
   - 观察移动动画是否流畅
   - 检查高亮块的宽度是否正确跟随按钮宽度
   - 快速移动鼠标到不同按钮，观察高亮块的跟随效果
5. **测试按钮点击功能**：
   - 点击按钮仍然应该执行原有功能（如跳转场景、打开面板等）

## 七、高级配置（可选）

### 1. 添加悬停效果（鼠标悬停时显示高亮）

可以在 `MenuHighlightController` 中添加 `OnPointerEnter` 和 `OnPointerExit` 事件，但这需要额外的代码修改。

### 2. 调整高亮块的样式

- 添加圆角：使用带圆角的 Sprite 作为 `Source Image`
- 添加阴影：添加 `Shadow` 或 `Outline` 组件
- 添加渐变：使用 `Gradient` 或其他 UI 效果

### 3. 使用键盘导航

可以添加键盘上下箭头键切换菜单项的功能，并自动触发高亮移动。

按照以上步骤完成搭建后，你的菜单高亮跟随效果就可以正常工作了！
